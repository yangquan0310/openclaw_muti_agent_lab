## 记忆（Memory）

### 文章 1：WorldEvolver——自演化世界模型，集成情景记忆与语义记忆
- **标题**：Self-Evolving World Models for LLM Agent Planning
- **作者**：Xuan Zhang, Wenxuan Zhang, See-Kiong Ng, Yang Deng
- **时间**：2026-06-29（arXiv 公告 2026-06-30）
- **主要内容**：提出 WorldEvolver 框架，在保持下游智能体和模型参数冻结的前提下，通过 (i) 情景记忆（基于真实动作转移的检索式仿真）、(ii) 语义记忆（从预测-观察错配中提取持久启发式规则）、(iii) 选择性前瞻（过滤低置信预测后再注入智能体推理上下文）三大模块在测试时修订部署上下文；在 ALFWorld / ScienceWorld / Word2World / AgentBoard 上同时取得最高预测精度和下游智能体成功率，证明测试时记忆修订可同时提升预测保真度与规划性能。
- **链接**：https://arxiv.org/abs/2606.30639

### 文章 2：DuoMem——双空间蒸馏构建可部署在设备上的记忆智能体
- **标题**：DuoMem: Towards Capable On-Device Memory Agents via Dual-Space Distillation
- **作者**：Peyman Hosseini, Ondrej Bohdal, Ahmed Alajrami, Andrea Maracani, Ignacio Castro, Matthew Purver, Mete Ozay, Savas Ozkan, Taha Ceritli
- **时间**：2026-06-29
- **主要内容**：针对 LLM 智能体依赖大模型与长上下文难以在资源受限设备上部署的问题，提出"上下文空间蒸馏 + 参数空间蒸馏"双空间框架，把程序性问题求解能力从 72B 教师蒸馏到 4B 学生；在 ALFWorld 任务上将 4B 模型成功率从 4.3% 提升到 77.9%，逼近 72B 教师（87.1%），仅增加 <10M 可训练参数与几 MB 预计算教师记忆，且推理速度较教师快 3× 以上，可实时部署在边缘设备。
- **链接**：https://arxiv.org/abs/2606.29961

### 文章 3：EVAF——选择性参数化巩固的测试-再测试协议
- **标题**：EVAF: A Test-Retest Protocol for Selective Parametric Consolidation
- **作者**：Haoliang Han
- **时间**：2026-06-29
- **主要内容**：针对长程语言智能体在上下文窗口消失后"哪些经验应被持久化"的问题，提出 Echo-Valence Attractor Field（EVAF）门控 LoRA 巩固机制与配套的"测试-再测试"协议；在 GPT-2 与 TinyLlama 上，EVAF 优先巩固高价值、高惊讶度的经验，并通过路由互补的记忆通道保持检索可达的事实记忆；实验显示比冻结基线、纯检索基线、非门控持续更新基线在干扰后具有更强的行为持久性，且参数漂移与跨人设污染更低；为"记忆访问"与"记忆深度"是两种独立计算操作这一论断提供证据。
- **链接**：https://arxiv.org/abs/2606.29916

### 文章 4：Mandol——长期对话智能体的凝聚式记忆系统
- **标题**：Mandol: An Agglomerative Agent Memory System for Long-Term Conversations
- **作者**：Yuhan Zhang, Zhiyuan Guo, Ziheng Zeng, Wei Wang, Wentao Wu, Lijie Xu
- **时间**：2026-06-29
- **主要内容**：针对长期对话智能体跨会话、多类型、复杂关联记忆的查询需求，提出 Mandol 凝聚式记忆架构：(1) 分层记忆模型——基础层表示原始记忆，高层抽象层将基础记忆凝聚为可追溯的抽象记忆，统一以结构化语义图表示；(2) SemanticMap+SemanticGraph 凝聚式语义数据结构——原生融合 KV、向量、图三种结构，消除跨数据库 I/O；(3) 无 LLM 参与的定量查询机制——查询自适应路由、定量去噪、冲突解决与 token 受限上下文生成；在 LoCoMo 与 LongMemEval 上取得最佳整体准确率，并实现 5.4× 检索加速与 4.8× 插入加速（10 QPS 并发负载下）。
- **链接**：https://arxiv.org/abs/2606.29778

## 决策与推理（Decision-Making & Reasoning）

### 文章 5：不确定性感知生成与模糊性下的决策算法
- **标题**：Uncertainty-Aware Generation and Decision-Making Under Ambiguity
- **作者**：Nico Daheim, Iryna Gurevych
- **时间**：2026-06-29
- **主要内容**：把贝叶斯决策理论与风险规避决策方法引入 LLM 决策算法，在辅导与自动同行评审两个任务上，对辅导策略与评审分数的不确定性进行建模，并用 conformal prediction 给出策略与分数的覆盖保证；经验上不确定性感知决策能提高生成效用，但需谨慎实现——风险规避规则在歧义高时会因优化"通用"输出而退化，贝叶斯方法总体更稳健；为决策理论改进 LLM 决策提出明确开放挑战。
- **链接**：https://arxiv.org/abs/2606.30578

### 文章 6：NeuReasoner——理论驱动的推理能力边界探测
- **标题**：NeuReasoner: Theory-grounded Mapping of Reasoning Elicitation Boundaries
- **作者**：Aydin Javadov, Shyngys Aitkazinov, Tobias Hoesli, Florian von Wangenheim, Bjoern Schuller, Joseph Ollier
- **时间**：2026-06-29
- **主要内容**：构建理论驱动的推理能力 elicitation 工具 NeuReasoner，由"神经透镜（受功能特异性启发）+ 认知透镜（取自 Erotetic 推理理论）"经单模型内部模块化整合；用认知心理学行为任务套件 CogBench 与标准数学/编程基准联合评估，发现 LLM 推理能力主要在 post-training 中被"放大"而非"引入"——elicitation 在算术推理、代码生成、贝叶斯推理、奖励学习上可匹配甚至超过思维模式基线，但在**风险决策与不确定性下决策**任务上仅靠 elicitation 难以恢复，且模型规模与 elicitation 之间存在双向交互；首次系统绘制"推理 elicitation 何时成功、何时失败"的边界图谱。
- **链接**：https://arxiv.org/abs/2606.29971

## 认知建模与可解释性（Cognitive Modeling & Interpretability）

### 文章 8：后置概念瓶颈模型的忠实性失效分析
- **标题**：On the Faithfulness of Post-Hoc Concept Bottleneck Models
- **作者**：Laines Schmalwasser, Jan Blunk, Niklas Penzel, Julia Niebling, Joachim Denzler
- **时间**：2026-06-29（ECCV 2026 接收）
- **主要内容**：把人类通过高级概念（"鸟的腹部颜色"）理解世界这一认知建模思想与可解释 AI 桥接，分析后置概念瓶颈模型（CBM）在目标预测准确率之外的"概念忠实性"：发现两类失效——辅助数据协变量偏移导致的概念表示不忠实，并给出上界；VLM 代理概念标签的系统性噪声导致的第二种不忠实；提出将"概念忠实性"与"预测准确率"解耦的新指标；实证显示标准基于准确率的评估无法识别这些不忠实行为。
- **链接**：https://arxiv.org/abs/2606.30498

### 文章 9：CRISTAL——神经符号分析，从 AI 合成的世界模型出发
- **标题**：The CRISTAL Method: Neurosymbolic analysis from AI-synthesized world models
- **作者**：Rafael Kaufmann, Felix Neubürger, Michael Walters, Thomas Kopinski, Dimitrije Marković
- **时间**：2026-06-29
- **主要内容**：把人类分析师在投资分析等领域因认知偏差而表现受限的现象作为切入点，提出 CRISTAL（Coherent Reliable Intentional Synthesis of Truthful Analysis Logic）神经符号框架——从自然语言先验知识课程出发，构造可解释、动态的概率程序，支持全贝叶斯推理（含不确定性量化与预算感知数据获取），并用 LLM 进行代码合成与学习持续精化世界模型；在合成股票基准的公司分类任务上，仅 5 个样本 + 5 秒预算即达到贝叶斯最优准确率，显著超越 SOTA LLM（约 40% 且需多一个数量级数据/算力）。
- **链接**：https://arxiv.org/abs/2606.29799

### 文章 10：LLM 代码漏洞检测中的认知启发式偏差
- **标题**：Words Speak Louder Than Code: Investigating Cognitive Heuristics in LLM-Based Code Vulnerability Detection
- **作者**：Asif Shahriar, Hongyu Cai, Hadjer Benkraouda, Gang Wang, Z. Berkay Celik
- **时间**：2026-06-29
- **主要内容**：首次系统探索 LLM 在代码漏洞检测中是否受到与人类相同的认知启发式偏差——通过控制代码不变、仅改变周围上下文以触发光环效应（作者署名）、框架效应（任务目标/后果）、锚定效应（先前分析结果），评估 8 个 LLM × 3 种编程语言；跨模型平均敏感性：框架效应 33.2% > 锚定 23.5% > 光环 18.4%；语义推理类的漏洞比模式匹配类更易受影响；并提出概念验证黑盒认知攻击，可压制多达 97% 已检出漏洞。
- **链接**：https://arxiv.org/abs/2606.30587
