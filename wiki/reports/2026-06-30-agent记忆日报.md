## 摘要

本期日报覆盖 arXiv 平台上 2026-06-23 至 2026-06-26 发布的 LLM/Agent 记忆机制相关论文（共 18 篇核心论文）。重点聚焦长期记忆、记忆系统评估、记忆安全、记忆架构四大方向。本批次论文呈现三大趋势：(1) 从单一记忆组件转向"全栈记忆系统"评估；(2) 记忆安全（投毒、隐私、治理）成为新焦点；(3) 多模态视觉记忆与机器人时空记忆开始规模化涌现。

## 主题一：长期记忆系统评估与基准

### 文章 1：DMV-Bench
- **标题**：DMV-Bench: Diagnosing Long-Horizon Multimodal Agents' Visual Memory with Incidental Cue Injection
- **作者**：Yujin Tang, Chenming Shang, Ruize Xu 等
- **时间**：2026-06-25
- **主要内容**：提出首个多模态 Agent 视觉记忆交互式基准，基于 1000 件家居电商商品目录构建文本泄漏约束的像素级信号，引入 DualMem 双编码（视觉+言语）架构。在 Gemini 2.5 Flash 和 Qwen2.5-VL-7B 上全面优于字幕基线和 3 个最新多模态记忆系统。

### 文章 2：MEMPROBE
- **标题**：MEMPROBE: Probing Long-Term Agent Memory via Hidden User-State Recovery
- **作者**：Enze Ma, Yufan Zhou, Wei-Chieh Huang 等
- **时间**：2026-06-23
- **主要内容**：将长期记忆评估重构为"可审计的后交互工件"——基于隐藏用户状态库的恢复任务。包含 50 个模拟用户、31 个隐藏维度（共 1550 个恢复目标）。发现"任务完成成功"与"记忆可恢复"是两种独立能力：任务完成率近饱和，但类别平衡恢复率仅约 0.6，且在 top-k 检索下进一步下降。

### 文章 3：Are We Ready For An Agent-Native Memory System?
- **标题**：Are We Ready For An Agent-Native Memory System?
- **作者**：Wei Zhou, Xuanhe Zhou, Shaokun Han 等
- **时间**：2026-06-23
- **主要内容**：从数据管理视角系统评估 12 个代表性记忆系统与 2 个基线，覆盖 5 个基准工作负载（11 个数据集）。提出四模块分析框架（表征存储、抽取、检索路由、维护）。发现无单一架构全场景主导，效果高度依赖记忆结构与工作负载瓶颈的匹配度；局部维护比全局重组更具成本效益。

## 主题二：记忆可靠性与安全

### 文章 4：TRUSTMEM
- **标题**：TRUSTMEM: Learning Trustworthy Memory Consolidation for LLM Agents with Long-Term Memory
- **作者**：Tianyu Yang, Sudipta Paul, Vijay Srinivasan 等
- **时间**：2026-06-23
- **主要内容**：针对记忆更新中的遗漏、损坏、幻觉问题，提出 Memory Transition Verifier（覆盖度/保留度/忠实度）+ 偏好引导强化学习。在 MemoryAgentBench/HaluMem 上达 SOTA，记忆抽取提升 12.14 F1，过渡级遗漏/损坏/幻觉分别降低 40.1%/79.1%/50.0%。

### 文章 5：Securing LLM-Agent Long-Term Memory Against Poisoning
- **标题**：Securing LLM-Agent Long-Term Memory Against Poisoning: Non-Malleable, Origin-Bound Authority with Machine-Checked Guarantees
- **作者**：Yedidel Louck
- **时间**：2026-06-23
- **主要内容**：形式化定义"记忆可锻性"，证明内容/谱系型防御在"洗白攻击"下均不可靠。提出 TMA-NM（非锻造信息流控制），在 8 个前沿模型的跨防御/跨攻击基准中，现存防御失败率最高达 68%，TMA-NM 达到 0% 攻击成功率。

### 文章 6：Agents That Know Too Much
- **标题**：Agents That Know Too Much: A Data-Centric Survey of Privacy in LLM Agents
- **作者**：Nada Lahjouji, Ashwin Gerard Colaco 等
- **时间**：2026-06-25
- **主要内容**：从"以数据为中心"视角系统调研 LLM Agent 隐私，按数据源（数据库/文档/API/记忆/消息）组织风险与治理机制。两个关键发现：(1) 仅信息流控制能同时覆盖组合式与跨会话推断泄漏；(2) 现有基准均未在单一隐私策略下驱动 Agent 跨越其所有数据面。

### 文章 7：Memory Contagion
- **标题**：Memory Contagion: Cross-Temporal Propagation of Evaluator Bias via Agent Memory
- **作者**：Zewen Liu
- **时间**：2026-06-22
- **主要内容**：识别并形式化"记忆传染"现象——评估者偏见通过 Agent 记忆实现跨时态传播。在完美合并（oracle）下仍可传播；老模型（Gamma_A=13.18）易感，新模型（V4-Pro, Claude）免疫。证明并非所有评估者偏见都能跨时态边界传播。

## 主题三：记忆架构创新

### 文章 8：RAVEN
- **标题**：RAVEN: Long-Horizon Reasoning & Navigation with a Visuo-Spatio-Temporal Memory
- **作者**：Yixun Hu, Zhicheng Zheng, Lihan Zha 等
- **时间**：2026-06-23
- **主要内容**：面向机器人的长期记忆系统，直接存储视觉嵌入+位姿+时间到向量数据库，并在空间地图上 grounding 检索。规避有损的图像-文本字幕化，在长视距视频 QA 上超越字幕记忆系统，匹配前沿 VLM 但检索成本低 10×。已在 Unitree Go1 机器人上完成部署。

### 文章 9：Forget to Improve
- **标题**：Forget to Improve: On-Device LLM-Agent Continual Learning via Budget-Curated Memory
- **作者**：Beining Wu, Zihao Ding, Jun Huang 等
- **时间**：2026-06-23
- **主要内容**：提出净价值/字节评分（=价值-危害）治理 Agent 经验记忆全生命周期。三类决策：KEEP（按 RAM/能量预算驱逐）、SHARE（仅在价值>上行链路成本时分享）、TRUST（按来源门控对等条目）。在 Jetson 异构测试床上，记忆减少 2.7×、上行链路 2.4×、注入成功率从 0.75 降至 0。

### 文章 10：Governed Shared Memory for Multi-Agent LLM Systems
- **标题**：Governed Shared Memory for Multi-Agent LLM Systems
- **作者**：Yanki Margalit, Nurit Cohen-Inger, Erni Avram 等
- **时间**：2026-06-23
- **主要内容**：形式化"舰队记忆问题"，识别 4 种基础失败模式（未授权泄漏、陈旧传播、矛盾持久化、来源塌缩）。实现生产多租户记忆服务 MemClaw，发现并披露"非对称作用域执行"问题与"流水线排序冲突"问题。

### 文章 11：Memory Depth, Not Memory Access
- **标题**：Memory Depth, Not Memory Access: Selective Parametric Consolidation for Long-Running Language Agents
- **作者**：Haoliang Han
- **时间**：2026-06-25
- **主要内容**：针对长时运行语言 Agent，提出"选择性参数合并"机制——区别于"记忆访问"，强调记忆深度。将外部记忆的选择性片段参数化到模型权重中，避免每次检索的延迟与上下文开销。

### 文章 12：Supersede
- **标题**：Supersede: Diagnosing and Training the Memory-Update Gap in LLM Agents
- **作者**：Vedant Patel
- **时间**：2026-06-25
- **主要内容**：聚焦 LLM Agent 记忆更新能力差距（memory-update gap），提出诊断+训练联合方法，桥接记忆更新理论与实践的鸿沟。
