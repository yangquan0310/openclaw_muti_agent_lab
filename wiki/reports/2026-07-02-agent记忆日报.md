## 摘要

本期日报聚焦 2026-07-01（过去 24 小时内）arXiv 上发布的 Agent 记忆相关核心论文（共 7 篇），覆盖选择性记忆更新控制、分层语义 KV 记忆、自适应上下文弹性伸缩、贝叶斯信念轨迹评估、财务 Agent 行为漂移、技能组合六大方向。本批次呈现三大趋势：(1) 记忆更新从"无条件接受"向"选择性评估"演进（Janus 的 Momentum Trigger）；(2) 记忆与上下文管理边界模糊化，KV Cache 成为新型语义记忆载体（SeKV）；(3) 记忆的"时间性"被重新审视——历史路径依赖在控制代价中扮演角色（hysteresis）。

## 主题一：选择性记忆更新控制

### 文章 1：Janus — 插件式 LLM 记忆更新控制器
- **标题**：The Past Is Prologue: A Plug-in Controller for Selective Updates in Sequentially Evolving LLM Memory
- **作者**：Zihan Chen, Songwei Dong, Chengshuai Shi, Peng Wang, Song Wang, Cong Shen, Jundong Li
- **时间**：2026-07-01（Published Time: 2026-07-01 00:28 GMT）
- **主要内容**：顺序演化的 LLM 记忆使 Agent 能复用过往经验，但现有系统通常不加判断地接受每次本地生成的记忆更新，导致有用知识被覆盖、规则过于具体化或记忆偏向近期样本。Janus 提出"记忆动量触发器"（Memory Momentum Trigger）识别记忆更新轨迹中的可疑偏离，并在覆盖度、边界和新鲜任务构成的紧凑混合评估集上比较新旧记忆，而非回放完整历史。方法无关模型，可即插即用。

## 主题二：分层语义记忆与 KV Cache

### 文章 2：SeKV — 自适应分辨率 KV Cache
- **标题**：SeKV: Resolution-Adaptive KV Cache with Hierarchical Semantic Memory for Long-Context LLM Inference
- **作者**：Amirhossein Abaskohi, Giuseppe Carenini, Peter West, Yuhang He
- **时间**：2026-07-01（Published Time: 2026-07-01 00:28 GMT，v1: 2026-06-30）
- **主要内容**：LLM 在长上下文场景中 KV Cache 成为内存瓶颈，现有压缩方法（token 驱逐或语义分组）无法在生成阶段恢复被压缩-span 的 token 级细节。SeKV 将上下文组织为熵引导的语义跨度，存储在 GPU-CPU 内存层级中——GPU 上保留轻量摘要向量用于粗路由，CPU 上保留低秩 SVD 基用于按需 token 级重建。训练得到的 zoom-in 机制在解码时选择性展开查询相关跨度。在 128K 上下文下，GPU 内存降低 53.3%，同时准确率较最强语义压缩基线提升 5.9%。

### 文章 3：ACE — 自适应上下文弹性伸缩器
- **标题**：ACE: Pluggable Adaptive Context Elasticizer across Agents
- **作者**：Ning Liao, Zihao Long, Xiaoxing Wang, Xue Yang, Yaoming Wang, Ziyuan Zhuang, Xunliang Cai, Rongxiang Weng, Junchi Yan
- **时间**：2026-07-01（Published Time: 2026-07-01 00:54 GMT，v1: 2026-06-30）
- **主要内容**：Agentic 任务轨迹长度快速增长，对固定上下文窗口的 LLM Agent 构成挑战。现有上下文管理技术（截断、摘要）一旦丢弃或压缩信息便不可恢复。ACE 提出"无损消息维护层"存储每条历史步骤的原始消息与压缩抽象，"上下文编排层"在每步决策时动态为每个历史步骤分配 raw/abstract/drop 的弹性类型。这一可逆设计确保主 LLM 始终收到紧凑但信息丰富的上下文。ACE 适配 ReAct、DeepAgent、WebThinker、MiroFlow 四种 Agent 框架，无需训练或架构修改。

## 主题三：Agent 记忆的时间性与路径依赖

### 文章 4：记忆中的迟滞效应
- **标题**：When Regulation Has Memory: Hysteresis and Control Burden in Artificial Agency
- **作者**：Veronique Ziegler
- **时间**：2026-07-01（Published Time: 2026-07-01 00:14 GMT，v1: 2026-06-29）
- **主要内容**：自适应 Agent 通常依据其行为来评判，但稳定表象下维持稳定的内部代价可能在增长。通过自适应不确定性调节的计算模型驱动 Agent 穿越不确定性目标的连续变化然后反转，研究发现调节自适应增益形成可复现的迟滞回路——相同目标在不同路径（趋向还是远离更苛刻状态）下需要不同控制水平，且在干扰暴露前提供稳定化时 Agent 所需的自适应增益更低。**意义**：提示评估 Agent 应同时关注"是否保持有序"和"为此付出了多少调节代价"。

## 主题四：Agent 信念与行为稳定性评估

### 文章 5：BayesBench — 多轮证据积累信念轨迹评估
- **标题**：BayesBench: Evaluating LLM Belief Trajectories Under Multi-Turn Evidence Accumulation
- **作者**：Ankur Samanta, Akshayaa Magesh, Tal Lancewicki, Ayush Jain, Youliang Yu, Paul Sajda, Kaveh Hassani, Aditya Modi, Daniel R. Jiang, Yonathan Efroni
- **时间**：2026-07-01（Published Time: 2026-07-01 00:06 GMT，v1: 2026-06-29）
- **主要内容**：LLM 部署在多轮对话中，每轮提供的新证据应减少关于环境的不确定性。但现有评估只在单轮格式下对最终答案打分，忽视这一动态过程。BayesBench 在三个渐进复杂任务（贝叶斯估计、贝叶斯预测、贝叶斯决策）上评估 LLM 的信念更新与理性贝叶斯推理者的接近程度。研究揭示当前 LLM 在信念更新中的系统性偏差。

### 文章 6：FinPersona-Bench — 财务 Agent 行为 mandate 漂移
- **标题**：FinPersona-Bench: A Benchmark for Longitudinal Psychometric Stability of Autonomous Financial Agents
- **作者**：Muhammad Usman Safder, Ayesha Gull, Rania Elbadry, Fan Zhang, Yankai Chen, Xueqing Peng, Xue Liu, Preslav Nakov, Zhuohan Xie
- **时间**：2026-07-01（Published Time: 2026-07-01 00:52 GMT，v1: 2026-06-30）
- **主要内容**：LLM 作为自主金融 Agent 部署时以" preserve capital"或"避免投机性赌注"等显式行为 mandate 初始化，但在长周期中市场上下文积累后这些 mandate 逐渐失去行为影响力（Mandate Salience Decay, MSD）。FinPersona-Bench 通过将可观察价格与隐藏基本面解耦的合成市场，在三种失败模式（平静市场无信号交易、崩盘期间恐慌抛售、泡沫期间忽视基本面价值）上客观评估 MSD。**意义**：提示"持久化行为指令"本身的持久性是一个被忽视的问题。

## 主题五：技能记忆与组合

### 文章 7：SkillComposer — LLM Agent 的生成式技能组合
- **标题**：Generative Skill Composition for LLM Agents
- **作者**：Xinyu Zhao, Zhen Tan, Vaishnav Tadiparthi, Nakul Agarwal, Kwonjoon Lee, Ehsan Moradi Pari, Hossein Nourkhiz Mahjoub, Tianlong Chen
- **时间**：2026-07-01（Published Time: 2026-07-01 01:18 GMT，v1: 2026-06-30）
- **主要内容**：技能封装了执行专业任务的程序性知识（包括沙箱环境设置、测试运行、跨文件重构等），随着技能库增长，"选择合适的技能组合"成为核心瓶颈。现有方法将 Agent 推理暴露给整个技能库或依赖嵌入/LLM 排序器进行技能检索，均忽略技能组合的结构性本质——即哪些技能、多少技能、以何种顺序的联合决策。SkillComposer 提出生成式技能组合方法，在 SkillsBench 和两个生产级编码 Agent（GPT-5.2-Codex, Gemini-3-Pro-Preview）上，技能库使用率提升 +23.1pp 和 +18.2pp，提示 token 成本低于顶级检索基线。
