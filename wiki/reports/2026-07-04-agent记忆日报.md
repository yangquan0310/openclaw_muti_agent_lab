### 文章4：Mnemosyne: Agentic Transaction Processing for Validating and Repairing AI-generated Workflows
- **arXiv ID**：[2607.00269](https://arxiv.org/abs/2607.00269)
- **作者**：EYU Chang 等
- **时间**：2026-07-02 00:11 UTC 公布
- **主要内容**：提出 **ATP（Agentic Transaction Processing）事务模型**，把生成的 workflow 动作视为「不可信提案」，必须在声明的可执行约束集 C 下通过确定性准入才提交。原则是双向的：「提案不是真相」与「任何提案都不能预见所有扰动」——任何主体都可提案，但只有 runtime 准入并提交；当不可预见的中断发生时，在界内反应式修复。Mnemosyne 实现包括 append-only 转移日志、有效状态投影、依赖安全的补偿、有效承诺记录。证明四条相对 C 的安全属性（authority separation、serial-equivalent admission、evidence-preserving repair、obligation containment）+ bounded-reactive-repair 保证。九个 falsification 测试全部拒绝而合法工作通过，投影与验证开销 <6%。

### 文章7：DiscoLoop: Looping Discrete Embeddings and Continuous Hidden States for Multi-hop Reasoning
- **arXiv ID**：[2607.00341](https://arxiv.org/abs/2607.00341)
- **作者**：DiscoLoop 研究组
- **时间**：2026-07-02 00:16 UTC 公布
- **主要内容**：在两跳推理任务中标准非循环 Transformer 存在 depth-local storage 问题——早期层学到的知识在第二跳检索处不可用。Looped Transformer 通过复用同一 memory 缓解但泛化仍不完美。指出剩余瓶颈是表征层面的：第一个 loop 通常使 bridge entity 几乎完美可解码，但对应 hidden state 与 bridge token embedding 仍对齐差。免训练重新对齐干预几乎弥合泛化差距。提出 DiscoLoop，循环传递**离散 embedding 通道 + 连续 hidden-state 通道**，符号与合成语言多跳推理几近完美、训练步数显著减少；实际预训练中相对循环 Transformer 基线取得更低训练损失与更强基准性能。

## 📊 本期观察

1. **「可学习记忆」成为高频主题**：AutoMem（昨日已发布）与今日 PMD 共同把记忆管理抽象为可独立训练 / 可蒸馏的认知技能。前者侧重端到端自动化优化（结构 + 熟练度），后者侧重把跨 episode 策略信号蒸馏进策略权重，结果都说明「记忆工程」是相对任务工程的独立杠杆轴。
2. **「记忆即对象生命周期」视角**：Self-GC（GC-style 上下文对象治理）与 Mnemosyne（ATP 事务模型）共同从「纯文本上下文」走向「带索引、可恢复、可验证的内存对象」，反映社区正在把 Agent 上下文当作受控资源管理，而不是用启发式裁剪或事后摘要掩盖。
3. **记忆评测走向「行为层」**：Beyond Perplexity 明确指出 TTT 的代理指标无法支撑「部署记忆 / 个性化 / 部署后学习」声明，需要 claim-calibrated 行为评估。这是与昨日 Memory Sycophancy 基准相呼应的同一趋势：从「能不能存/取」走向「可不可以被检测到失败/可不可以声称拥有能力」。
4. **多 Agent 记忆共享新模式**：MAGNET 用「显式世界状态追踪 + 性格 Agent + ATLAS 图验证」解决长篇叙事一致性；Managed Autonomy 把 Agent 行为映射到 gear 状态 + SMARRT 治理，强调安全与生命周期而不止任务结果。
5. **AI Agent 自身反思/审慎（reconsideration）开始形式化**：Difficulty-Routed Service Control 把「何时该再考虑」建模为 router–escalated 决策，呼应「运行时是否自我降级 / 升级」的通用问题。
