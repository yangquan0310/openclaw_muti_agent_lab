## 一、问题发现

用户提问"你的会话为什么会在这里"指向 `/root/data/disk/.openclaw/agents/steward/sessions/`。经排查，这是一个**不应当存在的孤儿目录**——OpenClaw 当前的真实 sessions 目录是 `/root/.openclaw/agents/steward/sessions/`（v2026.6.1 时代的 home），而 `/data/disk/.openclaw/` 是 v2026.5.x 时代的旧 runtime 残留。

`/root/data/disk/.openclaw/` 实际是**两个独立文件系统的错误拼接**：
- `/root/.openclaw/` 在根分区 `/dev/vda2`（dev=64770）
- `/data/disk/` 在独立磁盘 `/dev/vdb`（dev=64784）—— 20GB 挂载点
- `/root/data/disk/` 路径在根分区上，是个**凭空多出来的孤儿目录**

## 二、根因分析

### 2.1 错误模式

108 个 `*.trajectory-path.json` 文件里 `runtimeFile` 字段全部写成 `/root/data/disk/.openclaw/agents/...` 路径，**多了一个 `/root` 前缀**。

OpenClaw 的 trajectory 指针文件 schema：
```json
{
  "traceSchema": "openclaw-trajectory-pointer",
  "schemaVersion": 1,
  "sessionId": "<uuid>",
  "runtimeFile": "<trajectory 实际路径>"
}
```

`runtimeFile` 应该是绝对路径。**错误值**：`/root/data/disk/.openclaw/agents/{agent}/sessions/{id}.trajectory.jsonl`；**正确值**：`/data/disk/.openclaw/agents/{agent}/sessions/{id}.trajectory.jsonl`。

### 2.2 影响 agent 分布

| agent | 错误指针数 |
|-------|-----------|
| steward | 74 |
| psychologist | 17 |
| physicist | 6 |
| programmer | 7 |
| mathematician | 4 |
| auditor / instructor / presenter / reviewer / writer | 共 0（少数） |
| **总计** | **108** |

### 2.3 推测根因

OpenClaw 内部在写 trajectory 指针时，可能用了类似 `path.relative(sessionsRoot, absPath)` 之后**再与 cwd 拼接**的逻辑：

```js
// 错误代码推测
const relPath = path.relative(sessionsRoot, absPath);  // -> "/data/disk/.openclaw/..."
const finalPath = path.join(process.cwd(), relPath);  // cwd=/root -> "/root/data/disk/..."
```

`process.cwd()` = `/root`（gateway 进程工作目录）→ 错误地把绝对路径 `/data/disk/...` 解释为相对路径后又拼回 `/root/data/disk/...`。

- **2026-06-04 21:23 CST**：孤儿副本未跟随清理，仍在 `/root/data/disk/.openclaw/agents/steward/sessions/`
