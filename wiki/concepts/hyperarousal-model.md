# 过度觉醒模型（Hyperarousal Model）

> 失眠的核心特征是在皮层、认知和生理领域存在唤醒增加

---

## 一、概念定义

**核心定义**：过度觉醒模型（Hyperarousal Model）提出失眠的核心特征是在皮层、认知和生理领域存在唤醒增加（Hyperarousal），解释了为何失眠者在有充足睡眠机会时仍难以入睡和维持睡眠。

**核心构念**：多层面唤醒过度——失眠不仅是夜间现象，而是24小时持续的系统性唤醒过度。

**概念辨析**：
- 过度觉醒 vs. 失眠：过度觉醒是失眠的机制；失眠是过度觉醒的表现
- 过度觉醒 vs. 压力反应：压力反应是短暂的；过度觉醒是慢性的持续状态
- 过度觉醒 vs. 睡眠驱动力下降：睡眠驱动力下降是另一种失眠模型；过度觉醒强调激活增加

## 二、操作性定义

### 2.1 三个层面的唤醒

| 层面 | 表现 | 测量指标 |
|------|------|----------|
| **皮层唤醒** | 脑电高频活动增加 | EEG高频(beta/gamma)活动 |
| **认知唤醒** | 担忧、反刍、侵入性思维 | 认知唤醒量表 |
| **生理唤醒** | 交感神经激活、cortisol升高、心率增快 | 生理指标测量 |

### 2.2 测量方式

| 方式 | 操作定义 | 代表研究 |
|------|----------|----------|
| **多导睡眠图(PSG)** | 测量睡眠结构和脑电活动 | Riemann et al., 2010 |
| **日间多次睡眠潜伏期测试(MSLT)** | 测量日间嗜睡程度 | 【未检索确认】 |
| **皮质醇测量** | 测量HPA轴功能 | 【未检索确认】 |
| **认知唤醒问卷** | 测量睡前认知唤醒程度 | 【未检索确认】 |
| **心率变异性(HRV)** | 测量自主神经系统激活 | 【未检索确认】 |

### 2.3 唤醒过度的判定标准

| 指标 | 失眠者特征 |
|------|----------|
| 睡眠潜伏期 | 延长 |
| EEG高频活动 | 增加 |
| 心率 | 加快 |
| 皮质醇水平 | 升高 |
| 认知唤醒 | 增强 |

---

## 三、核心特点

| 特点 | 描述 |
|------|------|
| **系统性** | 不仅是睡眠问题，而是全身性唤醒过度 |
| **24小时持续** | 白天和夜间都处于过度觉醒状态 |
| **多层面性** | 包括皮层、认知和生理三个层面 |
| **个体差异** | 不同失眠者的过度觉醒模式可能不同 |
| **可干预性** | 可通过CBT-I等干预降低过度觉醒 |

## 四、理论解释

### 4.1 过度觉醒模型
**Riemann et al., 2010**

核心机制：
- 失眠的核心是24小时持续的唤醒过度
- 唤醒过度干扰睡眠启动和维持
- 包括皮层、认知和生理三个层面
- 与HPA轴（下丘脑-垂体-肾上腺轴）功能异常相关

适用性：为理解失眠的机制提供全面框架。

### 4.2 神经认知模型
**Riemann et al., 2017**

核心机制：
- 失眠涉及皮层-皮层下-体感和自主神经系统之间的相互作用异常
- 过度觉醒是这些系统相互作用失调的结果
- 认知因素（如担忧）在觉醒过度中起关键作用

适用性：解释为何认知干预（如CBT-I）有效。

### 4.3 认知-生理交互理论

核心机制：
- 认知唤醒（如担忧）激活生理觉醒
- 生理觉醒反过来增强认知唤醒
- 形成认知-生理唤醒的恶性循环

适用性：解释为何睡前认知活动干扰睡眠。

### 4.4 过度觉醒与记忆巩固

核心机制：正常睡眠时记忆得到巩固；过度觉醒干扰这一过程，导致记忆问题。

适用性：解释为何失眠者常有认知功能抱怨。
