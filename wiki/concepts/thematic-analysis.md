# 主题分析（Thematic Analysis）

> 识别、分析和报告数据中反复出现的模式（主题）的质性数据分析方法

---

## 一、概念定义

**核心定义**：主题分析（Thematic Analysis）是一种识别、分析和报告数据中反复出现的模式（主题）的质性数据分析方法，由Braun & Clarke（2006）系统化，广泛应用于心理学、教育学、健康科学等领域。

**核心构念**：主题识别——从质性数据中识别有意义的模式（主题）并进行分析。

**概念辨析**：
- 主题分析 vs. 扎根理论：主题分析不强调理论建构；扎根理论强调发展新理论
- 主题分析 vs. 内容分析：内容分析侧重量化计数；主题分析侧重意义模式
- 主题分析 vs. 叙事分析：主题分析关注跨案例模式；叙事分析关注个别故事的完整性

## 二、操作性定义

### 2.1 六步操作流程

| 步骤 | 操作定义 | 关键活动 |
|------|----------|----------|
| **1. 熟悉数据** | 反复阅读，熟悉数据全貌 | 记录初步想法 |
| **2. 生成初始编码** | 识别有意义的数据片段并标记 | 系统性编码所有数据 |
| **3. 搜索主题** | 将编码聚类为潜在主题 | 制作主题地图 |
| **4. 审查主题** | 检验主题与数据的契合度 | 绘制编码-主题映射表 |
| **5. 定义与命名** | 精炼每个主题的内涵 | 撰写主题定义 |
| **6. 撰写报告** | 将分析结果写成文本 | 选择典型引用 |

### 2.2 理论立场选项

| 维度 | 选项 | 说明 |
|------|------|------|
| **隐性/显性** | 显性分析 | 分析数据的表面意义 |
| | 隐性分析 | 分析数据背后的深层意义 |
| **归纳/演绎** | 归纳驱动 | 数据驱动，从数据中发现主题 |
| | 演绎驱动 | 理论驱动，用理论框架分析数据 |
| **真实/虚构** | 真实叙事 | 分析真实经历和叙事 |
| | 虚构文本 | 分析虚构文本（如文学、媒体） |

### 2.3 编码标准

| 标准 | 要求 |
|------|------|
| 编码一致性 | 同一编码者前后一致；多编码者间一致 |
| 主题饱和度 | 新数据不再产生新编码或主题 |
| 主题内聚度 | 主题内编码相互关联 |
| 主题间区分度 | 不同主题间有明确区分 |

## 四、理论解释

### 4.1 主题分析的认识论
**Braun & Clarke, 2006**

核心机制：主题分析是一种"工具"，可在不同认识论立场下使用——无论是实证主义、建构主义还是其他立场。

适用性：研究者可根据自己的认识论选择分析方法。

### 4.2 主题作为"模式"的理论

核心机制：主题是数据中反复出现的意义模式——不是数据本身，而是数据中反复出现的"关于某事"。

适用性：为识别和定义主题提供概念框架。

### 4.3 主题分析的质量标准
**Braun & Clarke, 2006**

核心机制：好的主题分析应具备：
- 清晰定义的主题
- 内部同质、外部异质的主题
- 与数据和研究问题相关的有意义的主题

适用性：为评估主题分析质量提供标准。

### 4.4 数据饱和的判定
**Naeem et al., 2024**

核心机制：新数据不再挑战或扩展已有主题框架时，判定为饱和——而非简单的"无新信息出现"。

适用性：为确定样本量和数据收集的终点提供指导。

## 五、边界条件

| 边界条件 | 影响 | 说明 |
|----------|------|------|
| 认识论立场 | 影响分析方法选择 | 实证主义vs.建构主义 |
| 研究问题 | 影响编码和主题方向 | 描述性vs.解释性 |
| 数据类型 | 影响分析过程 | 访谈、文本、图像等 |
| 理论驱动程度 | 影响主题发现方式 | 归纳vs.演绎 |
| 研究者经验 | 影响编码一致性和深度 | 新手vs.经验丰富 |
| 样本量 | 影响主题饱和度 | 通常15-30个访谈可达饱和 |
