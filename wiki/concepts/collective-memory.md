# 集体记忆（Collective Memory）

> 社会群体共享的对过去事件、经验和意义的记忆

---

## 一、概念定义

**核心定义**：集体记忆（Collective Memory）指社会群体共享的对过去事件、经验和意义的记忆，由Maurice Halbwachs（1950）首次系统提出，是社会认同和文化传承的基础。

**核心构念**：社会共享记忆——不是个体记忆的简单相加，而是通过社会互动共同建构和传承的记忆。

**概念辨析**：
- 集体记忆 vs. 自传体记忆：集体记忆是社会层面的；自传体记忆是个体层面的
- 集体记忆 vs. 历史记录：历史记录是客观事实的记录；集体记忆是社会建构的意义
- 集体记忆 vs. 文化记忆：文化记忆更强调代际传承；集体记忆更强调群体内的共享

## 二、操作性定义

### 2.1 研究对象层次

| 层次 | 操作定义 | 例子 |
|------|----------|------|
| **家族记忆** | 家庭成员共享的家族历史 | 家族故事、节日传统 |
| **社区记忆** | 社区成员共享的当地历史 | 社区历史事件 |
| **民族记忆** | 民族成员共享的历史叙事 | 国家历史、民族英雄 |
| **全球记忆** | 全球化群体共享的事件记忆 | 国际重大事件 |

### 2.2 测量方式

| 方式 | 操作定义 |
|------|----------|
| 群体内一致性测量 | 测量群体成员对共同历史的记忆一致性 |
| 社会认知测量 | 测量个体对"群体历史"的认知 |
| 内容分析 | 分析群体产出（教科书、纪念物等）中的记忆内容 |
| 问卷调查 | 测量群体成员的记忆共享程度 |

### 2.3 核心特征操作化

| 特征 | 操作定义 |
|------|----------|
| 共享程度 | 群体成员记忆一致性的程度 |
| 情感强度 | 集体记忆引发的情感共鸣程度 |
| 身份关联度 | 集体记忆与群体身份的关联程度 |

## 三、核心特点

| 特点 | 描述 |
|------|------|
| **社会建构性** | 在社会互动中共同建构，而非自然形成 |
| **群体边界** | 不同群体有不同版本的集体记忆 |
| **身份功能** | 塑造群体认同和凝聚力 |
| **动态演变** | 随时间和情境不断重构 |
| **排他性** | 群体记忆往往排他，某些记忆被选择，某些被压制 |
| **物质载体** | 通过纪念物、仪式、教科书等物质形式传承 |

## 四、理论解释

### 4.1 集体记忆理论
**Halbwachs, 1950**

核心机制：
- 记忆需要社会框架才能被回忆
- 个人记忆通过社会互动被组织和理解
- 社会群体提供记忆的"框架"

适用性：为理解集体记忆的社会性质提供基础。

### 4.2 文化工具体系理论
**Wertsch, 2008**

核心机制：集体记忆通过"文化工具"(texts, monuments, etc.)传承，这些工具塑造了记忆的内容和形式。

适用性：解释集体记忆如何被物质化和传承。

### 4.3 社会同一性理论
**Tajfel & Turner, 1979**

核心机制：集体记忆是社会同一性形成和维持的核心资源——通过共享的历史叙事，群体成员获得身份认同。

适用性：解释为何集体记忆对群体凝聚力重要。

### 4.4 记忆政治学理论

核心机制：集体记忆是政治资源——谁有权定义"历史"，谁的记忆被保存或抹去，是权力斗争的焦点。

适用性：解释集体记忆的选择性和政治性。
