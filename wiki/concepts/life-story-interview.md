# 生命故事访谈法（Life Story Interview）

> 通过深度访谈收集个体完整生命历程叙述的质性研究方法

---

## 一、概念定义

**核心定义**：生命故事访谈法（Life Story Interview）是一种通过深度访谈收集个体完整生命历程叙述的质性研究方法，旨在获取受访者对自身经历的意义建构和生命叙事。

**核心构念**：叙事建构——通过访谈收集个体对生命经历的故事化叙述。

**概念辨析**：
- 生命故事访谈 vs. 叙事访谈：生命故事访谈特指收集完整生命历程；叙事访谈可针对特定主题
- 生命故事访谈 vs. 口述史：口述史更强调历史事件的记录；生命故事访谈更强调个人意义建构
- 生命故事访谈 vs. 传记法：传记通常由研究者撰写；生命故事访谈是受访者的自我叙述

---

## 二、操作性定义

### 2.1 核心结构

| 阶段 | 访谈重点 | 典型问题 |
|------|----------|----------|
| 人生主线 | 整体生命轨迹和转折点 | "请简单介绍一下您的整个人生历程" |
| 高峰体验 | 最具意义的经历 | "您人生中最重要的成就是什么？" |
| 低谷体验 | 最困难的经历及应对 | "您经历过的最困难的时期是什么？" |
| 重要他人 | 影响深远的人际关系 | "谁对您的人生产生了最重要的影响？" |
| 未来愿景 | 对未来的期待和规划 | "您对未来有什么期待和规划？" |
| 生命主题 | 贯穿性的主题和意义 | "如果用几个词来概括您的人生，会是什么？" |

### 2.2 访谈参数

| 参数 | 标准 | 说明 |
|------|------|------|
| **访谈时长** | 2-3小时 | 完整生命故事需要足够时间 |
| **访谈次数** | 1-3次 | 多次访谈可获取更丰富数据 |
| **访谈形式** | 半结构化 | 有预设问题但保持灵活性 |
| **录音/录像** | 是 | 需要完整记录以便转录分析 |
| **转录** | 逐字转录 | 包括停顿、笑声等非言语信息 |

### 2.3 数据收集要求

| 要求 | 说明 |
|------|------|
| 建立信任关系 | 需要与受访者建立信任以获取深层叙事 |
| 开放性问题 | 鼓励受访者自由叙述 |
| 追问技巧 | 深入挖掘意义和细节 |
| 敏感性意识 | 对敏感话题保持敏感 |

---

## 三、核心特点

| 特点 | 描述 |
|------|------|
| **完整性** | 关注个体生命的整体叙事，而非片段 |
| **意义建构** | 强调受访者对经历的意义赋予 |
| **时间维度** | 贯穿过去、现在和未来 |
| **关系性** | 重视人际关系对生命的影响 |
| **反思性** | 要求受访者回顾和反思生命历程 |
| **叙事性** | 以故事形式组织生命经验 |

## 四、理论解释

### 4.1 生命故事理论
**McAdams, 1993, 2001**

核心机制：
- 个体通过建构"生命故事"来获得自我同一性
- 生命故事是内在的、不断发展的叙事
- 高峰和低谷体验是故事的关键章节
- 生命主题贯穿整个叙事

适用性：为生命故事访谈提供理论基础和结构框架。

### 4.2 叙事同一性理论

核心机制：同一性是通过叙事建构的——我们通过讲述自己的故事来理解"我是谁"。

适用性：解释为何生命故事对自我理解重要。

### 4.3 三维叙事空间理论
**Clandinin & Connelly, 2000**

核心机制：叙事探究发生在三维空间——时间性（temporality）、社会性（sociality）和场所性（place）。

适用性：为叙事研究提供方法论框架。

### 4.4 职业叙事研究应用

核心机制：在职业情境中，生命故事访谈可捕捉：
- 职业选择的生命脉络
- 职业意义的建构过程
- 职业身份的演变

适用性：为理解创意工作者的职业心理提供深度视角。

## 五、边界条件

| 边界条件 | 影响 | 说明 |
|----------|------|------|
| 访谈者技能 | 影响数据质量 | 需要训练有素的访谈者 |
| 信任关系 | 影响叙事深度 | 需要建立足够信任 |
| 受访者反思能力 | 影响叙事丰富度 | 高反思能力者叙事更丰富 |
| 文化背景 | 影响叙事内容 | 不同文化有不同的生命主题 |
| 敏感话题 | 影响信息获取 | 需要谨慎处理 |
| 时间资源 | 影响访谈次数 | 多次访谈需要更多资源 |

## 六、在职业研究中的应用

| 应用场景 | 研究问题 | 访谈重点 |
|----------|----------|----------|
| AI对创意工作者的影响 | 如何理解AI带来的职业变化 | 职业转折点、未来愿景 |
| 职业意义建构 | 如何赋予职业经历以意义 | 关键职业事件、职业主题 |
| 职业身份演变 | 职业身份如何随时间变化 | 身份叙事、认同故事 |
