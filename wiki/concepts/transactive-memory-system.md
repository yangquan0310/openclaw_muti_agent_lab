# 交互记忆系统（Transactive Memory System, TMS）

> 群体成员通过社会互动发展出的共享知识存储和检索系统

---

## 一、概念定义

**核心定义**：交互记忆系统（Transactive Memory System, TMS）指群体成员通过社会互动发展出的共享知识存储和检索系统，成员间分工存储不同领域的知识，通过交流相互获取信息。

**核心构念**：分布式记忆存储——知识不是存储在个体脑中，而是分布在群体成员之间。

**概念辨析**：
- TMS vs. 集体记忆：TMS强调成员间的知识分工和检索；集体记忆强调共享的历史叙事
- TMS vs. 外部记忆：TMS通过人际互动获取信息；外部记忆通过物理设备获取
- TMS vs. 协同记忆：TMS强调成员间的知识专长分工；协同记忆强调共同完成记忆任务

## 二、操作性定义

### 2.1 核心机制

| 机制 | 操作定义 | 例子 |
|------|----------|------|
| **目录更新** | 群体成员相互了解彼此擅长的知识领域 | 知道"问谁关于什么问题" |
| **知识分配** | 将不同类型信息分配给最合适的成员 | 张三负责技术，李四负责财务 |
| **检索协调** | 知道从谁那里获取特定信息 | 检索时能找到正确的成员 |

### 2.2 测量方式

| 方式 | 操作定义 | 代表研究 |
|------|----------|----------|
| **群体TMS问卷** | 测量成员对TMS各机制的认知 | 【未检索确认】 |
| **记忆任务表现** | 测量群体记忆任务的表现 | Hollingshead, 1998 |
| **访谈法** | 了解成员对知识分工的认知 | 【未检索确认】 |

### 2.3 TMS质量指标

| 指标 | 操作定义 |
|------|----------|
| 目录准确性 | 成员对他人专长的认知是否准确 |
| 检索效率 | 能否快速找到正确的知识来源 |
| 知识覆盖度 | 群体整体知识的覆盖范围 |

## 三、核心特点

| 特点 | 描述 |
|------|------|
| **分布式存储** | 知识存储在群体成员中，而非集中 |
| **专长分工** | 不同成员负责不同知识领域 |
| **社会依赖** | 依赖成员间的社会互动 |
| **动态调整** | TMS随群体互动不断调整和发展 |
| **可扩展性** | 可扩展至人-机系统 |
| **脆弱性** | 依赖成员的可用性和准确性 |

## 四、理论解释

### 4.1 交互记忆理论
**Wegner, 1987**

核心机制：
- TMS是群体共享的"外部记忆"
- 通过三种机制运作：目录更新、知识分配、检索协调
- 提高群体记忆效率

适用性：为理解人际知识共享提供框架。

### 4.2 亲密关系中的TMS
**Wegner et al., 1991**

核心机制：亲密关系（如夫妻）发展出更成熟的TMS，成员间更了解彼此的专长，能更高效地共享信息。

适用性：解释亲密关系的认知优势。

### 4.3 人-机交互记忆系统
**Sparrow et al., 2011; Wegman, 2014**

核心机制：数字设备（如搜索引擎、云存储）成为TMS的一部分——人将知识"外包"给设备，形成人-机混合记忆系统。

适用性：解释数字时代TMS的变化。

### 4.4 群体记忆理论

核心机制：TMS是群体记忆形成的基础机制——通过成员间的知识分工，形成比任何个体都大的"群体记忆库"。

适用性：解释TMS与集体记忆的关系。
