# 默认模式网络（Default Mode Network, DMN）

> 大脑在静息状态下活跃的一组相互连接的脑区

---

## 一、概念定义

**核心定义**：默认模式网络（Default Mode Network, DMN）指大脑在静息状态（非执行特定任务）下活跃的一组相互连接的脑区，主要包括后扣带回皮层、楔前叶、内侧前额叶皮层等，与自我参照加工、情景记忆和未来规划密切相关。

**核心构念**：静息态活动——DMN在大脑"休息"时活跃，与大脑执行外部任务时的网络呈负相关。

**概念辨析**：
- DMN vs. 任务正网络：DMN在静息时活跃；任务正网络在执行任务时活跃
- DMN vs. 其他静息态网络：DMN是静息态网络中研究最多的
- DMN vs. 默认模式：默认模式指大脑的"默认"活动状态

## 二、操作性定义

### 2.1 核心脑区

| 脑区 | 英文名 | 功能 |
|------|--------|------|
| **后扣带回皮层** | Posterior cingulate cortex (PCC) | 记忆和情绪整合 |
| **楔前叶** | Precuneus | 自我参照和情景记忆 |
| **内侧前额叶皮层** | medial Prefrontal cortex (mPFC) | 自我参照加工 |
| **角回** | Angular gyrus | 语义加工和记忆 |
| **颞顶联合区** | Temporal-parietal junction (TPJ) | 社会认知 |

## 三、核心特点

| 特点 | 描述 |
|------|------|
| **静息态活跃** | 在非任务状态（静息、休息、走神）时活跃 |
| **任务抑制** | 执行外部任务时被抑制 |
| **自我参照** | 主要负责自我相关信息的加工 |
| **记忆整合** | 参与情景记忆的提取和整合 |
| **未来模拟** | 参与想象未来情景 |
| **年龄相关变化** | DMN连接随年龄变化，影响认知功能 |

## 四、理论解释

### 4.1 DMN功能理论
**Buckner et al., 2008**

核心机制：DMN的核心功能是：
- 心理模拟（mind-wandering）
- 情景记忆提取
- 未来情景模拟
- 社会认知

这些功能共同服务于自我理解和社会适应。

适用性：为理解DMN的多种功能提供统一框架。

### 4.2 警觉-非警觉理论

核心机制：DMN活动与意识的警觉状态有关——静息时DMN活跃对应非警觉的意识状态；任务执行时DMN抑制对应警觉状态。

适用性：解释DMN与意识状态的关系。

### 4.3 记忆巩固理论

核心机制：DMN在静息时参与记忆巩固——通过重新激活和整合日间经历，形成长期记忆。

适用性：解释为何睡眠对记忆巩固重要。

### 4.4 DMN-焦虑-睡眠关联模型
**Shen et al., 2023**

核心机制：DMN连接失调是睡眠质量差与焦虑症状关联的神经基础——睡眠问题导致DMN功能异常，进而影响情绪调节。

适用性：解释睡眠、DMN和焦虑的关系。

## 五、边界条件

| 边界条件 | 调节方向 | 具体发现 | 效应量 | 研究 |
|----------|----------|----------|--------|------|
| 年龄 | 调节 | DMN连接随年龄变化，老年人DMN效率下降 | d=0.3 | 【未检索确认】 |
| 睡眠质量 | 正向调节 | 睡眠质量差→DMN连接失调 | β=0.35 | Shen et al., 2023 |
| 焦虑症状 | 正向调节 | 焦虑与DMN过度活跃相关 | β=0.30 | 【未检索确认】 |
| 抑郁症状 | 正向调节 | 抑郁与DMN功能异常相关 | β=0.32 | 【未检索确认】 |
| 阿尔茨海默病 | 负向调节 | 疾病状态下DMN显著受损 | d=0.5 | 【未检索确认】 |
| 认知训练 | 负向调节 | 训练可能改善DMN效率 | β=-0.20 | 【未检索确认】 |
