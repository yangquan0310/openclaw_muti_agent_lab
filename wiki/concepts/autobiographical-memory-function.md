# 自传体记忆功能（Autobiographical Memory Function）

> 自传体记忆在个体心理生活中所发挥的作用

---

## 一、概念定义

**核心定义**：自传体记忆功能（Autobiographical Memory Function）指自传体记忆在个体心理生活中所发挥的作用，包括自我功能（Self function）、社会功能（Social function）和导向功能（Directive function）。

**核心构念**：功能导向——自传体记忆不仅是信息存储，更是服务于自我认同、社会关系和决策的心理工具。

**概念辨析**：
- 自传体记忆功能 vs. 自传体记忆：功能是记忆"做什么"；记忆是信息的存储系统
- 自传体记忆功能 vs. 一般记忆功能：自传体记忆功能强调与自我相关的特殊功能
- 功能 vs. 过程：功能是记忆的作用；过程是记忆如何运作

---

## 二、操作性定义

### 2.1 三大功能

| 功能 | 操作定义 | 典型行为 |
|------|----------|----------|
| **自我功能** | 构建和维护自我概念、身份和连续性 | 回忆高峰/低谷体验 |
| **社会功能** | 与他人分享故事、建立亲密关系 | 分享经历、讲述故事 |
| **导向功能** | 从过去经验中提取教训，指导决策 | 从过去学习做决定 |

### 2.2 测量工具

| 工具 | 操作定义 | 信效度 | 代表研究 |
|------|----------|--------|----------|
| **自传体记忆功能问卷(AMFQ)** | 测量三种功能的使用频率 | α=0.78-0.88 | Bluck & Levine, 1998 |
| **自传体记忆功能编码系统** | 分析自发回忆中的功能 | 编码一致性>0.80 | 【未检索确认】 |

### 2.3 功能使用指标

| 指标 | 操作定义 |
|------|----------|
| 功能使用频率 | 回忆自传体记忆时各功能使用的频率 |
| 功能满足度 | 各功能满足个体需要的程度 |
| 功能灵活性 | 根据情境选择合适功能的能力 |

## 三、核心特点

| 特点 | 描述 |
|------|------|
| **多功能性** | 自传体记忆同时服务多种心理功能 |
| **情境敏感性** | 不同情境激活不同功能 |
| **个体差异** | 不同个体对不同功能的依赖程度不同 |
| **文化差异** | 不同文化中各功能的相对重要性可能不同 |
| **发展变化** | 功能使用可能随年龄变化 |
| **可干预性** | 可通过训练增强特定功能的使用 |

## 四、理论解释

### 4.1 自传体记忆功能框架
**Bluck & Levine, 1998**

核心机制：自传体记忆有三大功能：
- 自我功能：建构和维护自我同一性
- 社会功能：建立和维持社会联系
- 导向功能：为当前和未来行为提供指导

适用性：为理解自传体记忆的多重作用提供框架。

### 4.2 自我功能理论

核心机制：
- 身份建构：生命故事构成自我同一性的核心
- 自我连续性：连接过去、现在和未来的自我
- 自我评价：通过回忆过去评估自我价值

适用性：解释为何自传体记忆对自我概念重要。

### 4.3 社会功能理论

核心机制：
- 分享经历以建立联系
- 通过共同记忆加深友谊
- 文化传承与集体记忆

适用性：解释自传体记忆的社会性质。

### 4.4 导向功能理论

核心机制：
- 从过去成功/失败中学习
- 预测未来情境
- 指导目标设定和决策

适用性：解释自传体记忆如何支持适应性决策。
