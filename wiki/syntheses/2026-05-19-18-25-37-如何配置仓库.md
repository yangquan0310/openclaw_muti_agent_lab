# 仓库

> 实验室统一项目仓库，存放所有项目。

## 路径

```
/root/data/disk/仓库/
```

## 仓库结构

```
/root/data/disk/仓库/
├── README.md              # 仓库总览（项目索引）
│
├── 项目A/                 # 每个项目一个文件夹
│   ├── README.md
│   ├── metadata.json
│   └── ...
│
├── 项目B/
│   └── ...
│
└── ...
```

> 项目类型在 `README.md` 索引表中标注，**不按类型分目录**。

## 项目管理技能

| 项目类型 | 管理技能 |
|----------|----------|
| 论文项目 | thesis-manager |
| 课程项目 | course-manager |
| 程序项目 | program-manager |

## 访问权限

- 所有 Agent 均可读取
- 写入权限按项目分配
