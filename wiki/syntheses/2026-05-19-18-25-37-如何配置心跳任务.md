# HEARTBEAT.md — 心跳任务模板

> **定义**：记录 Agent 的定时任务、维护周期和执行状态。
> **结构由大管家维护，内容由各代理维护。**

## 表格字段规范

### 列定义

| 字段 | 说明 | 格式示例 |
|------|------|----------|
| **执行时间** | 定时任务触发时间 | `每日 03:00` / `每周一 09:00` |
| **负责人** | 执行任务的代理 | `大管家（steward）` |
| **任务ID** | 唯一标识符 | UUID，如 `ab40d36a-e823-4404-8411-cc9446414562` |
| **任务名称** | 简短描述 | `每日TOOLS更新任务` |
| **功能描述** | 详细功能说明 | `更新个人脚本索引、维护项目库` |
| **脚本位置** | 相关脚本存储路径 | `~/.openclaw/workspace/{agent_id}/scripts/` |
| **执行方式** | 执行方式 | `子代理执行` / `主代理执行` |
| **cron状态** | 任务当前状态 | 见下方状态取值 |

### cron状态取值

| 状态 | 含义 |
|------|------|
| `enabled` | 已启用，任务正常执行中 |
| `disabled` | 已禁用，任务暂停执行 |
| `error` | 执行出错，需要检查 |
| `pending` | 待配置，已创建但尚未启用 |

### 行排序规则

- 按**执行时间**增序排列（从早到晚）
- 示例：`00:00` → `03:00` → `04:00` → `05:00`

---

## 设计原则

1. **结构统一**：所有 Agent 的 HEARTBEAT.md 使用相同表格结构
2. **历史保留**：已停用的任务不删除，用删除线标记并注明停用日期
3. **版本追踪**：每次修改更新「历史版本」章节
4. **状态透明**：cron状态实时反映任务健康状况
