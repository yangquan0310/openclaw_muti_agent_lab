## 四、GB/T 7714-2015 标准格式示例

### 中文电子文献
```
作者. 题名[EB/OL]. (发布日期)[引用日期]. 获取路径.
```
**示例**：
```
陆林. 五大精神心理问题影响我国青少年健康成长[EB/OL]. (2024-08-01)[2026-05-13]. https://www.sciencenet.cn/...
```

### 中文期刊
```
作者. 题名[J]. 刊名, 年, 卷(期): 起止页码.
```
**示例**：
```
戴晓阳, 等. 项目反应理论初评[J]. 心理科学, 1991(1): 页码.
```

### 外文专著
```
姓, 名. 题名[M]. 译者. 出版地: 出版社, 出版年.
```
**示例**：
```
Piaget, J, Inhelder, B. The Psychology of the Child[M]. Weaver H, Trans. New York: Basic Books, 1969.
```

### 外文期刊
```
姓, 名. 题名[J]. 刊名, 年, 卷(期): 起止页码.
```
**示例**：
```
Fitzpatrick K K, Darcy A, Vierhile M. Delivering cognitive behavior therapy to young adults with symptoms of depression and anxiety using a fully automated conversational agent[J]. JMIR Mental Health, 2017, 4(2): e19.
```

### 标准
```
发布单位. 标准号—年份 标准名[S]. 出版地: 出版者, 出版年.
```
**示例**：
```
全国人民代表大会常务委员会. 中华人民共和国个人信息保护法[S]. 北京: 中国法制出版社, 2021.
```
