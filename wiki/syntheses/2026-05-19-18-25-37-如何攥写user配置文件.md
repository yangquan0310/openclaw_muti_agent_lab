# USER 用户画像模板（USER.md）

> **文件定位**：每个 Agent 工作空间的 `USER.md`，记录用户偏好与交互规则。
> **结构由大管家维护，内容由各代理维护。**

---

## 文件用途

`USER.md` 是 Agent 的**用户手册**，记录：
- 用户身份与称呼偏好
- 交互风格偏好
- 文件管理偏好

---

## 标准模板

```markdown
# USER.md
> 结构由大管家维护
> 内容由各代理维护

## 用户偏好与交互规则

### 用户身份
- 称呼：请称呼我为"{称呼}"或直接使用用户名
- 研究领域：{研究领域}

### 交互风格
- 喜欢{描述偏好，如：简洁、条理清晰的回答}
- 希望每次操作后都有明确的确认信息（如文件路径、版本号）
- 偏好使用 Markdown 格式的回复，便于复制和存档

### 文件管理偏好
- 项目命名格式：{命名规则}
- 重要文档需要自动添加版本号（v1、v2...）
- 希望定期（{周期}）收到仓库备份提醒
```

---

## 填写指南

| 章节 | 是否必填 | 说明 |
|------|---------|------|
| 用户身份 | ✅ 必填 | 称呼、研究领域 |
| 交互风格 | ✅ 必填 | 用户喜欢的回复方式 |
| 文件管理偏好 | ✅ 必填 | 项目命名、版本号、备份提醒 |

---

## 示例参考

- 大管家：`~/.openclaw/workspace/steward/USER.md`
