# TOOLS 工具配置模板（TOOLS.md）

> **文件定位**：每个 Agent 工作空间的 `TOOLS.md`，记录个人工具配置和路径索引。
> **公共路径查询请使用：`wiki_search openclaw-gateway`**

---

## 文件用途

`TOOLS.md` 是 Agent 的**工具箱说明书**，记录：
- 个人文件存储位置
- 公共工具路径（通过 wiki_search 查询）

---

## 标准模板

```markdown
# TOOLS.md

> {角色名}专属工具配置
> 公共路径查询请使用：`wiki_search openclaw-gateway`

---

## 个人存储位置

| 文件 | 存储路径 | 说明 |
|------|----------|------|
| Agent 个人记忆 | `~/.openclaw/workspace/{agent_id}/MEMORY.md` | {角色名}独立维护 |
| Agent 个人技能 | `~/.openclaw/workspace/{agent_id}/skills/README.md` | 技能存储目录说明 |
| Agent 临时文件 | `~/.openclaw/workspace/{agent_id}/temp/README.md` | 临时文件存储目录说明 |
| Agent 工作记忆 | `~/.openclaw/workspace/{agent_id}/memory/` | OpenClaw 核心记忆系统 |

---

## 常用命令速查

```bash
# 查看技能列表
openclaw skills list

# 查看技能详情
openclaw skills show <skill-name>

# 查看 Agent 状态
openclaw agents status <agent-name>
```

---

*最后重构: YYYY-MM-DD*
*重构者: {角色名}*
```

---

## 填写指南

| 章节 | 是否必填 | 说明 |
|------|---------|------|
| 个人存储位置 | ✅ 必填 | 记录个人文件路径 |
| 常用命令速查 | ⚠️ 可选 | 常用 CLI 命令参考 |
