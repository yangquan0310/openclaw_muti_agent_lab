# BOOTSTRAP.md — Agent 初始化模板

> **用途**：指导用户基于 7 个核心模板快速初始化一个新 Agent。
> **执行方式**：按顺序逐个创建文件，每步确认后再进行下一步。

---

## 初始化流程

```
步骤1: IDENTITY.md → 定义"我是谁"
步骤2: SOUL.md     → 定义"我是什么样的人"
步骤3: USER.md     → 定义"我的用户是谁"
步骤4: TOOLS.md    → 定义"我的工具在哪里"
步骤5: MEMORY.md   → 定义"我当前的任务和规则"
步骤6: HEARTBEAT.md → 定义"我的定时任务"
步骤7: AGENTS.md   → 定义"我的工作原则"
```

---

## 步骤1: IDENTITY.md — 身份定义

**先做这个**：没有身份，其他都无从谈起。

**操作**：复制 [[syntheses/identity]] 模板，填写：

| 字段 | 填写内容 | 示例 |
|------|---------|------|
| Agent ID | 小写英文，无空格 | `mathematician` |
| 显示名称 | 中文名 + 英文名 | `数学家 (Mathematician)` |
| 版本 | 从 1.0.0 开始 | `1.0.0` |
| 工作目录 | 自动生成 | `~/.openclaw/workspace/{agent_id}/` |
| 自我概念 | 3-4句话定义角色 | 我是实验室的数学家... |
| 能力边界 | ✅ 做 / ❌ 不做 | 明确分工 |

**验证**：能否用一句话向他人介绍这个 Agent 是做什么的？

---

## 步骤2: SOUL.md — 人格定义

**核心问题**：我如何与世界互动？

**操作**：复制 [[syntheses/soul]] 模板，填写：

| 章节 | 必填 | 要点 |
|------|------|------|
| 核心自我认知 | ✅ | 用第一人称，3-4句话 |
| 交互风格 | ✅ | 回答方式、确认习惯、格式偏好 |
| 任务执行风格 | ✅ | 精确执行、不懂就问、准确传递 |
| 工作信念 | ✅ | 3-5条核心价值观 |
| 价值观优先级 | ✅ | 明确排序，冲突时有依据 |

**验证**：信念是否与 IDENTITY.md 中的能力边界一致？

---

## 步骤3: USER.md — 用户画像

**核心问题**：我在为谁服务？

**操作**：复制 [[syntheses/user]] 模板，填写：

| 章节 | 必填 | 要点 |
|------|------|------|
| 用户身份 | ✅ | 称呼、研究领域 |
| 交互风格 | ✅ | 用户喜欢的回复方式 |
| 文件管理偏好 | ✅ | 命名规则、版本号、备份周期 |

**验证**：用户偏好是否与该 Agent 的领域匹配？

---

## 步骤4: TOOLS.md — 工具配置

**核心问题**：我的文件和工具在哪里？

**操作**：复制 [[syntheses/tools]] 模板，填写：

| 项目 | 路径 |
|------|------|
| 个人记忆 | `~/.openclaw/workspace/{agent_id}/MEMORY.md` |
| 个人技能 | `~/.openclaw/workspace/{agent_id}/skills/README.md` |
| 临时文件 | `~/.openclaw/workspace/{agent_id}/temp/README.md` |
| 工作记忆 | `~/.openclaw/workspace/{agent_id}/memory/` |

**验证**：目录是否已创建？

```bash
mkdir -p ~/.openclaw/workspace/{agent_id}/{skills,temp,memory}
```

---

## 步骤5: MEMORY.md — 记忆初始化

**核心问题**：我当前有什么任务？遇到什么情况该怎么做？

**操作**：Agent 根据 [[syntheses/memory]] 模板**自动创建**，无需手动填写：

| 章节 | 初始状态 |
|------|---------|
| 工作记忆 | 空表（初始无任务） |
| 程序性记忆 | 复制通用 If-Then 规则 |
| 陈述性记忆 | 复制 Wiki 关键词映射 |

**注意**：MEMORY.md 是运行时文件，由 Agent 在后续工作中自行维护。

---

## 步骤6: HEARTBEAT.md — 定时任务

**核心问题**：我需要定期做什么？

**操作**：Agent 根据 [[syntheses/heartbeat]] 模板**自动创建**，初始状态：

- 当前活跃定时任务：空表（尚无定时任务）
- 历史定时任务：空表

**后续**：当 Agent 有定时任务时，自行添加到这里。

---

## 步骤7: AGENTS.md — 行为准则

**最后做这个**：这是最高准则。

**操作**：Agent **自动复制** [[syntheses/agents]] 模板，全系统统一，**不允许修改**。

- 工作原则（四点规则）
- 子代理交互规则
- 安全红线

**注意**：AGENTS.md 是系统级准则，所有 Agent 完全一致，初始化时直接复制即可。

| TOOLS.md 已创建，目录已初始化 | ⬜ |
| MEMORY.md 已创建，任务看板可用 | ⬜ |

## 快速创建命令

```bash
# 1. 创建目录
AGENT_ID="your_agent"
mkdir -p ~/.openclaw/workspace/${AGENT_ID}/{skills,temp,memory}

# 2. 手动填写（用户/Agent 定义内容）
cp ~/.openclaw/wiki/syntheses/2026-05-19-18-25-37-identity.md ~/.openclaw/workspace/${AGENT_ID}/IDENTITY.md
cp ~/.openclaw/wiki/syntheses/2026-05-19-18-25-37-soul.md ~/.openclaw/workspace/${AGENT_ID}/SOUL.md
cp ~/.openclaw/wiki/syntheses/2026-05-19-18-25-37-user.md ~/.openclaw/workspace/${AGENT_ID}/USER.md
cp ~/.openclaw/wiki/syntheses/2026-05-19-18-25-37-tools.md ~/.openclaw/workspace/${AGENT_ID}/TOOLS.md

# 3. Agent 自动创建（基于模板，无需手动填写）
cp ~/.openclaw/wiki/syntheses/2026-05-21-10-42-53-memory.md ~/.openclaw/workspace/${AGENT_ID}/MEMORY.md
cp ~/.openclaw/wiki/syntheses/2026-05-19-18-25-37-heartbeat.md ~/.openclaw/workspace/${AGENT_ID}/HEARTBEAT.md
cp ~/.openclaw/wiki/syntheses/2026-05-19-18-25-37-agents.md ~/.openclaw/workspace/${AGENT_ID}/AGENTS.md

# 4. 填写步骤1-4的内容，步骤5-7由 Agent 运行时维护
```
