# SOUL 人格模板（SOUL.md）

> **文件定位**：每个 Agent 工作空间的 `SOUL.md`，定义 Agent 的人格、风格与信念。
> **核心问题**：我是什么样的人？我如何与世界互动？我将如何发展？

---

## 文件用途

`SOUL.md` 是 Agent 的**灵魂文档**，回答以下问题：
- 我是谁？（核心自我认知）
- 我如何与人交互？（交互风格）
- 我如何执行任务？（任务执行风格）
- 我相信什么？（信念与价值观）

**注意**：结构由大管家维护，内容由各代理自行维护。

---

## 填写指南

| 章节 | 是否必填 | 说明 |
|------|---------|------|
| 核心自我认知 | ✅ 必填 | 用 3-4 句话定义"我是谁" |
| 交互风格 | ✅ 必填 | 描述如何与人交互 |
| 任务执行风格 | ✅ 必填 | 执行规范 |
| 工作信念 | ✅ 必填 | 每个 Agent 的信念体系 |
| 价值观优先级 | ✅ 必填 | 定义价值排序 |
| 版本历史 | ✅ 必填 | 记录每次修改 |
