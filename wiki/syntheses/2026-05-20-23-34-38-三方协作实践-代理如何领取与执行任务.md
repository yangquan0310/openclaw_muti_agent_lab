# 三方协作实践：代理领取任务与执行流程

> 本文档记录 agent-self-development（插件）+ knowledge-manager（技能）+ wiki维护（项目）三方协作的完整流程。

---

## 一、三方角色定位

| 角色 | 作用 |
|------|------|
| **agent-self-development** | 插件工具：task.* / event.* 提供任务追踪能力 |
| **knowledge-manager** | 技能：执行 wiki 管理操作的规范 |
| **wiki维护** | 项目：工作台，存储任务/事件/产出物 |

---

## 二、领取任务

### 四步曲

```
1. 明确约束目标
   ↓
2. 申请审批
   ↓
3. 更新TODO任务树
   ↓
4. 推进执行
```

### 详解

| 步骤 | 动作 | 执行者 | 产出 |
|------|------|--------|------|
| **1. 明确约束目标** | 与用户确认验收标准和边界条件 | 大管家 | 约束目标写入 TODO |
| **2. 申请审批** | 向用户展示约束目标和执行方案 | 大管家 | 用户确认后方可继续 |
| **3. 更新TODO任务树** | 创建任务行，绑定约束目标、分配子代理 | 大管家 | 任务行状态：⬜ 待开始 |
| **4. 推进执行** | 按 SKILL 协作规范推进任务 | 大管家或子代理 | task.advance × 6 |

## 三、任务树与子任务

### 主任务 vs 子任务

| 类型 | 创建者 | 说明 |
|------|--------|------|
| **主任务** | 大管家 | 对应项目 TODO 中的顶级任务 |
| **子任务** | 大管家或子代理 | 对应任务树中的子步骤 |

### 任务树结构（大管家视角）

大管家只定**约束目标/输入/产出**，子任务由子代理自己拆解：

```markdown
- [ ] **主任务**（大管家负责）
  - 📄 约束目标：...
  - 📄 输入：...
  - 📄 产出：...
  - 📄 子代理分配：子代理 A、子代理 B
  - （子任务由子代理自己拆解，大管家不写死）
```

子代理收到后自己拆解：

```markdown
- [ ] **子任务 A**（子代理 A 负责）
  - 📄 约束目标：继承主任务约束
  - 📄 输入：...
  - 📄 产出：...
  - [ ] 子任务细分（子代理自己决定）
```

## 四、TODO 与 task 工具同步

### 状态对应

| task 工具状态 | TODO 标记 | 说明 |
|--------------|-------------|------|
| draft | ⬜ 待开始 | 刚创建 |
| active | 🔄 进行中 | 执行中 |
| completed | ✅ 已完成 | 任务完成 |

### 同步规则

| 场景 | TODO.md | task 工具 |
|------|---------|-----------|
| 大管家领取时 | 添加主任务行（⬜ 待开始） | task.create |
| 子代理领取时 | 添加子任务行（⬜ 待开始） | task.create |
| 执行中 | 标记进度（🔄 进行中） | task.advance |
| 完成时 | 标记 ✅ | task.update → event.report → task.archive |

---

## 五、推进执行

### 推进规则

| 执行者 | 场景 | 说明 |
|--------|------|------|
| **大管家** | 主任务推进、子任务未分配 | 直接执行 |
| **子代理** | 子任务已分配给子代理 | 子代理创建自己的 task.json 做计划 |

### 子任务完整生命流程

```
子任务创建
    ↓
task.create（子代理创建自己的 task.json）
    ↓
明确计划
    ↓
申请审批（用户确认）
    ↓
task.advance（分步执行）
    ↓
task.update（更新状态）
    ↓
分析归因（deviation / attribution）
    ↓
event.report（事件记录）
    ↓
调节（更新自己相关文件）
    ↓
task.archive（归档）
```

### 大管家更新主任务

```
所有子任务完成
    ↓
大管家更新主 task.json
    ↓
event.report
    ↓
task.archive
```

## 七、目录结构

```
项目/
├── .agent/
│   ├── tasks/              # 主任务 JSON
│   │   └── {主任务runId}.json
│   └── events/            # 事件报告
│       └── {日期}/
│           └── {主任务runId}.md
├── .agent/
│   └── {子代理ID}/       # 子代理任务目录
│       ├── tasks/
│       │   └── {子任务runId}.json
│       └── events/
│           └── {日期}/
│               └── {子任务runId}.md
├── README.md
├── SKILL.md
└── TODO.md
```

## 八、关键参数

| 参数 | 说明 |
|------|------|
| `baseDir` | 必须指定项目路径，任务/事件生成到 `项目/.agent/` |
| `runId` | 任务唯一ID |
| `status` | 任务状态：draft → active → completed |
