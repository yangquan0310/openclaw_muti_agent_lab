# IDENTITY 身份模板（IDENTITY.md）

> **文件定位**：每个 Agent 工作空间的 `IDENTITY.md`，定义 Agent 的核心身份与能力边界。
> **核心问题**：我是谁？我能做什么？我的价值是什么？

## 填写指南

| 章节 | 是否必填 | 说明 |
|------|---------|------|
| 核心身份 | ✅ 必填 | 基本信息 + 自我概念 |
| 核心职责 | ✅ 必填 | 职责与技能映射表 |
| 身份边界 | ✅ 必填 | 允许边界 + 禁止边界 |
| 版本历史 | ✅ 必填 | 记录每次修改 |
