## 大管家专属技能

### feishu-voice（飞书语音消息发送）

| 属性 | 内容 |
|------|------|
| **版本** | v1.0.0 |
| **创建日期** | 2026-05-23 |
| **路径** | `~/.openclaw/skills/feishu-voice/` |
| **触发词** | 发送语音消息、用语音回复、语音回复 |
| **依赖** | ffmpeg, lark-cli |

### 功能说明

将 TTS 生成的 MP3 音频转换为飞书原生语音消息气泡（非文件附件）。

### 工作流程

```
MP3 → ffmpeg 转换(MPG/OGG/Opus) → lark-cli 上传 → 获取 file_key → 发送 msg_type=audio → 飞书语音气泡
```

### 使用方式

```bash
# 命令行发送
python3 ~/.openclaw/workspace/steward/skills/feishu-voice/scripts/send_voice.py <mp3_path> [open_id]
```

### Python 调用

```python
from send_voice import send_feishu_voice
result = send_feishu_voice(audio_path="/path/to/tts.mp3", open_id="ou_xxx")
```

### 关键发现

- **MiniMax TTS 输出 MP3 格式**，但飞书原生语音消息需要 **OPUS in OGG** 格式
- lark-cli 原生支持 `--audio` 发送本地文件为语音气泡
- OpenClaw 内置 TTS 工具输出的 MP3 只能作为文件附件发送，不能直接作为语音气泡
- feishu-voice 技能通过格式转换解决此兼容性问题

### API 端点

| 步骤 | 端点 | 方法 |
|------|------|------|
| 获取 token | `https://open.feishu.cn/open-apis/auth/v3/tenant_access_token/internal` | POST |
| 上传文件 | `https://open.feishu.cn/open-apis/im/v1/files?file_type=opus` | POST |
| 发送语音 | `https://open.feishu.cn/open-apis/im/v1/messages?receive_id_type=open_id` | POST |
