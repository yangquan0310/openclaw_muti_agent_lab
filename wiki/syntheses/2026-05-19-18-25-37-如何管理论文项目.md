# 论文项目

> 多代理协同完成论文从立项到投稿的全流程。

---

## 多代理写作角色

| 角色 | Agent | 核心技能 | 职责 |
|------|-------|----------|------|
| **项目管理者** | 大管家 | `thesis-manager` | 创建/整理项目目录、维护 metadata.json、归档旧版本 |
| **文献综述者（数学）** | 数学家 | `research-assistant` | 数学建模、统计分析相关文献检索与综述 |
| **文献综述者（物理）** | 物理学家 | `research-assistant` | 物理建模、理论推导相关文献检索与综述 |
| **文献综述者（心理）** | 心理学家 | `research-assistant` | 心理学理论、实验设计相关文献检索与综述 |
| **论文撰写者** | 写作助手 | `thesis-writer` | 三层写作规范、修改方法论、术语管理 |
| **质量审查者** | 审稿助手 | `thesis-reviewer` | 8维度审稿清单、建设性反馈、论证一致性检验 |

## 项目目录结构

```
论文项目/
├── README.md              # 项目总览（人类视角）
├── metadata.json          # 机器可读架构
├── SKILL.md               # 项目级操作手册
├── TODO.md                # 进度看板
├── .agentignore           # 可见性控制文件
│
├── uploads/               # 用户上传的原始材料（Agent 只读）
├── manuscripts/           # 论文草稿
├── docs/                  # 定稿（需用户 [APPROVED] 后方可写入）
├── knowledge/             # 研究助手管理
│   ├── index.json         # 文献知识库
│   ├── note/              # 结构化笔记
│   ├── review/            # 文献综述
│   ├── search_query/      # 检索条件
│   └── retrieval_report/  # 检索报告
├── temp/                  # 临时文件和归档草稿
└── .agent/                # 元数据层（隐藏目录）
    ├── events/            # 事件流
    ├── locks/             # 并发控制
    ├── decisions/         # 决策存档
    ├── tasks/             # 任务索引
    └── agents/            # 项目级代理角色规范
        ├── psychologist.md
        ├── mathematician.md
        ├── physicist.md
        ├── writer.md
        └── reviewer.md
```

## 协作流程

```
1. 大管家创建项目目录 → 初始化 metadata.json + README.md
2. 领域专家检索文献 → 建立 knowledge/index.json
3. 领域专家合成文献综述 → knowledge/review/
4. 写作助手撰写论文草稿 → manuscripts/
5. 审稿助手审查质量 → 8维度检查清单
6. 用户确认 → [APPROVED] → 定稿移入 docs/
7. Git 版本控制 → development 分支日常提交，完成整体时合并到 main
```

## 四文件契约

| 文件 | 职责 | 维护者 | 必填 |
|------|------|--------|------|
| `README.md` | 项目名片：名称、类型、目的 | 大管家 / 用户 | ✅ |
| `metadata.json` | 机器可读架构 | 大管家 | ✅ |
| `SKILL.md` | 论文写作工作流程、格式规范 | 写作助手 | ✅ |
| `TODO.md` | 当前任务状态、进度看板 | 大管家 / 用户 | ✅ |

## Git 工作流

### 双分支策略

| 分支 | 用途 | 推送时机 |
|------|------|---------|
| `main` | 稳定版本，已完成的论文/章节 | **完成整体任务时** |
| `development` | 日常写作，章节修改中 | **完成阶段子任务时** |

**规则**：
- 日常写作只推 `development`
- 完成整体任务（整篇论文终稿、整章完成）时合并到 `main`
- **禁止直接推 main**

### Commit 格式
```
ch{两位数字} v{轮次}: {简要说明}
```
示例：`ch10 v2: 内容框架`、`ch10 v6: 终稿完成`

### 完成整体任务流程
```bash
git checkout development
git add -A
git commit -m "chXX v6: 终稿完成"
git push origin development
git checkout main
git merge development
git push origin main
git checkout development
```

## 👥 Agent 角色速查

| 角色 | 核心职责 | 可操作目录 | 禁止事项 |
|------|----------|-----------|---------|
| **大管家** | 整理目录、维护元数据、归档版本 | 全局 | 不评审论文、不撰写内容 |
| **心理学家** | 文献检索、理论分析、实验设计 | `knowledge/*` | 不修改论文正文 |
| **写作助手** | 整合综述、撰写草稿、修改论文 | `manuscripts/` | 不评审、不管理目录 |
| **审稿助手** | 8维度审核、输出审稿意见 | `manuscripts/`（只读） | 不修改论文手稿 |
| **数学家** | 数学建模、公式推导、统计分析 | `knowledge/*` | 不撰写正文 |
| **物理学家** | 物理文献检索、理论推导、实验方案 | `knowledge/*` | 不撰写正文 |
