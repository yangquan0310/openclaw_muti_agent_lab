## 3. 修复 #3：search fallback 主动提示（🟡）

### 3.1 问题回顾

**v6.0.5 现状**（audit 报告 #3）：`scripts/search/utils.py:444` `if include_fallback and (not papers or len(papers) < limit)` —— fallback **已实际触发**，但仅打印 `[search_by_keyword] CNKI 返回 0 篇` 一行 print，**未主动告诉用户"已切到 Semantic Scholar，建议用英文搜"**。用户感知不到 fallback 已发生。

### 3.2 修复方案

在 `search_by_keyword()` 内：
1. fallback 触发时多打两行：`⚠️ fallback 已触发 → <engine>（<reason>）` + 调关键词建议
2. 引入 `_meta` 字典返回 `fallback_used` / `fallback_reason` / `fallback_count` 字段
3. `main.py` `_run_search` 改走 `search_by_keyword()`（不再只走 WikiSearchReport），CLI JSON 输出带 `fallback_used`
4. CLI stderr 额外打 `⚠️ fallback 已触发` 提示（用户视角可见）
