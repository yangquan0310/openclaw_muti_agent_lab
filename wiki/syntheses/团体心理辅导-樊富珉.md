## 书籍简介

### 作者简介

- **樊富珉**：清华大学教育研究所心理研究室，在团体辅导与咨询领域有20年探索和研究经验
- **何瑾**：北京大学学生心理健康教育与咨询中心专职教师

### 核心理念

团体辅导被称为"神奇的圆圈"——一群人围坐在一起，经过几次密集的互动，每个团体成员都会产生积极的改变，更适应、更快乐、更健康、更和谐。

### 教材特色

1. 整本教材按照一门课程的教授顺序编排，共分为6个单元
2. 学生在上课的同时也在参与团体辅导，学习者将经历团体辅导的几个阶段
3. 每个单元由五个板块构成：团体活动导入、技术点拨篇、知识学习篇、活动参考、单元作业

## 团体发展四阶段理论

根据科瑞(Corey, 1982)的经典理论，一个完整的团体发展会经历：

| 阶段 | 核心任务 | 成员特征 |
|------|----------|----------|
| **初期阶段** | 建立信任、明确目标、建立规范 | 既带着希望和好奇，也带着担心和恐惧 |
| **转换阶段** | 处理焦虑和冲突、鼓励开放 | 有关键期的矛盾和冲突，会产生焦虑和不安 |
| **工作阶段** | 解决问题、学习新行为 | 有很强的凝聚力，沟通顺畅 |
| **结束阶段** | 总结经验、整合收获、迁移应用 | 总结经验，将零散的收获组合起来 |

## 第一单元 团体辅导之准备篇

### 一、团体辅导场所要求

| 要求 | 说明 |
|------|------|
| **舒适性** | 通风、温度亮度适合、布置整洁、有地毯和软枕、色彩温馨优雅 |
| **功能性** | 配合团体性质和功能设计，如录像、录音设施、纸笔，白板等 |
| **保密性** | 窗户透光不透明，保护隐私，有安全感 |
| **互动性** | 座位排成圆形，房间有足够活动空间 |
| **非干扰性** | 远离厕所或图书馆等公共地方，隔音效果好 |

### 二、团体暖身活动

#### 刮大风（10分钟）

**操作**：成员坐成圆圈，椅子比人数少一。选一人作带领者说"大风吹"，其他人回应"吹什么"，带领者说出某特征，具有该特征的人立刻起立换位置，带领者也找空位坐下。一轮结束必有一人没座位，作为下一轮带领者。

**点评**：打破沉默、消减陌生感，让更多陌生人有接触机会。

### 三、团体准备阶段的工作

#### （一）了解服务对象的潜在需要

通过观察、问卷调查、心理测验等方法辨识心理辅导需求。

#### （二）确定团体的性质、主题与目标

**团体辅导目标分类**：

1. **成长性团体目标**：开发心理潜能，促进人格成长，增进心理健康
2. **训练性团体目标**：敏感性训练，训练处理人际关系，增进社会适应
3. **治疗性团体目标**：重视潜意识问题，缓解症状，恢复心理平衡

#### （三）甄选团体成员

**招募途径**：
- 通过宣传手段，成员自愿报名
- 辅导教师根据咨询情况选择建议报名
- 其他渠道如班主任介绍或转介

**甄选考虑因素**：
- 性别（理想为男女比例平衡）
- 成员背景（彼此熟悉程度）
- 知识能力水平
- 行为表现
- 同质性程度

### 四、团体辅导常用技术

#### 一般辅导沟通技术

| 技术 | 说明 |
|------|------|
| **积极倾听** | 用心理解语言背后的真实含义，设身处地体会感受 |
| **复述** | 以更清晰、准确的语言重新描述信息 |
| **反映** | 关注成员的感觉，通过语言、动作反映成员信息（内容反映+情感反映） |
| **澄清** | 针对混淆不清的信息，使意思更清楚准确 |
| **提问** | 开放式提问（获得更多信息）vs 封闭式提问 |
| **总结** | 概括团体活动过程中发生的事情 |

#### 促进团体互动技术

| 技术 | 说明 |
|------|------|
| **建立关系** | 无条件关注、真诚、同感、尊重，营造温暖安全氛围 |
| **连结** | 将成员表达的观念、行为或情绪相似之处衔接 |
| **催化** | 协助成员增加有意义对话 |
| **阻止** | 防止不适当行为，针对事不对人 |
| **反馈** | 表达对成员具体的反应 |

#### 加强影响的技术

| 技术 | 说明 |
|------|------|
| **解释** | 为成员言行赋予意义，帮助自我了解 |
| **保护** | 确保成员免于不必要的伤害 |
| **支持** | 鼓励成员，增强信心 |
| **自我表露** | 适度分享个人经验、感受和观点 |
| **询问** | 开放式询问（who/what/when/where/why/how） |
| **对质** | 明确指出思想、感觉、行为方面的矛盾和不一致 |
| **示范** | 通过电影、录像、领导者行为提供仿效榜样 |

### 五、团体领导者

#### 领导行为类型

| 类型 | 特点 |
|------|------|
| **关系导向** | 重视人际关系、关怀、支持 |
| **工作导向** | 任务目标导向、重视生产力 |

#### 三种领导风格

| 风格 | 特点 |
|------|------|
| **权威型** | 所有事由领导者决定，成员不知下一步如何做 |
| **民主型** | 鼓励并协助成员完成讨论和决定 |
| **放任型** | 领导者避免参与决定，完全由成员决定 |

#### 领导者角色

- 创造者、领导者、教育者、协调者
- 朋友、促进者、治疗师、鼓励者、评估者

#### 成功领导者特征（Coreys）

1. 良好的意愿，对他人有真诚兴趣
2. 有能力与人分忧共乐
3. 认识并接纳个人能力
4. 有个人独特的辅导风格
5. 愿意开放和冒险
6. 自我尊重和自我欣赏
7. 愿意作典范
8. 愿意冒可能出错的险
9. 具有成长的取向
10. 具有幽默感

## 第二单元 团体辅导之创始篇

### 一、团体创始阶段的特点

| 特点 | 说明 |
|------|------|
| **团体结构松散** | 成员不了解团体要做什么，在未知中摸索 |
| **人际沟通表面化** | 接近与逃避并存，保持"公众形象" |
| **多种情绪体验** | 希望与焦虑并存，疑问众多 |

### 二、创始阶段领导者任务

1. **建立信任感**：自我介绍、态度热忱、说明规则、鼓励表达
2. **示范作用**：为团体确定步调和形成规范
3. **确定团体目标和个人目标**
   - 目标要具体明确
   - 目标要真实可实现
   - 目标可以验证
4. **形成团体基本规则**
5. **明晰团体中的责任**
6. **提供适度的指导**
7. **签订团体契约**

### 三、创始阶段常用活动

| 活动 | 时间 | 操作要点 |
|------|------|----------|
| **松鼠大树** | 10分钟 | 3人一组，大树包围松鼠，喊"松鼠"换位，喊"大树"重组，喊"地震"全部变换 |
| **相识接龙** | 5分钟 | 握手自我介绍，猜拳输的跟随赢家，形成长龙 |
| **无家可归** | 10分钟 | 按数字重新分组，体验游离与归属感 |
| **互助拍拍背** | 5分钟 | 双手搭前方同学背上按摩敲打 |

### 四、团体辅导的功能

| 功能 | 说明 |
|------|------|
| **教育功能** | 培养社会性，学习社会规范，自我教育 |
| **发展功能** | 促进正常人的健康发展，扫除成长障碍 |
| **预防功能** | 预防问题发生，减少心理问题发生概率 |
| **治疗功能** | 减轻心理问题，培养新的能力 |

### 五、团体辅导的原则

1. **专业原则**：专业人员带领，有组织有计划
2. **民主原则**：尊重每位成员，建立安全心理氛围
3. **共同原则**：根据成员共同问题组织
4. **启导原则**：鼓励、启发、引导，助人与自助
5. **发展原则**：用发展变化的观点看待成员问题
6. **综合原则**：综合选取各种有效技术
7. **保密原则**：尊重隐私，但涉及危险时例外

### 六、团体辅导与个别辅导的区别

| 方面 | 团体辅导 | 个别辅导 |
|------|----------|----------|
| **互动程度** | 多向沟通，丰富但深度有限 | 一对一深度心理互动 |
| **助人氛围** | "我助人人，人人助我" | 来访者主要是被帮助对象 |
| **问题类型** | 人际关系方面更有优势 | 心理困扰较大者更适合 |
| **辅导技术** | 更复杂，需要团体特有技术 | 基本技术 |

### 活动1：循环自我介绍

**目的**：引发个人参与团体的兴趣
**时间**：30-50分钟
**操作**：
1. 领导者(第一号)先报姓名，右手边成员(第二号)报姓名并重复第一号姓名
2. 第三号报姓名后重复前两号，依此类推
3. 第二次加上特征介绍，第三次加上个性、班级
