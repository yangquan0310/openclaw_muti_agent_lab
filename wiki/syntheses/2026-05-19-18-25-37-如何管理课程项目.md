# 课程项目

> 多代理协同完成课程从备课到授课评估的全流程。

---

## 多代理协作角色

| 角色 | Agent | 核心技能 | 职责 |
|------|-------|----------|------|
| **项目管理者** | 大管家 | `course-manager` | 创建/整理项目目录、维护 metadata.json、归档旧版本 |
| **课程设计** | 教员 | `course-designer` | 教学目标设定、教学大纲编写、课时安排 |
| **课件制作** | 呈现师 | `lark-slides` | 飞书幻灯片制作、可视化设计、课堂互动设计 |
| **质量审核** | 督导 | `course-reviewer` | 教学大纲审查、课件质量检查、教学效果评估 |

---

## 项目目录结构

```
课程项目/
├── README.md              # 课程总览（人类视角）
├── metadata.json          # 机器可读架构
├── SKILL.md               # 课程级操作手册
├── TODO.md                # 进度看板
├── .agentignore           # 可见性控制文件
│
├── uploads/               # 用户上传的原始材料（教材、大纲、参考资料）
├── syllabus/              # 教学大纲、教案
├── slides/                # 课件（呈现师制作）
├── docs/                  # 定稿（需用户 [APPROVED] 后方可写入）
├── knowledge/             # 课程知识库
│   ├── index.json         # 知识点索引
│   ├── note/              # 结构化笔记
│   ├── review/            # 课程综述/研究现状
│   └── quiz/              # 题库
├── temp/                  # 临时文件和归档草稿
└── .agent/                # 元数据层（隐藏目录）
    ├── events/            # 事件流
    ├── locks/             # 并发控制
    ├── decisions/         # 决策存档
    ├── tasks/             # 任务索引
    └── agents/            # 项目级代理角色规范
        ├── steward.md
        ├── instructor.md
        ├── psychologist.md
        ├── presenter.md
        └── auditor.md
```

---

## 协作流程

```
1. 大管家创建项目目录 → 初始化 metadata.json + README.md
2. 教员设计课程大纲 → syllabus/ 目录
3. 呈现师制作课件 → slides/ 目录
4. 督导审查质量 → 教学大纲 + 课件质量检查
5. 用户确认 → [APPROVED] → 定稿移入 docs/
6. Git 版本控制 → development 分支日常提交，完成整体时合并到 main
```

---

## 四文件契约

| 文件 | 职责 | 维护者 | 必填 |
|------|------|--------|------|
| `README.md` | 项目名片：名称、类型、目的 | 大管家 / 用户 | ✅ |
| `metadata.json` | 机器可读架构 | 大管家 | ✅ |
| `SKILL.md` | 课程设计工作流程、格式规范 | 教员 | ✅ |
| `TODO.md` | 当前任务状态、进度看板 | 大管家 / 用户 | ✅ |

## 备课流水线（v1-v7）

```
v1(需求分析)
   ↓
v2(内容框架) ←── v3(学术前沿补充) 的修改意见
   ↓
v4(课件脚本) ←── v5(审校意见) 的修改意见
   ↓
v6(终稿教案 + 课件编译)
   ↓
v7(Git提交 + 飞书传递 + 收工)
```

| 轮次 | 文件名 | 主导角色 | 产出内容 |
|------|--------|----------|----------|
| v1 | 需求分析 | 教员 | 教学目标、重难点、课时分配 |
| v2 | 内容框架 | 教员 | 知识框架、知识点清单 |
| v3 | 学术前沿补充 | 心理学家 | 前沿文献、研究进展 |
| v4 | 课件脚本 | 呈现师 | 每页内容规划 |
| v5 | 审校意见 | 督导 | 审核脚本与内容框架匹配度 |
| v6 | 终稿教案 + 课件 | 教员/呈现师 | 教案整合 + 课件编译 |
| v7 | Git提交 + 飞书传递 | 大管家 | 提交Git、飞书传递、清理 |

**反馈循环**：v3 向 v2 提意见，v5 向 v4 提意见。

---

## Git 工作流

| 分支 | 用途 | 推送时机 |
|------|------|---------|
| `main` | 稳定版本 | **完成整体任务时** |
| `development` | 日常备课 | **完成阶段子任务时** |

**Commit 格式**：`chXX vX: 简要说明`

---

## 👥 Agent 角色速查

| 角色 | 负责阶段 | 核心产出 | 可操作目录 | 禁止事项 |
|------|----------|----------|-----------|---------|
| **教员** | v1, v2 | 需求分析、内容框架 | `chapters/*/manuscripts/` | 不做课件设计 |
| **心理学家** | v3 | 学术前沿补充 | `chapters/*/knowledge/` | 不写内容框架 |
| **呈现师** | v4, v6 | 课件脚本、编译 pptx | `chapters/*/manuscripts/` | 不写教学目标 |
| **督导** | v5 | 审校意见 | 全局（只读） | 不修改内容 |
| **大管家** | v7 | Git 提交、飞书传递 | 全局 | 不撰写内容 |
