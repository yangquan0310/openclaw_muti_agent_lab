# Baddeley 2000 — 工作记忆的第四组件：情景缓冲器

> **来源**：Trends in Cognitive Sciences, 4(11), 417-423（DOI: 10.1016/S1364-6613(00)01538-2）
> **作者**：Alan D. Baddeley
> **年份**：2000
> **类型**：paper（理论扩展）
> **引用**：高（核心经典）
> **状态**：draft（待老板确认；尚未读全文 PDF）

## 一句话总结

**Baddeley 提出工作记忆的第四组件"情景缓冲器"（Episodic Buffer）——它是一个容量有限的、跨多种编码模态的临时存储系统，负责整合来自语音回路、视空画板和长时记忆的信息，是工作记忆与情景记忆的桥梁。**

## 关键内容

### 工作记忆的多组件模型演化

| 年份 | 组件 | 模型 |
|------|------|------|
| 1968/1974 | 语音回路（Phonological Loop）+ 视空画板（Visuospatial Sketchpad）| 二组件 |
| 1986 | + 中央执行系统（Central Executive）| 三组件 |
| **2000** | **+ 情景缓冲器（Episodic Buffer）** | **四组件** |
| 2007-2011 | + 注意控制系统（episodic buffer 与 LTM 双向连接）| 完整工作记忆模型 |

### 情景缓冲器的特征

| 特征 | 描述 |
|------|------|
| **容量** | 有限（类似短时记忆，但**非固定数量**）|
| **编码** | **跨模态整合**（视觉+听觉+语义+情节）|
| **接口** | 与长时记忆系统（情景+语义）双向连接 |
| **意识** | 可能是意识经验的"统一场" |
| **角色** | **工作记忆与情景记忆的桥梁**——让工作记忆处理"片段"时能调用 LTM 上下文 |

### 三个核心功能

1. **整合多模态信息**（视觉+听觉+语义）
2. **暂时存储整合后的表征**
3. **桥接到长时记忆**（提取相关 LTM 上下文辅助工作）

### 与 Atkinson-Shiffrin 1968 modal model 的对比

| 维度 | Atkinson-Shiffrin 1968 | Baddeley 2000 |
|------|----------------------|---------------|
| 结构 | 单一短时记忆（STM）| **多组件** + 中枢系统 |
| 容量 | 7±2 块 | 组件各自容量 + 整合 |
| LTM 交互 | 单向（STM→LTM 复述）| **双向 + 缓冲器** |
| 编码 | 单一（语音）| **多模态** |
