# Conway & Pleydell-Pearce 2000 — 自传体记忆的自我记忆系统建构理论

> **年份**：2000

## 一句话总结

**自传体记忆通过"自我记忆系统"（Self-Memory System, SMS）组织——SMS 由长时自我（长期目标/自我图式）+ 自传体知识库（情景式+语义式）构成；记忆提取受自我目标（"工作自我"）自上而下调控，与平台式分布的存储自下而上激活相互作用。**

## 关键内容

### 核心框架

| 组件 | 描述 |
|------|------|
| **工作自我（working self）** | 短时执行的当前目标、计划、自我概念激活态 |
| **长时自我（long-term self）** | 稳定的目标、自我图式、价值体系 |
| **自传体知识库（autobiographical knowledge base）** | 三层：lifetime periods → general events → event-specific knowledge |
| **存储平台（storehouse）** | 分布式长期存储 |

### 三层自传体知识

| 层次 | 时间跨度 | 抽象程度 | 例 |
|------|---------|---------|-----|
| **L1: Lifetime periods** | 几年-几十年 | 主题化 | "我在大学时期" |
| **L2: General events** | 数天-数月 | 重复主题 | "我参加某项目的那个学期" |
| **L3: Event-specific knowledge** | 数秒-数小时 | 单一情景 | "2023-05-12 答辩的那一刻" |

### 核心机制

- **自上而下（top-down）**：工作自我的当前目标激活长时自我
- **自下而上（bottom-up）**：当前情境/线索激活平台式存储
- **提取 = 双向匹配**：当目标与情境匹配时，自传体知识被激活
- **特异性原则**：抑郁/焦虑个体特异性降低（提取到 L2 而非 L3）

### 理论意义

1. **统一框架**：整合了 Tulving 情景/语义、Schacter 提取失败、Williams 特异性训练
2. **自我中心性**：自传体记忆不是"过去的事实"而是"为自我服务的目标驱动系统"
3. **预测具体性**：抑郁/焦虑预测特异性降低，可通过特异性训练改善
