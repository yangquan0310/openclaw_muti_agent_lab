# Tulving 1972 — 情景记忆与语义记忆的经典区分

> **来源**：In E. Tulving & W. Donaldson (Eds.), *Organization of Memory* (pp. 381-403). Academic Press, 1972
> **作者**：Endel Tulving
> **年份**：1972
> **类型**：book chapter（理论经典）
> **引用**：5126
> **状态**：draft（待老板确认；Zotero 库中无此条目）

## 一句话总结

**Tulving 提出长时记忆的二分法——情景记忆（episodic memory，时间-地点-个人经验的具体事件）vs. 语义记忆（semantic memory，事实性知识），这一区分成为后续 50 年记忆分类学的奠基。**

## 关键内容

### 二分核心

| 维度 | 情景记忆（Episodic）| 语义记忆（Semantic）|
|------|------------------|------------------|
| **内容** | 特定时空中的个人经验 | 一般事实、概念、词义 |
| **时间** | 特定时刻（"我昨天吃了什么"）| 跨时间的（"巴黎是法国首都"）|
| **参照** | 自传体（self-referential）| 客观事实（objective）|
| **意识** | 时间旅行意识（mental time travel）| 知道感（noetic consciousness）|
| **编码** | 多模态（视觉+听觉+情绪+地点）| 命题/语义网络 |
| **提取** | 重新体验（re-experiencing）| 提取事实（retrieval of fact）|

### Tulving 的核心论断

> "Episodic memory is a recently evolved, late-developing, and early-deteriorating past-oriented memory system, more vulnerable to neuropathology than semantic memory, and it is the category of memory most uniquely human."

### 后续扩展

| 年份 | 扩展 | 关键点 |
|------|------|--------|
| 1983 | Encoding specificity principle | 提取线索匹配编码情境 |
| 1985 | Synaptic theory of memory consolidation | 神经巩固 |
| 2001 | Episodic memory: An overview | 综述 + 神经关联 |
| 2002 | 情景记忆的"自我"成分 | 加入 self-reference |
| 2005 | 意识二分（noetic vs. autonoetic）| 体验性差异 |

### 与博士论文主轴的连接

- **Tulving 区分的情景/语义**——是**自传体记忆**（情景）vs. 一般知识（语义）的基础
- **博士论文主轴**："数字化存储对自传体记忆的影响"——本身就是 Tulving episodic memory 的数字化研究
- 数字化存储**主要影响情景记忆**（照片+聊天记录+视频都是"个人经验的时间-地点信息"）
