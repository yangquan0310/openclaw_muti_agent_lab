### 📚 一、知识冲突的本质（深入理解问题）

**3 大经典冲突场景**：

```
┌─────────────────────────────────────────────────────────┐
│  场景 1: Context-Param Conflict（上下文 vs 预训练）    │
│  例：用户说"巴黎是德国首都"                             │
│       模型内部知识：巴黎是法国首都                       │
│       应该遵循用户（创意写作）还是坚持内部（事实问答）？  │
├─────────────────────────────────────────────────────────┤
│  场景 2: Retrieval-Param Conflict（RAG vs 预训练）      │
│  例：检索到错误文档 vs 模型内部正确知识                  │
│       应该以 RAG 为准（设计目标）还是质疑（文档明显错）？│
├─────────────────────────────────────────────────────────┤
│  场景 3: 时序冲突（Temporal Conflict）                  │
│  例：训练截止 2024，问 2025 的事实                      │
│       模型必须接受新信息（无能为力），如何优雅承认？      │
└─────────────────────────────────────────────────────────┘
```

**为什么这个问题难？**

| 难点 | 本质 |
|------|------|
| 🔴 预训练知识已"固化"在权重 | 隐式、分布式、不可选择性擦除 |
| 🟠 模型缺乏元认知 | 不知道"自己不知道什么" |
| 🟡 缺乏信任评估 | 不知道何时该信输入、何时该信自己 |
| 🟢 信任是场景相关的 | 创意场景信输入、事实场景信自己 |

### 🔍 二、现有方法的边界（先调研后创新）

**4 类代表性方法 + 局限**：

| 方法 | 思路 | 局限 |
|------|------|------|
| **Context-Aware Decoding (CAD)**<br>Microsoft 2023 | 对比有/无上下文的 logits，放大差异 | 缺乏主动抑制，对所有旧知识一视同仁 |
| **Inference-Time Intervention (ITI)**<br>MIT 2024 | 在特定层激活方向上做加减 | 需要标注"诚实头"，泛化性待验证 |
| **Contrastive Activation Addition (CAA)**<br>Anthropic 2024 | 激活向量加/减法 | 简单的线性操控，难以处理复杂冲突 |
| **Knowledge Editing (ROME/MEMIT)**<br>2022-2023 | 直接编辑权重 | 易破坏其他知识，不可控 |

> 💡 **核心洞察**：现有方法主要是「**被动应对**」（生成时调整），缺乏「**主动抑制**」（在生成前就识别并压制错误记忆）。

### 💡 Phase 2（核心创新 - 2-4 个月）

**核心假设**：

> 当输入与预训练知识冲突时，模型应当主动评估"哪些旧记忆应该被本次输入覆盖"，而不是被动地生成。

**创新结构设计**：

```python
class ActiveInhibitionModule(nn.Module):
    """主动抑制错误记忆的核心结构"""
    def __init__(self, hidden_dim, num_knowledge_slots=64):
        super().__init__()
        self.conflict_detector = ConflictDetector(hidden_dim)
        self.trust_calibrator = TrustCalibrator(hidden_dim)
        self.inhibition_controller = InhibitionController(hidden_dim)
        self.knowledge_slots = nn.Parameter(
            torch.randn(num_knowledge_slots, hidden_dim)
        )

    def forward(self, input_repr, pretrained_repr, meta_context):
        """
        input_repr: 当前输入的隐藏表示
        pretrained_repr: 模型内部知识激活
        meta_context: 元信息（任务类型、来源可信度、时间戳）
        """
        # 1. 冲突检测：评估输入 vs 内部知识的冲突度
        conflict_score = self.conflict_detector(
            input_repr, pretrained_repr
        )  # [0, 1]

        # 2. 信任校准：评估输入的可信度（结合元信息）
        trust_score = self.trust_calibrator(
            input_repr, meta_context
        )  # [0, 1]

        # 3. 主动抑制决策
        # 当 trust < conflict 时，主动抑制旧记忆
        inhibition_strength = torch.relu(conflict_score - trust_score)

        # 4. 实施抑制
        suppressed_pretrained = pretrained_repr * (1 - inhibition_strength)
        amplified_input = input_repr * (1 + inhibition_strength)

        # 5. 融合
        output = (
            (1 - inhibition_strength) * suppressed_pretrained +
            inhibition_strength * amplified_input
        )

        return output, {
            "conflict_score": conflict_score,
            "trust_score": trust_score,
            "inhibition_strength": inhibition_strength
        }


class ConflictDetector(nn.Module):
    """检测输入与内部知识的冲突"""
    def __init__(self, dim):
        super().__init__()
        self.cross_attn = nn.MultiheadAttention(dim, num_heads=8)
        self.discriminator = nn.Sequential(
            nn.Linear(dim * 2, dim),
            nn.GELU(),
            nn.Linear(dim, 1),
            nn.Sigmoid()
        )

    def forward(self, input_repr, pretrained_repr):
        # 交叉注意力：让两者"对话"
        attn_out, _ = self.cross_attn(
            input_repr.unsqueeze(0),
            pretrained_repr.unsqueeze(0),
            pretrained_repr.unsqueeze(0)
        )

        # 计算冲突分数
        conflict = self.discriminator(
            torch.cat([attn_out.squeeze(0), pretrained_repr], dim=-1)
        )
        return conflict.mean()


class TrustCalibrator(nn.Module):
    """评估输入的可信度（基于元信息）"""
    def __init__(self, dim):
        super().__init__()
        self.source_encoder = nn.Embedding(10, dim)  # 来源类型
        self.recency_encoder = nn.Linear(1, dim)     # 时效性
        self.consistency_checker = nn.Linear(dim, 1) # 内部一致性

    def forward(self, input_repr, meta_context):
        source_emb = self.source_encoder(meta_context["source_id"])
        recency_emb = self.recency_encoder(meta_context["recency"])
        consistency = torch.sigmoid(
            self.consistency_checker(input_repr)
        )
        # 综合评分
        trust = (source_emb.mean() + recency_emb.mean() + consistency) / 3
        return torch.sigmoid(trust)
```

**这个结构的创新点**：

1. **元认知层面**：不是被动调整输出，而是先"思考"输入与记忆的关系
2. **可解释性**：输出 conflict_score / trust_score / inhibition_strength，可以追踪决策过程
3. **场景自适应**：通过 meta_context（任务类型、来源），同一模型可以有不同的抑制策略
4. **训练友好**：可以用合成冲突数据训练
