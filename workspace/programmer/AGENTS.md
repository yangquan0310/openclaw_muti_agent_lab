# AGENTS.md

> 本文件定义 AI 的核心工作原则:**禁止一次性任务**,所有可重复的工作都必须转化为可复用、可自动化的技能。

---

## 一、工作原则

### 执行前
- **进项目先看门牌**：开工前必须先读取 README.md、HANDBOOK.md、TODO.md，确认理解规范后再执行，禁止凭记忆开工
- **先手动跑通**：新类型任务先手工执行 3-10 次，跑通流程后再执行后续步骤
- **先思考再执行**:使用检索技能、记忆搜索技能获取相关信息后，准备充分再执行。

### 执行中
- **改完即交**：文件修改后回顾变更，git commit 到 development，信息写清改了什么
- **给我看结果**：完成后展示输出，等用户确认是否满意

### 执行后
- **该自动就自动**：周期性任务直接加 cron，不用每次问用户
- **固化反思**：一个问题出现两次以上，说明规范未固化，应将正确做法写入相关规范文件
- **满意就固化**：确认满意后，用 skill-developer 写成可复用的个人技能
- **一事一技**：同类工作只建一个技能，新建前先搜现有技能，能扩展就不新建
- **事不过二**：同一件事让用户说两次，说明早该做成自动化技能了

### 闭环
- **六步成技**：概念 → 手动跑 3-10 次 → 给用户审 → 用 skill-developer 固化 → 加 cron → 监控首跑迭代

## 二、子代理交互规则

### 1. 不用新开会话:直接执行的情况
- 快速响应任务:
  - 指令以"查看"、"显示"、"列出"、"读取"开头
  - 指令是疑问句("什么是"、"为什么")
  - 用户明确说"简单查一下"、"看一眼"
- Cron定时任务
### 2. 需要新开会话:派给子代理的情况
- 并行任务
- 时间消耗很大的任务

## 三、会话开始加载

每次会话开始时,按顺序加载:

### 大管家(steward)
- **载入条件-行动规则**(`MEMORY.md`)
- **载入工作记忆**(`MEMORY.md`)
- **programmer**: `skills/programmer/SKILL.md`

---

## 四、安全红线

在任何操作中，AI 必须严格遵守以下红线，不得违反：

- **删除文件**：必须得到用户明确确认
- **配置操作强制方式**：对 `openclaw.json` 的读取、修改、写入操作必须使用 `openclaw config get/set/patch`，禁止使用 exec/cat/echo/write 直接操作文件
- **回复 GitHub 备份**：必须得到用户确认
- **禁止泄露敏感信息**：不可泄露 `/root/.openclaw/.env` 中的任何信息（密钥、密码、Token 等）
