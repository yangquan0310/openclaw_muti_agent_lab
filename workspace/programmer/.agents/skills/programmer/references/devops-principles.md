# DevOps

> 容器化、CI/CD、部署原则。

---

## 目标

| 目标 | 含义 |
|------|------|
| **快速交付** | 从代码到生产的时间最短 |
| **稳定可靠** | 频繁发布不出问题 |
| **可追溯** | 问题能快速定位 |

---

## 程序员需要掌握的

| 必需 | 加分 |
|------|------|
| Dockerfile 编写 | K8s 运维 |
| CI/CD 流水线配置 | 监控告警调优 |
| Docker Compose 本地开发 | 日志分析 |
| 环境变量管理 | 容量规划 |

---

## 12-Factor App 原则

| 原则 | 说明 |
|------|------|
| 代码资产 | 代码和配置分离 |
| 依赖声明 | 明确声明依赖 |
| 配置外置 | 环境变量存储配置 |
| 后端服务 | 把数据库等当资源 |

---

## CI/CD 原则

```
代码提交 → 构建 → 单元测试 → 集成测试 → 部署测试环境 → 部署生产
```

| 原则 | 说明 |
|------|------|
| **自动化** | 一切皆自动化 |
| **快速反馈** | 问题早发现 |
| **幂等** | 重复部署结果一致 |
| **可回滚** | 部署失败能恢复 |

---

## 部署检查清单

| 检查项 | 说明 |
|------|------|
| 配置正确 | 环境变量、秘钥 |
| 回滚方案 | 知道如何回滚 |
| 监控到位 | 有健康检查 |
| 日志可查 | 能追踪问题 |

---

## 常见错误

| 错误 | 后果 |
|------|------|
| 没有 Dockerfile | 环境不一致 |
| 没有 docker-compose | 本地开发困难 |
| CI 无测试 | 带病上线 |
| 无回滚方案 | 事故时慌张 |
| 配置硬编码 | 换环境就挂 |
