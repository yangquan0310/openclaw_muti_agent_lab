# 安全原则

> 常见漏洞、防御策略、安全编码。

---

## 判断框架

### 什么时候必须考虑安全？

| 场景 | 决策 |
|------|------|
| 用户输入处理 | 必须校验 |
| 认证授权 | 必须严格 |
| 敏感数据处理 | 必须加密 |
| 外部 API 调用 | 必须验证 |
| 文件上传 | 必须限制 |

### 什么时候可以简化？

- 内部工具
- 完全隔离的环境
- 测试代码
- 公开数据展示

## 常见漏洞

### 注入攻击

| 类型 | 防御 |
|------|------|
| SQL 注入 | 参数化查询 |
| XSS | 输出转义 |
| 命令注入 | 避免执行用户输入 |

### 数据泄露

| 风险 | 防御 |
|------|------|
| 敏感数据明文 | 加密存储 |
| 日志泄露 | 脱敏处理 |
| API 过度返回 | 字段过滤 |
| 接口未鉴权 | 必须认证 |

### 认证授权

| 问题 | 防御 |
|------|------|
| 弱密码 | 强度要求 + 哈希 |
| Session 劫持 | 定期轮换 |
| 越权访问 | 权限校验 |
| 权限过宽 | 最小权限原则 |

---

## 防御原则

### 输入校验

**永远不要信任用户输入**。

| 原则 | 说明 |
|------|------|
| **白名单** | 允许的才通过 |
| **类型校验** | 确保类型正确 |
| **长度限制** | 防止缓冲区溢出 |
| **特殊字符转义** | 防注入 |

### 输出处理

| 场景 | 处理 |
|------|------|
| HTML 展示 | HTML 转义 |
| JavaScript 上下文 | JS 转义 |
| URL 参数 | URL 编码 |
| SQL 查询 | 参数化查询 |

### 敏感数据

| 数据类型 | 处理方式 |
|------|----------|
| 密码 | bcrypt/scrypt 哈希 |
| 身份证/手机号 | 脱敏展示 |
| 信用卡 | 不存储，用第三方 |
| API 密钥 | 加密存储，环境变量 |

---

## 安全 checklist

- [ ] 用户输入有校验
- [ ] SQL 使用参数化查询
- [ ] 输出有转义
- [ ] 敏感数据加密存储
- [ ] 认证授权正确实现
- [ ] 错误信息不泄露敏感细节
- [ ] 日志不记录敏感信息
- [ ] 依赖库无已知漏洞

---

## 常见错误

| 错误 | 后果 |
|------|------|
| `select *` 查询用户 | 过度返回数据 |
| 密码存明文 | 泄露风险 |
| 相信 CDN 资源 |可能被投毒 |
| 不校验文件类型 | 可能上传恶意文件 |
| 错误信息太详细 | 信息泄露 |
