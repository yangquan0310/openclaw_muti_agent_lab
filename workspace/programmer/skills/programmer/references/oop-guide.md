# OOP 指南

> 面向对象编程核心概念

---

## 什么是面向对象编程（OOP）

一种程序设计范式，通过"对象"来组织代码。对象 = 数据（属性）+ 行为（方法）。

---

## 四大特性

| 特性 | 说明 |
|------|------|
| **封装** | 把数据和方法装进一个单元（类），隐藏内部细节 |
| **继承** | 子类复用父类的属性和方法 |
| **多态** | 同一接口，不同实现 |
| **抽象** | 简化复杂系统，只暴露必要接口 |

---

## 核心概念

### 类与对象

```python
# 类：蓝图/模板
class Dog:
    def __init__(self, name: str):
        self.name = name  # 属性
    
    def bark(self) -> str:  # 方法
        return f"{self.name} says 汪"

# 对象：类的实例
my_dog = Dog("旺财")
print(my_dog.bark())  # 旺财 says 汪
```

### 消息传递

对象之间通过调用方法相互通信：

```python
# 发送消息
result = my_dog.bark()

# 多个对象协作
class Owner:
    def __init__(self, name: str, pet: Dog):
        self.name = name
        self.pet = pet
    
    def call_pet(self) -> str:
        return f"{self.name} calls {self.pet.name}"
```

---

## 面向对象 vs 面向过程

| 维度 | 面向过程 | 面向对象 |
|------|----------|----------|
| 组织单位 | 函数 | 类/对象 |
| 数据管理 | 分散 | 封装在对象内 |
| 扩展方式 | 修改函数 | 添加新类 |
| 适用场景 | 简单线性任务 | 复杂系统 |

---

## 何时使用 OOP

**适合 OOP**：
- 复杂业务逻辑，多个实体相互作用
- 需要复用和继承
- 需要模拟真实世界实体

**不适合 OOP**：
- 简单脚本，一次性任务
- 纯数学计算，无实体概念
- 函数式更自然的场景
