## 需求分析

### 需求采集

```
用户反馈 → 数据分析 → 竞品分析 → 业务调研 → 老板/战略需求
```

### 需求分类

| 类型 | 说明 | 示例 |
|------|------|------|
| 基础需求 | 必须有的功能 | 用户登录、数据安全 |
| 期望需求 | 用户期望的功能 | 更快的加载速度 |
| 兴奋需求 | 超预期的功能 | AI 智能推荐 |
| 无差别需求 | 有没有无所谓 | 主题皮肤 |

### 需求优先级

**Kano 模型**：

```
               满意度
                  ↑
                  │    ✱ 兴奋需求
                  │   ╱
                  │  ╱
                  │ ╱
                  │╱─────────────→ 必备需求
            ─────┼────────────────→ 线性需求
                  │
                  │    ✱ 无差异需求
                  └─────────────────→
                          不完善度
```

**MoSCoW 优先级**：

| 优先级 | 含义 | 交付要求 |
|--------|------|----------|
| Must | 必须有 | 这次必须交付 |
| Should | 应该有 | 尽量交付 |
| Could | 可以有 | 时间允许才交付 |
| Won't | 这次不做 | 未来考虑 |

## 产品设计

### 用户故事模板

📄 模板位置：[用户故事模板](../assets/templates/用户故事模板.md)

### 功能设计示例

```markdown
## 功能：用户登录

### 概述
支持邮箱/手机号登录，支持第三方 OAuth

### 用户流程
1. 用户输入账号密码
2. 系统验证
3. 登录成功 → 跳转首页
4. 登录失败 → 提示错误

### 需求详情

| 字段 | 类型 | 必填 | 校验 |
|------|------|------|------|
| 邮箱 | string | 是 | 邮箱格式 |
| 密码 | string | 是 | 6-20位 |

### 异常处理

| 场景 | 提示 |
|------|------|
| 账号不存在 | 「该账号未注册」 |
| 密码错误 | 「密码错误，还能N次」 |
| 账号被禁用 | 「账号已被禁用」 |
```

## 常见问题

| 问题 | 解决方案 |
|------|----------|
| 需求变更频繁 | 建立变更流程，评估影响 |
| 需求不清晰 | 多问「为什么」，明确用户场景 |
| 优先级冲突 | 用数据说话，按 MoSCoW 排序 |
