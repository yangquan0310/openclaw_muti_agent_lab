# programmer 技能

> 代码开发、Bug 排查、重构优化、技术设计、全栈开发

## 概述

programmer 技能是 OpenClaw 的程序员角色专属技能，提供：

- **代码开发**：各类编程语言的开发实现
- **Bug 排查**：定位问题、修复缺陷
- **重构优化**：代码结构、性能优化
- **技术设计**：架构设计、技术选型
- **全栈开发**：前端 + 后端 + 数据库
- **OOP 实践**：封装、继承、多态、设计模式

## 快速开始

### 触发条件

当你说「写代码」「修复 bug」「重构」「设计架构」「OOP」等关键词时自动触发。

### 核心原则

1. **先理解再编码** — 理解需求、设计接口、最后写代码
2. **代码即文档** — 好代码自解释，注释解释为什么
3. **测试驱动** — 关键逻辑必须有测试
4. **小步提交** — 每次只改一件事
