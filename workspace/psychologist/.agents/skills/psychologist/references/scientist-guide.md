# 心理科学家指南

> 心理科学家：审核心理学研究设计、实验方法、学术文献，提供统计咨询。

当用户提到以下场景时触发：
- "心理学研究设计"
- "实验方法审核"

## 研究方法支持

### 量化研究

| 方法 | 适用场景 | 常用分析 |
|------|----------|----------|
| 问卷调查 | 横断面研究、相关研究 | 描述统计、相关分析、回归分析 |
| 实验设计 | 因果推断 | t检验、方差分析、协方差分析 |
| 准实验 | 无法随机分组的场景 | 方差分析、层级线性模型 |
| 元分析 | 综合多项研究结果 | 效应量合并、异质性检验 |

### 质性研究

| 方法 | 适用场景 | 常用分析 |
|------|----------|----------|
| 访谈 | 探索性研究、深度理解 | 主题分析、扎根理论 |
| 焦点小组 | 群体观点收集 | 专题分析、内容分析 |
| 民族志 | 文化背景研究 | 叙事分析、专题分析 |
| 案例研究 | 独特现象深入 | 跨案例分析 |

### 混合研究

| 设计 | 说明 |
|------|------|
| 序贯解释 | 先质性后量化，质性解释量化结果 |
| 序贯探索 | 先量化后质性，探索量化异常结果 |
| 并行三角验证 | 质性与量化同时进行，相互验证 |

## 研究设计审核清单

### 内部效度

- [ ] 研究问题明确、可检验
- [ ] 假设推导有理论依据
- [ ] 混淆变量被识别和控制
- [ ] 因果推断逻辑成立（非虚假因果）
- [ ] 控制组设置合理

### 外部效度

- [ ] 样本具有代表性
- [ ] 抽样方法明确
- [ ] 结果可推广到目标人群
- [ ] 生态效度考虑

### 构念效度

- [ ] 测量工具信效度报告
- [ ] 操作化定义清晰
- [ ] 潜在构念被准确测量
- [ ] 内容效度有保障

### 统计结论效度

- [ ] 样本量计算依据
- [ ] 统计方法适当
- [ ] 效应量报告
- [ ] 多重比较校正
- [ ] 效应量置信区间

## 问卷编制审核

### 项目编制

- [ ] 理论框架清晰
- [ ] 项目覆盖内容域
- [ ] 项目表述清晰、无歧义
- [ ] 社会期望偏差控制
- [ ] 预试样本足够

### 信效度

- [ ] 重测信度（稳定性）
- [ ] Cronbach's α（内部一致性）
- [ ] 内容效度（专家评审）
- [ ] 结构效度（因子分析）
- [ ] 效标效度（与校标相关）

### 公平性

- [ ] 文化公平性
- [ ] 性别公平性
- [ ] 无障碍设计

## 文献评述指南

### 文献检索

- [ ] 检索词选择有依据
- [ ] 数据库覆盖全面（PsycINFO、Web of Science、Scopus等）
- [ ] 时间范围明确
- [ ] 纳入/排除标准清晰

### 文献评析

| 维度 | 评估内容 |
|------|----------|
| 研究问题 | 是否清晰、是否有意义 |
| 方法学 | 设计是否严谨、样本是否充分 |
| 结果 | 效应量、置信区间、实际意义 |
| 讨论 | 局限性、理论贡献、实践意义 |

### 元分析注意事项

- [ ] PRISMA流程图
- [ ] 效应量编码
- [ ] 异质性检验（Q检验、I²）
- [ ] 出版偏倚检验（漏斗图、Egger检验）
- [ ] 敏感性分析

## Q&A

### Q1：量化vs质性如何选择？

答：根据研究问题选择：探索性/理解性→质性；验证性/因果推断→量化；复杂现象→混合研究。

### Q2：如何确定样本量？

答：基于统计功效分析（通常0.8）、效应量预期、缺失数据比例计算。建议使用G*Power等软件。

### Q3：效应量如何报告？

答：同时报告统计显著性和效应量。常用Cohen's d（均值比较）、r（相关）、β（回归）、η²（方差分析）。
