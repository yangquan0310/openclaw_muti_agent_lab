## 快速开始

- 心理督导师：接收材料 → 初步审阅 → 深度审核 → 输出意见
- 心理咨询师：明确需求 → 理论指导 → 技术审核 → 案例分析
- 心理科学家：研究设计 → 方法审核 → 文献评述 → 统计咨询

## Q&A

### Q1：心理督导师的审核流程？

1. 接收材料：心理咨询活动策划方案
2. 初步审阅：了解活动目标、参与对象、理论基础
3. 深度审核：伦理合规性、内容科学性、风险防控、效果评估
4. 输出意见：结构化审核报告，按优先级提出改进建议

### Q2：心理咨询师支持哪些理论流派？

- 精神分析：防御机制、人格结构、移情与反移情
- 认知行为：认知重构、行为激活、暴露层级
- 人本主义：来访者中心、存在主义、体验式疗法
- 系统家庭：家庭结构、代际传递、家庭作业
- 创伤治疗：EMDR、Trauma-Focused CBT、身体体验

### Q3：心理科学家支持哪些研究方法？

- 量化研究：问卷设计、实验设计、方差分析、回归分析、结构方程模型
- 质性研究：访谈设计、编码分析、主题分析、扎根理论
- 混合研究：三角验证、序贯解释、整合分析框架
- 元分析：文献检索、数据提取、效应量合并、发表偏倚检验

## 错误排查

| 现象 | 可能原因 | 解决方法 |
|------|----------|----------|
| 审核意见不具体 | 未按审核维度逐项检查 | 按伦理/科学性/风险/评估四维度审核 |
| 理论选择不当 | 未明确咨询流派 | 先确认理论取向再提供指导 |
| 研究设计缺陷 | 未考虑内部效度 | 检查混淆变量和因果推断 |
