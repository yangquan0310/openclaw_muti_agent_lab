# 临床督导师能力标准

> 基于 APA 能力本位督导模型

---

## 一、督导能力模型（Competency-Based Model）

### 1.1 核心能力框架

| 能力领域 | 具体能力 |
|----------|----------|
| 督导关系 | 建立有效的督导联盟 |
| 概念化能力 | 案例概念化与理论应用 |
| 干预能力 | 治疗干预的督导 |
| 评估能力 | 临床评估的督导 |
| 伦理实践 | 伦理决策与保密 |
| 多样性 | 多元文化督导能力 |
| 研究应用 | 循证实践的整合 |

### 1.2 督导胜任力发展阶段

```
初学者 → 中级学习者 → 高级初学者 → 胜任者 → 精通者 → 专家
```

| 阶段 | 特征 | 督导重点 |
|------|------|----------|
| 初学者 | 缺乏经验，需明确指导 | 提供结构化反馈 |
| 中级学习者 | 有一定经验 | 促进反思性实践 |
| 胜任者 | 能独立处理常见案例 | 深化理论整合 |
| 精通者 | 复杂案例处理 | 专业化发展 |

## 二、APA 督导指南（2014/2015）

### 2.1 督导过程的核心要素

1. **督导关系的建立**
   - 明确督导目标和期望
   - 建立信任和开放的沟通氛围
   - 协商督导合约

2. **专业发展评估**
   - 形成性评估（过程性反馈）
   - 总结性评估（阶段性评价）
   - 胜任力等级判定

3. **循证实践整合**
   - 研究证据的应用
   - 临床专业知识
   - 来访者特征与偏好

### 2.2 督导中的伦理考量

- 保密性与报告义务
- 双重关系避免
- 知情同意
- 胜任力边界
- 文化敏感性

## 三、国际督导实践比较

### 3.1 七国督导实践研究要点

| 国家 | 督导模式 | 特色 |
|------|----------|------|
| 美国 | 能力本位 | 强调胜任力评估 |
| 加拿大 | 发展性 | 关注成长阶段 |
| 英国 | 体验性 | 强调自我反思 |
| 澳大利亚 | 整合性 | 多元方法融合 |
| 以色列 | 关系中心 | 督导联盟为核心 |
| 中国 | 培训性 | 以老带新传统 |
| 南非 | 赋能性 | 社区导向 |

## 四、督导互动分析框架

### 4.1 督导中的互动类型

| 互动类别 | 描述 |
|----------|------|
| 教学性互动 | 知识传授、技能培训 |
| 支持性互动 | 情感支持、鼓励肯定 |
| 挑战性互动 | 引发反思、质疑假设 |
| 过程性互动 | 关注情感和人际过程 |

### 4.2 有效督导实践指标

- 督导师-被督导者关系的质量
- 督导中使用的技术（录像、角色扮演、案例讨论）
- 循证实践的整合程度
- 文化胜任力的发展
- 伦理问题的处理能力
