# 循证实践与临床督导

> Evidence-Based Practice in Clinical Supervision

---

## 一、循证实践（EBP）三要素

### 1.1 三支柱模型

```
         研究证据
            △
           / \
          /   \
         /     \
        /   ★   \
       /_________\
   临床专业知识  来访者特征/偏好
```

| 要素 | 说明 |
|------|------|
| 研究证据 | 来自系统的临床研究 |
| 临床专业知识 | 督导者的经验和判断 |
| 来访者特征 | 文化、价值观、偏好 |

### 1.2 EBP 在心理学的应用

**APA 循证实践定义（2006）**：
> 循证实践是通过整合研究证据、临床专业知识以及来访者特征来促进最佳临床结果的心理学实践。

## 二、循证督导框架

### 2.1 督导中的循证整合

| 维度 | 循证内容 |
|------|----------|
| 督导关系 | 基于研究的关系增强策略 |
| 教学策略 | 有效学习的证据 |
| 反馈方法 | 促进行为改变的反馈技术 |
| 评估工具 | 信效度支持的评估方法 |

### 2.2 督导效果的评估指标

- **过程指标**：督导关系的质量、督导中的学习体验
- **结果指标**：来访者进步、被督导者胜任力提升
- **中介变量**：督导联盟、反思性实践

## 三、临床督导的证据基础

### 3.1 有效督导的研究发现

| 研究领域 | 主要发现 |
|----------|----------|
| 督导关系 | 督导联盟质量是有效督导的核心 |
| 反馈技术 | 即时反馈比延迟反馈更有效 |
| 反思实践 | 结构化反思促进专业发展 |
| 视频督导 | 录像回看增强自我觉察 |

### 3.2 督导模式的发展

| 模式 | 代表人物 | 核心观点 |
|------|----------|----------|
| 发展性督导 | Stoltenberg | 沿循证实践路径成长 |
| 胜任力督导 | Falender & Shafranske | 能力为本的评估 |
| 权变督导 | Lases & Goor | 结果导向的反馈 |
| 反思性督导 | Hawkins & Shohet | 聚焦反思过程 |

## 四、证据基础的心理评估

### 4.1 循证心理评估原则

1. **测量有效性**：使用信效度支持的工具
2. **跨情境一致性**：评估结果的稳定性
3. **文化公平性**：评估的文化敏感性
4. **整合性**：多来源信息的综合

### 4.2 评估工具选择标准

| 标准 | 要求 |
|------|------|
| 信度 | 内部一致性、重测信度 |
| 效度 | 结构效度、内容效度 |
| 标准化 | norm参照群体明确 |
| 实用性 | 施测简便、解释清晰 |
