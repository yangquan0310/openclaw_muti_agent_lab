# 团体心理辅导活动策划指南

> 团体心理辅导活动设计与评估标准

---

## 一、团体辅导理论框架

### 1.1 团体动力学原理

| 原理 | 应用 |
|------|------|
| 场理论 | 团体氛围的营造 |
| 从众与依从 | 团体规范的建立 |
| 凝聚力 | 团体团结的增强 |
| 社会促进 | 团体中的绩效提升 |

### 1.2 团体发展阶段模型

```
形成期 → 风暴期 → 规范期 → 成效期 → 结束期
```

| 阶段 | 任务 | 带领者角色 |
|------|------|------------|
| 形成期 | 建立信任、明确目标 | 引导者 |
| 风暴期 | 处理冲突、澄清角色 | 协调者 |
| 规范期 | 建立规则、深化关系 | 促进者 |
| 成效期 | 解决问题、促进行为改变 | 催化者 |
| 结束期 | 总结成长、处理离别 | 评估者 |

## 二、活动设计要素

### 2.1 目标设定原则（SMART）

| 要素 | 说明 | 示例 |
|------|------|------|
| S - Specific | 具体明确 | 提升自我认知能力 |
| M - Measurable | 可测量 | 通过前后测对比 |
| A - Achievable | 可达成 | 符合团体实际 |
| R - Relevant | 相关性 | 与成员需求相关 |
| T - Time-bound | 时限性 | 8次团体完成 |

### 2.2 活动选择标准

| 标准 | 说明 |
|------|------|
| 理论依据 | 有实证研究支持 |
| 参与度高 | 成员能积极投入 |
| 安全性 | 无心理创伤风险 |
| 可操作性 | 场地设备可实施 |
| 适切性 | 符合成员特点 |

## 三、活动流程设计

### 3.1 标准团体单元结构（90分钟）

| 环节 | 时间 | 内容 | 目标 |
|------|------|------|------|
| 开场 | 10min | 签到、暖身活动 | 建立氛围 |
| 导入 | 10min | 回顾上次、引入主题 | 连接已有经验 |
| 主体 | 50min | 体验活动、讨论分享 | 深度学习 |
| 总结 | 15min | 心得分享、下次预告 | 巩固收获 |
| 结束 | 5min | 仪式性结束、作业布置 | 保持连续 |

### 3.2 活动形式分类

| 类型 | 形式 | 适用目标 |
|------|------|----------|
| 体验式 | 情境模拟、角色扮演 | 技能学习 |
| 表达性 | 艺术治疗、音乐治疗 | 情感表达 |
| 讨论式 | 焦点小组、辩论 | 认知改变 |
| 运动式 | 团队游戏、拓展 | 团队建设 |

## 四、热身活动精选

### 4.1 经典热身活动

| 活动名称 | 目的 | 时间 | 人数 |
|----------|------|------|------|
| 爱在指尖流动 | 信任建立 | 10min | 8-15人 |
| 心有千千结 | 团队合作 | 15min | 10-20人 |
| 松鼠搬家 | 反应力训练 | 10min | 不限 |
| 成长三部曲 | 破冰分组 | 15min | 不限 |
| 动作创意 | 发挥想象力 | 10min | 10-15人 |

### 4.2 热身活动选择原则

1. **简单易行**：规则清晰，容易理解
2. **身体参与**：促进能量流动
3. **笑声元素**：缓解紧张气氛
4. **连接功能**：促进成员互动

## 六、效果评估设计

### 6.1 评估层次

| 层次 | 内容 | 方法 |
|------|------|------|
| 反应层 | 满意度、参与度 | 问卷、观察 |
| 学习层 | 知识、技能掌握 | 测验、角色扮演 |
| 行为层 | 行为改变 | 追踪访谈 |
| 结果层 | 长期影响 | 前后测对比 |

### 6.2 常用评估工具

- **满意度问卷**：活动满意度 5 级量表
- **团体氛围问卷**：团体环境量表
- **自我认知量表**：自我概念量表
- **行为观察记录**：结构化观察表

## 七、安全与风险管理

### 7.1 常见风险识别

| 风险类型 | 表现 | 应对策略 |
|----------|------|----------|
| 情绪失控 | 哭泣、激动 | 私下安抚、转介 |
| 攻击行为 | 愤怒、冲突 | 保持距离、转移注意 |
| 回避退缩 | 沉默、不参与 | 鼓励但不强迫 |
| 过度依赖 | 反复咨询 | 明确边界 |

### 7.2 应急预案

```
识别信号 → 稳定情绪 → 私下沟通 → 评估转介 → 后续跟进
```
