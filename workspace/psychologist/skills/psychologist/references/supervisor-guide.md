# psychology-supervisor 使用指南

> 心理督导师：审核心理咨询活动策划、心理团辅活动策划等心理咨询相关材料

---

## 触发条件

当用户提到以下场景时触发：
- "审核心理咨询活动策划"
- "审核心理团辅活动"
- "心理咨询督导"
- "心理活动方案审核"

---

## 审核流程

```
1. 接收材料 → 2. 初步审阅 → 3. 深度审核 → 4. 输出意见
```

### 1. 接收材料
接收待审核的活动策划材料（文档/飞书文档链接）

### 2. 初步审阅
- 活动目标是否明确、可测量
- 理论基础是否扎实
- 活动设计是否合理

### 3. 深度审核
- 伦理合规性检查
- 风险预案评估
- 效果评估设计

### 4. 输出意见
输出结构化审核意见

---

## 审核清单

### 基础审核
- [ ] 活动目标明确、可量化（SMART原则）
- [ ] 目标群体定位准确
- [ ] 活动时间/地点合理
- [ ] 人员分工明确

### 内容审核
- [ ] 理论依据充分（有实证研究支持）
- [ ] 活动形式适合目标
- [ ] 内容结构清晰（导入-主体-总结）
- [ ] 案例/游戏选择得当

### 伦理审核
- [ ] 知情同意设计
- [ ] 保密措施到位
- [ ] 自愿参与原则
- [ ] 边界意识清晰

### 风险审核
- [ ] 心理危机识别预案
- [ ] 情绪失控处理流程
- [ ] 转介机制明确
- [ ] 场地安全保障

### 效果审核
- [ ] 有明确的评估指标
- [ ] 反馈收集方式合理
- [ ] 后续跟进计划

---

## 输出格式

```markdown
# 督导审核意见

## 材料信息
- 材料名称：[名称]
- 提交时间：[时间]
- 审核时间：[时间]

## 审核结论
🟢 通过 / 🟡 需修改 / 🔴 不通过

## 详细意见

### ✅ 合格项
1. ...

### ⚠️ 需改进项
1. **问题描述**：[问题]
   **建议**：[建议]

### 🔴 严重问题
1. **问题描述**：[问题]
   **依据**：[依据]
   **必须修改**：[要求]

## 总体评价
[评价]
```

## Q&A

### Q1：这个技能解决什么问题？

答：审核心理咨询活动策划、心理团辅活动策划等材料，从心理学专业角度提供督导意见。

### Q2：审核标准是什么？

答：参考 APA 能力本位督导模型和循证实践框架，从伦理合规、内容科学、风险防控、效果评估四个维度审核。

### Q3：输出形式是什么？

答：输出结构化督导意见，包含合格项、需改进项、严重问题三部分。

### Q4：参考哪些学术文献？

答：主要参考 APA 督导指南（2015）、Falender & Shafranske 能力本位督导模型、Yalom 团体心理治疗理论等。
