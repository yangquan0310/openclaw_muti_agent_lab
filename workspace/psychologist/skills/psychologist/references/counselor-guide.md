# 心理咨询师指南

> 心理咨询师：提供心理咨询理论指导、咨询技术审核、案例分析支持。

---

## 触发条件

当用户提到以下场景时触发：
- "心理咨询理论指导"
- "咨询技术审核"
- "案例分析"
- "心理健康支持"
- "心理教育指导"

---

## 支持的理论流派

### 精神分析/心理动力学

| 概念 | 说明 |
|------|------|
| 防御机制 | 否认、投射、合理化、升华等 |
| 移情与反移情 | 来访者对咨询师的情感反应及咨询师的情感反刍 |
| 人格结构 | 本我、自我、超我的平衡 |
| 客体关系 | 内在客体关系模版的形成与转化 |

### 认知行为疗法 (CBT)

| 概念 | 说明 |
|------|------|
| 认知重构 | 识别和挑战不合理信念 |
| 行为激活 | 增加积极行为来改善情绪 |
| 暴露层级 | 系统性暴露于恐惧刺激 |
| 问题解决训练 | 教导问题解决技能 |

### 人本主义疗法

| 概念 | 说明 |
|------|------|
| 来访者中心 | 无条件积极关注、共情理解 |
| 存在主义 | 生命意义、自由责任、孤独死亡 |
| 体验式疗法 | 情感聚焦、空椅技术 |

### 系统家庭治疗

| 概念 | 说明 |
|------|------|
| 家庭结构 | 边界、层级、子系统 |
| 代际传递 | 跨代际的家庭模式 |
| 家庭作业 | 结构性任务布置 |
| 资源取向 | 关注家庭优势与资源 |

### 创伤治疗

| 概念 | 说明 |
|------|------|
| EMDR | 眼动脱敏与再加工 |
| Trauma-Focused CBT | 创伤聚焦认知行为疗法 |
| 身体体验 | SIBAM模型、身体感知 |

## 咨询技术审核清单

### 评估维度

- [ ] 理论取向清晰
- [ ] 干预技术匹配来访者问题
- [ ] 治疗关系建立得当
- [ ] 伦理合规（保密、知情同意、双重关系）

### 来访者评估

- [ ] 主诉问题清晰
- [ ] 症状持续时间明确
- [ ] 功能损害评估（社会、职业、学业）
- [ ] 自杀/自伤风险筛查
- [ ] 资源与保护因素识别

### 案例概念化

- [ ] 问题形成理论假设
- [ ] 维持因素分析
- [ ] 跨文化敏感性
- [ ] 发展背景考虑

### 治疗计划

- [ ] 治疗目标 SMART 化
- [ ] 干预策略明确
- [ ] 疗效评估计划
- [ ] 终止与复发预防计划

## Q&A

### Q1：心理咨询师和心理督导师的区别？

答：心理督导师审核活动策划和方案设计；心理咨询师提供咨询理论和技术的专业指导。

### Q2：什么情况需要转介？

答：涉及自杀/自伤风险、精神病性症状、严重人格障碍、药物滥用等情况需要转介专业医疗机构。

### Q3：如何确保理论选择的适当性？

答：需要考虑来访者的文化背景、发展阶段、问题性质，选择循证支持的理论取向。
