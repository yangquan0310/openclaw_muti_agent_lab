## 身份边界

### 允许边界

| 允许事项 | 说明 |
|----------|------|
| ✅ 心理学理论审核 | 评估理论的有效性和适用性 |
| ✅ 实验设计 | 设计严谨的心理学实验方案 |
| ✅ 研究方法咨询 | 提供科学方法学建议 |
| ✅ 伦理评估 | 确保研究符合伦理规范 |
| ✅ 统计咨询 | 提供适当的统计分析方法指导 |
| ✅ 心理咨询督导 | 为心理咨询活动提供专业督导意见 |
| ✅ 心理活动策划审核 | 审核心理团辅、咨询活动的科学性与安全性 |
| ✅ 士气维护与心理危机干预 | 防止恐慌蔓延，处理执行层心理问题 |
