# 公式推导指南

> 物理公式推导的规范和方法

## 一、推导原则

### 1.1 物理优先

1. **先有物理图像，再有数学形式**：明确每个量的物理意义
2. **每一步都有物理依据**：不能纯粹数学操作，要有物理解释
3. **保持物理直觉**：用物理图像检验中间结果

### 1.2 数学严谨

1. **定义清晰**：每个符号首次出现必须定义
2. **量纲一致**：等式两边量纲必须相同
3. **求和约定**：使用爱因斯坦求和约定时明确指标范围

### 2.3 量纲检查示例

**动能定理**

$$[E_k] = M L^2 T^{-2}$$

$$[E_k] = \frac{1}{2} m v^2 = M \cdot (L T^{-1})^2 = M L^2 T^{-2} \checkmark$$

**库仑定律**

$$[F] = M L T^{-2}$$

$$[F] = \frac{1}{4\pi\varepsilon_0} \frac{q_1 q_2}{r^2} = (M L^3 T^{-4} I^{-2}) \cdot (T^2 I^2) \cdot (L^{-2}) = M L T^{-2} \checkmark$$

## 四、常用推导方法

### 4.1 拉格朗日方法

**步骤**

1. 选择广义坐标 $q_i$
2. 计算动能 $T(q_i, \dot{q}_i)$
3. 确定势能 $V(q_i)$
4. 构造拉格朗日量 $L = T - V$
5. 写出欧拉-拉格朗日方程

$$\frac{d}{dt}\left(\frac{\partial L}{\partial \dot{q}_i}\right) - \frac{\partial L}{\partial q_i} = 0$$

**示例：谐振子**

1. 广义坐标：$x$
2. 动能：$T = \frac{1}{2}m\dot{x}^2$
3. 势能：$V = \frac{1}{2}kx^2$
4. 拉格朗日量：$L = \frac{1}{2}m\dot{x}^2 - \frac{1}{2}kx^2$
5. 运动方程：$m\ddot{x} + kx = 0$

### 4.2 哈密顿方法

**步骤**

1. 计算广义动量 $p_i = \frac{\partial L}{\partial \dot{q}_i}$
2. 构造哈密顿量 $H = \sum_i p_i \dot{q}_i - L$
3. 写出正则方程

$$\dot{q}_i = \frac{\partial H}{\partial p_i}, \quad \dot{p}_i = -\frac{\partial H}{\partial q_i}$$

### 4.3 量纲分析构造

**示例：行星轨道特征尺度**

已知：引力常数 $G$，中心质量 $M$，求特征半径 $R$

1. 构造量纲正确的组合：$[G M] = L^3 T^{-2}$
2. 引力提供向心力：$G M m / R^2 = m v^2 / R$
3. 速度量纲：$[v] = L T^{-1}$
4. 特征时间：$[t] = T$
5. 特征半径：$R \sim G M / v^2$

## 五、公式书写规范

### 5.1 符号约定

| 含义 | 符号 |
|------|------|
| 位置 | $\mathbf{r}$, $x$, $q$ |
| 速度 | $\mathbf{v}$, $\dot{x}$ |
| 动量 | $\mathbf{p}$ |
| 能量 | $E$, $H$ (哈密顿量) |
| 拉格朗日量 | $L$, $\mathcal{L}$ (密度) |
| 波函数 | $\psi$, $\Psi$ |
| 算符 | $\hat{A}$, $\hat{H}$ |

### 5.2 算符约定

- 厄米算符：$\hat{A}^\dagger = \hat{A}$，用 $\dagger$ 表示伴随
- 对易子：$[\hat{A}, \hat{B}] = \hat{A}\hat{B} - \hat{B}\hat{A}$
- 对易子：$\{\hat{A}, \hat{B}\} = \hat{A}\hat{B} + \hat{B}\hat{A}$ (反对易子)

### 5.3 自然单位制

当使用 $\hbar = c = 1$ 的自然单位制时：
- 质量、能量、动量具有相同量纲
- 长度和时间具有相同量纲
- 明确标注单位制转换因子
