# 术语与风格规范

> 术语管理与风格必须遵守的规范

---

## 术语管理

### 规则

1. **首次出现定义**：术语首次出现时必须给出定义
2. **全篇统一**：同一概念全程使用同一术语
3. **禁止同义混用**：不要用一个概念的多个同义词

### 术语表示例

| 标准术语 | 可接受变体 | 禁用变体 |
|----------|------------|----------|
| 自传体记忆 | Autobiographical Memory | ~~自传记忆~~ |
| 外部存储 | External Storage | ~~外部记忆~~ |
| 认知卸载 | Cognitive Offloading | ~~认知卸载~~ |

### 自检

全文搜索一个术语——所有出现处是否：
- 拼写一致？
- 含义一致？

## "我们"的使用规则

### 正确用法

"我们"仅限描述操作行为：

```
我们采用定向遗忘范式检验假设。
我们排除了认知负荷的干扰。
```

### 错误用法

"我们"禁止表达观点：

```
~~我们认为这个结论是正确的。~~
~~我们的研究证明了这一理论。~~
```

### 修正方式

表达观点时使用"提示"、"表明"、"可能意味着"：

```
本研究结果表明，外部存储改变了编码格式。
```

## 引文格式

### 规则

1. **格式统一**：全文使用统一的引文格式
2. **消除占位符**：所有引用必须完整（有作者、年份、期刊等）
3. **APA 格式**：推荐使用 APA 7th 格式

### 正确示例

```
(Anderson & Green, 2001)
(Sparrow et al., 2011)
(Hutmacher, 2024)
```

### 错误示例

```
~~[@作者年]~~  ← 占位符
~~(作者, 年份)~~  ← 引用不完整
```
