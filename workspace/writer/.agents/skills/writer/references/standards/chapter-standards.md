# 篇章规范

> 篇章层写作必须遵守的规范

---

## 核心规则

| 规则 | 说明 |
|------|------|
| **引言-主体-结论闭环** | 每章形成"提问题-回答-收束"闭环 |
| **段间有逻辑过渡** | 不是"此外/另外/同时"，而是逻辑衔接 |
| **篇尾回应篇首** | 结论回应对引言提出的问题 |
| **子论点编排** | 各子论点服务于章节核心论证目标 |

---

## 章节闭环

### 规则

每章形成**引言-主体-结论**闭环：
- **引言**：提问题/背景/目标
- **主体**：展开论证/提供证据
- **结论**：回应引言/总结发现

### 自检

读完一章后，能否用一句话概括"这章论证了什么、结论是什么"？
- 如果能 → 闭环合格
- 如果不能 → 检查引言和结论是否对应

---

## 子论点编排

### 规则

确定章节的核心论证目标 → 分解为若干子论点 → 每个子论点分配段落 → 按逻辑顺序排列

### 自检

各段落是否都支撑该章的核心论证目标？
- 有没有段落与章节目标无关？
- 子论点之间是否有逻辑递进？

---

## 过渡句

### 规则

过渡句不是"此外/另外/同时"。应说明前后两段之间的逻辑关系。

### 三种常见场景

| 场景 | 过渡内容 |
|------|----------|
| **综述章** | 上一主题结论 → 与下一主题的理论关联 |
| **实验讨论** | 前一实验发现 → 未解决问题 → 下一实验如何检验 |
| **方法到结果** | 方法概述 → 为什么需要这些分析 → 结果 |

### 实验间桥接三要素

1. **前实验发现**：一句话概括
2. **理论缺口**：未解决的什么问题
3. **下实验预期**：如何检验该问题

---

## 论证闭环

### 规则

- **每章结尾**：回应章首问题
- **全文结尾**：回应核心命题

### 自检

逐章检查：
- 章首提的问题，章尾是否给出了答案？
- 全文引言提的核心问题，总讨论是否给出了回答？

---

## 术语统一

### 规则

全篇使用同一套术语：
- 首次出现时定义
- 后续保持一致

### 自检

全文搜索一个术语——所有出现处是否：
- 拼写一致？
- 含义一致？

---

## 自检清单

| # | 检查项 | 通过标准 |
|---|--------|----------|
| 1 | 章节闭环 | 能一句话概括章节论证目标和结论 |
| 2 | 子论点编排 | 各段都服务于章节核心目标 |
| 3 | 过渡句 | 说明逻辑关系，不是填充词 |
| 4 | 论证闭环 | 章尾回应章首，全文结尾回应核心命题 |
| 5 | 术语统一 | 全文一致 |
