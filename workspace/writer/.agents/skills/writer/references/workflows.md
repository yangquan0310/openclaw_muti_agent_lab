## 快速开始

- 全新写作：明确任务 → 建立论证地图 → 执行写作 → 修改核查 → 终稿交付
- 修改润色：读取原文档 → 建立论证地图 → 创建修改清单 → 汇报确认 → 执行修改
- 校对审核：格式检查 → 引用核查 → 数字校验 → 最终润色

## Q&A

### Q1：全新写作的标准流程？

1. 明确任务：确认文档类型、核心命题
2. 建立论证地图：核心论点→子论点→证据
3. 执行写作：按句子→段落→篇章三层执行
4. 修改核查：术语→引用→结构→逻辑→表达
5. 终稿交付：格式校对、最终润色

### Q2：修改文章必须注意什么？

1. 先读取原文档，建立论证地图
2. 创建修改清单（优先级：术语→引用→结构→逻辑→表达）
3. 必须先汇报修改计划，等确认后再执行
4. 修改后进行终极核查

### Q3：如何区分证据、推测、解读？

- 证据层：必须有引用，可被第三方验证
- 推测层：归因到研究者，用"研究表明"等弱语气
- 解读层：基于本研究，用"我们认为"等本研究主语

## 错误排查

| 现象 | 可能原因 | 解决方法 |
|------|----------|----------|
| 论点不清晰 | 主题句缺失或位置不当 | 补充主题句，放段落首句 |
| 引用缺失 | 重要主张无文献支持 | 补充文献引用 |
| 逻辑跳跃 | 论据与论点脱节 | 增加过渡句或补充论据 |
| 术语不一致 | 同一概念多种表述 | 按术语表统一 |
