# writer（通用写作技能）

> 适用于一切写作任务：学术论文、综述、报告、方案、文档等。

---

## 核心功能

| 功能 | 说明 |
|------|------|
| **学术写作** | 论文撰写、修改、审查 |
| **通用写作** | 报告、方案、说明文档、商务写作 |
| **修改润色** | 结构调整、表达精准化、风格统一 |
| **论证检验** | 证据-推测-解读三层区分 |

---

## 触发条件

当您提到以下场景时触发：
- 任何写作任务：「写」「写作」「撰写」「起草」
- 任何修改任务：「编辑」「修改」「润色」
- 任何文档类型：「论文」「文章」「报告」「文档」「方案」「说明」

---

## 使用方法

1. **明确任务**：告诉我要写什么类型的文档
2. **建立框架**：按写作原则（句子→段落→篇章）组织内容
3. **执行写作**：确保证据-推测-解读三层区分清晰
4. **修改核查**：按修改方法论逐层检查

---

## 写作原则

### 三层写作规范

| 层级 | 核心规则 | 详细参考 |
|------|----------|----------|
| **句子** | 主语为实体名词；动词精确；定义与论述分离 | [sentence-standards.md](references/sentence-standards.md) |
| **段落** | 主题句点明论点；选择明确结构；论点-证据-推理可辨 | [paragraph-standards.md](references/paragraph-standards.md) |
| **篇章** | 引言-主体-结论闭环；段间有逻辑过渡；篇尾回应篇首 | [chapter-standards.md](references/chapter-standards.md) |

### 证据-推测-解读三层区分

| 层 | 定义 | 自检 |
|----|------|------|
| **事实/证据** | 可被第三方验证 + 有数据 + 肯定语气 + 必有引用 | "可被验证吗？" |
| **他人推测** | 其他研究者的解释 + 归因到研究者 + 弱语气 | "是别人的解读吗？" |
| **本研究推测** | 本研究对数据的解释 + "提示/可能/支持" + "本研究"主语 | "是我们自己的解读吗？" |
