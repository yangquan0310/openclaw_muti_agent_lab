# 章节模板

> 通用章节写作模板

---

## 章节结构

```
[章节标题]

[过渡句：衔接上一章节，引出本章内容]

[主题句1]
  - 支持证据/数据
  - 分析说明
[主题句2]
  ...

[本章小结过渡句]
```

---

## 各章节要点

| 章节 | 要点 |
|------|------|
| 引言 | 问题重要性 → 研究现状 → 研究问题 → 假设 |
| 方法 | 被试选择 → 材料 → 程序 → 分析策略 |
| 结果 | 先描述性后推论性，图表编号连续 |
| 讨论 | 结果总结 → 机制解释 → 局限 → 未来 |
