# 学术论文模板

> 通用学术论文结构模板

---

## 标准结构

| 章节 | 内容 |
|------|------|
| 标题 | 研究主题的精确描述 |
| 摘要 | 研究问题、方法、结果、结论（200-300字） |
| 关键词 | 3-5个核心术语 |
| 引言 | 问题背景 → 文献综述 → 研究空白 → 本研究贡献 |
| 方法 | 被试、材料、程序、分析方法 |
| 结果 | 描述性统计 + 推论性统计 |
| 讨论 | 结果解释 → 与前人研究对比 → 局限 → 未来方向 |
| 结论 | 核心发现的简洁总结 |
| 参考文献 | APA 7th 格式 |
