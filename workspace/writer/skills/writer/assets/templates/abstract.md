# 摘要模板

> 标准摘要结构（200-300字）

---

## 结构要素

| 部分 | 内容 | 字数 |
|------|------|------|
| 研究背景 | 问题重要性 + 前人研究空白 | 50字 |
| 研究目的 | 本研究要解决的问题 | 30字 |
| 研究方法 | 被试/范式/分析策略 | 50字 |
| 研究结果 | 核心发现（带统计量） | 60字 |
| 研究结论 | 理论/实践意义 | 30字 |

---

## 示例

```
[研究背景] 外部存储是否影响记忆表征一直存在争议。[研究目的]
本研究探讨照片拍摄对视觉记忆的影响机制。[研究方法] 实验1采用
经典范式考察了... [研究结果] 结果发现..., 交互作用显著..., 
p < .001。[研究结论] 这表明...
```

---

*关键词：3-5个，按重要性排序*
