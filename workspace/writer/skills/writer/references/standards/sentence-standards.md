# 句子规范

> 句子层写作必须遵守的规范

---

## 核心规则

| 规则 | 说明 | 反面案例 |
|------|------|----------|
| **主语为实体名词** | 主语应是具体可指代的名词 | ~~现象~~、~~情况~~、~~因素~~ |
| **动词精确** | 每个动作有明确的动词 | ~~产生~~、~~造成~~、~~导致~~ |
| **定义与论述分离** | 先定义概念，再展开论述 | 定义和论述混在一起 |
| **禁止隐喻/口语** | 学术文本禁止文学化表达 | "记忆的仓库"、"大脑的舞台" |

---

## 主语规则

### 合格主语

| 合格主语 | 说明 |
|----------|------|
| 具体研究者 | Anderson、Green、Smith 等 |
| 具体理论 | 痕迹转化理论、自我记忆系统模型 |
| 具体变量 | 漂移率、反应时、正确率 |
| 具体脑区 | 前额叶、海马、内侧颞叶 |

### 不合格主语

| 不合格主语 | 问题 | 修正方式 |
|------------|------|----------|
| 现象 | 模糊、不可指代 | 替换为具体变量或理论 |
| 情况 | 模糊、不可指代 | 替换为具体行为或状态 |
| 因素 | 模糊、不可指代 | 替换为具体机制或变量 |
| 研究 | 太宽泛 | 指明谁的研究或哪个研究 |

### 自检

```
检查每句话的主语：
- 主语是否具体可指代？
- 主语是否是一个实体名词？
```

---

## 动词规则

### 合格动词

| 合格动词 | 适用场景 |
|----------|----------|
| 发现、揭示、表明 | 报告实证结果 |
| 提出、认为、指出 | 报告理论观点 |
| 检验、验证、考察 | 报告研究操作 |
| 影响、调节、预测 | 报告变量关系 |

### 不合格动词

| 不合格动词 | 问题 | 修正方式 |
|------------|------|----------|
| 产生 | 模糊，不指明如何产生 | 替换为具体机制动词 |
| 造成 | 模糊，不指明因果路径 | 替换为具体因果动词 |
| 导致 | 模糊，不指明中间过程 | 替换为具体过程动词 |
| 造成影响 | 冗余 | 简化为"影响" |

### 自检

```
检查每个动词：
- 动词是否精确？
- 动词是否描述了具体的动作或过程？
```

## 定义与论述分离

### 规则

1. **定义在前**：先给出概念的定义或操作化描述
2. **论述在后**：定义后再展开理论论述或实证报告
3. **禁止混合**：不要在定义句中夹带论述

### 示例

**正确**：
```
主动遗忘是指个体主动抑制特定信息的可提取性。
研究表明，定向遗忘指令可以有效降低目标项目的提取率。
```

**错误**：
```
~~主动遗忘是指个体主动抑制特定信息的可提取性，研究表明...~~
```

### 自检

```
检查每个段落：
- 定义句是否独立成句？
- 定义和论述是否分开？
```

---

## 禁用表达

| 禁用表达 | 修正方式 |
|----------|----------|
| 记忆的仓库 | 记忆存储 |
| 大脑的舞台 | 神经活动 |
| 心灵的窗户 | 直接测量 |
| 至关重要 | 重要/关键 |
| 不可或缺 | 必要/必需 |
| 由此可见 | 因此/结果 |
| 总而言之 | 总之/综上 |

---

## 自检清单

| # | 检查项 | 通过标准 |
|---|--------|----------|
| 1 | 主语为实体名词 | 能指明具体对象 |
| 2 | 动词精确 | 不使用"产生/造成/导致"等模糊词 |
| 3 | 定义与论述分离 | 定义句独立成句 |
| 4 | 无隐喻/口语 | 无文学化表达 |
