# 引用与参考文献指南

> 学术写作中的引用规范

---

## 引用核心理念

> **每个引用都有据可查，每个论点都有源可依**

引用不是装饰，而是论证的基石。没有引用的主张是个人意见，不是学术论证。

---

## 引用类型

### 1. 直接引用 (Direct Quote)

**定义**：逐字复制原文，必须加引号。

**使用场景**：
- 原文表达特别精准，无法改写
- 原文是核心概念定义
- 需要引用原文的权威性

**格式**：
```
短引用（<40词）："直接引用内容" (Author, Year, p. #)。

长引用（≥40词）：
"缩进整段引用内容。
整段引用内容续写。
整段引用内容结尾。" 
    (Author, Year, p. #).
```

**注意事项**：
- [ ] 直接引用必须标注页码
- [ ] 避免过长引用（>1段）
- [ ] 融入句子时注意语法

### 2. 间接引用/转述 (Paraphrase)

**定义**：用自己的话重新表达原意。

**使用场景**：
- 表达原文观点而非原话
- 缩短原文篇幅
- 将多处来源整合

**格式**：
```
(Author, Year)
或
Author (Year) found that ...
```

**注意事项**：
- [ ] 必须真正理解原意才能转述
- [ ] 转述不等于替换同义词
- [ ] 必须标注来源

### 3. 总结 (Summary)

**定义**：概括长篇原文的主要观点。

**使用场景**：
- 综述多篇文献的核心发现
- 简化方法描述
- 概括理论框架

**格式**：
```
(Author1, Year; Author2, Year)
或
Previous research (Author1, Year; Author2, Year) has shown that ...
```

### 4. 二次引用 (Secondary Citation)

**定义**：引用他人文献中的引用（慎用）。

**格式**：
```
"直接引用内容" (qtd. in Author, Year, p. #).
```

**注意事项**：
- [ ] 尽量查找原始文献
- [ ] 仅在无法获取原始文献时使用
- [ ] 需要同时引用原始文献和二次引用来源

## APA 7th 引用格式

### 文内引用 (In-text Citation)

#### 单作者

```
Author (Year) found that ...
或
... (Author, Year).
```

#### 双作者

```
Author1 and Author2 (Year) found that ...
或
... (Author1 & Author2, Year).
```

#### 三作者及以上

首次引用：```
Author1, Author2, and Author3 (Year) found that ...
```
后续引用：```
Author1 et al. (Year) found that ...
```

#### 多篇引用

```
(Author1, Year; Author2, Year; Author3, Year)
```

#### 同作者同年

```
(Author, Yeara, Yearb)
```

### 参考文献列表 (Reference List)

**位置**：文末，单独页

**格式**：
```
Author, A. A., & Author, B. B. (Year). Title of article. 
    Journal Name, Volume(Issue), pages. https://doi.org/xxxxx
```

**示例**：
```
Anderson, M. C., & Green, C. (2001). Suppressing unwanted memories 
    by executive control. Nature, 410(6826), 366-369. 
    https://doi.org/10.1038/35066528
```

## 引用常见错误

### 错误一：引用格式不一致

**错误**：同一段落混用不同格式
```
~~Some researchers found X (Anderson, 2001). 
Other studies showed Y (Smith, 2005)~~
```

**正确**：统一格式
```
Some researchers found X (Anderson, 2001), and other studies 
showed Y (Smith, 2005).
```

### 错误二：引用与参考文献不匹配

**错误**：文内引用了但参考文献列表没有
```
~~(NonExistent, 2025)~~
```

**正确**：确保每条文内引用都有对应参考文献

### 错误三：间接引用不标注来源

**错误**：改写但不标注
```
~~The memory system involves multiple components.~~
```

**正确**：标注来源
```
The memory system involves multiple components (Baddeley, 2000).
```

### 错误四：过度直接引用

**错误**：大段直接引用代替自己分析
```
~~"Long direct quote paragraph..." (Author, Year, p. 1).
"Long direct quote paragraph..." (Author, Year, p. 2).
"Long direct quote paragraph..." (Author, Year, p. 3).~~
```

**正确**：用转述代替大部分引用
```
Author (Year) conducted a series of experiments examining the 
memory system. The findings revealed three key components: 
first, ...; second, ...; third, ... (Author, Year).
```

## 何时引用

### 需要引用

| 场景 | 示例 |
|------|------|
| 引用他人观点 | "Self-referential processing enhances memory" (Kelley, 2002) |
| 引用数据 | "Response time decreased by 200ms" (Study, Year) |
| 引用方法 | "The Think/No-Think paradigm was used" (Anderson & Green, 2001) |
| 引用理论 | "Working memory has limited capacity" (Baddeley, 2000) |

### 不需要引用

| 场景 | 示例 |
|------|------|
| 常识性知识 | Water freezes at 0°C. |
| 我的个人观点 | I believe this approach is better. |
| 非共享性信息 | Data from my unpublished study... |

### 引用判断标准

**问自己**：
1. 这个信息是否普遍接受？（是→不需要引用）
2. 这个信息是否来自某个具体研究？（是→需要引用）
3. 这个观点是否是我的原创？（是→不需要引用）

## 引用质量检查

| # | 检查项 | 通过标准 |
|---|--------|----------|
| 1 | 每条引用都有对应参考文献 | 无孤立引用 |
| 2 | 每条参考文献都有文内引用 | 无未使用参考文献 |
| 3 | 引用格式一致 | 全文同一风格 |
| 4 | 直接引用有页码 | 页码标注完整 |
| 5 | 转述正确 | 非同义词替换 |
| 6 | 避免过度引用 | 直接引用 < 10% 总字数 |

## 本章小结

1. **引用类型**：直接引用（逐字）、转述（改写）、总结（概括）
2. **APA 格式**：文内引用 + 参考文献列表对应
3. **常见错误**：格式不一致、引用不匹配、过度直接引用
4. **引用原则**：每个论点有源可依，每个引用有据可查
