# 写作过程指南

> 从任务理解到终稿的系统化写作流程

---

## 核心理念

> **写作是迭代过程**，**规划 > 写作 > 修改**，**每个阶段有明确目标**

写作不是一次性输出，而是"规划→起草→修改"的迭代循环。

---

## 五阶段流程

```
阶段1: 理解任务 → 阶段2: 规划 → 阶段3: 起草 → 阶段4: 修改 → 阶段5: 校对
```

---

## 阶段1: 理解任务

### 操作步骤

1. **细读任务说明**：理解要求回答什么问题
2. **分解标题**：识别关键词（主题、限制、指令词）
3. **明确边界**：确定涵盖范围和不涵盖范围

### 任务分解检查

```
任务: "分析数字技术对青少年自传体记忆的影响"
│
├── 主题: 数字技术、自传体记忆
├── 限制: 青少年群体
├── 指令词: 分析（评估、比较、解释）
└── 边界: 影响 ≠ 原因、机制 ≠ 现象
```

### 常见指令词

| 指令词 | 要求 |
|--------|------|
| 分析 (Analyze) | 分解为组成部分，解释关系 |
| 评估 (Evaluate) | 判断价值/重要性 |
| 比较 (Compare) | 找出异同点 |
| 解释 (Explain) | 阐明原因/机制 |
| 讨论 (Discuss) | 探索多方面观点 |

---

## 阶段2: 规划

### 操作步骤

1. **广泛阅读**：收集相关文献和资料
2. **做笔记**：记录关键论点、证据、引用
3. **批判思考**：评估来源可靠性、识别论点漏洞
4. **形成论点**：明确你要论证的核心主张

### 规划产出

```
核心论点: [一句话概括]
│
├── 论点1: [支持核心论点的子论点]
│   ├── 证据1
│   └── 证据2
├── 论点2
│   └── ...
└── 潜在反驳
    └── 反驳论证
```

### 结构规划

**引言**：
- 背景（1-2句）
- 研究现状（1-2句）
- 研究缺口（1句）
- 研究目的（1句）
- 核心论点（1句）

**主体**：
- 按逻辑顺序排列论点
- 每论点配 2-3 个证据
- 预期反驳并准备回应

**结论**：
- 总结核心论点
- 阐述理论/实践意义
- 指出研究局限和未来方向

---

## 阶段3: 起草

### 操作步骤

1. **自由写作**：不追求完美，先输出内容
2. **按计划推进**：围绕论点展开
3. **及时记录引用**：避免后续重复查找
4. **允许修改计划**：写作中发现新想法很正常

### 写作顺序

**常见顺序**（推荐）：
```
Methods → Results → Discussion → Introduction → Abstract
```
- 先写熟悉的部分建立信心
- 最后写引言，因为需要全文视野

**可选顺序**：
- 从引言开始（适合有清晰框架的情况）
- 从结论开始（适合想好核心论点的情况）

### 段落写作

**每段结构**：
```
主题句（论点）
  ↓
支撑句1（证据/引用）
  ↓
支撑句2（解释/分析）
  ↓
过渡句（引入下段）
```

---

## 阶段4: 修改

### 操作步骤

1. **搁置草稿**：完成初稿后休息一下
2. **宏观检查**：结构、论证、逻辑
3. **微观检查**：句子、词汇、引用
4. **迭代修改**：每次聚焦一个层面

### 宏观检查清单

| 维度 | 检查项 |
|------|--------|
| **结构** | 引言是否提出问题？主体是否回答问题？结论是否总结并回应引言？ |
| **论证** | 每个论点是否有足够证据支撑？论证链是否完整？ |
| **逻辑** | 段落之间是否有逻辑过渡？是否有逻辑断层？ |
| **一致性** | 术语是否统一？格式是否一致？ |

### 微观检查清单

| 维度 | 检查项 |
|------|--------|
| **句子** | 主语明确？动词精确？定义与论述分离？ |
| **词汇** | 无口语化？无冗余？术语统一？ |
| **引用** | 所有引用完整？格式统一？ |
| **证据** | 证据-推测-解读三层区分？ |

---

## 阶段5: 校对

### 操作步骤

1. **格式校对**：检查引用格式、参考文献格式
2. **语言校对**：拼写、语法、标点
3. **细节检查**：数字格式、缩写一致性
4. **最终检查**：通读全文确认流畅

### 校对清单

| # | 检查项 |
|---|--------|
| 1 | 拼写检查（使用拼写检查器 + 人工检查） |
| 2 | 语法检查（主谓一致、时态一致） |
| 3 | 标点检查（无多余空格、无错误标点） |
| 4 | 引用格式检查（文本引用 + 参考文献列表） |
| 5 | 数字格式检查（<10 用单词，>10 用数字） |
| 6 | 缩写首次定义检查 |
| 7 | 页面格式检查（行距、字号、边距） |

### 校对技巧

1. **倒序检查**：从结论开始读，避免被内容带跑
2. **大声朗读**：朗读时更容易发现不流畅的地方
3. **打印检查**：屏幕阅读容易忽略细节错误
4. **他人校对**：自己看多了容易漏错

## 时间管理

### 建议时间分配

| 阶段 | 建议时间占比 |
|------|--------------|
| 理解任务 | 10% |
| 规划 | 20% |
| 起草 | 40% |
| 修改 | 20% |
| 校对 | 10% |

### 常见错误

| 错误 | 结果 | 修正 |
|------|------|------|
| 不规划直接写 | 结构混乱、论证分散 | 先画框架图 |
| 一次写完不改 | 错误多、质量差 | 留出修改时间 |
| 一直改不改完 | 永远无法提交 | 设截止日期 |
| 不校对就提交 | 细节错误影响评分 | 严格执行校对清单 |

---

## 本章小结

1. **写作是迭代**：规划→起草→修改→校对，循环往复
2. **规划先行**：好的规划减少后期大幅修改
3. **分阶段检查**：宏观（结构）→微观（细节）
4. **留出时间**：校对是最后防线，不能省
