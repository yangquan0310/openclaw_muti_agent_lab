# 证据-推测-解读三层区分

> 每句学术文本必须归入以下三层之一

---

## 三层定义

| 层 | 定义 | 语气 | 引用 | 自检问题 |
|----|------|------|------|----------|
| **事实/证据** | 可被第三方验证的实证结果 | 肯定 | 必须有 | "可被验证吗？" |
| **他人推测** | 其他研究者对证据的解释 | 弱 | 归因到研究者 | "是别人的解读吗？" |
| **本研究推测** | 本研究对自数据的解释 | 弱 | 本研究主语 | "是我们自己的解读吗？" |

---

## 第一层：事实/证据

### 定义

可被第三方验证的实证结果：
- 有具体数据（均值、标准差、p值等）
- 肯定语气
- 必有引用

### 示例

```
Anderson和Green(2001)采用Think/No-Think范式发现，
重复抑制后目标词提取率(M = 23%, SD = 8%)显著低于基线(M = 71%, SD = 12%)。
```

### 自检

- 是否有具体数据？
- 语气是否肯定？
- 是否标注来源？

---

## 第二层：他人推测

### 定义

其他研究者对证据的解释：
- 归因到具体研究者
- 弱语气（"认为"、"提出"、"表明"）
- 不直接说"本研究"

### 示例

```
研究者由此提出，主动遗忘依赖于前额叶-海马通路的抑制性调控
（Anderson & Green, 2001）。
```

### 自检

- 是否归因到具体研究者？
- 语气是否弱化？
- 是否标注来源？

---

## 第三层：本研究推测

### 定义

本研究对自数据的解释：
- 弱语气（"提示"、"表明"、"可能意味着"）
- "本研究"作主语
- 不用"证明"、"确认"

### 示例

```
这一交互作用提示，外部存储可能改变了编码阶段的加工格式。
```

### 自检

- 语气是否弱化（提示/可能/表明）？
- 主语是否是"本研究"？
- 是否移除了"证明"、"确认"等强语气词？

---

## 常见混淆与纠错

### 混淆一：证据层用了推测语气

**错误**：
```
~~实验发现，外部存储可能降低了记忆细节。~~
```

**正确**：
```
实验发现，外部存储条件下记忆细节显著减少(M = 3.2, SD = 1.1)
（内部组：M = 5.8, SD = 1.3）。
```

### 混淆二：推测层没有归因到研究者

**错误**：
```
~~这表明记忆受到外部存储的影响。~~
```

**正确**：
```
研究者认为，外部存储改变了记忆的编码策略（Wang et al., 2023）。
```

### 混淆三：本研究推测用了强语气

**错误**：
```
~~本研究证明了外部存储改变记忆表征格式。~~
```

**正确**：
```
本研究发现，外部存储条件下表征相似性下降减缓，
提示编码格式发生了系统性偏移。
```

## 自检流水线

逐句检查，每句话必须能归入三层之一：

```
第1步：这句话有具体数据吗？
  ├─ 有 → 证据层（检查：肯定语气 + 必有引用）
  └─ 无 → 第2步

第2步：这是别人的解读吗？
  ├─ 是 → 他人推测层（检查：归因到研究者 + 弱语气）
  └─ 否 → 第3步

第3步：这是我们对自数据的解读吗？
  ├─ 是 → 本研究推测层（检查：弱语气 + "提示/可能/表明"）
  └─ 否 → 需要重写
```

---

## 本章小结

1. **证据层**：有数据 + 肯定语气 + 必有引用
2. **他人推测**：归因到研究者 + 弱语气
3. **本研究推测**：弱语气 + "提示/可能/表明"
