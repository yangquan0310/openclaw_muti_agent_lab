# 编辑与润色指南

> 修改润色的系统化方法

---

## 核心理念

> **好文章是改出来的**，**每次修改聚焦一个层面**

初稿不是终稿。写作是迭代过程，需要多轮修改才能产出精品。

---

## 修改层次

### 第一层：结构修改（最高优先级）

**问题**：整体论证结构是否清晰？

**检查**：
- [ ] 引言是否提出研究问题？
- [ ] 主体是否回答研究问题？
- [ ] 结论是否总结并回应引言？
- [ ] 各段落是否服务于核心论点？
- [ ] 段落顺序是否逻辑递进？

### 第二层：论证修改

**问题**：每个论点是否有足够证据支撑？

**检查**：
- [ ] 每个论点都有证据支撑吗？
- [ ] 证据是否相关且充分？
- [ ] 论证链是否完整（论点→证据→推理）？
- [ ] 是否回应了潜在反驳？

### 第三层：段落修改

**问题**：每个段落是否有效论证一个观点？

**检查**：
- [ ] 有明确的主题句吗？
- [ ] 主题句是否统领全段？
- [ ] 各句是否角色清晰（论点/证据/推理）？
- [ ] 是否有逻辑过渡？

### 第四层：句子修改

**问题**：每个句子是否清晰有效？

**检查**：
- [ ] 主语是否明确？
- [ ] 动词是否精确？
- [ ] 是否删除冗余？
- [ ] 定义与论述是否分离？

### 第五层：语言润色

**问题**：语言是否流畅准确？

**检查**：
- [ ] 是否有拼写错误？
- [ ] 标点是否正确？
- [ ] 术语是否统一？
- [ ] 格式是否一致？

## 修改流程

### 1. 搁置初稿

**规则**：完成初稿后，至少搁置 24 小时。

**原因**：近距离写作会"当局者迷"，需要时间拉开心理距离。

### 2. 宏观到微观

**顺序**：
```
结构 → 论证 → 段落 → 句子 → 语言
```

**原因**：修改低优先级问题可能导致需要重写高优先级内容。

### 3. 每次只改一个层面

**方法**：使用"寻找-替换"策略
- 第一轮：专门找结构问题
- 第二轮：专门找论证问题
- 第三轮：专门找语言问题

### 4. 打印修改

**方法**：打印出来用笔标注

**原因**：屏幕阅读会漏掉更多错误。

## 句子润色

### 常见问题与修正

#### 问题一：主语模糊

**问题**：
```
~~It is believed that memory can be enhanced.~~
```

**修正**：
```
Researchers believe that memory can be enhanced (Author, Year).
或
Memory can be enhanced (Author, Year).
```

#### 问题二：动词模糊

**问题**：
```
~~The experiment produced changes in memory.~~
```

**修正**：
```
The experiment increased/decreased memory performance.
```

#### 问题三：冗余表达

**问题**：
```
~~In this particular situation, the specific results showed that...~~
```

**修正**：
```
Results showed that...
```

#### 问题四：定义与论述混合

**问题**：
```
~~Working memory, which refers to the system responsible for 
temporarily storing and manipulating information...~~
```

**修正**：
```
Working memory is the system responsible for temporarily storing 
and manipulating information (Baddeley, 2000). This system...
```

### 润色检查清单

| # | 检查项 |
|---|--------|
| 1 | 每句有明确主语（非"It/There is"开头） |
| 2 | 动词精确（无"产生/造成/导致"类模糊词） |
| 3 | 无冗余词（删除显而易见的说明） |
| 4 | 定义独立成句 |
| 5 | 术语全文统一 |
| 6 | 无填充词（此外、另外、同时） |

## 段落润色

### 检查主题句

**方法**：遮住其他句子，只读首句

**问题**：
```
~~[首句] Memory is important.
[续句] Many studies have examined memory...
[续句] The experiment included 100 participants...
[续句] Results showed...
~~
```

**问题**：首句太宽泛，无法统领全段。

**修正**：
```
[首句] Working memory capacity predicts academic performance.
[续句] Supporting evidence comes from...
[续句] For example, ...
[续句] These findings suggest...
~~
```

### 检查结构一致性

**问题**：段落结构混乱

```
~~论点1内容
证据1
论点2内容
证据2
论点1补充
证据3
~~
```

**修正**：
```
论点1内容
证据1
证据2
证据3
论点2内容
证据4
证据5
~~
```

### 检查过渡

**方法**：删掉过渡句，看逻辑是否断裂

**问题**：
```
~~[段1末] ... findings suggest X.
[段2首] Moreover, Y was observed.~~
```

**问题**：段1的结论和段2的开头没有逻辑关联。

**修正**：
```
[段1末] ... findings suggest X.
[段2首] This pattern of results can be explained by Y.
~~
```

## 语言润色

### 删除冗余

| 冗余表达 | 简洁表达 |
|----------|----------|
| in order to | to |
| due to the fact that | because |
| at this point in time | now |
| in the event that | if |
| a large number of | many |
| is able to | can |

### 避免重复

**问题**：
```
~~The study investigated memory. Another study examined 
memory in children. Memory performance was measured.~~
```

**修正**：
```
The study investigated memory. Another study examined 
this construct in children. Performance was measured.
```

### 统一术语

**问题**：
```
~~The participants completed the memory task. Then they 
filled out the cognitive test. Finally, they performed 
the recollection assessment.~~
```

**修正**：
```
The participants completed the memory task. Then they 
completed the cognitive test. Finally, they performed 
the recollection assessment.
```

## 最终校对

### 格式校对

| 检查项 | 标准 |
|--------|------|
| 行距 | 双倍行距 |
| 字号 | 12号 |
| 边距 | 2.54cm (1 inch) |
| 页码 | 右上角 |

### 引用校对

| 检查项 | 标准 |
|--------|------|
| 文内引用 | 与参考文献列表匹配 |
| 参考文献格式 | 全文一致 |
| 直接引用 | 有页码 |

### 数字校对

| 检查项 | 标准 |
|--------|------|
| <10 | 用单词（one, two） |
| ≥10 | 用数字（10, 20） |
| 单位 | 用数字（5 cm） |
| 句首 | 避免用数字开头 |

## 本章小结

1. **从宏观到微观**：先改结构，后改语言
2. **每次只改一个层面**：避免混乱
3. **搁置后修改**：拉开心理距离
4. **多轮迭代**：初稿到终稿需要多轮修改
