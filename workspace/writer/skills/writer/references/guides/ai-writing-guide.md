# AI写作去痕指南

> 如何让写作听起来不像AI-generated

---

## 核心理念

> **好文章是改出来的**，**每次修改聚焦一个层面**

AI检测器分析的是**统计结构、概率流、节奏**，不是词汇替换。同义词交换效果有限（通常只能降低5-15个百分点），但结构性改写效果显著。

---

## AI写作的四大信号

| 信号 | AI特征 | 修正方向 |
|------|--------|----------|
| **Perplexity（困惑度）** | 每个词的选择过于可预测 | 引入意外、独特的选择 |
| **Burstiness（突发性）** | 句子长度统一（中长句） | 变化句长：短句+长句交替 |
| **结构可预测性** | 每个段落都是：主题句→支持点→总结 | 打破公式化结构 |
| **过渡词密度** | 过度使用 moreover/furthermore/in conclusion | 减少或替换为自然连接 |

---

## 修正技术

### 1. 变化句长（最重要）

**问题**：每句话长度差不多，没有节奏感。

**修正**：
- 找3个连续相似长度的句子
- 把其中一个缩短到6-8词
- 把另一个扩展加从句或限定语

**示例**：
```
Before: 
The correlation held across all subgroups. 
Over both time points. 
Regardless of which control variable we included.

After:
The correlation held. 
Across all subgroups, over both time points, and regardless of which control 
variable we included, the relationship between X and Y remained significant.
```

### 2. 重写引言和结论

**问题**：引言像教科书模板，结论像总结。

**引言修正**：
- 用具体主张或张力开头（不是定义）
- 用具体场景或观察开头
- 用直接问题开头

**结论修正**：
- 不要总结，要推论
- 指出一个悬而未决的问题
- 用平实语言说下一步（不用"综上所述"）

### 3. 删除可预测的过渡词

**需要删除的词**：
- Furthermore, Moreover, Additionally
- It is important to note that
- In conclusion, In summary
- This highlights the importance of
- As mentioned above

**替换方式**：
| 删除 | 替换 |
|------|------|
| Furthermore | 删掉或用具体逻辑替代 |
| Moreover | Building on this |
| Additionally | A related issue is |
| In conclusion | （直接写推论） |

### 4. 打破段落均匀性

**问题**：每个段落长度几乎相同。

**修正**：
- 有的段落2句话
- 有的段落6-7句话
- 让内容决定长度，不是模式

### 5. 替换AI词汇

**高频AI词汇**（过度使用）：
- Additionally, Aligned with, Crucial
- Delve, Emphasizing, Enduring
- Enhance, Fostering, Garner
- Highlight (verb), Interplay
- Intricate, Key (adjective)
- Landscape (abstract), Pivotal
- Showcase, Tapestry, Testament
- Underscore (verb), Valuable, Vibrant

**替换**：
| AI词汇 | 自然表达 |
|--------|----------|
| crucial | important / key |
| enhance | improve / increase |
| Furthermore | 删掉或"Also" |
| Moreover | 删掉或"Also" |
| significant | notable / marked |
| demonstrates | shows / reveals |

### 6. 替换"is/are"替代词

**问题**：LLM用 elaborate constructions 替代简单系词。

| 过度使用 | 简单表达 |
|----------|----------|
| serves as | is |
| stands as | is |
| represents | is |
| boasts | has |
| features | has |

### 7. 使用第一人称（适度）

**适用场景**：
- 方法描述
- 分析解释
- 结论反思

**示例**：
```
I selected these three case studies because...
After reviewing 47 articles, I noticed...
My initial hypothesis was wrong — the data showed...
```

### 8. 加人称声音

**不要只报告，要评论**：
```
Before: The experiment produced interesting results.
After: I genuinely don't know how to feel about this. 3 million lines of code, 
generated while the humans presumably slept.
```

## 学术写作特殊注意

### 必须保留的内容

| 内容 | 原因 |
|------|------|
| 引用 | 改写可能扭曲归属 |
| 数据和日期 | 小错误破坏可信度 |
| 论点意义 | 论证漂移削弱防御性 |
| 专业词汇 | 过度简化损害专业性 |

### 引用句处理

包含引用的句子需要**小心处理**：
1. 隔离引用句
2. 只修改周围结构
3. 保持被引用命题稳定

## 自检清单

| # | 检查项 | 通过标准 |
|---|--------|----------|
| 1 | 句长变化 | 有长句也有短句 |
| 2 | 无AI过渡词 | Furthermore/Moreover ≤2次 |
| 3 | 引言非模板 | 有具体主张，不是定义开头 |
| 4 | 结论非总结 | 有推论，不是"In conclusion" |
| 5 | 段落长度变化 | 不是每段都相同长度 |
| 6 | 无AI高频词 | 无 crucial/enhance/fostering 等 |
| 7 | 无过度em dash | 搜索"—" ≤1次 |

---

## 本章小结

1. **结构性改写 > 词汇替换**：改变句长、段落结构、节奏
2. **变化产生人性**：长句短句交替、结构变化
3. **内容决定形式**：不要模板化，让内容自然流动
4. **保留核心**：引用、数据、专业术语必须保留
