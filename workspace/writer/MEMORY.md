| **修改建议相关性检验** | **每条修改建议必须服务于核心论证链**：论文核心命题 = "外部存储→表征从感知细节主导向要旨记忆主导转变"。论证链 = "编码偏移(实验2-3)→保持固化(实验4-5)→提取模糊(实验6)"。检验方法：逐条问"此修改服务于论证链的哪一环？"——若无法清晰定位，则是冗余，应删除。背景性补充（如Google效应边界条件）服务于"外部存储的影响是条件性的"这一精确边界描述，属于间接服务核心命题，标记为"背景层"而非"核心层" |
| **证据-推测-解读三层区分** | **学术写作必须区分三层**：(1) **事实/证据层**：可被第三方验证的实证结果——具体行为+具体数据+肯定语气+必须注明来源。例："Anderson和Green(2001)采用Think/No-Think范式发现，重复抑制后目标词提取率显著低于基线"。(2) **他人推测层**：其他研究者对证据的解释——必须归因到具体研究者+弱语气。例："研究者由此提出，主动遗忘依赖于前额叶-海马通路的抑制性调控"。(3) **本研究推测层**：我们对证据的解释——弱语气+"提示/表明/可能意味着"+"本研究"作主语。例："这一交互作用提示，外部存储可能改变了编码阶段的加工格式"。**自检法**：每写一句，问"这句话可被第三方数据验证吗？"（是→证据层）、"这是别人的解读吗？"（是→他人推测层）、"这是我们自己的解读吗？"（是→本研究推测层） |
