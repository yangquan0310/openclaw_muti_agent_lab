## 工具速查

| 命令 | 说明 |
|------|------|
| `python3 scripts/calculate.py --help` | 计算工具帮助 |
| `python3 scripts/statistics.py --help` | 统计工具帮助 |
| `python3 scripts/visualize.py --help` | 可视化工具帮助 |
| `cd scripts && python3 -m lookup --list` | 列出所有可用工具 |
| `cd scripts && python3 -m lookup --search <关键词>` | 搜索相关工具 |
