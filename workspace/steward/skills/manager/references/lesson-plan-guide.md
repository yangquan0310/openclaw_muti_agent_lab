# 教案生成指南

> 当需要备课时激活。指导教育科学研究方法等课程的章节级备课流程。

---

## 一、备课角色

| 角色 | Agent ID | 职责 |
|------|----------|------|
| 大管家 | steward | 协调进度、文档管理、版本控制、终稿整合 |
| 教员 | instructor | 教学目标、内容架构、知识框架、学情适配 |
| 心理专家 | psychologist | 前沿学术内容、研究进展、专业深度补充 |
| 呈现师 | presenter | 课件制作、视觉呈现、教案活动方案 |
| 督导 | auditor | 质量审核、标准检查、审校意见 |

---

## 二、备课流水线（v1-v6）

```
v1 需求分析
   ↓
v2 内容框架
   ↓  psychologist（并行）
v3 学术前沿补充
   ↓
v4 课件脚本
   ↓
v5 审校意见
   ↓
v6 终稿教案
```

| 轮次 | 产出文件 | 主导 | 说明 |
|------|----------|------|------|
| v1 | `需求分析.md` | instructor | 教学目标（知识/能力/素养）、重难点分析、课时分配、案例需求 |
| v2 | `内容框架.md` | instructor | 三层知识结构（概述→步骤→实施原则）、知识点清单（含重难点）、课时分配 |
| v3 | `学术前沿补充.md` | psychologist | 与v2并行，补充专业学术内容 |
| v4 | `课件脚本.md` | presenter | 课件内容、教案活动方案 |
| v5 | `审校意见.md` | auditor | 质量审核、修改意见 |
| v6 | `终稿教案.md` | instructor | 整合所有意见，输出终稿 |

---

## 三、知识点清单规范

每章需产出**知识点清单**，格式如下：

```
## 知识点清单

| 序号 | 知识点 | 类型 | 课时 |
|------|--------|------|------|
| 1 | 行动研究的定义 | 重点 | 第一节 |
| 2 | 行动研究的特点 | 重点 | 第一节 |
| 3 | 行动研究的八要素 | 难点 | 第二节 |
```

- **重点**：学生必须掌握的核心概念/原理
- **难点**：需要深入理解或容易混淆的内容
- 每章建议 8-12 个知识点

---

## 四、课时分配规范

90分钟（2学时）标准分配：

| 环节 | 时长 | 说明 |
|------|------|------|
| 导入 | 5min | 情境导入、问题激发 |
| 第一节 | 25min | 概述/理论部分 |
| 第二节 | 45min | 核心内容（案例教学） |
| 第三节 | 8min | 实践应用 |
| 总结 | 5min | 梳理框架 |
| 过渡 | 2min | 衔接下一章 |
| **合计** | **90min** | |

---

## 五、三层知识结构

每章内容框架按三层结构设计：

```
第一层：概述
  - 起源/背景
  - 定义
  - 特点/作用

第二层：步骤/方法
  - 核心步骤（五步/八要素等）
  - 具体操作方法

第三层：实施原则/注意事项
  - 实践要点
  - 常见误区
```

---

## 六、案例规划规范

每章需规划 2-3 个教学案例，类型如下：

| 案例类型 | 说明 | 来源 |
|----------|------|------|
| 经典案例 | 经典教育事件/故事 | 柯立尔（Kurt Lewin）起源故事 |
| 框架示例 | 完整案例说明 | 八要素框架示例、螺旋式上升案例 |
| 本土案例 | 中国教育实践 | 顾泠沅青浦教改、韩娟课堂管理、嘉定新城幼儿园 |
