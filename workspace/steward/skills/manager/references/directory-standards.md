# 目录规范

> 所有项目必须遵守的目录结构标准

---

## 一、规范的本质

目录结构是项目的**骨骼**。固定的目录结构让任何人都能快速定位文件：uploads/ 放原始文件，manuscripts/ 放手稿，temp/ 放临时文件。

混乱的目录结构是项目管理失控的第一个信号。

---

## 二、根目录契约文件

以下文件**必须位于项目根目录**，不可移动：

| 文件 | 用途 |
|------|------|
| README.md | 项目总览 |
| HANDBOOK.md | 操作手册 |
| TODO.md | 任务看板 |
| metadata.json | 机器可读配置 |

---

## 三、标准目录

| 目录 | 用途 | 说明 |
|------|------|------|
| uploads/ | 原始上传文件 | 保留原始版本 |
| manuscripts/ | 手稿/草稿 | 论文/文档草稿 |
| temp/ | 临时文件 | 缓存、中间产物 |
| .agents/ | 代理配置 | 角色规范、代理配置 |
| archive/ | 历史归档 | 旧版本归档（课程项目） |

---

## 四、论文专用目录

| 目录 | 用途 |
|------|------|
| knowledge/ | 论文知识库 |
| retrieval_report/ | 检索报告 |

---

## 五、课程专用目录

| 目录 | 用途 |
|------|------|
| syllabus/ | 教学大纲 |
| chapters/ | 章节内容 |
| shared/ | 共享资源 |

---

## 六、程序专用目录

| 目录 | 用途 |
|------|------|
| src/ | 源代码 |
| test/ | 测试代码 |
| docs/ | 文档 |
| logs/ | 日志 |

---

## 七、命名规则

| 对象 | 规则 | 示例 |
|------|------|------|
| 目录名 | 小写、单词间横线或无 | uploads/, manuscripts/ |
| 草稿文件 | {标题}_R{n}.md | 论文标题_R0.md |
| 版本归档 | {原名}_v{n}.md | 教案_v1.md |

---

## 八、保护文件

以下文件**不可移动、不可删除**：

- README.md
- HANDBOOK.md
- TODO.md
- metadata.json
- .agentignore
- .gitignore
