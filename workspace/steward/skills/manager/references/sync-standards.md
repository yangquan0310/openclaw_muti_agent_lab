# TODO 与 task 工具同步规则

---

## 一、同步的本质

TODO.md 是人可读的任务看板，task 工具是机器可执行的任务管理。两者同步是为了让大管家和子代理都能看到任务进度。

大管家用 TODO.md 追踪整体进度，子代理用 task 工具管理具体执行。

---

## 二、状态对应

| task 工具状态 | TODO 标记 | 说明 |
|--------------|-------------|------|
| draft | ⬜ 待开始 | 刚创建 |
| active | 🔄 进行中 | 执行中 |
| completed | ✅ 已完成 | 任务完成 |

---

## 三、同步时序

| 场景 | TODO.md | task 工具 |
|------|---------|-----------|
| 大管家领取时 | 添加主任务行（⬜ 待开始） | task.create |
| 子代理领取时 | 添加子任务行（⬜ 待开始） | task.create |
| 执行中 | 标记进度（🔄 进行中） | task.advance |
| 完成时 | 标记 ✅ | task.update → event.report → task.archive |

---

## 四、任务树结构（大管家视角）

大管家只定**约束目标/输入/产出**，子任务由子代理自己拆解：

```markdown
- [ ] **主任务**（大管家负责）
  - 📄 约束目标：...
  - 📄 输入：...
  - 📄 产出：...
  - 📄 子代理分配：子代理 A、子代理 B
  - （子任务由子代理自己拆解，大管家不写死）
```

子代理收到后自己拆解：

```markdown
- [ ] **子任务 A**（子代理 A 负责）
  - 📄 约束目标：继承主任务约束
  - 📄 输入：...
  - 📄 产出：...
  - [ ] 子任务细分（子代理自己决定）
```

---

## 五、目录结构

```
项目/
├── .agents
│   ├── tasks/              # 主任务 JSON
│   │   └── {runId}.json
│   └── events/            # 事件报告
│       └── {日期}/
│           └── {runId}.md
├── README.md
├── HANDBOOK.md
└── TODO.md
```

---

## 六、关键参数

| 参数 | 说明 |
|------|------|
| `baseDir` | 必须指定项目路径，任务/事件生成到 `项目/.agents` |
| `runId` | 任务唯一ID |
| `status` | 任务状态：draft → active → completed |
