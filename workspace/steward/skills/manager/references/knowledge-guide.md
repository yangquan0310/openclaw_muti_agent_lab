# 知识库管理指南

> 当用户提到"知识库管理"、"wiki维护"、"整理wiki"、"清理知识库"、"检查wiki结构"时，使用本指南。

---

## 一、知识库的本质

知识库是实验室的**长期记忆**。大管家的职责是维护知识库的结构清晰、内容时效、链接可用。

知识库不创造知识，只管理知识的存储和检索。

---

## 二、维护对象

**Wiki 知识库**：`/root/.openclaw/wiki/`

---

## 三、Wiki 结构

| 目录 | 内容 |
|------|------|
| concepts/ | 概念定义和解释 |
| entities/ | 实体人物/项目/工具 |
| references/ | 参考资料 |
| syntheses/ | 综合分析报告 |

## 五、核心机制

```
领取 wiki 维护任务
    ↓
阅读项目 README/SKILL 了解规范
    ↓
明确约束目标
    ↓
完善 TODO 任务树
    ↓
执行清理/更新/同步
```

## 七、整理流程

**第一步：检查结构**。查看各目录文件分布，识别需要清理的内容。

**第二步：识别问题**。找出重复文件、断裂链接、过时内容。

**第三步：执行清理**。删除冗余文件、修复链接、更新过时内容。

**第四步：验证结果**。运行 `wiki_lint` 检查结构完整性。

**第五步：汇报用户**。输出整理摘要。
