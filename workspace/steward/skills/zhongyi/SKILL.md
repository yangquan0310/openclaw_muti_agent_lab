# 中医辨证技能（TCM Diagnosis）v1.0.0

> 给定一段 **文本症状描述**，输出 **八纲辨证** + **候选证型 + 主方** + **免责声明**。
> 严格限制：**仅学习参考，不构成医疗建议**（免责见内联输出）。

## 核心能力

1. **八纲判定**：自动判定表里 / 寒热 / 虚实 / 阴阳四个维度
2. **证型候选**：基于规则匹配的 Top-N 证型候选（带 score、舌、脉、教材出处）
3. **方剂映射**：候选证型对应的主方（含方名、主治、组成药物、教材出处）
4. **免责声明**：强制随每次输出附带
5. **可解释性**：每个候选证型均提供 scored 关键词命中与冲突惩罚明细

## 适用场景

| ✅ 用 | ❌ 不要用 |
|------|---------|
| 学习 / 教学场景的辨证训练 | 真实患者在线问诊（须执业中医师面诊） |
| 把"症状文本 → 候选证型"自动化，作为研究 / 数据流水线的一环 | 需要影像、舌诊图像的诊断（本技能 v1 不支持图片识别） |
| 用 --self-test 校验知识库的覆盖度 | 急症、危重症（请拨 120） |
| **作为 LLM 的 retrieval 起点**：用本技能筛候选，再用 LLM 综合判断 | 立法 / 合规 / 医保 / 工伤认定 |
| 给上层 Agent 提供"中医参考"答复的事实基础 | 自己开方 / 配药 / 煎服（必须执业中医师处方） |

## 调用方式

### CLI（推荐）

```bash
# 人类可读
tcm diagnose --symptoms "头痛3天，怕冷，无汗，鼻塞流清涕，咳嗽痰白稀，脉浮紧"

# JSON 输出（便于上层 Agent 调用）
tcm diagnose --symptoms "..." --json

# 调整候选条数
tcm diagnose --symptoms "..." --top-n 5

# 跑全部内置用例
tcm self-test

# 跑指定用例（按标题模糊匹配）
tcm self-test 风寒感冒

# 列证型 / 列方剂
tcm list
tcm list-formulas

# 版本
tcm version
```

### Python 模块

```python
from tcm_diagnose import TCMDiagnose
from pathlib import Path

diag = TCMDiagnose(skill_root=Path(__file__).resolve().parent.parent)
result = diag.diagnose("发热重，咽痛口渴，舌尖红苔薄黄，脉浮数", top_n=3)
# result["zheng_candidates"][0]["id"] → "Z-外感-002"
# result["formulas"][0]["name"]       → "银翘散"
```

## 算法要点

| 步骤 | 做法 |
|------|------|
| 1. 特征提取 | 把症状文本按寒 / 热 / 汗 / 舌 / 脉 / 部位等维度标注 (extract_features) |
| 2. 八纲判定 | 基于特征 → 表里、寒热、虚实、阴阳 |
| 3. 候选打分 | 对 32 证型逐一比对关键词（high=5, mid=2, low=1） |
| 4. 八纲冲突惩罚 | 用户明显为寒 → 对 热证 大幅扣分（-3），反之亦然 |
| 5. 取 Top-N | score > 0 优先；全部 ≤ 0 时 fallback 取前 3 |
| 6. 方剂映射 | 每个候选找 main_formula_id |
| 7. 附带 disclaimer | 不可省略 |

## 已知边界与限制

1. **纯文本输入**：缺少望/闻/切 → 不可能完成可靠辨证。
2. **规则匹配覆盖率有限**：症状组合多、长尾，v1 用关键词匹配，存在漏检。
3. **未实现 LLM 综合排序**：v1 保持纯规则，输出可解释；v2 可叠加 LLM rerank（hook 已预留 `_meta.scoring_method`）。
4. **未实现舌诊 / 脉象图片识别**：v2 才考虑接入。
5. **未实现舌脉细粒度特征**：仅"舌淡红"/"舌红"等高层描述区分。
6. **评分未做归一化**：score 范围受关键词权重影响，**绝对值不应被理解为概率**。
