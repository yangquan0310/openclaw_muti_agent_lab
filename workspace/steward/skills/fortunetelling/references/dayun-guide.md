# 大运流年分析指南

> 本指南详细介绍大运和流年的排盘方法与运势分析。

---

## 一、大运基础

### 1.1 什么是大运

大运是八字命理中的时间分析体系，每一步大运持续**十年**，由一对干支组成。

**大运的核心作用**：
- 大运代表人生的"大趋势"、"大环境"
- 大运好则十年总体顺利，大运差则十年多波折
- 大运是命局运势的"展开方式"

### 1.2 起运年龄计算

**基本规则**：

| 出生年干 | 男命 | 女命 |
|----------|------|------|
| 阳干(甲丙戊庚壬) | 顺行 | 逆行 |
| 阴干(乙丁己辛癸) | 逆行 | 顺行 |

**计算方法**：
1. 计算从出生日到下一个节气的天数
2. 用天数除以3，得出起运岁数
3. 余数按1天=4个月，1时辰=10天折算

**节气歌诀**：
```
立春惊蛰并清明，谷雨立夏小满临；
芒种夏至和小暑，立秋白露秋分迎；
寒露霜降立冬节，大雪冬至小寒行。
```

### 1.3 大运排法

从月柱干支出发，按顺逆规则依次排列：

**顺行排法**（阳男阴女）：
```
月柱 → 下一支 → 下下一支...
例：月柱甲辰 → 乙巳 → 丙午 → 丁未 → ...
```

**逆行排法**（阴男阳女）：
```
月柱 → 上一支 → 上一支...
例：月柱甲辰 → 癸卯 → 壬寅 → 辛丑 → ...
```

## 二、大运分析

### 2.1 大运十神

大运天干与日主的关系决定十神：

| 十神 | 与日主关系 | 运势倾向 |
|------|-----------|----------|
| 比肩 | 同我同性 | 独立竞争 |
| 劫财 | 同我异性 | 争夺合作 |
| 食神 | 我生同性 | 创造力泄 |
| 伤官 | 我生异性 | 才华展现 |
| 偏财 | 我克同性 | 财运波动 |
| 正财 | 我克异性 | 稳定收入 |
| 七杀 | 克我同性 | 压力挑战 |
| 正官 | 克我异性 | 事业升迁 |
| 偏印 | 生我同性 | 变动转型 |
| 正印 | 生我异性 | 学业贵人 |

### 2.2 大运吉凶判断

**判断标准**：大运干支是否有利于命局用神

**大运与命局配合**：

| 组合 | 吉凶 | 说明 |
|------|------|------|
| 大运生助用神 | 大吉 | 运势上升，事事顺遂 |
| 大运克制忌神 | 中吉 | 虽有波折，但终能化解 |
| 大运泄用神 | 小凶 | 运势受阻，需要努力 |
| 大运克制用神 | 大凶 | 运势低迷，需谨慎行事 |
| 大运生助忌神 | 小凶 | 小人当道，是非较多 |

### 2.3 大运与五行

| 大运五行 | 对日主作用 | 运势倾向 |
|----------|-----------|----------|
| 生助日主 | 身旺则凶，身弱则吉 | 得助力或压力 |
| 泄日主 | 身旺则吉，身弱则凶 | 才华展现或精力消耗 |
| 克日主 | 身旺则吉，身弱则凶 | 压力转化为动力或健康受损 |
| 被日主克 | 身旺则凶，身弱则吉 | 得财或破财 |

## 三、流年分析

### 3.1 什么是流年

流年即当年的年干支，每年变化一次。

**流年的作用**：
- 流年管一年吉凶
- 流年与大运叠加决定当年运势
- 流年是命运的"微观显现"

### 3.2 流年与太岁

太岁即流年地支，是当年值年的神煞：

| 地支 | 太岁 | 特点 |
|------|------|------|
| 子 | 鼠太岁 | 壬子年 |
| 丑 | 牛太岁 | 癸丑年 |
| ... | ... | ... |

### 3.3 犯太岁

**犯太岁的类型**：

| 类型 | 含义 | 化解方式 |
|------|------|----------|
| 值太岁 | 本命年 | 穿戴红色、放置太岁符 |
| 冲太岁 | 地支相冲 | 保守行事、避免变动 |
| 刑太岁 | 地支相刑 | 低调行事、注意是非 |
| 害太岁 | 地支相害 | 防范小人、谨慎投资 |

**地支相冲**：
```
子午冲、丑未冲、寅申冲、卯酉冲、辰戌冲、巳亥冲
```

### 3.4 流年吉凶判断

**流年与大运的关系**：

| 大运/流年 | 均为用神 | 均为忌神 | 相反 |
|-----------|----------|----------|------|
| 运势 | 最佳 | 最差 | 平缓 |
| 特点 | 心想事成 | 困难重重 | 有波折但可度过 |

## 四、大运交脱

### 4.1 什么是交运

交运是大运交替的年份，通常是人生变动期。

**交运年份特点**：
- 身心波动较大
- 可能发生重大人生变化
- 工作、感情、健康可能发生转折

**交运前后的处理**：
- 交运年前后1-2年需特别注意
- 避免做重大决定
- 保持低调，积蓄能量

### 4.2 交运时间计算

交运时间 = 起运岁数 + 交运序号 × 10

## 五、综合分析

### 5.1 分析步骤

1. **确定用神忌神**：根据命局判断
2. **分析大运趋势**：大运干支与命局的关系
3. **叠加流年**：流年对大运的影响
4. **判断吉凶**：综合评估运势高低

### 5.2 十年大运总览模板

```
大运1: XX岁-XX岁  干支  五行  十神
大运2: XX岁-XX岁  干支  五行  十神
...
```

### 5.3 各年龄段大运特点

| 年龄段 | 大运特点 | 重点关注 |
|--------|----------|----------|
| 0-18岁 | 学业成长 | 教育、学习环境 |
| 18-30岁 | 事业起步 | 职业选择、感情 |
| 30-45岁 | 事业巅峰 | 成就、婚姻、子女 |
| 45-60岁 | 事业稳定 | 健康、家庭 |
| 60岁后 | 晚年运势 | 养老、子女 |
