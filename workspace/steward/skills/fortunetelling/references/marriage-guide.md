# 婚姻情感分析指南

> 本指南介绍如何通过八字分析学业、事业、婚姻等方面的运势。

---

## 一、婚姻基础

### 1.1 配偶星

| 性别 | 配偶星 | 说明 |
|------|--------|------|
| 男命 | 正财、偏财 | 正财为正妻，偏财为妾/情人 |
| 女命 | 正官、七杀 | 正官为正夫，七杀为偏夫/情人 |

### 1.2 婚姻宫

**日支为婚姻宫**，代表配偶的住所和婚姻状态：

| 日支 | 婚姻宫特点 |
|------|------------|
| 子 | 智慧灵活，需水相配 |
| 丑 | 务实稳定，宜土金相配 |
| 寅 | 积极进取，宜水木相配 |
| 卯 | 温和美丽，宜水火相配 |
| 辰 | 变动较大，宜金水相配 |
| 巳 | 热情神秘，宜土金相配 |
| 午 | 热情冲动，宜水相配 |
| 未 | 温和善良，宜火土相配 |
| 申 | 机智变通，宜水金相配 |
| 酉 | 精确完美，宜土水相配 |
| 戌 | 忠诚守护，宜金水相配 |
| 亥 | 纯真包容，宜木火相配 |

## 三、婚姻运势

### 3.1 各阶段婚姻运势

| 阶段 | 年龄 | 影响因素 |
|------|------|----------|
| 早婚 | 20-25岁 | 大运流年配偶星动向 |
| 中婚 | 25-35岁 | 正缘出现时机 |
| 晚婚 | 35岁以上 | 姻缘缘分 |

### 3.2 结婚最佳年份

**判断标准**：
1. 流年与大运形成合配偶星
2. 流年冲动婚姻宫
3. 桃花星旺盛

**有利组合**：
- 流年与命局合成配偶星
- 大运、流年与婚姻宫相合
- 桃花星与配偶星相配

### 3.3 婚姻不顺的标志

| 标志 | 说明 |
|------|------|
| 配偶星受制 | 正财/正官被克破 |
| 婚姻宫被冲 | 日支被流年冲动 |
| 官杀混杂 | 女命官杀并见 |
| 财星过旺 | 男命财多身弱 |
| 伤官见官 | 女命伤官克官 |

## 四、姻缘预测

### 4.1 正缘特征

**正缘到来时的迹象**：
- 大运与命局配偶星相合
- 流年冲动婚姻宫
- 桃花星与配偶星并临
- 身边出现稳定的追求者

### 4.2 配偶属相

根据命局推算有利属相：

| 日主 | 有利属相 | 不利属相 |
|------|----------|----------|
| 木日主 | 水、鼠、猪 | 金、猴、鸡 |
| 火日主 | 木、虎、兔 | 水、鼠、猪 |
| 土日主 | 火、蛇、马 | 木、虎、兔 |
| 金日主 | 土、牛、龙、狗、羊 | 火、蛇、马 |
| 水日主 | 金、猴、鸡、申、酉 | 土、牛、龙、狗、羊 |

### 4.3 年龄差

| 命局特点 | 理想年龄差 |
|----------|------------|
| 日主强旺 | 相差较大 |
| 日主衰弱 | 相差较小 |
| 配偶星旺 | 年龄相近 |
| 配偶星弱 | 年龄差距大 |

## 五、婚姻宫分析

### 5.1 宫位与六亲

| 宫位 | 代表 | 说明 |
|------|------|------|
| 年柱 | 祖辈/长辈 | 早婚受祖辈影响 |
| 月柱 | 父母/同辈 | 中婚与原生家庭相关 |
| 日柱 | 自己/配偶 | 婚姻的核心宫位 |
| 时柱 | 子女/晚年 | 晚婚或再婚 |

### 5.2 婚姻宫被影响

**婚姻宫被冲**：
- 婚姻变动
- 配偶健康问题
- 分离或离婚

**婚姻宫被合**：
- 第三者介入
- 婚姻稳定
- 配偶有外遇

**婚姻宫被刑**：
- 婚姻是非
- 配偶脾气暴躁
- 感情争执

## 六、婚姻建议

### 6.1 增进感情

| 十神 | 建议 |
|------|------|
| 正财/正官 | 稳定关系，注重家庭 |
| 偏财/七杀 | 保持新鲜感，适度空间 |
| 印星 | 加强沟通，增进了解 |
| 食伤 | 表达情感，创造浪漫 |

### 6.2 化解不利

| 问题 | 化解方法 |
|------|----------|
| 配偶星受克 | 流年规避克配偶星的方位 |
| 婚姻宫被冲 | 结婚选吉日，注意调理 |
| 桃花过旺 | 收敛自身行为，远离是非 |
