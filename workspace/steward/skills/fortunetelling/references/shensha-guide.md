# 神煞指南

> 本指南介绍八字命理中的重要神煞，包括吉神和凶煞。

---

## 一、神煞概述

### 1.1 什么是神煞

神煞是八字命理中代表特殊吉凶的星曜标记，是对八字基本分析的重要补充。

**神煞的作用**：
- 辅助判断命局吉凶
- 补充十神分析的不足
- 提供更精细的命运信息

### 1.2 神煞分类

| 类别 | 说明 | 代表神煞 |
|------|------|----------|
| 吉神 | 带来福气、贵人 | 天乙贵人、文昌、太极贵人 |
| 凶煞 | 带来灾祸、小人 | 羊刃、驿马、空亡 |

## 四、神煞应用

### 4.1 神煞配合

| 组合 | 效果 |
|------|------|
| 吉神+吉神 | 大吉 |
| 吉神+凶煞 | 有吉有凶 |
| 凶煞+凶煞 | 大凶 |
| 吉神被制 | 吉事不成 |
| 凶煞被制 | 凶事化解 |

### 4.2 神煞与宫位

| 宫位 | 吉神作用 | 凶煞作用 |
|------|----------|----------|
| 年柱 | 祖辈荫庇 | 祖业凋零 |
| 月柱 | 父母帮助 | 父母多灾 |
| 日柱 | 自身吉利 | 自身多难 |
| 时柱 | 子女发达 | 子女不顺 |

### 4.3 神煞化解

| 凶煞 | 化解方法 |
|------|----------|
| 羊刃 | 佩戴印星饰品 |
| 桃花 | 摆放植物 |
| 驿马 | 稳定发展 |
| 空亡 | 佩戴贵人饰品 |
| 灾煞 | 注意安全 |
