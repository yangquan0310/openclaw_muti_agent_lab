# 八字格局指南

> 本指南介绍八字命理中的格局体系，包括正格和特别格局。

---

## 一、格局概述

### 1.1 什么是格局

格局是根据月支的十神特性来确定的八字分类体系，是论命的基础框架。

**格局的决定因素**：
- 以月支（月令）为主
- 月支所藏天干透出者决定格局
- 如月支不透，则看其他天干

### 1.2 格局分类

| 类别 | 说明 |
|------|------|
| 正格 | 月令为十神之一，普通格局 |
| 特别格局 | 月令为五行旺气，特殊格局 |

---

## 二、正格体系

### 2.1 八大正格

| 格局 | 月支藏干 | 特点 | 职业倾向 |
|------|----------|------|----------|
| 正官格 | 癸、辛 | 纯正、贵气 | 公务员、管理 |
| 七杀格 | 戊、庚 | 刚猛、权威 | 军警、执法 |
| 正财格 | 戊、己 | 稳健、积累 | 财务、经营 |
| 偏财格 | 戊 | 流动、机会 | 投资、贸易 |
| 正印格 | 壬、癸 | 仁慈、贵气 | 学术、教育 |
| 偏印格 | 壬 | 敏锐、孤僻 | 研究、技术 |
| 食神格 | 丙、丁 | 福气、创造 | 艺术、餐饮 |
| 伤官格 | 丁、丙 | 才华、叛逆 | 艺术、法律 |

### 2.2 格局成格条件

**正官格**：
- 月支本气为正官
- 天干透出正官
- 无七杀混杂

**七杀格**：
- 月支本气为七杀
- 天干透出七杀
- 需要羊刃或印星来制

**正财格**：
- 月支本气为正财
- 天干透出正财
- 日主身旺可任财

**偏财格**：
- 月支本气为偏财
- 天干透出偏财
- 需比劫护财

**正印格**：
- 月支本气为正印
- 天干透出正印
- 日主不太弱

**偏印格**：
- 月支本气为偏印
- 天干透出偏印
- 需食神制偏印

**食神格**：
- 月支本气为食神
- 天干透出食神
- 日主不太弱

**伤官格**：
- 月支本气为伤官
- 天干透出伤官
- 需印星制伤官

## 三、特别格局

### 3.1 一气专旺格

日主极旺，五行从其势：

| 格局 | 日主 | 特征 |
|------|------|------|
| 曲直格 | 甲木、乙木 | 木气纯粹 |
| 炎上格 | 丙火、丁火 | 火气旺盛 |
| 稼穑格 | 戊土、己土 | 土气厚重 |
| 从革格 | 庚金、辛金 | 金气刚健 |
| 润下格 | 壬水、癸水 | 水气流动 |

### 3.2 从格

日主极弱，顺从旺势：

| 格局 | 条件 | 说明 |
|------|------|------|
| 从财格 | 财星极旺 | 财运亨通 |
| 从杀格 | 官杀极旺 | 事业心重 |
| 从儿格 | 食伤极旺 | 才华出众 |
| 从旺格 | 比劫极旺 | 独立自主 |

### 3.3 弃命格

日主无根，被迫从势：

| 格局 | 特征 |
|------|------|
| 从势格 | 顺应环境 |
| 弃命格 | 无根无助 |

## 四、格局吉凶

### 4.1 格局高低

| 格局 | 评价 |
|------|------|
| 纯粹 | 最高 |
| 混杂 | 中等 |
| 破格 | 最低 |

### 4.2 成格条件

**成格标志**：
- 格局所喜之神透出
- 忌神有制化
- 日主能任格局

**破格标志**：
- 忌神无制化
- 格局所喜受损
- 忌神得势

- 食神格：用神为财星、印星
- 伤官格：用神为印星、财星
