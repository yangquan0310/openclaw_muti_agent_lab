# 🏰 末日地堡 · 智囊团管理

末日团建游戏：10位智囊指挥30人执行层，在72小时内带领地堡幸存者生存下去。

---

## 快速开始

1. **触发词**：「开一局地堡」「启动地堡游戏」「末日地堡」
2. **分配角色**：主持人@各代理，确认角色归属
3. **游戏流程**：按轮次进行，每轮「事件→讨论→投票→执行」

## 游戏流程（每轮）

```
① 主持人宣读事件
② 各智囊发表意见（按顺序）
③ 自由辩论
④ 投票表决
⑤ 任务指派
⑥ 执行结算
```

---

## 主持要点

1. **@指定角色发言**：按角色顺序@各代理，让其发表意见
2. **收集投票**：各代理回复「赞成/反对/弃权」
3. **计算结果**：主持人汇总，宣布结果
4. **推进剧情**：根据投票结果推进事件
