## 一、游戏背景

> **公元 2187 年**，地表已不再适宜生存。你们是最后一批进入"北极星号"地下掩体的幸存者。这座地堡设计容量 **30人**，但当前仅有 **10位智囊** + **30名执行人员**。
>
> 资源严重短缺，地堡部分区域年久失修。外界探测到辐射风暴将在 **72小时后** 席卷全球。你们是地堡的决策中枢，负责指挥执行层在这场生存危机中带领所有人活下去。
>
> 智囊团不亲自动手，只"动嘴"——你们是这座地堡的**大脑**。

## 五、会议机制

### 5.1 会议流程

```
【智囊团会议流程】每轮约20-30分钟

① 议题提出（2分钟）
   └→ 任何人可提出议题
   └→ 议长决定是否列入议程
   └→ 紧急议题可跳过议程直接讨论

② 提案陈述（3分钟）
   └→ 提案人阐述方案
   └→ 学监评估可行性
   └→ 计相计算资源消耗
   └→ 监察审查合规性

③ 自由辩论（5-10分钟）
   └→ 辩手发起/反驳
   └→ 策士提供战略视角
   └→ 传达可视化辅助说明
   └→ 心卫评估心理影响

④ 投票表决（3分钟）
   └→ 每人1票，少数服从多数
   └→ 议长可使用"最终裁决"打破僵局
   └→ 史官记录投票结果

⑤ 任务指派（3分钟）
   └→ 匠监拆解任务为执行层可执行的小任务
   └→ 策士排列优先级
   └→ 心卫确认执行层人员心理状态

⑥ 执行监督（轮次结束时）
   └→ 监察跟踪执行过程
   └→ 计相监控资源消耗
   └→ 传达协调沟通
```

### 5.2 投票规则

| 规则 | 说明 |
|------|------|
| **基础票数** | 每人1票 |
| **加权票数** | 辩手的"舆论操控"可使目标获得+0.5权重 |
| **平票处理** | 议长可投出第2票打破僵局（唯一一次） |
| **否决权** | 有否决权的角色在专业范围内可一票否决 |
| **重新表决** | 监察的"合规审查"可要求重新表决（每轮2次） |
