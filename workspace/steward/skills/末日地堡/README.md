# 🏰 末日地堡 · 智囊团管理

> 团建游戏技能 · 在飞书群聊中开展末日生存决策游戏

---

## 快速开始

1. **触发词**：「开一局地堡」「启动地堡游戏」「末日地堡」
2. **分配角色**：主持人@各代理，确认角色归属
3. **游戏流程**：按轮次进行，每轮「事件→讨论→投票→执行」

## 游戏流程

```
① 议题提出（2分钟）
② 提案陈述（3分钟）
③ 自由辩论（5-10分钟）
④ 投票表决（3分钟）
⑤ 任务指派（3分钟）
⑥ 执行结算
```
