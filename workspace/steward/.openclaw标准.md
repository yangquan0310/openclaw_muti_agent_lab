# .openclaw 标准规范

> 定义 .openclaw 目录的命名、格式、安全、文件管理等标准。
> 版本：v1.0.0 | 更新：2026-05-25 | 负责人：大管家

---

## 一、目录与文件命名规范

### 1.1 目录命名

| 目录 | 含义 | 备注 |
|------|------|------|
| `agents/` | 各 Agent 会话数据 | 按 Agent ID 命名子目录 |
| `memory/` | Agent 记忆数据库 | `*.sqlite` 文件 |
| `skills/` | 系统技能包 | 可执行技能目录 |
| `plugin-skills/` | 插件技能软链接 | 指向 `npm/` 或扩展目录 |
| `plugins/` | 插件目录 | 含 `installs.json` |
| `credentials/` | 凭证配置 | JSON 格式 |
| `logs/` | 日志文件 | 含 config、gateway、stability |
| `cron/` | 定时任务 | 含 jobs.json |
| `media/` | 媒体缓存 | 自动清理超过 30 天的文件 |
| `wiki/` | 知识库 | Obsidian vault |

### 1.2 文件命名

| 文件 | 命名格式 | 例子 |
|------|----------|------|
| 配置备份 | `openclaw.json.bak.N` 或 `openclaw.json.bak.YYYYMMDD` | `openclaw.json.bak.20260525` |
| 最近正常 | `openclaw.json.last-good` | — |
| 数据库 | `{agent}.sqlite` | `steward.sqlite` |
| 数据库备份 | `{agent}.sqlite.bak.YYYYMMDD` | `steward.sqlite.bak.20260520` |
| 日志 | `{type}-{date}.jsonl` | `main-2026-05-25.jsonl` |
| 凭证 | `{service}-{agent}.json` | `lark.secrets.json` |
| 允许来源 | `feishu-{agent}-allowFrom.json` | `feishu-steward-allowFrom.json` |

## 三、安全规范

### 3.1 敏感文件（禁止提交 Git）

```
# .gitignore 中已配置
.env
credentials/
state/
memory-tdai/
logs/
media/
browser/
browser-existing-session/
subagents/
tasks/
delivery-queue/
session-delivery-queue/
cron/runs/
```

### 3.2 文件权限标准

| 文件类型 | 权限 | 说明 |
|----------|------|------|
| `openclaw.json` | `600`（rw-------） | 包含配置，不可泄露 |
| `.env` | `600`（rw-------） | 包含所有 API Key |
| `credentials/*.json` | `600`（rw-------） | 包含 secrets |
| 目录 | `700`（rwx------） | 目录权限收紧 |
| `openclaw.json.bak*` | `600`（rw-------） | 备份同权限 |
| `logs/*.jsonl` | `640`（rw-r-----） | 日志可读但不可改 |
| README.md | `644`（rw-r--r--） | 公开文档 |

### 3.3 API Key 管理

```bash
# 验证 .env 权限
ls -la ~/.openclaw/.env
# 预期：-rw------- 1 root root

# 如果权限错误，修复
chmod 600 ~/.openclaw/.env

# 禁止在命令行中明文传递 Key
# 错误：curl -H "Authorization: Bearer sk-xxx" ...
# 正确：从 .env 读取环境变量
```

### 3.4 凭证文件格式

`credentials/` 下的 JSON 文件统一格式：

```json
{
  "service": "feishu",
  "agent": "steward",
  "created": "2026-04-10",
  "updated": "2026-05-25"
}
```

⚠️ **禁止**在 credentials JSON 中明文存储密钥，应使用系统配置的密钥路径引用。

## 四、Git 提交规范

### 4.1 提交类型

| type | 说明 | 示例 |
|------|------|------|
| `config` | 配置文件变更 | `config: 更新 openclaw.json 模型配置` |
| `feat` | 新增功能 | `feat: 添加飞书日历技能` |
| `fix` | 问题修复 | `fix: 修复内存数据库 VACUUM 脚本` |
| `doc` | 文档更新 | `doc: 更新 README.md Agent 列表` |
| `cleanup` | 清理工作 | `cleanup: 删除过期备份文件` |
| `backup` | 备份操作 | `backup: 手动备份 openclaw.json` |

### 4.2 提交检查清单

```
提交前必查（全部通过才能 commit）：
    [1] .env 不在 git add 列表中
    [2] credentials/ 不在 git add 列表中
    [3] 无大于 10MB 的文件在暂存区
    [4] git status 显示预期文件
```

### 4.3 分支管理

| 分支 | 用途 | 保护规则 |
|------|------|----------|
| `main` | 稳定版本 | 仅通过 PR 合并，禁止直接推送 |
| `development` | 日常开发 | 直接推送，每日至少 sync |

## 五、插件与技能规范

### 5.1 插件安装标准

```bash
# 官方插件（stock）
openclaw plugins install <plugin-id>

# 社区插件（clawhub）
clawhub install <skill-name>

# 验证安装
openclaw plugins list | grep enabled
```

### 5.2 插件启用规则

| 插件类型 | 是否启用 | 说明 |
|----------|----------|------|
| `active-memory` | ✅ 必须 | 核心记忆功能 |
| `browser` | ✅ 必须 | 浏览器自动化 |
| `deepseek` | ✅ 必须 | 默认模型之一 |
| `document-extract` | ✅ 必须 | 文档处理 |
| `exa` | ✅ 必须 | 搜索功能 |
| `tavily` | ✅ 必须 | 搜索备用 |
| `memory-core` | ✅ 必须 | 记忆核心 |
| 其他 | 按需启用 | 禁用不用的插件节省资源 |

### 5.3 技能软链接规范

`plugin-skills/` 下的软链接必须指向：
- `~/.openclaw/npm/node_modules/@larksuite/openclaw-lark/skills/*`（飞书系）
- `~/.openclaw/npm/node_modules/@openclaw/qqbot/skills/*`（QQ 系）
- `~/.local/share/pnpm/global/.../openclaw/dist/extensions/*/skills/*`（内置扩展）

## 六、配置规范

### 6.1 openclaw.json 结构规范

```json
{
  "version": 2,
  "agents": { ... },
  "channels": { ... },
  "models": { ... },
  "plugins": { ... },
  "skills": { ... }
}
```

**关键规范：**
- 不在配置中明文写入 API Key（通过 `.env` 引用）
- 模型配置使用 provider ref，不写死 base URL（除非自托管）
- channel 配置中 token 使用 `env:VAR_NAME` 引用

### 6.2 环境变量规范（.env）

```
KEY分类：
  [模型类] MODEL_* / *_API_KEY / *_BASE_URL
  [飞书类] FEISHU_*_APP_SECRET
  [腾讯类] TENCENT*
  [工具类] JINA_* / EXA_* / TAVILY_*
  [Git类]  GITHUB_*
  [Zotero] ZOTERO_*
```

### 6.3 定时任务规范

```bash
# cron 任务使用标准格式
# 时间：本地时间（Asia/Shanghai），不转换 UTC
# 示例：每日 09:00 = "0 9 * * *"
```
