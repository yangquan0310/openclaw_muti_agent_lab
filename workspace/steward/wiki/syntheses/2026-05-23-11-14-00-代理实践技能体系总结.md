# 代理实践技能体系总结

> 杨权设计，2026-05-23
> 来源：各代理技能体系分析

---

## 一、核心理念

**"实践是代理最重要的东西。"**

每个代理在自己工作空间创建了一个以**实践活动命名**的技能，收录：
- 指南（guides）
- 常用工具（tools）
- 常用模板（templates）

---

## 二、设计意图

| 设计 | 说明 |
|------|------|
| **实践命名** | 技能以活动命名，而非身份命名 |
| **指南下沉** | 入口文件只做路由，详细内容在 references/ |
| **边界明确** | 每技能明确"能做什么"和"不能做什么" |
| **快速检索** | 内置搜索脚本，支持关键词查询 |
| **版本追踪** | 每次更新记录版本历史 |

---

## 三、核心结构

```
{agent}/skills/{agent}/
├── SKILL.md          # 入口文件
├── ...              # 其他文件(夹)
├── references/       # 指南目录
├── scripts/          # 脚本工具
└── assets/          # 模板资源
```

---

## 四、SKILL.md 章节

| 章节 | 说明 |
|------|------|
| **核心原则** | 3-5条执行准则 |
| **边界条件** | 能做什么 + 不能做什么 |
| **快速调用** | 常用命令 |
| **指南导航** | 路由到 references/ 具体指南 |
| **{其他内容}** | 按需添加（非必须） |
| **版本历史** | 记录每次更新 |

---

## 五、代理技能一览

| 代理 | 技能名称 | 收录内容 |
|------|----------|----------|
| **大管家** | `manager` | 任务推进/派发、论文项目、课程项目、程序项目、知识库管理、项目整理 |
| **程序员** | `programmer` | OOP指南、架构指南、全栈开发、测试指南、运维指南、产品经理指南 |
| **写作助手** | `writer` | 写作流程、编辑规范、文体模板 |
| **审稿者** | `reviewer` | 质量审查、审稿意见、建设性反馈 |
| **呈现师** | `presenter` | PPT制作、演示设计、视觉规范 |
| **心理学家** | `psychologist` | 心理督导师指南、心理咨询师指南、心理科学家指南 |
| **教员** | `instructor` | 教学设计、课程管理 |
| **督导** | `auditor` | 质量督导 |
| **数学家** | `mathematician` | 数学建模、微分方程、优化问题、统计分析、假设检验、回归分析 |
| **物理学家** | `physicist` | 物理建模、理论分析、公式推导、交叉学科研究、模型验证 |
