# 网络小说 Idea：宗门发展大道（社会主义大道主线）

> **状态**：v0.1 草案（2026-09-06 记录）
> **来源**：老板口述创意，大管家整理归档
> **待办**：老板逐条补充「待完善细节」后迭代至 v0.2

## 一、一句话梗概

异世界入侵的威胁之下，修真宗门的胜负不再取决于顶尖战力，而取决于「发展模式」。主角从学识底层起步，遍习诸流发展大道，看尽奴隶流、封建流、资本流的红利与溃败，最终开创「社会主义大道」，以文明级的组织动员力反推异世界。

---

## 二、已确认设定（老板原话）

### 1. 大背景

- 宗门发展 + 抵抗异世界入侵，双线并行
- 全书看点核心 = **「如何发展宗门」**（非传统打怪升级）

### 2. 流派设定（发展模式即「大道」）

- 已点名流派：**奴隶流 / 封建流 / 资本流**（可扩充，见待完善项）
- 构建工具：**金融学、政治哲学**等现代社科知识体系
- 主线大道：**社会主义大道**（由主人公开创）

### 3. 学识升级体系（成长骨架，替代传统修为境界）

| 等级 | 定位 | 说明 |
|------|------|------|
| 初中 / 中专 / 大专 / 本科 | **学习期** | 打基础，理解与掌握既有大道 |
| 研究生（硕士 → 博士） | 大道内深耕 | 在大道的某一个内容上做完善 |
| 研究员 | 大道完善者 | 在以往提出的某一大道上做系统性完善 |
| 院士 | **大道开创者** | 每一位院士要开创一条「发展大道」 |

---

## 三、整体思路整理（大管家梳理，标注【草案】处待老板确认）

### 概念层设计

1. **大道 = 「组织人、分配资源、发展力量」的理论体系**
   - 把政治经济学说史写成修真道统史
   - 奴隶 → 封建 → 资本 → 社会主义的演替逻辑，可设计为大道间「谁更能适应外部压力（异世界入侵）下的动员需求，谁就上位」的底层规律，天然形成大道之间的竞争与更替【草案】
2. **学识等级 = 新修为体系**
   - 升级动力从「打坐攒灵气」变为「知行合一」：理论学习 + 实践检验（解决真实发展问题才可晋阶）【草案】
   - 晋升形式可参考现实：考试 / 答辩 / 实践成果 / 发表「道论」【草案】
3. **院士 = 开派祖师级**
   - 每位院士开创一大道 → 宗门内部天然形成「诸子百家」式的思想史与学术派系斗争
4. **现代知识降维打击修真社会**
   - 金融工具（股份制、信贷、期货、保险）→ 改造宗门商号与灵脉经济
   - 政治哲学工具（群众路线、组织动员、制度设计）→ 瓦解旧大道的人身依附与阶级撕裂

### 主线结构建议【草案】

| 幕 | 阶段 | 内容 |
|----|------|------|
| 第一幕 | 求学 | 主角低等级开局，学遍诸流，亲历各大道红利与溃败（如资本流的周期危机、封建流的门阀内耗） |
| 第二幕 | 开创 | 大危机中（资本流崩溃 / 异世界总攻临近），主角总结诸流利弊，开创「社会主义大道」 |
| 第三幕 | 落地 | 试点 → 推广 → 与旧大道既得利益者（门阀、财团、学阀）斗争 |
| 第四幕 | 对决 | 组织动员力质变 → 文明级反攻异世界；与异世界背后的另一种「终极大道」决战 |

### 潜在看点

- **知识降维打击**：用金融、政治哲学重构修真社会运转方式
- **成长反差感**：现代教育等级修仙化（「我堂堂本科」也能成为战力宣言）
- **思想斗争外化**：学术答辩 ≈ 斗法、发展竞赛 ≈ 道争、论文 ≈ 功法
- **制度实验爽点**：把一段大道从零到一「试点成功」的过程写成爽点单元

## 四、待完善细节（需老板补充 / 拍板）

> 按重要度排序；老板可直接在回复里逐条编号回答

### A. 世界观底层（优先级最高，决定主线骨架）

1. **异世界入侵设定**：入侵者是谁？是另一个修真文明（持不同发展大道）还是非人种族 / 深渊魔物？当前局势（第几次入侵、距总攻还有多久、宗门占优还是劣势）？
2. **传统修真要素去留**：灵气、灵根、境界、法宝、丹药还存在吗？学识等级与战斗力是什么关系？（战力 = 学识等级 × 资源？还是学识只决定「治国/组织」能力，战斗另有体系？）
3. **势力格局**：单宗门内部视角，还是多宗门 / 宗门-王朝-商会的外部大格局？主角宗门在食物链什么位置？

### B. 学识体系机制

4. **晋升机制细节**：升级靠什么？考试 / 答辩 / 实战功绩？院士「开创大道」如何被验证？（要多少人修行见效才算立住？有无开错道的失败院士？）
5. **寿命与代际**：高等级（院士）有延寿吗？若无延寿，大道如何跨代传承（影响叙事时间跨度）？
6. **主角设定**：开局年龄与天赋（天才 / 平凡）？有无金手指？（金手指类型会影响社会主义大道的说服力——靠系统还是靠思考？）

### C. 大道体系

7. **完整流派谱系**：除奴隶 / 封建 / 资本外，是否还有别的流（如神权流、军国流、自由结社流、技术流）？社会主义大道之前的历史「最高形态」是谁？
8. **大道胜负裁决方式**：两个大道冲突如何分高下？（论战 / 实战 / 发展竞赛「谁先把宗门带出危机」？）
9. **修仙版社会主义的具体形态**【需老板认可尺度】：灵脉与生产资料公有？按贡献分配？术法研发公共化？基层动员组织？——以及**现实映射浓度**：是直接使用政治经济学概念原名，还是做修仙语境的包装改写（涉及网文审核风险，需老板定调）。

### D. 叙事与市场定位

10. **读者定位**：男频？感情线（无 CP / 单女主 / 后宫）？篇幅预期（百万字量级？）与平台（起点 / 番茄）？
11. **主角与诸流终局关系**：社会主义大道最终是「取代并埋葬」旧流，还是「兼容并包、集诸流之大成」（对应现实中社会主义对资本主义技术成果的继承逻辑）？
12. **节奏预期**：从初中开局到院士 / 开创大道，大致多少年（书内时间）与多少万字（书外篇幅）？
