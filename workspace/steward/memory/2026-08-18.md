## 二、核心方法论沉淀(do 型规则)

### 1. 流通本质 = 生生不息之辨(非"被克冲刑害破"判定)

> 老板 2026-08-18 15:43 拍板:"清浊之辨的核心不在于被克冲刑害破,而在于是否生生不息"

**§1.1 双层分析框架**:
- **应用聚焦层**(决定看哪里):以哪个干支为中心——默认日干;可换日支/婚姻宫、月支/事业宫、年支/家宅、时支/子女、官星/官运、财星/财运、夫星/妻星/婚姻星
- **流通方法层**(决定怎么看):**核心 = 生生不息之辨**——清浊 = 该中心能否生生不息的结果
  - 清 = 有源 + 有流 + 不枯
  - 浊 = 无源 / 无流 / 被阻断
- **被克冲刑害破 ≠ 清浊判定**——只是浊的可能原因
- **不息三要素**:有源(上游生扶)/ 有流(下游传递)/ 不枯(不被合绊/冲散/害断)

### 2. 应用聚焦层 vs 流通方法层 = 不矛盾(叠加关系)
