## 🛠️ 关键技术细节 (未来需要知道)

### 1. rclone 坚果云 WebDAV 配置

```ini
# ~/.config/rclone/rclone.conf
[nutstore]
type = webdav
url = https://dav.jianguoyun.com/dav
vendor = other
user = <email>
pass = <obscured-via-rclone-obscure>
```

**Zotero 同步路径**: `nutstore:quanquanzi/zotero/`

### 2. Al-Kari title PATCH bug 修复

**问题**: Zotero Web API PATCH 需要 `If-Unmodified-Since-Version: <version>` 自定义头 (不是 HTTP 标准的 `If-Match`)

**修法**:
```python
req = urllib.request.Request(url, data=..., method='PATCH')
req.add_header('If-Unmodified-Since-Version', str(version))  # Zotero 自定义
```

**坑**: arXiv title 被 `arxiv_title_parse` 误抓 `?search_query=...` — 需要重新手动设置 title

### 3. Semantic Scholar API 字段

**注意**:
- 字段名是 `query` (不是 `q`)
- 没 API key 时 HTTPSConnectionPool Max retries exceeded (不是代码 bug)
- API key 放 .env 的 `SEMANTIC_SCHOLAR_API_KEY`

### 4. Zotero itemKey 8 字符规范

- 例: `WSZJGS59` (δ-mem 论文) / `ERZMJJTP` (δ-mem note) / `Q8NF2W5T` (Diehl 2026) / `VNPN6FHT` (Buzsaki 2002)
- 8 字符 base62, 在 Zotero 库内唯一
- 笔记 (note) 也用 8 字符 itemKey, 区别于论文的 8 字符

### 5. Pexpect 颜色码问题

**坑**: 工具输出有 ANSI 颜色码时, `expect`/`pexpect` 解析会失败 (匹配不到 prompt)
**修法**: 工具加 `--no-color` 或 `NO_COLOR=1` 环境变量

### 6. OpenClaw 工具调用上限

**实际经验**:
- 1 轮 ≤ 3 工具调用 = 安全
- 1 轮 5 工具 = 可能触发 deadlock
- 1 轮 8+ 工具 = **几乎必** 触发飞书 connector #90559 deadlock
- 大响应 (workboard_decompose) **单独** 1 轮
