## 1. 概念边界

- **Embedding** = 文本→向量，**向量化本身不排序**（单步映射）
- **向量相似度排序**（cosine / dot product）= **初排（first-stage ranking）**——这是 `memorySearch` 默认行为
- **Reranking** = 在初排 topK 上用 **cross-encoder / LLM 精排**——OpenClaw 当前**没暴露钩子**

也就是说：**embedding 后能做的"重排"在 OpenClaw 配置里只有 3 个内置算法**（MMR / Hybrid / Temporal Decay），**不能调外部 LLM 做精排**。

## 2. Work-around（agent 层绕过）

```python
# 在 agent prompt / skill 里手动调外部 rerank API
1. memory_search(query, maxResults=20)   # 拿 20 个候选
2. 调外部 rerank API:                    # 二次精排
   - Cohere Rerank 3.5
   - bge-reranker-v2-m3（自托管）
   - Jina Rerank
   - LLM 直接打分
3. 取精排后 topK 注入 prompt
```

**优点**：完全可控、可用任何模型
**缺点**：**绕过 schema 限制**（=不优雅），且**每次搜索都得多一次 API 调用**（延迟 + 成本）
