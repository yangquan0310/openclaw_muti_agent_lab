## 八、建议执行顺序

### 第一批：A 类（0 询问，立即清，~200M）

```bash
# A1: 清 /tmp 测试文件
rm -f /tmp/asr_tts_*.{mp3,ogg} /tmp/tts_*.json /tmp/test_zh.mp3 /tmp/gen_tts_*.sh

# A2+A3: 清空日志（已废弃）
rm -f ~/.openclaw/logs/main.jsonl ~/.openclaw/logs/gateway-restart.log

# A4: 留最近 5 个备份
cd ~/.openclaw && ls -t openclaw.json.bak* | tail -n +6 | xargs rm -f

# A5: 30 天前 cron runs
find ~/.openclaw/cron/runs/ -mtime +30 -delete

# A6: npm 商店清理
pnpm store prune

# A7: 修 .env 权限
chmod 600 ~/.openclaw/.env
```

### 第二批：B 类（需同意，~1G）

```bash
# B1: doctor 推荐的 35 个 orphan 转档
# （需要 openclaw doctor --fix 安全跑，但本机 1.9GB 可能 OOM）
# 替代方案：手动 mv 到 archive 子目录

# B2: 60 天前会话归档（按 agent 维度）
for agent in programmer psychologist writer; do
    find ~/.openclaw/agents/$agent/sessions/ -mtime +60 -type f -exec mv {} ~/.openclaw/agents/$agent/archive/ \;
done

# B3: sqlite VACUUM
for db in steward psychologist instructor; do
    sqlite3 ~/.openclaw/memory/${db}.sqlite "PRAGMA wal_checkpoint(TRUNCATE); VACUUM;"
done
```
