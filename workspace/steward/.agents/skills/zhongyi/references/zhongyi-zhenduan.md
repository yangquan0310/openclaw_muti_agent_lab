## 〇、五运六气（历法→辨证的桥梁）

> **核心思想**：辨证皆来自历法——**五运六气 = 历法（天时）→ 人体发病（辨证）的桥梁**。
> 某年某运某气偏盛 → 相应脏腑发病倾向 → 对应证型（联动本文件证型库）。
> **与八字联动**：出生时刻的干支（历法坐标）定**先天体质**（见 `bazi-jiankang.md`）；
> 流年流月的五运六气定**后天发病诱因**——先天弱脏 + 当运当气克伐 = 高危。

### 〇.3 主气六步（年年不变 · 定四时常态）

| 步 | 时段 | 主气 | 常态病机 |
|:---:|:---|:---|:---|
| 初之气 | 大寒→春分 | 厥阴风木 | 风邪犯表 |

### 〇.4 辨证应用（两步合参）

1. **先天**：查命局五行旺衰 → 定先天弱脏（`bazi-jiankang.md`：五行缺/被克/过旺 = 病位）
2. **后天**：查当年干支 → 定五运六气 → 定当运克伐方向
3. **合参**：先天弱脏 ∩ 当运当气克伐 = 今年高危脏腑 → 提前对应本文件证型库防治

## 一、外感类（Z-WAI-GAN）— 4 条

### Z-外感-001  风寒感冒
- **八纲**：表 / 实 / 寒 / 阳
- **主症**：恶寒重，发热轻，无汗，头痛，身痛，关节酸痛，鼻塞，流清涕，咳嗽，痰白稀。
- **舌象**：舌淡红，苔薄白而润。
- **脉象**：浮紧（表实）；若汗出恶风则浮缓（表虚）。
- **主方**：麻黄汤（太阳伤寒表实证） / 桂枝汤（太阳中风表虚证）。
- **教材出处**：《中医诊断学》第二章"问寒热"节"恶寒发热"；《伤寒论·辨太阳病脉证并治上》原文（"太阳病，或已发热，或未发热，必恶寒、体痛、呕逆，脉阴阳俱紧者，名为伤寒"）。

### Z-外感-002  风热感冒
- **八纲**：表 / 实 / 热 / 阳
- **主症**：发热重，恶寒轻，咽干或咽痛，咳嗽痰黄稠，鼻塞流黄浊涕，口微渴。
- **舌象**：舌尖红，苔薄黄。
- **脉象**：浮数。
- **主方**：银翘散（风热表证）/ 桑菊饮（风热犯肺咳嗽为主）。
- **教材出处**：《中医诊断学》第二章"问寒热"；《温病条辨·上焦篇》原文（"太阴风温，但咳，身不甚热，微渴者，辛凉轻剂桑菊饮主之"）。

### Z-外感-003  风燥感冒（温燥）
- **八纲**：表 / 实 / 燥 / 阳
- **主症**：发热微恶风寒，干咳少痰或无痰，口鼻干燥，咽干，痰黏难咯。
- **舌象**：舌红少津，苔薄白而干。
- **脉象**：浮细数。
- **主方**：桑杏汤（温燥） / 杏苏散（凉燥）。
- **教材出处**：《中医诊断学》第二章；《温病条辨·秋燥篇》。

### Z-外感-004  暑湿感冒
- **八纲**：表 / 实 / 暑湿 / 阳
- **主症**：夏季发病，发热，汗出热不解，头重如裹，身重倦怠，胸闷，呕恶，纳呆，腹泻。
- **舌象**：舌红，苔黄腻。
- **脉象**：濡数。
- **主方**：新加香薷饮（暑湿表证） / 藿香正气散（外寒内湿）。
- **教材出处**：《中医诊断学》第二章"问寒热·但热不寒"；《温病条辨·上焦篇》。

## 二、心系类（Z-XIN）— 4 条

### Z-心-001  心气虚
- **八纲**：里 / 虚 / 气虚
- **主症**：心悸，气短，活动时加重，自汗，神疲乏力，面色㿠白。
- **舌象**：舌淡，苔薄白。
- **脉象**：虚细或细弱。
- **主方**：养心汤 / 归脾汤（兼脾虚）。
- **教材出处**：《中医诊断学》第四章"问诊·问心悸"；《方剂学》补益剂"养心汤"章。

### Z-心-002  心血虚
- **八纲**：里 / 虚 / 血虚
- **主症**：心悸，失眠多梦，眩晕，健忘，面色无华，唇甲色淡。
- **舌象**：舌淡，苔薄白。
- **脉象**：细弱。
- **主方**：归脾汤（心脾两虚）/ 酸枣仁汤（虚烦不寐）。
- **教材出处**：《中医诊断学》第四章；《金匮要略·血痹虚劳病脉证并治第六》"虚劳虚烦不得眠，酸枣仁汤主之"。

### Z-心-003  心火旺（心火亢盛）
- **八纲**：里 / 实 / 热 / 阳
- **主症**：心烦，失眠，口舌生疮（舌尖尤甚），口渴，小便短赤涩痛。
- **舌象**：舌尖红，苔黄。
- **脉象**：数。
- **主方**：导赤散 / 泻心汤。
- **教材出处**：《中医诊断学》第四章"望舌"；《方剂学》清热剂"导赤散"章；《小儿药证直诀》导赤散原方。

### Z-心-004  心阳虚
- **八纲**：里 / 虚 / 寒 / 阴
- **主症**：心悸怔忡，胸闷气短，形寒肢冷，面色苍白，唇甲青紫。
- **舌象**：舌淡胖嫩，苔白滑。
- **脉象**：沉细无力或结代。
- **主方**：桂枝甘草汤（心阳不振）/ 四逆汤（亡阳）。
- **教材出处**：《中医诊断学》第四章；《伤寒论·辨太阳病脉证并治上》"发汗过多，其人叉手自冒心，心下悸，欲得按者，桂枝甘草汤主之"。

## 三、肝系类（Z-GAN）— 4 条

### Z-肝-001  肝阳上亢
- **八纲**：里 / 本虚标实 / 阳亢
- **主症**：头晕胀痛，面红目赤，耳鸣如潮，急躁易怒，口苦，失眠多梦，腰膝酸软。
- **舌象**：舌红，苔黄。
- **脉象**：弦细数或弦有力。
- **主方**：天麻钩藤饮。
- **教材出处**：《中医诊断学》第四章"问头晕"；《方剂学》治风剂"天麻钩藤饮"章（胡光慈《中医内科杂病证治新义》原方）。

### Z-肝-002  肝气郁结
- **八纲**：里 / 实 / 气滞
- **主症**：情志抑郁或急躁易怒，胸胁、少腹胀闷窜痛，善太息，咽部异物感（梅核气），月经不调。
- **舌象**：舌淡红，苔薄白。
- **脉象**：弦。
- **主方**：柴胡疏肝散（肝郁）/ 逍遥散（肝郁血虚）。
- **教材出处**：《中医诊断学》第四章"问胸胁"；《方剂学》理气剂"柴胡疏肝散"章；《景岳全书》柴胡疏肝散原方。

### Z-肝-003  肝火旺（肝火上炎）
- **八纲**：里 / 实 / 热 / 阳
- **主症**：胁肋灼痛，面红目赤，头痛眩晕，耳鸣如潮，口苦口干，急躁易怒，便秘尿黄。
- **舌象**：舌红，苔黄。
- **脉象**：弦数。
- **主方**：龙胆泻肝汤。
- **教材出处**：《中医诊断学》第四章；《方剂学》清热剂"龙胆泻肝汤"章（清·《医方集解》引《太平惠民和剂局方》）。

### Z-肝-004  肝血虚
- **八纲**：里 / 虚 / 血虚
- **主症**：眩晕耳鸣，目涩夜盲，爪甲不荣，面色无华，肢体麻木，筋脉拘挛，月经量少色淡。
- **舌象**：舌淡，苔薄白。
- **脉象**：弦细。
- **主方**：补肝汤 / 四物汤（血虚通用）。
- **教材出处**：《中医诊断学》第四章；《方剂学》补益剂"四物汤"章（《仙授理伤续断秘方》原方）。

## 四、脾系类（Z-PI）— 5 条

### Z-脾-001  脾气虚
- **八纲**：里 / 虚 / 气虚
- **主症**：纳少，腹胀，食后尤甚，大便溏薄，神疲乏力，少气懒言，面色萎黄或㿠白。
- **舌象**：舌淡胖有齿痕，苔白。
- **脉象**：濡缓或弱。
- **主方**：四君子汤（脾虚基础方） / 六君子汤（兼痰湿） / 参苓白术散（脾虚湿盛）。
- **教材出处**：《中医诊断学》第四章"问饮食"；《方剂学》补益剂"四君子汤"章（《太平惠民和剂局方》原方）。

### Z-脾-002  脾阳虚
- **八纲**：里 / 虚 / 寒 / 阴
- **主症**：腹胀纳呆，脘腹冷痛，喜温喜按，大便清稀或完谷不化，四肢不温。
- **舌象**：舌淡胖，苔白滑。
- **脉象**：沉迟无力。
- **主方**：理中丸 / 附子理中丸。
- **教材出处**：《中医诊断学》第四章；《方剂学》温里剂"理中丸"章；《伤寒论·辨霍乱病脉证并治第十三》"霍乱……寒多不用水者，理中丸主之"。

### Z-脾-003  脾虚湿困（脾虚湿盛）
- **八纲**：里 / 虚 / 湿
- **主症**：脘腹胀闷，纳呆便溏，肢体困重，倦怠嗜睡，头重如裹。
- **舌象**：舌淡胖，苔白腻。
- **脉象**：濡缓。
- **主方**：参苓白术散 / 苓桂术甘汤。
- **教材出处**：《中医诊断学》第四章；《方剂学》祛湿剂"参苓白术散"章；《太平惠民和剂局方》原方。

### Z-脾-004  脾不统血
- **八纲**：里 / 虚 / 气不摄血
- **主症**：皮下紫癜，鼻衄，齿衄，月经量多色淡或崩漏，食少便溏，神疲乏力。
- **舌象**：舌淡胖，苔白。
- **脉象**：细弱。
- **主方**：归脾汤。
- **教材出处**：《中医诊断学》第四章；《方剂学》补益剂"归脾汤"章（严用和《济生方》原方）。

### Z-脾-005  湿热蕴脾
- **八纲**：里 / 实 / 热 / 湿
- **主症**：脘腹胀满，纳呆，恶心呕吐，口苦黏腻，身重困倦，尿黄，大便溏而不爽或下利脓血。
- **舌象**：舌红，苔黄腻。
- **脉象**：濡数。
- **主方**：茵陈蒿汤（湿热黄疸） / 黄连解毒汤 / 三仁汤（湿温初起）。
- **教材出处**：《中医诊断学》第四章；《方剂学》清热剂"茵陈蒿汤"章；《伤寒论·辨阳明病脉证并治》"瘀热在里，身必发黄，茵陈蒿汤主之"。

## 五、肺系类（Z-FEI）— 5 条

### Z-肺-001  肺气虚
- **八纲**：里 / 虚 / 气虚
- **主症**：咳嗽气短，痰清稀，语低声怯，自汗畏风，易感冒，神疲乏力。
- **舌象**：舌淡，苔薄白。
- **脉象**：虚弱。
- **主方**：补肺汤 / 玉屏风散（表虚易感）。
- **教材出处**：《中医诊断学》第四章"问咳嗽"；《方剂学》补益剂"补肺汤"章。

### Z-肺-002  肺阴虚
- **八纲**：里 / 虚 / 阴虚 / 热
- **主症**：干咳少痰或痰中带血，口干咽燥，声音嘶哑，潮热盗汗，颧红。
- **舌象**：舌红少津，少苔或无苔。
- **脉象**：细数。
- **主方**：沙参麦冬汤 / 百合固金汤。
- **教材出处**：《中医诊断学》第四章；《方剂学》治燥剂"沙参麦冬汤"章（《温病条辨·上焦篇》原方）。

### Z-肺-003  风寒犯肺
- **八纲**：表里 / 实 / 寒
- **主症**：咳嗽声重，气急，咳痰稀薄色白，常伴鼻塞流清涕，头痛，恶寒发热。
- **舌象**：舌淡红，苔薄白。
- **脉象**：浮紧。
- **主方**：麻黄汤 / 三拗汤 / 止嗽散。
- **教材出处**：《中医诊断学》第四章；《方剂学》解表剂"止嗽散"章（《医学心悟》原方）。

### Z-肺-004  风热犯肺
- **八纲**：表里 / 实 / 热
- **主症**：咳嗽频剧，气粗或咳声嘶哑，痰黄黏稠，咽痛，口渴，鼻流黄涕。
- **舌象**：舌红，苔薄黄。
- **脉象**：浮数。
- **主方**：桑菊饮 / 银翘散。
- **教材出处**：《中医诊断学》第四章；《温病条辨·上焦篇》。

### Z-肺-005  痰湿阻肺
- **八纲**：里 / 实 / 痰湿
- **主症**：咳嗽痰多，痰白黏稠易咯，胸闷脘痞，纳呆，身重倦怠。
- **舌象**：舌淡胖，苔白腻。
- **脉象**：滑或濡滑。
- **主方**：二陈汤（基础） / 三子养亲汤（痰壅气逆） / 苓桂术甘汤。
- **教材出处**：《中医诊断学》第四章；《方剂学》祛痰剂"二陈汤"章（《太平惠民和剂局方》原方）。

## 六、肾系类（Z-SHEN）— 4 条

### Z-肾-001  肾阴虚
- **八纲**：里 / 虚 / 阴虚 / 热
- **主症**：腰膝酸软，头晕耳鸣，潮热盗汗，五心烦热，失眠多梦，口干咽燥，遗精，月经量少。
- **舌象**：舌红少苔或无苔，或有裂纹。
- **脉象**：细数。
- **主方**：六味地黄丸 / 左归丸。
- **教材出处**：《中医诊断学》第四章"问腰"；《方剂学》补益剂"六味地黄丸"章（钱乙《小儿药证直诀》原方，"地黄丸"）。

### Z-肾-002  肾阳虚
- **八纲**：里 / 虚 / 寒 / 阴
- **主症**：腰膝酸冷，畏寒肢冷，面色㿠白，精神萎靡，小便清长，夜尿多，或浮肿。
- **舌象**：舌淡胖，苔白。
- **脉象**：沉细无力或沉迟。
- **主方**：金匮肾气丸 / 右归丸。
- **教材出处**：《中医诊断学》第四章；《方剂学》补益剂"肾气丸"章；《金匮要略·妇人杂病脉证并治第二十二》崔氏八味丸原方。

### Z-肾-003  肾气虚（肾气不固）
- **八纲**：里 / 虚 / 气虚
- **主症**：腰膝酸软，听力减退，小便频数清长，夜尿多，滑精早泄，女子带下清稀。
- **舌象**：舌淡，苔白。
- **脉象**：沉弱。
- **主方**：金匮肾气丸 / 缩泉丸 / 五子衍宗丸。
- **教材出处**：《中医诊断学》第四章；《方剂学》补益剂。

### Z-肾-004  肾精不足
- **八纲**：里 / 虚 / 精亏
- **主症**：小儿发育迟缓（"五迟""五软"），成人早衰，耳鸣耳聋，健忘恍惚，须发早白，男子精少不育，女子经闭不孕。
- **舌象**：舌淡红，苔薄白。
- **脉象**：细弱或尺脉弱。

## 七、复合证类（Z-FU-HE）— 6 条

### Z-复合-001  气血两虚
- **八纲**：里 / 虚 / 气虚血虚
- **主症**：神疲乏力，少气懒言，面色淡白或萎黄，头晕目眩，心悸失眠，唇甲淡白。
- **舌象**：舌淡，苔薄白。
- **脉象**：细弱。
- **主方**：八珍汤（四君+四物） / 十全大补汤 / 人参养荣汤。
- **教材出处**：《中医诊断学》第四章；《方剂学》补益剂"八珍汤"章（《正体类要》原方）。

### Z-复合-002  气滞血瘀
- **八纲**：里 / 实 / 气滞血瘀
- **主症**：情志不遂诱发，胸胁胀闷窜痛，刺痛固定，拒按，妇女经前乳胀，月经色暗有块，舌紫暗。
- **舌象**：舌紫暗或有瘀斑，苔薄白。
- **脉象**：弦涩。
- **主方**：血府逐瘀汤 / 柴胡疏肝散合桃红四物汤。
- **教材出处**：《中医诊断学》第四章；《方剂学》理血剂"血府逐瘀汤"章（王清任《医林改错》原方）。

### Z-复合-003  痰湿内阻
- **八纲**：里 / 实 / 痰湿
- **主症**：形体肥胖，痰多易咯，胸闷脘痞，呕恶纳呆，头晕目眩，嗜睡。
- **舌象**：舌胖，苔白腻或白滑。
- **脉象**：滑或濡滑。
- **主方**：二陈汤（基础） / 温胆汤 / 导痰汤。
- **教材出处**：《中医诊断学》第四章；《方剂学》祛痰剂"温胆汤"章（《三因极一病证方论》原方）。

### Z-复合-004  阴虚火旺
- **八纲**：里 / 虚 / 阴虚 + 火旺
- **主症**：潮热盗汗，五心烦热，颧红咽干，遗精，或口舌生疮，或咳嗽痰少带血。
- **舌象**：舌红，少苔或剥苔。
- **脉象**：细数。
- **主方**：知柏地黄丸 / 大补阴丸 / 黄连阿胶汤。
- **教材出处**：《中医诊断学》第四章；《方剂学》补益剂"知柏地黄丸"章（《医宗金鉴》原方）。

### Z-复合-005  阳虚水泛（脾肾阳虚水停）
- **八纲**：里 / 虚 / 寒 / 水停
- **主症**：全身浮肿，腰以下为甚，畏寒肢冷，小便不利，心悸气短，腹胀便溏。
- **舌象**：舌淡胖，苔白滑。
- **脉象**：沉迟无力。
- **主方**：真武汤 / 苓桂术甘汤。
- **教材出处**：《中医诊断学》第四章"问水肿"；《方剂学》祛湿剂"真武汤"章；《伤寒论·辨太阳病脉证并治中》"太阳病发汗，汗出不解，其人仍发热，心下悸，头眩，身瞤动，振振欲擗地者，真武汤主之"。

### Z-复合-006  心脾两虚
- **八纲**：里 / 虚 / 气血两虚（偏心脾）
- **主症**：心悸怔忡，失眠多梦，健忘，纳少腹胀，神疲乏力，面色萎黄，月经量少色淡，或淋漓不断。
- **舌象**：舌淡嫩，苔白。
- **脉象**：细弱。
- **主方**：归脾汤。
- **教材出处**：《中医诊断学》第四章；《方剂学》补益剂"归脾汤"章。

## 八、寒热错杂与表里同病（Z-OTHER）— 2 条

> 下述 4 个证型在主表中已以"近义/复合"形式覆盖（如"心悸"在 Z-心-001/002、"肾虚水泛"在 Z-复合-005），但任务书曾逐一点名要求，故在此**显式独立成条**，便于 programmer 后续 v1.1 升级时按 ID 拉取。

### Z-心-005  心悸（心虚胆怯证）
- **八纲**：里 / 虚 / 气虚+胆虚
- **主症**：心悸不宁，善惊易恐，坐卧不安，少寐多梦而易惊醒，恶闻声响；易由惊吓而发作。
- **舌象**：舌淡，苔薄白。
- **脉象**：细数或弦细。
- **主方**：安神定志丸（《医学心悟》） / 酸枣仁汤（偏肝血虚者）。
- **教材出处**：《中医诊断学》第四章"心悸"；《方剂学》安神剂章节"安神定志丸"。

### Z-肝-005  肝风内动
- **八纲**：里 / 本虚标实 / 风动
- **主症**：眩晕欲仆，头摇而痛，项强肢颤；或突然昏倒，不省人事，口眼㖞斜，半身不遂；或手足蠕动，舌颤；或瘛疭（抽搐）。
- **舌象**：舌红，苔腻或苔少而干。
- **脉象**：弦细或弦劲有力。
- **主方**：羚角钩藤汤（热极生风） / 镇肝熄风汤（阴虚阳亢化风） / 天麻钩藤饮（肝阳化风）。
- **教材出处**：《中医诊断学》第四章"肝风内动"节；《方剂学》治风剂"羚角钩藤汤"章、《医学衷中参西录》"镇肝熄风汤"章。

### Z-肺-006  燥邪伤肺（凉燥 / 外燥袭肺）
- **八纲**：表里 / 实 / 燥（偏凉）
- **主症**：干咳少痰或无痰，咽干鼻燥，咳嗽少津而咯痰不爽；与风燥感冒（温燥）相对偏凉，秋深初冬多见，兼微恶风寒。
- **舌象**：舌淡红，苔薄白而干。
- **脉象**：浮细略紧（凉燥）。
- **主方**：杏苏散（《温病条辨》凉燥方） / 桑杏汤（温燥方）。
- **教材出处**：《中医诊断学》第四章"咳嗽·燥邪伤肺"；《方剂学》治燥剂"杏苏散 / 桑杏汤"章；《温病条辨·秋燥篇》原文。

### Z-肾-005  肾虚水泛
- **八纲**：里 / 虚 / 寒 / 水停
- **主症**：全身水肿，腰以下为甚，按之凹陷难起；腰膝酸冷，畏寒肢冷；小便短少不利，或夜尿清长；心悸气短；腹胀便溏。
- **舌象**：舌淡胖，苔白滑。
- **脉象**：沉迟无力。
- **主方**：真武汤 / 济生肾气丸（肾阳虚水泛兼小便不利）。
- **教材出处**：《中医诊断学》第四章"水肿"节；《方剂学》祛湿剂"真武汤"章；《伤寒论·辨太阳病脉证并治中》/《伤寒论·辨少阴病脉证并治第十一》第 316 条；《济生方》"济生肾气丸"。
