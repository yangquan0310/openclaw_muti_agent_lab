# 中药参考库（zhongyi-zhongyao）

> **定位**：方剂库（`zhongyi-fangji.md`）全部组成药物的性味归经功效索引。
> **用途**：辨证定证型 → 方剂定主方 → 中药解释"为什么这味药在这里"。
> **来源**：《中药学》（中国中医药出版社"十四五"规划教材，钟赣生主编）。
> **声明**：本文件仅供学习参考，**不构成医疗建议**；剂量一律遵原方/执业中医师处方。

药名: 麻黄

## 一、解表药

### 1.1 辛温解表

- **麻黄**：辛微苦温｜肺、膀胱｜发汗解表，宣肺平喘，利水消肿｜风寒表实、咳喘、风水水肿｜发汗力强，虚人慎用
- **桂枝**：辛甘温｜心、肺、膀胱｜发汗解肌，温通经脉，助阳化气｜风寒表虚、寒凝血滞诸痛、痰饮水肿
- **紫苏叶**：辛温｜肺、脾｜解表散寒，行气和胃，解鱼蟹毒｜风寒感冒兼气滞、胸闷呕恶
- **生姜**：辛微温｜肺、脾、胃｜解表散寒，温中止呕，温肺止咳，解毒｜风寒感冒、胃寒呕吐、肺寒咳嗽
- **荆芥穗**：辛微温｜肺、肝｜解表散风，透疹消疮（炒炭止血）｜感冒头痛、麻疹不透、疮疡初起
- **防风**：辛甘微温｜膀胱、肝、脾｜祛风解表，胜湿止痛，止痉｜感冒头痛、风湿痹痛、破伤风
- **羌活**：辛苦温｜膀胱、肾｜解表散寒，祛风胜湿，止痛｜风寒夹湿感冒、上半身风湿痹痛
- **独活**：辛苦微温｜肾、膀胱｜祛风除湿，通痹止痛，解表｜风寒湿痹（下半身尤宜）、风寒夹湿感冒
- **藁本**：辛温｜膀胱、肝｜祛风散寒，除湿止痛｜巅顶头痛、风寒湿痹

### 1.2 辛凉解表

- **薄荷**：辛凉｜肺、肝｜疏散风热，清利头目，利咽透疹，疏肝行气｜风热感冒、头痛目赤、咽痛、麻疹不透
- **牛蒡子**：辛苦寒｜肺、胃｜疏散风热，宣肺利咽，解毒透疹，消肿疗疮｜风热感冒、咽痛、麻疹、痈肿
- **桑叶**：甘苦寒｜肺、肝｜疏散风热，清肺润燥，平抑肝阳，清肝明目｜风热感冒、肺燥咳嗽、目赤
- **菊花**：甘苦微寒｜肺、肝｜疏散风热，平肝明目，清热解毒｜风热感冒、目赤昏花、肝阳眩晕
- **柴胡**：辛苦微寒｜肝、胆、肺｜疏散退热，疏肝解郁，升举阳气｜寒热往来、肝郁气滞、中气下陷
- **升麻**：辛微甘微寒｜肺、脾、胃、大肠｜发表透疹，清热解毒，升举阳气｜麻疹不透、胃火牙痛、中气下陷
- **淡豆豉**：苦辛凉｜肺、胃｜解表，除烦，宣发郁热｜外感表证、热病烦闷

### 2.3 清热解毒

- **连翘**：苦微寒｜肺、心、小肠｜清热解毒，消肿散结，疏散风热｜风热感冒、温病初起、痈肿瘰疬

### 2.4 清热凉血

- **生地黄**：甘苦寒｜心、肝、肾｜清热凉血，养阴生津｜热入营血、血热出血、阴虚内热、津伤口渴
- **玄参**：甘苦咸微寒｜肺、胃、肾｜清热凉血，滋阴降火，解毒散结｜热入营血、阴虚火旺、瘰疬痰核
- **牡丹皮**：苦辛微寒｜心、肝、肾｜清热凉血，活血散瘀｜血热斑疹、温毒发斑、血瘀经闭、无汗骨蒸

- **枸杞**：甘平｜肝、肾｜滋补肝肾，益精明目｜肝肾阴虚、腰膝酸软、头晕目眩、目昏
- **龟板胶**：甘咸寒｜肝、肾、心｜滋阴潜阳，益肾健骨，养血补心｜阴虚阳亢、骨蒸潮热、腰膝痿软
- **鹿角胶**：甘咸温｜肝、肾｜温补肝肾，益精养血｜肾阳不足、精血亏虚、虚劳羸瘦
- **菟丝子**：辛甘平｜肝、肾、脾｜补益肝肾，固精缩尿，安胎，明目，止泻｜肝肾不足、阳痿遗精、胎动不安
- **杜仲**：甘温｜肝、肾｜补肝肾，强筋骨，安胎｜腰膝酸痛、肾虚腰痛、胎动不安

## 十六、收涩药

- **山茱萸**：酸涩微温｜肝、肾｜补益肝肾，收涩固脱｜眩晕耳鸣、腰膝酸软、遗精遗尿、大汗虚脱
- **乌梅**：酸涩平｜肝、脾、肺、大肠｜敛肺止咳，涩肠止泻，安蛔止痛，生津止渴｜久咳、久泻久痢、蛔厥、虚热消渴

## 十七、方剂-中药联动速查（常用核心药对）

- **六味地黄丸**：熟地黄（补肾阴）+ 山茱萸（补肝涩精）+ 山药（补脾固精）＋泽泻/茯苓/牡丹皮（三泻）
- **四君子汤**：人参 + 白术 + 茯苓 + 甘草 → 补气基础方
- **四物汤**：当归 + 川芎 + 白芍 + 熟地黄 → 补血基础方
- **参苓白术散**（方库未列，常用）＝四君子 + 山药、扁豆、薏苡仁等 → 健脾祛湿
- **逍遥散**：柴胡 + 当归 + 白芍 + 白术 + 茯苓 + 甘草 → 疏肝健脾
- **半夏厚朴汤**：半夏 + 厚朴 + 茯苓 + 生姜 + 紫苏叶 → 行气化痰

## ⚠️ 安全提醒

1. **有毒药**：附子、半夏、苦杏仁、桃仁——须炮制/煎煮规范，严禁自行配服
2. **峻烈药**：大黄、芒硝（攻下）、麻黄（发汗）——虚人慎用
3. **反药**：半夏反乌头（十八反）——配伍禁忌
