# 事业/工作解读框架（Career Analysis Framework）

> 西方占星术中关于事业/工作/职业方向的解读框架。
> 本文件是 astrology 技能的子模块。

## ⚠️ 免责
> 本框架仅供学术研究与文化记录使用，**不构成职业规划建议**。

---

## 一、核心宫位

| 宫位 | 主题 |
|---|---|
| **10 宫** | 事业、公众形象、人生方向 |
| **6 宫** | 日常工作、健康、服务 |
| **2 宫** | 价值观、金钱态度 |
| **1 宫** | 自我形象 |

## 二、核心星体

| 星体 | 解读 |
|---|---|
| **太阳** | 核心身份、领导力 |
| **土星** | 纪律、责任、长期目标 |
| **木星** | 扩展、机遇、乐观 |
| **火星** | 行动力、竞争力 |
| **中天（MC）** | 公众形象 |

## 三、解读框架

### 1. 职业方向（按太阳星座/元素）

| 元素 | 倾向方向 |
|---|---|
| **火象** | 领导、创业、销售、表演 |
| **土象** | 金融、管理、运营、实业 |
| **风象** | 传媒、教育、咨询、IT |
| **水象** | 心理、艺术、护理、研究 |

### 2. 事业高度（按土星状态）

| 土星状态 | 解读 |
|---|---|
| 土星入庙（摩羯/水瓶） | 事业潜力高 |
| 土星擢升（天秤） | 平衡的发展 |
| 土星失势 | 事业需更多努力 |
| 土星与中天 | 公众形象受纪律约束 |
| 土星与太阳 | 自我与责任的平衡 |

### 3. 事业节奏（按木星状态）

| 木星状态 | 解读 |
|---|---|
| 木星入庙 | 机遇多 |
| 木星与中天 | 公众认可 |
| 木星与太阳 | 自信扩展 |
| 木星与土星 | 自由与纪律的平衡 |

## 四、综合评估

```
事业强度 = 太阳分 × 0.30 + 土星分 × 0.30 + 10 宫分 × 0.25 + 木星分 × 0.15
```

## 五、文化提醒

- 职业选择应基于**兴趣 + 能力 + 市场需求 + 个人价值观**
- 星盘是心理倾向，**不替代职业规划**
