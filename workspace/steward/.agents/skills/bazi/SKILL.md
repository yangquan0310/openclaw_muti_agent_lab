# 八字排盘

> 给定一个公历出生时间，输出完整的四柱八字 + 十神 + 五行 + 地支藏干。
> 本技能是"算命"系列的基础模块，可作为大运、流年、神煞等上层算法的输入。

## 核心能力

1. **完整四柱**：年柱 / 月柱 / 日柱 / 时柱
2. **节气切月**：月柱按节气——非农历月切
3. **立春换年**：年柱以立春为界——非正月初一
4. **子时换日**：23:00–00:59 出生 → 日柱取次日
5. **十神**：从日主视角，按五行生克 + 阴阳同性/异性判定
6. **地支藏干**：取本气——必要时展开中气/余气
7. **农历 + 节气 + 生肖** 一并输出
8. **流年/流月/流时推算**（v1.1.0+）：
   - 目标时刻四柱
   - 目标柱与**命主日主**的十神关系
   - 目标柱与**命局同位置柱**的关系——六合/六冲/三合/天克/天比等查表，见 references/bazi-rules.md
   - 关系数据表与 `bazi.py` 解耦——`scripts/bazi_relations.py`，便于传统命理学口径调整

## 流派归属

## 何时使用本技能

- 用户问 "我的生辰八字是什么？"
- 上层算法——排大运、流年、神煞、合婚需要基础四柱
- 需要把公历时间标准化为传统命理时间坐标

## 何时 **不要** 使用

- 用户只问"今天是农历几号" → 用 cnlunar 直接查
- 用户问"两个时间差多少天" → 用 `datetime` / `pendulum`
- 不涉及命理推理的纯日历问题

## 调用方式

### CLI

```bash
bazi 1996-03-10 14:30                          # 单张排盘——人类可读
bazi 1996-03-10                                # 默认 12:00
bazi 1996-03-10 14:30 --json                   # 输出 JSON——便于上层消费

# 流年 / 流月 / 流时——v1.1.0+
bazi 1996-03-10 12:00 --liunian 2025           # 流年柱 + 与命局关系
bazi 1996-03-10 12:00 --liumonth 2025-06       # 流月柱 + 与命局关系
bazi 1996-03-10 12:00 --liushi 2025-06-15 14:30  # 流时柱 + 与命局关系

# 多 flag 可组合，如同时看流年+流月+流时
bazi 1996-03-10 12:00 --liunian 2025 --liumonth 2025-06 --liushi 2025-06-15 14:30

# JSON 模式——任意 flag 都可组合 --json
bazi 1996-03-10 12:00 --liunian 2025 --json

# 自测
bazi --self-test                               # 跑全部 45 用例——13 基础 + 10 流年/月/时 + 12 v1.8.0 模块 + 1 zaisha 校验 + 5 反查/组合 + 3 v1.9.0 农历/四柱
bazi --self-test "1996-03-10 12:00"            # 跑特定出生日的全部用例——含流年流月流时

# v1.8.0 新增：分析层 4 子命令——替代手算
bazi 1996-03-10 17:30 --zhengge                # 正格——八格 + 透干 + 施药方向
bazi 1996-03-10 17:30 --wangshuai                  # 旺衰——旺衰四维 + 调候 + 流通
bazi 1996-03-10 17:30 --shensha                # 神煞——28 神煞 × 4 柱 = 一体两面
bazi 1996-03-10 17:30 --shiyao               # 施药融合——正格 ∩ 旺衰
bazi 1996-03-10 17:30 --dayun --gender 男     # 大运——顺/逆排 + 起运 + 10 步
bazi --reverse --year 丙子 --month 辛卯 --day 丙午 --hour 丁酉  # 八字反查
```

### Python 模块

```python
from datetime import datetime
from bazi import build_bazi_from_str, liunian, liumonth, liushi

bz = build_bazi_from_str("1996-03-10", "14:30")
print(bz.pretty())
print(bz.day_master)        # '丙'
print(bz.year.gan_shishen)  # '比肩'

# 流年：给个年份，返回流年柱 + 十神 + 与命主关系
print(liunian(bz, 2025))
# {'year': 2025,
#  'target_year_pillar': {'gan': '乙', 'zhi': '巳'},
#  'vs_day_master': {'gan_shishen': '正印', 'zhi_shishen': '比肩', 'zhi_benqi': '丙'},
#  'vs_birth_year': {'gan_rels': ['天干相生'], 'zhi_rels': ['无特殊关系'], 'combined': ['普通']}}

# 流月
print(liumonth(bz, 2025, 6))

# 流时
print(liushi(bz, datetime(2025, 6, 15, 14, 30)))
```
