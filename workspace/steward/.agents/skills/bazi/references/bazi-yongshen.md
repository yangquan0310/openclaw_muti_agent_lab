# 八字用神判定 · 子流程参考

> **本文档是八字技能（bazi skill）用神判定的内部参考。**
> 适用于：单盘 / 合盘 / 流年解读中"用神是什么"的判定。
> **核心问题**：基于正格 + 势局，融合得出最终用神。
> **不是**第四种分析——用神是**融合产物**（Layer 2 子流程），不是 Layer 1 分析并列。

## 一、用神判定三层模型（核心）

```
[Step 1] 正格 → 用神方向（基于格局类型，不依赖旺衰）
   ↓
[Step 2] 势局 → 精化用神（含调候 + 扶抑 + 流通）
   ↓
[Step 3] 融合 → 最终用神（1-2 个五行）
```

| 层级 | 来源 | 输出 |
|---|---|---|
| **正格** | `bazi-zhengge.md` §三.1 喜忌总则（按格局类型）| 用神**方向**（如"财星"）|
| **势局** | 旺衰 + 调候 + 流通 | 用神**精化**（如"壬水第一，庚金次之"）|
| **融合** | 正格 ∩ 势局 | 用神**最终**（如"金水（壬水为核）"）|

### 1.1 优先级规则

| 优先级 | 规则 | 依据 |
|---|---|---|
| **1. 正格** | 用神方向基于格局类型，**不依赖旺衰** | 渊海子平 / 三命通会 / 子平真诠 |
| **2. 势局内部** | **调候优先于扶抑**（调候缺失则格局失衡） | 穷通宝鉴 / 滴天髓 |
| **3. 融合** | 调候 + 扶抑 → 最终用神（流通已独立为 Step 4）| 综合判定 |

> **核心**：**正格 ≠ 调候**。正格给方向，势局精化（含调候），融合得出最终用神。三者层次分明，**不冲突**。

## 四、融合 → 最终用神

### 4.1 融合公式

```
最终用神 = 正格方向 ∩ 势局精化
         = 方向优先（正格） + 精化补强（势局）
```

### 4.2 三种融合情况

| 情况 | 处理 | 举例 |
|---|---|---|
| **方向 = 精化** | 直接用 | 正格"金水" + 势局"金水" = "金水" |
| **方向 ⊂ 精化** | 取精化补强 | 正格"财" + 势局"金水" = "金水" |
| **方向 ≠ 精化** | **以正格方向为主**（正格权威），势局补充调候用神 | 正格"火" + 势局"水" = "火（兼用水调候）" |

### 4.3 反例（避免混淆）

| ❌ 误解 | ✅ 正确 |
|---|---|
| "正格用神必须等旺衰定了才能选" | "正格给方向，势局精化，**两者并行**" |
| "调候与正格冲突时调候优先" | "调候在势局内部优先于扶抑，**不是**与正格冲突" |
| "用神只看扶抑" | "用神 = 正格方向 + 势局精化（调候+扶抑）融合"（v1.1.0 起流通独立）|

### 4.4 输出

**一句话最终用神**（如"金水（壬水为核，庚辛次之）"）。

## 五、调候 vs 扶抑优先级（势局内部）

### 5.1 核心原则

**调候优先于扶抑**（穷通宝鉴）。

### 5.2 理由

- **调候缺失** → 命局失衡（如冬月丙火无壬水 = 寒滞）
- **扶抑失衡** → 用神可补救（如身旺可用克泄）

### 5.3 调候用神的特殊处理

| 情况 | 处理 |
|---|---|
| 调候用神 = 扶抑用神 | 强化用神 |
| 调候用神 ≠ 扶抑用神 | **调候优先** |
| 调候用神与正格方向冲突 | 以正格方向为主 + 调候用神作补充 |

### 5.4 实战示例（杨权）

```
调候：春月丙火 → 壬水第一
扶抑：4/4 极旺 → 金水（克泄）
   ↓
融合：金水（壬水为核，庚辛次之）
   ↓
最终用神：金水
```

## 六、实战案例

### 6.1 杨权（丙火 · 印绶格 · 身旺 4/4）

```
[Step 1] 正格 → 用神方向
  - 格局：印绶格
  - 喜忌总则：印绶格 + 身旺 → 财星制印
  - **用神方向：金水**

[Step 2] 势局 → 精化用神
  - 旺衰：4/4 极旺 → 扶抑 = 金水（克泄）
  - 调候：春月丙火 → 壬水第一
  - 流通：财破印（辛克卯）是关键制化
  - **精化用神：金水（壬水为核）**

[Step 3] 融合 → 最终用神
  - 方向 = 精化 = 金水
  - **最终用神：金水（壬水为核，庚辛次之）**
```

### 6.2 王雅欣（甲木 · 正财格 · 身偏旺 3/4）

```
[Step 1] 正格 → 用神方向
  - 格局：正财格
  - 喜忌总则：正财格 → 食伤生财 + 官杀护财
  - **用神方向：火金（食伤 + 官杀）**

[Step 2] 势局 → 精化用神
  - 旺衰：3/4 身偏旺 → 扶抑 = 火金（克泄）
  - 调候：夏末甲木 → 癸水 + 庚金
  - 流通：食伤生财是制化机制
  - **精化用神：火金（食伤 + 官杀）**

[Step 3] 融合 → 最终用神
  - 方向 = 精化 = 火金
  - **最终用神：火金**
```
