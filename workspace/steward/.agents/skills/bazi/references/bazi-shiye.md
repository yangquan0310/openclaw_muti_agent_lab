# 八字事业专题

> **本文档是八字技能事业分析的内部参考。**
> 适用于：所有八字解读中的"事业/工作/职业"判断——**单盘**。
> **核心问题**：你的事业怎么发展？适合什么工作？什么时候有事业变动？
> **不是**合盘分析 ——合盘见 [`bazi-hehun.md`](bazi-hehun.md)。

---

## 〇、设计原则

- **以对象为中心**——不是流程为中心：3 个对象 = 工作 + 创业 + 关系
- **官杀 = 看工作**——职位/上司/体制
- **食伤 = 看创业**——表达/创造/技术
- **只看异位关系**——不自比
- **关系 > 字本身**：字无意义，关系才是一切
- **隐晦必断**：多个候选必须用 5 规则选 1

> **事业 =工作——官杀 + 创业——食伤 + 关系——行业-人际**

---

## 一、官杀

> **这一章只讲"工作"是什么**

### 1.1 怎么找官杀

**操作**：

- 男命：**克我** = **官杀**——官 = 正官 = 上司；杀 = 七杀 = 压力
- 女命：**克我**也是官杀，但**财生官**——后面讲
- 看四干 + 地支藏干

**大白话**：先认清楚**这份工作是什么属性**

### 1.2 官杀的强度

**操作**：

- **得令**：月支是否生扶官杀——一般是水
- **有根**：地支有无同类
- **得生**：有无财生官
- **得助**：有无同类帮

**大白话**：官杀是**有**还是**没有**、是**强**还是**弱**

### 1.3 官杀的异位关系

#### 位置含义速查

- 年柱 = 祖辈、出身、童年底色
- 月柱 = 父母、事业、成长环境——最关键的能量
- 日柱 = **自己 + 配偶**
- 时柱 = 子女、晚年、未来

天干 = 外在表现、别人看到的你
地支 = 内在世界、家、隐藏的你

#### 7 大关系 + 暗含

- **冲**：动荡，如出身冲击事业、父母反对创业
- **合**：绑定，如配偶影响事业、领导绑定你
- **刑**：暗伤，如事业中有隐性问题
- **害**：阴损，如被人暗中使坏
- **破**：慢性消耗，如工作环境慢慢变差
- **生**：帮忙，如有人支持你
- **克**：压制，如领导压你

### 1.4 喜忌+流通位置

- **喜忌**：你极旺喜克泄 / 极弱喜生扶
- **流通位置**：官杀在五行流转中**卡住**还是**畅通**

### 1.5 一句话：这**工作**是什么样的？

> **这工作——官杀是 [材质] 做的，强度 [评分]，与你 [喜/忌]，在公司/体制中 [角色]。**

## 二、食伤

> **这一章只讲"创业能力/表达"是什么**

### 2.1 怎么找食伤

**男命**：

- **食神**——我生之异性= **食神** = 才华、口福、表达
- **伤官**——我生之同性= **伤官** = 创业、叛逆、表达

**女命**：

- **食神** = 才华、温柔表达
- **伤官** = 创业、强势表达

**5 规则判定真食伤**——多个候选时：

- **① 透干 > 藏支**
- **② 与日干紧贴**——同柱 > 隔柱
- **③ 与日干合化**——天作之合 = 最强证据
- **④ 与日干直接生克**
- **⑤ 配合施药方向**

### 2.2 食伤的强度

**同 §1.2**——4 维度打分

### 2.3 食伤的异位关系

**同 §1.3**

**重点暗含**：

- 食伤冲印 = **反权威**——顶撞上司、叛逆
- 食伤生财 = **生财有道**——用才华换钱
- 印克食伤 = **被压制**——被父母/体制管束才华

### 2.4 喜忌+流通位置

- **喜忌**：身旺喜食伤生财 / 身弱忌食伤泄身
- **流通位置**：食伤是**身→财**的**中间人**，没有它就生不出财

### 2.5 一句话：这**创业能力**是什么样的？

> **你的食伤是 [材质] 做的，强度 [评分]，与你 [喜/忌]，表达/创业风格 [十神特质]。**

## 三、关系

> **这一章只讲"事业环境和运势"**

### 3.1 工作稳定性

- 官杀与**日支**的关系：
  - 官杀**克**日支 = 工作**压力你**——不稳定
  - 官杀**生日支** = 工作**滋养你**——稳定
  - 官杀与日支**冲** = 工作变动

### 3.2 行业方向

- **施药 = 行业五行**
- 金 = 金融/机械/汽车/钢铁
- 木 = 教育/文化/出版/医药
- 水 = 流通/航运/酒水/旅游
- 火 = 科技/能源/互联网/餐饮
- 土 = 房产/农业/陶瓷/建筑

### 3.3 事业流通

```
印 → 身 → 食伤 → 财 → 官
木 → 火 → 土 → 金 → 水
```

**找堵点**：

- **印堵食伤** = 想法有但**不敢表达** → 影响晋升/创业
- **比劫夺财** = 同辈抢功 → 影响收入
- **官杀克身** = 工作压力太大 → 扛不住
- **身太旺无制** = 精力过剩 → 容易急躁

**大运配合**：

- 当前大运施药得力 = 事业上升
- 当前大运施药受克 = 事业受阻

### 3.4 一句话：这**事业**整体怎么样？

> **这事业 = [工作]+[创业]+[关系]，[整体评级]，堵点 = [主堵点]。**

## 四、综合判断实战

> **把前三章的框架套到老板身上，跑通一遍**

### 4.1 这**工作**是什么 → 癸

**字本身**：

- **癸** = 水 = **正官**——工作
- 位置：**年支子**——藏干
- 强度：**0/4 极弱**——藏支不透

**异位关系——不自比**：

- 年干丙 → **癸克丙**——水克火 = 官克身⚠️
- 月干辛 → 金生水 ✅——**财生官**
- 日干丙 → **癸克丙**——水克火 = 官克身⚠️
- 时干丁 → **癸克丁**——水克火 = 官克劫⚠️
- 月支卯 → 水生木 ✅——**官生印**
- 日支午 → **子午冲** ⚠️⚠️⚠️——**工作冲家**
- 时支酉 → 金生水 ✅——**偏财生官**

**位置含义暗含**：

- 官在**年支**——出身/祖辈→ 事业起点低
- 官**不透干**——藏支→ 事业**隐蔽/不稳定**
- 财生官——辛生子→ **有钱能办事业**

**喜忌+流通**：

- 喜忌：4/4 极旺喜金水 → **官是你的喜神** ✅
- 流通：财生官——金生水✅ 流通顺畅

**一句话工作**：

> **这工作——癸正官是水做的，0/4 极弱但藏年支，财——金生官——水流通好，是你的喜神但被家冲——子午冲。**

---

### 4.2 这**创业能力**是什么 → 午藏己

**字本身**：

- **己** = 土 = **食神**——才华/创业
- 位置：**日支午藏干**——藏支
- 强度：**0/4 极弱**——藏支不透

**异位关系——不自比**：

- 年干丙 → 丙火生己土 ✅——**印生食伤**
- 月干辛 → 辛金生己土 ✅——**财生食伤**
- 日干丙 → 丙火生己土 ✅——**印生食伤**
- 时干丁 → 丁火生己土 ✅——**劫生食伤**
- 年支子 → 土克水 ✅——**食伤制官**
- 月支卯 → 木克土 ⚠️——**印克食伤**
- 日支午 → 同柱 ✅
- 时支酉 → 土生金 ✅——**食伤生财**

**位置含义暗含**：

- 食神在**日支**——家/内在→ 才华**藏在内心**
- 食神**不透干** → 表达**不主动**
- **印生食伤多**——丙、丁都生己→ 才华**有，但被长辈/自己想法压制**

**喜忌+流通**：

- 喜忌：4/4 极旺 → **食伤是你的喜神**——生财
- 流通：印克食伤——卯克己= **堵点** ⚠️

**一句话创业**：

> **这创业能力——己食神是土做的，0/4 极弱但藏在日支，印克食伤堵点——卯克己，但财——金能生食伤 = 财能激活创业。**

---

### 4.3 这**事业**整体怎么样 → 关系 + 流通

**工作稳定性**：

- 官——癸在**年支** + 被**子午冲** = 事业**动荡**
- 但**财生官**——金生水流通好 = **有钱能办事业**

**行业方向**：

- 施药 = **金水**
- 金 = 金融/机械/汽车/科技硬件
- 水 = 流通/航运/酒水/旅游/互联网
- **适合行业**：金融、汽车、机械、互联网

**事业流通**：

```
印——卯→ 身——丙+丁+午= 生 → 身极旺
                          ↓
                       食伤——己= 弱——藏支⚠️
                          ↓
                 财——辛+酉→ 身 = 被劫 ❌
                          ↓
                     官——癸→ 印 = 通 ✅
```

**3 大堵点**：

- **堵点 1**：身旺 → **食伤极弱** ⚠️⚠️⚠️——**你表达不出、创业能力被压**
- **堵点 2**：财被劫 ⚠️⚠️——**你抢钱/同辈抢功**
- **堵点 3**：印克食伤——卯克己⚠️——**母亲/学习压制创业**

**唯一流通**：

```
财——辛+酉→ 官——癸→ 印——卯→ 身——丙
```

**大白话**：**钱 → 给你事业 → 让你学习 → 你做事**

### 4.4 一句话事业

> **这事业 = 极旺身 + 弱官 + 弱食伤 + 子午冲工作 + 印克食伤创业压制 + 财生官流通好。适合金融/机械/汽车行业，但表达/创业能力被压，需要刻意表达。**

---

### 4.5 化解方案

- **子午冲**——工作冲家→ **避免事业和工作过度冲突家庭**
- **印克食伤**——母亲/学习压制创业→ **少听长辈意见，多自己表达**
- **食伤弱**——你表达不出→ **多表达、多创作、多练习演讲**
- **财被劫**——你抢钱/同辈抢功→ **专注自己赛道，不与人争**
- **大运配合** → **等金水大运，事业会上升**

## 五、应用 v3.3.1 流通框架

> **本节按新流通框架**（v3.3.0 路径分析 + v3.3.1 距离规则）应用事业分析。
> **v3.3.1 框架核心**：
> - 流通 = 递归结构——**不是固定日干为中心**
> - 递归中心随场景变化——**事业 = 官星模式 = 官杀星**；**创业 = 食伤模式 = 食伤星**
> - 距离规则：**合/冲无视距离**——结构性关系；**生/克/刑/破/害紧贴/相邻**——力量性关系

### 5.1 事业场景的递归中心

**场景 1：官星模式——工作/职位**

- **递归中心：官杀星**——工作/职位/上司
- **分析目标**：命局所有元素对官杀星的影响——工作稳不稳
- **路径树**——以官杀星为根：
  - 官杀星所在位置 ← 相邻天干 + 同柱地支 + 相邻地支——无视距离
  - 上游递归类似

**场景 2：食伤模式——创业/表达**

- **递归中心：食伤星**——创业/表达
- **分析目标**：命局所有元素对食伤星的影响——创业能力强不强
- **路径树**——以食伤为根：
  - 食伤所在位置 ← 相邻天干 + 同柱地支 + 相邻地支——无视距离
  - 上游递归类似

**场景 3：财星模式——收入/财富**

- **递归中心：财星**——收入/财富
- **分析目标**：命局所有元素对财星的影响——财运好不好

### 5.2 距离规则的实战应用

**无视距离的场景**——合/冲：

- 任何柱的合/冲关系都可以直接分析
- 例：年干与官杀星合化 = **无视距离**
- 例：官杀星所在支与其他支冲 = **无视距离**

**紧贴/相邻的场景**——生/克/刑/破/害：

- 必须按紧贴/相邻判定
- 同柱 > 相邻 > **隔柱不直接作用**（**不**"减半"，根本不生效——除非合/冲无视距离）> 跨柱中转
- 例：官杀星与相邻天干生克 = **紧贴**——按力量判定
- 例：官杀星与隔柱天干生克 = **不直接作用**（除非合/冲无视距离）

### 5.3 实战模板

分析任何事业问题，按以下流程：

[1] **确定场景**：官星模式——工作or 食伤模式——创业or 财星模式——财运
[2] **画路径树**：以中心元素为根，向上游递归展开
[3] **判定距离**：每条路径上按距离规则判定
[4] **输出堵点**：按力量层级排序，输出主堵点、次堵点、唯一通路

### 5.4 与旧框架的区别

| 维度 | 旧框架（v1.x）| 新框架（v3.3.1）|
|------|-------------|----------------|
| **结构** | 按对象分类——工作+创业+关系| 场景化递归——官星/食伤/财星|
| **距离规则** | 全部按紧贴/相邻 | **合/冲无视距离 + 生克刑破害紧贴/相邻** |
| **路径分析** | 单一分析——每个对象分别看| 递归路径树——以中心元素为根|
| **实战输出** | 异位关系清单 | 路径分析 + 堵点清单 |
