## 二、核心立场 + 依据类目

### 2.1 五条核心立场

| # | 立场 | 反例——不许做 |
|---|------|----------------|
| 1 | **每句话标依据** —— 每一句断言后用 `[依据: 类别]` 标明来源 | "暗合生水"——混用术语|
| 2 | **术语洁净不混用** —— 暗合是暗合，相生是相生，合冲是合冲 | "酉子暗合"——子酉不合，是普通关系|
| 3 | **用现代汉语** —— 基于工具数据 + 传统命理逻辑给明确判断，用大白话写 | 堆术语不解释；说"候选方向供参考" |
| 4 | **不仿古不假托** —— 不编"古贤云"，不写"某派认为" | 不假装有师承 |
| 5 | **综合而非偏** —— 天干地支同等看，藏干取本气，不偏"天派"也不偏"地派" | 不一边倒 |

### 2.2 依据类目

```

[依据: 十神配置] -- 比肩/劫财/食神/伤官/偏财/正财/七杀/正官/偏印/正印
[依据: 藏干本气] -- 地支藏干本气判定十神

[依据: 六合六冲] -- 地支六合 / 六冲
[依据: 三合方合] -- 三合局 / 方合半会
[依据: 藏干中余气] -- 必要时展开中气/余气——默认只用本气
[依据: 流时推算] -- 流年 / 流月 / 流时柱的叠加
```

## 四、宫星系统（分析线核心组件）

> ** 2026-08-20 17:50 拍板**："星看交互，确定星的人际关系！宫有藏干，与星交互，确定整个宫的状态！"
> **定位**：宫星系统 = 六亲 / 具体事项（姻缘 / 事业 / 财等）分析的分析基础——**宫管环境，星管人，藏干是家里的员工，星是进门的住户——三层一起定一件事的吉凶**。

### 4.1 宫位系统（四柱六亲宫）

**宫 = 地支**（容器 / 部门 / 房子）——只有地支才有藏干，才能装人。

| 宫 | 位置 | 管什么 |
|:---|:---|:---|
| **祖上宫** | 年支 | 祖辈、出身、家宅、童年底色 |
| **父母宫**（兼事业宫）| 月支 | 父母、事业、成长环境、手足 |
| **夫妻宫**（婚姻宫）| 日支 | 婚姻、配偶、自身家庭 |
| **子女宫**（兼晚年宫）| 时支 | 子女、晚年、末运 |

> 出处对应：`bazi-liutong.md` 应用聚焦层（家宅祖上=年支 / 事业宫=月支 / 婚姻宫=日支 / 子女晚年=时支）+ `bazi-rules.md` §五（流年动年柱看祖上、流月动月柱看父母手足、流时动时柱看子女晚年）。

### 4.2 六亲星映射（哪星对应哪亲）

**星 = 十神**——星是六亲的代表，看"哪个星"就知道"哪个人"。

**男命**：

| 六亲 | 十神 | 说明 |
|------|------|------|
| **妻** | 正财——异性同五行 | 月干或时干 |
| **父亲** | 偏财 | 命中若无 = 父亲缘单薄 |
| **母亲** | 正印 | 月支藏干 |
| **女儿** | 正官 | 命中若弱 = 女缘单薄 |
| **儿子** | 七杀——部分流派/ 食神 | 命中若无 = 子缘薄 |
| **兄弟** | 比劫 | 命中多 = 兄弟多但易变对手 |

**女命**：

| 六亲 | 十神 | 说明 |
|------|------|------|
| **夫** | 正官——异性同五行 | 月干或时干 |
| **父亲** | 偏财 | 命中若无 = 父亲缘单薄 |
| **母亲** | 正印 | 月支藏干 |
| **儿子** | 食神——同性 | 命中若无 = 子缘薄 |
| **女儿** | 伤官 | 命中若无 = 女缘薄 |
| **兄弟** | 比劫 | 命中多 = 姐妹多 |

**性别未确认** → 用中性六亲，标注"六亲映射维度留白"（Step 0 规则）。

### 4.3 三层结构（宫 / 天干 / 藏干 / 星）

> ** 2026-08-20 17:45-17:47 拍板**："宫是容器，是部门，天干是负责人，宫藏干是员工" → 修正："宫一般是地支吧？地支才有藏干（员工）。毕竟天干是固定的。"

- **宫 = 地支** = 容器 / 部门 / 房子——管"在哪个领域"
- **天干 = 固定门牌**——四柱排出来就固定，是明面标签，**不参与"进/出"动态**
- **宫藏干 = 员工**——本气 / 中气 / 余气——部门里的内部人员配置，决定部门真正实力
- **星（十神）= 访客**——财 / 官 / 印 / 比劫 / 食伤——**星才是能"进宫"的**，看它落在哪个宫

### 4.4 星看交互 → 定星的人际关系

**星的状态不由它自己定，由它跟周围干支的交互定**：

- 星被**生/合** → 关系好、有助力（妻星得生 = 婚姻得力）
- 星被**克/冲/刑/害/破** → 关系差、有摩擦（夫星被伤官克 = 婚姻不顺）
- 星**透干** = 显性、明面；星**藏支** = 隐性、暗藏
- 例：妻星透月干被比劫争合 → 妻星被"抢" → 桃花竞争
- 例：夫星藏时支被克 → 夫星"受伤" → 姻缘曲折

### 4.5 宫藏干与星交互 → 定宫的状态

**星（人）进到宫里，跟藏干（员工）交互，交互结果 = 宫（家）的状态**：

- 星与藏干**相生/合** → 宫和睦，状态好（人住进家，家和万事兴）
- 星与藏干**相克/冲** → 宫内部冲突，状态差（人进门就吵，家宅不宁）
- 宫被**外部的冲/合/刑/害/破** → 房子本身动荡
- 例：妻星（正财）进夫妻宫（日支）→ 看妻星与日支藏干的关系 → 定婚姻宫状态

### 4.6 宫星配合判读（四步）

1. **先看宫**——位置对不对？宫被冲/合/刑/害/破 = 部门动荡
2. **再看星**——对应的六亲星（财/官/印/比劫/食伤）落在哪个宫？
3. **星落宫位**——夫妻星落夫妻宫 = "人住进家"（最好）；落他宫 = 异地/晚婚/聚少离多
4. **再看藏干**——员工强弱 = 内部细节（本气/中气/余气，决定部门真正实力）

**同一个宫，进的星不同，事就不同**（以日支为例）：

- 日支进的是妻星（正财）→ 婚姻事
- 日支进的是印星 → 配偶像"妈/管家"型
- 日支进的是比劫 → 配偶像"兄弟/对手"型

### 4.7 与场景化递归的衔接

> `bazi-liutong.md` §1.1.1 应用聚焦层 = 宫星系统的"中心切换"——**看婚姻 → 中心 = 夫妻宫（日支）+ 夫妻星；看事业 → 中心 = 事业宫（月支）+ 官杀星**。思路不变，只是中心可换。

| 场景 | 中心（递归中心）| 看什么 |
|:---|:---|:---|
| 命局身强弱 | **日干** | 身是否强 / 弱 |
| 婚姻宫 | **日支** | 婚姻是否稳 |
| 事业宫 | **月支** | 事业是否成 |
| 家宅祖上 | **年支** | 家宅是否宁 |
