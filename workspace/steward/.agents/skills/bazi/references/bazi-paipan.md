## 二、五条核心立场

| # | 立场 | 反例（不许做） |
|---|------|----------------|
| 1 | **每句话标依据** —— 每一句断言后用 `[依据: 类别]` 标明来源 | "暗合生水"（混用术语）|
| 2 | **术语洁净不混用** —— 暗合是暗合，相生是相生，合冲是合冲 | "酉子暗合"（子酉不合，是普通关系）|
| 3 | **用现代汉语** —— 基于工具数据 + 传统命理逻辑给明确判断，用大白话写 | 堆术语不解释；说"候选方向供老板参考" |
| 4 | **不仿古不假托** —— 不编"古贤云"，不写"某派认为" | 不假装有师承 |
| 5 | **综合而非偏** —— 天干地支同等看，藏干取本气，不偏"天派"也不偏"地派" | 不一边倒 |

## 三、解读流程（强制 5 步）

> **v1.4.0 老板纠错（2026-07-26 05:30）**：原 6 步流程结构不调理。
> **新流程逻辑链**：输入 → 基础分析 → 横向应用 → 时间维度 → 落地行动
> **核心改动**：(1) 必问项从独立步骤降级为 Step 1 的前置条件；(2) 格局 + 用神合并为 Step 2「分析」（二者都是命局基础分析，不是两个独立步骤）。

### Step 0：必问一件事 + 选问其他（前置条件，v1.1.1 老板修正）

**必问**：
- **命主性别？男命 / 女命**
  - **为什么必问**：性别 → 决定六亲映射（男命财=妻、官杀=子女；女命官杀=夫、食伤=子女）。这是解读骨架的一部分。

**选问**（按需 — 不是必问）：
- 命主行业 + 岗位？
- 出生真太阳时修正需求？
- 阴历 / 阳历（如有歧义）？
- 当前关注问题（事业 / 婚嫁 / 财运 / 健康）？

**老板没答必问怎么办**：先**给出通用版解析**（用中性六亲），再标"性别未确认 → 六亲映射维度留白"。

**老板没答选问怎么办**：直接**跳过该维度**，**不标"留白"**——只输出核心维度（必问 + 排盘 + 用神 + 流年 + 行动表）。

### Step 1：排盘（事实层）

```
调用 bazi 工具输出四柱：
- 年柱、月柱、日柱、时柱（天干 + 地支 + 藏干 + 十神）
- 农历 + 节气 + 生肖（生肖 = 年支，不看日支！）
- 节气校验：立春已过/未过、惊蛰已过/未过
```

**输出渠道区分**（决策 3 同步 §七.6）：
- **markdown 表格**：飞书 / 微信 / 完整文档场景
- **bullet list**（`- xxx：xxx`）：QQ 渠道（每张 markdown 表格在 QQ 会被拆成独立窗口）

> 不在 ASCII art 表格里硬塞十神 + 藏干 + 五行——按渠道选格式，老板能"听懂 + 用上"。

### Step 2：分析（基础层 · 三种分析并列）

> **v1.6.0 老板拍板**（2026-08-08 14:58）：原"格局 + 用神合一"重构为**三种分析并列** = **正格 + 势局 + 神煞**。
> - **正格** = 命局之"骨"（月令定格 + 八格标准 + 用神方向）
> - **势局** = 命局之"势"（旺衰 + 流通 + 调候 + 精化用神）
> - **神煞** = 命局之"助缘"（28 神煞 + 一体两面 + 五维映射）
> - 三者**不可分割**：正格定骨架、势局定流通、神煞定辅助
> - 详细理论见 `bazi-zhengge.md` + `bazi-shiju.md` + `bazi-shensha.md`

#### Step 2a：正格分析（命局之"骨"）

> **理论依据**：`bazi-zhengge.md` v1.0.0（渊海子平 + 三命通会 + 人伦大统赋 + 千里命稿）

**做什么**：

1. 月令定格（按日主查表）
2. 透干判定（月令本气是否透出天干）
3. 八格标准（透干成格 → 8 种标准格局）
4. 用神方向（按格局类型选喜忌，§三.1 总则）
5. 破格 / 救应（检验格局是否成立）

**输出要素**：

- 格局 = 一句话（如"正印格" / "正财格" / "七杀格"）
- 用神方向 = 一句话（如"财星制印" / "食神制杀"）
- 相神 / 忌神 / 仇神 = 各一句话

**一眼格局**（三档分类）：

| 档 | 内容 | 标签 |
|----|------|------|
| **强证据** | 工具可直接验证的事实 | `[依据: 十神配置]` 等 |
| **弱提示** | 工具层 + 古籍口径，需注意 | `[依据: 古籍口径]` |
| **不强解** | 工具未实现或知识不足 | 明确标出 |

#### Step 2b：势局分析（命局之"势"）

> **理论依据**：`bazi-shiju.md` v1.0.0（滴天髓 + 子平真诠 + 穷通宝鉴）

**做什么**：

1. 旺衰四维度（得令 / 得地 / 得生 / 得助）
2. 调候判定（春/夏/秋/冬）
3. 流通分析（阻滞 + 制化）
4. 特殊格局判定（正格不成时 → 从强/从弱/化气/一行得气/两神成象/三奇）
5. 融合用神（扶抑 + 调候 + 流通 → 最终用神）

**输出要素**：

- 旺衰 = 一句话（如"4/4 极旺" / "3/4 旺"）
- 调候用神 = 一句话（如"壬水第一"）
- 流通机制 = 一句话（如"财破印通关"）
- 最终用神 = 一句话（融合后）

#### Step 2c：神煞分析（命局之"助缘"）

> **理论依据**：`bazi-shensha.md` v2.1.1（一体两面 + 需求双面化 + 五维映射）

1. 按柱归位（年/月/日/时柱分别列出）

#### Step 2d：用神融合（Layer 2 子流程 · 仅 2a + 2b）★ v1.7.0 新增

> **理论依据**：`bazi-yongshen.md` v1.0.0（用神判定子流程参考）

> **关键原则**：⚠️ **神煞不进入用神判定**（用神 = 十神五行；神煞 = 28 神星）

**v1.7.0 新增**：原 v1.6.0 的"正格 + 势局 + 神煞"是 Layer 1 三种分析并列，**用神判定是 Layer 2 子流程**——基于正格（Step 2a）+ 势局（Step 2b）融合得出最终用神。**用神是融合产物，不是第四种分析**。

**做什么**：

1. **正格方向**（来自 Step 2a）：基于格局类型选喜忌总则
2. **势局精化**（来自 Step 2b）：旺衰 + 调候 + 流通 → 用神精化
3. **融合** → 最终用神（1-2 个五行，一句话）

**融合公式**：

```
最终用神 = 正格方向 ∩ 势局精化
         = 方向优先 + 精化补强
```

**三种融合情况**：

| 情况 | 处理 |
|---|---|
| 方向 = 精化 | 直接用 ✅ |
| 方向 ⊂ 精化 | 取精化补强 |
| 方向 ≠ 精化 | 以正格方向为主 + 势局补充调候 |

**调候 vs 扶抑优先级**（势局内部）：

- 调候用神 = 第一优先级（穷通宝鉴）
- 扶抑用神 = 第二优先级
- 冲突时 → **调候优先**

**输出要素**：

| 层级 | 来源 | 输出 |
|---|---|---|
| 正格方向 | `bazi-zhengge.md` §三.1 | 一句话 |
| 势局精化 | `bazi-shiju.md` §3-§5 | 一句话 |
| 最终用神 | 融合 | **一句话**（如"金水（壬水为核，庚辛次之）"）|

**为什么用神是融合产物，不是第四种分析**：

- 用神判定仅依赖正格 + 势局（神煞不参与）
- 三种分析并列（正格 + 势局 + 神煞）是命局的三个独立输入维度
- 用神是前两个输入维度的融合产物
- 神煞直接进入五维（Layer 3），不经融合

**详细规范**：见 `bazi-yongshen.md` v1.0.0

### Step 4：流年 / 月 / 时叠加（时间层）

按节气切流月，逐一分析：
- 干十神 vs 日主

## 六、行业五行匹配（v1.1.0 新增）

### 核心思路

不同行业的"气场" = 不同五行主导。命主五行 vs 行业五行 = 契合度。

| 行业大类 | 主五行 | 适合命主 |
|----------|--------|----------|
| **科技 / AI / 互联网** | 金（技术）+ 水（智慧）+ 火（创新） | 命中金水旺 |
| **金融 / 投资 / 销售** | 金 + 水 | 命中财星旺 |
| **文化 / 艺术 / 设计** | 木 + 火 | 命中食伤 / 印星 |
| **教育 / 研究** | 木 + 水 | 命中印星 |
| **服务 / 陪伴 / 心理** | 木（关怀）+ 火（温暖）+ 水（情感） | 命中食伤 + 印星 |
| **管理 / 行政** | 土 + 火 | 命中食伤 + 比劫 |
| **医疗 / 健康** | 木 + 火 | 命中印星 + 食伤 |

### 大管家风格判断

按老板的命主五行 + 老板行业 → 给出**契合度判断** + **调整方向**。

示例（虚位以待）：
- 命主丙火 + 行业"情感陪伴机器人研发" → **五行高度契合**（太阳温暖万物）
- 命主丙火极旺 + 研发岗位 → 印星滋养食伤（学习 → 创新）

## 七、输出美学（强制）

### 7.1 输出格式

```
## [主题]
（如：2026 你的事业运势）

[1-3 句话总结核心]

### [分段标题]
（如：排盘、分析、性格、事业、财、姻缘、健康、流月、行动表）
[用现代汉语写结论，每条带 [依据: ...]]

```

### 7.2 现代汉语规则

| ✅ 写 | ❌ 不写 |
|--------|---------|
| "你今年会被迫重新定义自己" | "今年流年柱伏吟日柱，自我重叠" |
| "今年不适合升职加薪" | "官杀弱而无补" |
| "钱会很紧" | "财星受克于比劫夹击" |
| "9 月不要借大额" | "9 月劫财+正财同台" |
| "7 月是沉淀期" | "7 月印+伤官对撞" |
| "今年你会撞上 3 年前的自己" | "日柱伏吟于流年" |

**原则：术语是工具不是终点。最终输出要让老板能"听懂 + 用上"。**

### 7.3 行动表(每份解读都带)

```
## 具体行动表
[1] 时间 + 动作 + 原因(用现代汉语)
[2] ...
```

### 7.4 节标题规则(v1.1.2 老板拍板)

**节标题必须简洁干净,不带括号副标题**。

| ✅ 写 | ❌ 不写 |
|--------|---------|
| `一、排盘` | `一、排盘(强证据)` |
| `五、婚姻` | `五、婚姻(敢断)` |


**括号副标题要表达的信息怎么放**:

| 旧位置 | 新位置 |
|--------|--------|
| 章节标题括号里 | 该章节**第一句话**直接陈述(如"按子平真诠+滴天髓+穷通宝鉴三书融合判定") |
| 表达强弱证据档位 | 在**条目末尾**用 `[依据: 类别]` 标 |
| 表达流派立场 | 用最末"具体行动表"前置一段引言点出 |

**原则**：**节标题是骨架,不能臃肿;正文才是细节、依据、立场的归处**。
副标题塞在括号里 → 老板读标题就被劝退,不如让正文自然承接。

### 7.5 输出精简规则(v8.45.0,2026-07-26 老板怒纠)

老板反馈:"为什么每次强调工具输出是马,是错误的。就是你的文本输出,有很多没必要的信息"。

**do 型规则(强制)**:

[1] **不重复标注工具 bug**
- ❌ 每次排盘都写"工具输出是马/鸡/猴是 bug"
- ✅ 只在**第一次**遇到 + **新场景**首次出现时提
- ✅ 后续直接用**正确的年支生肖**(默默纠错即可)

[2] **依据标签只在关键处使用**
- ❌ 每句话都贴 `[依据: 类别]`
- ✅ 只在**有争议 / 敢断 / 用户问"凭什么"**处使用

[3] **避免堆砌 metadata 噪音**
- ❌ 每次都列:节气精度 < 1 天 / 阳历默认 / 真太阳时默认 / 晚子时 / 早子时
- ✅ 只在**用户问"为什么"** / **边界情况**时才提

[4] **重复信息合并**
- ❌ 排盘用两张表(一张含藏干、一张不含)

- ❌ 事业+姻缘拆两个解读框架
- ✅ **一表联合展示**(用户问什么就给什么)

[5] **不强解清单只在用户问"还有什么强解"时才列**
- ❌ 每次结尾都贴"不强解清单"
- ✅ 默认省略,用户主动问才列

[6] **注 章节最小化**
- ❌ 每次结尾都"注:节气精度 < 1 天 / 真太阳时..."
- ✅ 只在**真太阳时不可忽略**(如新疆出生) + 用户问时才写

[7] **直接结论先行**
- ❌ 长铺垫 + 多个铺垫段 + 慢慢到结论
