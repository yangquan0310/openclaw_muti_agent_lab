## 一、流通路径分析框架

### 1.1 核心思想：流通是递归结构

- **流通的本质 = 递归分析**：每个元素的"如何被影响" = 向上游递归追溯
- **递归对象 = 场景中心**：不同场景下，递归的中心不同——不是固定日干
  - 命局模式 → 递归中心 = **日干**——命局对日干的影响
  - 婚姻宫模式 → 递归中心 = **日支**——命局对婚姻宫的影响
  - 婚姻星模式 → 递归中心 = **夫星/妻星**——命局对婚姻星的影响
  - 其他场景 → 递归中心 = 相应星曜，如子女宫 = 时支，官星 = 官杀星等
- **生效距离铁律（v3.4.0 老板拍板）**：递归路径上，**合/冲**可无视距离；**生/克/刑/破/害** = **只有临近（紧贴/相邻）生效**，隔柱不直接作用（不"减半"，根本不生效）
- **递归终止**：到年干为止——年干没有上游；到没有更上游的元素为止
- **v3.0.0 衔接**：本版本**保留** §一 4 条铁律——合化优先 / 冲刑破害 / 通关阻隔 / 藏干透干+ §二 3 节规则——天干作用 / 天干-地支 / 力量层级，**作为递归路径上每一步的判定依据**

### 1.2 路径分析树

```
                        ┌──[日干]──┐    ← 最终目的地——根
                       /     |     \
              [月干]    [日支]    [时干]    ← 3 个直接入口
              /    \      / \        |
        [年干] [月支] [月支] [时支]  [时支]  ← 第二层
              |       |  \          |
          [年支]   [年支] [日支]   [日支]  ← 第三层
```

**完整路径清单**——按"日干为根"递归：

| 目标元素 | 直接影响源 | 递归到上一层的入口 |
|----------|-----------|-------------------|
| **日干** | 月干、日支、时干 | ——3 个直接入口|
| **日支** | 月支、时支 | ——相近地支|
| **月干** | 年干、月支 | ——年干 = 相邻天干 / 月支 = 同柱地支|
| **时干** | 时支 | ——同柱地支|
| **月支** | 年支、日支 | ——相近地支；月干同柱在分析月干时已考虑|
| **时支** | 日支 | ——相近地支；时干同柱在分析时干时已考虑|
| **年干** | 年支 | ——同柱地支|
| **年支** | 月支 | ——相近地支；年干同柱在分析年干时已考虑|

### 1.3 路径相互作用机制

每条路径的相互作用，按以下规则判定。详见 §二 路径相互作用规则：

- **同柱干支优先**——规则 1—— 最强
- **横向相邻**——规则 2—— 次强
- **跨柱不直接**——规则 3—— 只能走同柱中转
- **同时生克 → 贪生忘克**——规则 4—— 生克取舍
- **地支 4 条铁律**——§一—— 合化优先 / 冲刑破害 / 通关阻隔 / 藏干透干

### 1.4 路径分析的判定顺序

按"日干为根"递归展开，**判定顺序**：

[1] **分析日干**——看月干、日支、时干 3 个直接入口
[2] **分析日支**——看月支、时支相近地支
[3] **分析月干**——看年干、月支
[4] **分析时干**——看时支
[5] **分析月支**——看年支、日支
[6] **分析时支**——看日支
[7] **分析年干**——看年支
[8] **分析年支**——看月支
[9] **判定堵点**——按力量层级，详见 §二.4

**每个节点的判定 = 8 个字**：

> **看紧贴 / 看同柱 / 看冲合 / 看生克**

### 1.5 场景与递归对象

> **关键洞察**：流通的递归结构在**不同场景下中心不同**——不是固定日干。

#### 三大基本场景

**场景 1：命局模式——默认**

- **递归中心：日干**
- **分析目标**：命局整体能量对日干的影响
- **路径树**（v3.1.0 8 层递归）：
  - 日干 ← 月干、日支、时干
  - 日支 ← 月支、时支
  - 月干 ← 年干、月支
  - 时干 ← 时支
  - 月支 ← 年支、日支
  - 时支 ← 日支
  - 年干 ← 年支
  - 年支 ← 月支

**场景 2：婚姻宫模式**

- **递归中心：日支**——婚姻宫 = 日支本身
- **分析目标**：命局所有元素对日支——婚姻宫的影响
- **路径树**——以日支为根：
  - 日支 ← 月支、时支——相近地支+ 日干——同柱
  - 月支 ← 年支、日支——同上递归
  - 时支 ← 日支——同上递归
  - 年干 ← 年支 + 与日支的合冲，如年干-日支六合/相冲
  - 年支 ← 月支
  - 月干 ← 年干、月支——间接通过月支影响日支
  - 时干 ← 时支——间接通过时支影响日支
- **判定动作**：每个路径上的"对日支的影响"是什么——按 §二 规则判定

**场景 3：婚姻星模式——夫星/妻星**

- **递归中心：婚姻星**——女命 = 正官/七杀；男命 = 正财/偏财
- **分析目标**：命局所有元素对婚姻星的影响
- **路径树**——以婚姻星所在位置为根：
  - 婚姻星，如正官辛金在时支酉← 时干——相邻天干+ 时支——同柱地支+ 月支——相邻地支
  - 时干 ← 时支——间接通过时支
  - 时支 ← 日支——相邻
  - 月支 ← 年支、日支
  - 其他路径类似场景 2，但中心换成婚姻星位置
- **判定动作**：每个路径上的"对婚姻星的影响"是什么——按 §二 规则判定

#### 关键原则

[1] **递归中心 = 场景相关的"星曜"**——不是固定的日干
[2] **生效距离铁律（v3.4.0 老板拍板）**：递归路径上，**合/冲**可无视距离；**生/克/刑/破/害** = **只有临近（紧贴/相邻）生效**，隔柱不直接作用（不"减半"，根本不生效）：
   - ✅ **无视距离**：地支六合——子丑合等、地支三合——申子辰等、地支六冲——子午冲等、天干五合——甲己合等、天干相冲
   - ❌ **只有临近生效**：生——生扶、克——克制、刑——三刑、破——六破、害——六害——**隔柱不直接作用（不"减半"，根本不生效）**
   - **本质**：**合/冲 = 结构性关系**——无视距离，因为合/冲本身就是结构；**生/克/刑/破/害 = 力量性关系**——**只有临近生效**，因为生克刑破害需要紧贴的能量传递
[3] **每种场景的路径树不同**：以"中心元素"为根，向**上游递归**展开
[4] **共用 §二 规则**：所有场景下，每条路径上的相互作用判定都按 §二 的 3 节规则——天干作用 / 天干-地支 / 力量层级

#### 相互作用距离总表

| 作用类型 | 无视距离？ | 说明 |
|---------|-----------|------|

- 看相互作用类型 → 是合/冲——无视距离还是生/克/刑/破/害——只有临近生效
- 合/冲：可以直接分析跨柱、隔柱的元素
- 生/克/刑/破/害：**只有临近（紧贴/相邻）生效**——隔柱不直接作用（不"减半"，根本不生效）

#### 实战应用

分析任何命局，**先确定场景**：

- 看整体命局 → 命局模式——中心 = 日干

## 二、路径相互作用规则

> **本节是 v3.0.0 §一——4 条铁律+ §二——4 条作用规则的整合引用**——内容不变，按路径分析框架重新排序。

### 2.1 地支流通 4 条铁律

#### 第一条：合化优先

- 地支出现**六合 / 三合 / 三会**时，**按新五行算**
- 一旦合或会成立，整个组合**整体看新五行**，不再按各自本气算
- 例：寅亥合木 → 寅亥合起来整体当木；亥卯未三合木 → 整体当木
- **判定意义**：合化优先于一切生克——先看是否成合/会，再论其他

#### 第二条：冲刑破害

- **冲、刑、破、害**的作用 = **把中气和余气震出来或打掉**
- 本气是核心受冲击最大；中气余气被冲击会"散"或"被震出来"参与流通
- 例：午酉相破 → 午中丁己被打掉；子午冲 → 子午中藏干被冲散
- **判定意义**：不要只看本气生克——冲刑破害真正改变的是中气和余气的力量分布

#### 第三条：通关与阻隔

- **通关**：当两个五行相克对峙时，**用中间五行化解**，如木土相克用火通关
- **阻隔**——最重要的判定原则：
  - **地支作用，紧贴优先**——紧贴的两个地支先作用
  - **隔住只论冲合，不论生克**——如果两个地支中间隔着其他支，**不直接论生克，只看冲合关系**
- 例：午-酉-子 → 午酉紧贴破——先论破，子午隔柱——隔住只论冲不论生克

#### 第四条：藏干透干 —— 藏干者得势

- **藏干得势**：藏在地支的藏干如果**得月令、有生扶、有根**，可以与透干相比
- **不一定透干就比藏干强**——得势的藏干力大过孤透的天干
- 例：午火虽不透，但午在月令当旺 = **午藏的丁火劫财得势**

#### 4 条铁律口诀

> **第一合化先算新五行**
> **第二冲刑破害震中余**
> **第三紧贴优先隔不论生克**
> **第四藏干得势与透争**

### 2.2 天干作用规则

> **专属于天干与天干之间**——横向相邻柱的天干互相作用的 3 条规则。

#### 规则 1：合化优先于生克

- 若两干相合且**化神成立**，则**合化结果覆盖原有的生克关系**
- 例：甲己合土——化神成立→ 甲己合力**当土**，不再按木土相克算
- 例：丙辛合水——化神成立需条件→ 合化结果覆盖原有的火克金
- **判定意义**：合化是"特殊路径"，一旦成立就**替换**原本的生克

#### 规则 2：冲克优先于生扶

- 若两干相冲，则**冲力直接抵消被冲方的部分能量**，**冲力大于普通生克**
- 例：天干相冲，如丙-壬冲、辛-乙冲等→ 被冲方**部分能量被抵消**
- 例：原本丙-壬是火克水，但若有冲的格局 → 冲力大于克力
- **判定意义**：冲是"破坏性力量"，**比普通克更猛**，**优先抵消被冲方能量**

#### 规则 3：生克按紧贴计算 —— v3.4.0 重大修正

**v3.4.0 修正（老板拍板）**：**刑/破/害/生/克 = 只有临近——紧贴/相邻生效；隔柱不直接作用——不"减半"，根本不生效**

- **同柱，如年干与年支为最紧**——同柱内天干地支紧贴
- **相邻柱，如年干与月干次之**——相邻柱天干横向紧贴
- **隔柱不直接作用**——隔柱距离根本不生效（除非合/冲无视距离）
- 例：年干-月干 = 相邻——力强；年干-日干 = 隔柱——**不直接作用**；年干-时干 = 隔两柱——**不直接作用**
- **判定意义**：**只有临近生效**（紧贴/相邻），隔柱不直接作用（除非合/冲无视距离）

### 2.3 天干与地支的作用

> **专属于天干坐地支**——同柱干支的 2 种特殊作用模式。

#### 盖头

- **天干作用地支**——克/耗地支，同柱内**最强**
- 例：丙午柱，丙火盖午火——火火比和——同类帮身，盖头之"和"
- 例：丙辛同柱，丙火克辛金 = **盖头**——天干克地支
- **判定意义**：盖头 = **天干主动压制/消耗地支**，**地支受克/耗**

#### 截脚

- **地支反克天干**，同柱内**地支反击**
- 例：壬丙同柱，壬水克丙火 = **截脚**——地支反克天干
- 例：午火反克壬水？不对，午火不能克壬水——截脚**必须地支能量能克天干**
- **判定意义**：截脚 = **地支反制天干**，**天干受克/制**——与盖头相反

#### 盖头 vs 截脚 区别

| 维度 | 盖头 | 截脚 |
|------|------|------|
| **主动方** | 天干 | 地支 |
| **被动方** | 地支 | 天干 |
| **关系** | 天干克/耗地支 | 地支反克天干 |
| **力量** | 同柱最强——地支受克/耗| 同柱次强——天干受反制|

**注意**：盖头和截脚可能**同时存在**——同一天干-地支组合既可以盖头又可以截脚，如壬丙同柱 + 丙辛同柱？不对，要看具体组合。

### 2.4 力量层级总表

| 层级 | 作用类型 | 力量 | 说明 |
|---|---|---|---|
| **1——最强** | 同柱干支 | 最大 | 地支生扶天干 > 天干作用地支 |
| **2** | 相邻柱横向 | 强 | 天干对天干、地支对地支，紧贴作用——**生/克/刑/破/害只有这一档生效** |
| **3** | 合 / 冲——无视距离 | 强 | 合化优先于生克；冲力大于普通生克；可跨柱/隔柱 |
| **4** | 跨柱干支 | 不直接作用 | 只能走同柱中转；仅日主取根例外 |
| ❌ | ~~隔柱横向~~ | **v3.4.0 已删** | **隔柱不直接作用**——不"减半"，根本不生效，除非合/冲无视距离 |
| ❌ | ~~隔两柱横向~~ | **v3.4.0 已删** | 隔柱不直接作用（除非合/冲） |
| **排序规则** | 生 vs 克 | 贪生忘克 | 同时生克时优先"生"；同柱生克优先同柱 |

**判定口诀（v3.4.0 修正）**：
> **先同柱——生克同柱优先，再相邻——只有临近生效，隔柱不直接作用——除非合/冲，贪生忘克，取根例外，合冲无视距离**

## 三、路径分析实战

> **本节是"路径分析框架"的实战操作手册**——按 §一.4 的判定顺序，每一层节点怎么分析、判定什么。

### 3.1 第一层：分析日干

**日干的 3 个直接入口**：

| 入口 | 类型 | 影响判定——按十神|
|------|------|------------------|
| **月干** | 相邻柱天干 | 印/比劫 = 帮身 ✅；食伤/财/官杀 = 泄耗克 ⚠️ |
| **日支** | 同柱地支 | 本气生扶 = 帮身 ✅；本气克泄 = 减力 ⚠️ |
| **时干** | 相邻柱天干 | 印/比劫 = 帮身 ✅；食伤/财/官杀 = 泄耗克 ⚠️ |

**判定动作**：

[1] 看 3 个入口**各自是什么十神**——判断帮身还是减力

**第 6 层：分析时支酉金**
