## 一句话定义

> **流通 = 命局能量向日干汇聚的路径分析。**
>
> **核心思想**：日干是命局的中心——所有其他元素——月干/日支/时干/其他地支/其他天干的分析，最终都是为了回答"对日干有什么影响"。
>
> **路径分析 = 树状递归**：日干 ← 月干/日支/时干 ← 各自的来源 ← 以此类推，**递归终止于年干**——无上游。

## 一、流通路径分析框架

### 1.1 双层分析框架：应用聚焦层 + 流通方法层

> **老板 2026-08-18 15:45 拍板**：流通的两个层次不矛盾，是**叠加关系**——
> - **应用聚焦层** = 决定看哪里（以哪个干支为中心）
> - **流通方法层** = 决定怎么看（用**生生不息之辨**——核心非"被克冲刑害破"）

#### 1.1.1 应用聚焦层（决定看哪里）

| 应用场景 | 中心（递归中心） | 看什么 |
|:---|:---|:---|
| 命局身强弱 | **日干** | 身是否强 / 弱 |
| 婚姻宫 | **日支** | 婚姻是否稳 |
| 事业宫 | **月支** | 事业是否成 |
| 家宅祖上 | **年支** | 家宅是否宁 |
| 子女晚年 | **时支** | 子女是否顺 |
| 官运 | **官杀星** | 事业官运 |
| 财运 | **财星** | 财运 |
| 夫星/妻星 | **夫星/妻星** | 婚姻星 |

> **关键**：默认中心 = **日干**；看其他场景 = 换中心。
> 例：看婚姻 → 中心 = **日支**；分析日支在年月时作用下是什么状态。

#### 1.1.2 流通方法层（决定怎么看）—— 核心：**生生不息之辨**

> **老板 2026-08-18 15:43 拍板**："**清浊之辨的核心不在于被克冲刑害破，而在于是否生生不息**"
>
> 按《滴天髓·清浊论》原典："**一清到底有精神**"——"精神" = **生生不息的能力**

**清浊之辨** = **该中心能否生生不息**：

| 判定 | 标准 |
|:---|:---|
| **清** | **有源 + 有流 + 不枯** = 能生生不息 |
| **浊** | **无源 / 无流 / 被阻断** = 不能生生不息 |

**被克冲刑害破 ≠ 清浊**：

| 误区 | 真相 |
|:---|:---|
| ❌ 被克冲刑害破 = 浊 | ✅ 被克冲刑害破 = **浊的可能原因** |
| ❌ 被克冲刑害破就浊 | ✅ 有被作用 ≠ 浊（如果该中心能不息，仍是**清**） |
| ❌ 无外因就清 | ✅ 无外因 ≠ 清（如果该中心已息，仍是**浊**） |

**不息三要素**：

| 要素 | 含义 | 怎么实现 |
|:---|:---|:---|
| **有源** | 上游有持续生扶 | 上游有生我的五行（如金生水） |
| **有流** | 下游能继续传递 | 下游有我生的五行（如水生木） |
| **不枯** | 不被阻断 | 不被合绊 / 冲散 / 害断 |

**实战示例**（以日支为中心分析婚姻宫）：

| 婚姻宫状态 | 清浊判定 | 理由 |
|:---|:---:|:---|
| 亥水日支 + 巳月支冲 + 金源头（年支戌中辛金）生扶 | **清** | 有源有流，虽冲犹清 |
| 亥水日支 + 孤立无援（无金生水、无木受水）| **浊** | 表面平静实则息 |
| 亥水日支 + 巳月冲 + 年时亥亥伏吟隔柱 + 金源头被合 | **浊** | 源被合 + 流被冲 |

#### 1.1.3 生效距离铁律（v3.4.0 老板拍板）

递归路径上：
- **合/冲**可无视距离
- **生/克/刑/破/害** = **只有临近（紧贴/相邻）生效**
- 隔柱不直接作用（不"减半"，根本不生效）

#### 1.1.4 递归终止

递归终止 = **该分析中心已无更上游的元素**为止。

- **不是固定"年干"**——终止条件随当前场景中心变化
- **例 1（命局身强弱模式，中心 = 日干）**：日干 ← 月干 ← 年干 ← 年支——**到年干为止**（因为年干无上游）
- **例 2（婚姻宫模式，中心 = 日支）**：日支 ← 月支 ← 年支——**到年支为止**（因为年支无上游，年干同柱在年支分析中已纳入）
- **例 3（官星模式，中心 = 官杀星）**：官星所在位置 ← 邻居 ← 邻居的上游——**到该路径最上游为止**——具体取决于官星落在哪一柱

> **关键原则**——**终止 = "该路径上再无更上游的递归入口"**，**不**是固定的"年干"边界。

### 1.2 核心心法（老板 2026-08-17 03:48 拍板）

> **流通分析的范围**：同柱、天干之间、地支之间
> **流通的职责**：只做分析找问题，**不治病施药**（治病施药 = 施药环节的事，见 `bazi-shiyao.md`）

**流通三维**：

- **同柱**：干支一体（年柱/月柱/日柱/时柱内部）
- **天干之间**：年-月-日-时横向
- **地支之间**：年-月-日-时横向

### 1.3 路径分析树

> **🆕 v3.4.6 修正**：本节展示**默认场景——命局身强弱模式（中心 = 日干）**的路径分析树；其他场景的路径树见 §1.6 三大基本场景。

```
                        ┌──[日干]──┐    ← 最终目的地——根（默认场景中心）
                       /     |     \
              [月干]    [日支]    [时干]    ← 3 个直接入口
              /    \      / \        |
        [年干] [月支] [月支] [时支]  [时支]  ← 第二层
              |       |  \          |
          [年支]   [年支] [日支]   [日支]  ← 第三层
```

**完整路径清单**——按"**当前分析中心**"递归（默认 = 日干）：

| 目标元素 | 直接影响源 | 递归到上一层的入口 |
|----------|-----------|-------------------|
| **日干**（默认中心）| 月干、日支、时干 | ——3 个直接入口|
| **日支** | 月支、时支 | ——相近地支|
| **月干** | 年干、月支 | ——年干 = 相邻天干 / 月支 = 同柱地支|
| **时干** | 时支 | ——同柱地支|
| **月支** | 年支、日支 | ——相近地支；月干同柱在分析月干时已考虑|
| **时支** | 日支 | ——相近地支；时干同柱在分析时干时已考虑|
| **年干** | 年支 | ——同柱地支|
| **年支** | 月支 | ——相近地支；年干同柱在分析年干时已考虑|

> **关键**：场景中心可换（详见 §1.6）——婚姻宫模式中心 = 日支、婚姻星模式中心 = 夫星/妻星、官星模式中心 = 官杀星 等——对应路径树按中心元素展开。

### 1.5 路径分析的判定顺序

按"**当前分析中心**为根"递归展开，**判定顺序**（以下为**默认命局模式——中心 = 日干**——的 8 层递归；其他场景按 §1.6 三大基本场景的路径树调整）：

[1] **分析日干**——看月干、日支、时干 3 个直接入口
[2] **分析日支**——看月支、时支相近地支
[3] **分析月干**——看年干、月支
[4] **分析时干**——看时支
[5] **分析月支**——看年支、日支
[6] **分析时支**——看日支
[7] **分析年干**——看年支
[8] **分析年支**——看月支
[9] **判定堵点**——按力量层级，详见 §二.4

**每个节点的判定 = 8 个字**：

> **看紧贴 / 看同柱 / 看冲合 / 看生克**

> **🆕 v3.4.6 修正**：判定顺序**取决于场景**——本节展示的是**默认命局模式（日干中心）**的 8 层递归；其他场景（婚姻宫 / 婚姻星 / 官星 / 财星）的路径树见 §1.6。

### 1.6 场景与递归对象

> **关键洞察**：流通的递归结构在**不同场景下中心不同**——不是固定日干。

#### 三大基本场景

**场景 1：命局模式——默认**

- **递归中心：日干**
- **分析目标**：命局整体能量对日干的影响
- **路径树**（v3.1.0 8 层递归）：
  - 日干 ← 月干、日支、时干
  - 日支 ← 月支、时支
  - 月干 ← 年干、月支
  - 时干 ← 时支
  - 月支 ← 年支、日支
  - 时支 ← 日支
  - 年干 ← 年支
  - 年支 ← 月支

**场景 2：婚姻宫模式**

- **递归中心：日支**——婚姻宫 = 日支本身
- **分析目标**：命局所有元素对日支——婚姻宫的影响
- **路径树**——以日支为根：
  - 日支 ← 月支、时支——相近地支+ 日干——同柱
  - 月支 ← 年支、日支——同上递归
  - 时支 ← 日支——同上递归
  - 年干 ← 年支 + 与日支的合冲，如年干-日支六合/相冲
  - 年支 ← 月支
  - 月干 ← 年干、月支——间接通过月支影响日支
  - 时干 ← 时支——间接通过时支影响日支
- **判定动作**：每个路径上的"对日支的影响"是什么——按 §二 规则判定

**场景 3：婚姻星模式——夫星/妻星**

- **递归中心：婚姻星**——女命 = 正官/七杀；男命 = 正财/偏财
- **分析目标**：命局所有元素对婚姻星的影响
- **路径树**——以婚姻星所在位置为根：
  - 婚姻星，如正官辛金在时支酉← 时干——相邻天干+ 时支——同柱地支+ 月支——相邻地支
  - 时干 ← 时支——间接通过时支
  - 时支 ← 日支——相邻
  - 月支 ← 年支、日支
  - 其他路径类似场景 2，但中心换成婚姻星位置
- **判定动作**：每个路径上的"对婚姻星的影响"是什么——按 §二 规则判定

#### 关键原则

[1] **递归中心 = 场景相关的"星曜"**——不是固定的日干
[2] **生效距离铁律（v3.4.0 老板拍板）**：递归路径上，**合/冲**可无视距离；**生/克/刑/破/害** = **只有临近（紧贴/相邻）生效**，隔柱不直接作用（不"减半"，根本不生效）：
   - ✅ **无视距离**：地支六合——子丑合等、地支三合——申子辰等、地支六冲——子午冲等、天干五合——甲己合等、天干相冲
   - ❌ **只有临近生效**：生——生扶、克——克制、刑——三刑、破——六破、害——六害——**隔柱不直接作用（不"减半"，根本不生效）**
   - **本质**：**合/冲 = 结构性关系**——无视距离，因为合/冲本身就是结构；**生/克/刑/破/害 = 力量性关系**——**只有临近生效**，因为生克刑破害需要紧贴的能量传递
[3] **每种场景的路径树不同**：以"中心元素"为根，向**上游递归**展开
[4] **共用 §二 规则**：所有场景下，每条路径上的相互作用判定都按 §二 的 3 节规则——天干作用 / 天干-地支 / 力量层级

- 合/冲：可以直接分析跨柱、隔柱的元素
- 生/克/刑/破/害：**只有临近（紧贴/相邻）生效**——隔柱不直接作用（不"减半"，根本不生效）

#### 实战应用

分析任何命局，**先确定场景**：

- 看整体命局 → 命局模式——中心 = 日干

每种模式都按"以中心元素为根的递归路径树"展开分析。

## 二、路径相互作用规则

> **本节是 v3.0.0 §一——4 条铁律+ §二——4 条作用规则的整合引用**——内容不变，按路径分析框架重新排序。

### 2.1 地支流通核心规则——支气如何发挥到天干

> **核心问题**：**地支的藏干通过什么方式"发挥"到天干？**
> **判定工具**：**刑冲破害合 + 生克** 共 7 种机制。
> **基础数据来源**——哪些地支相互作用、各自如何影响藏干发挥，详见 **`bazi-rules.md` §五 + §2.2**：
> - 藏干表（含取用要点） → `bazi-rules.md` §2.2
> - 六合 / 三合 / 三会的藏干影响 → `bazi-rules.md` §5.1 / §5.3 / §5.4
> - 六冲 / 相害 / 六破的藏干影响 → `bazi-rules.md` §5.2 / §5.5 / §5.6

**7 种机制判定"支气发挥到天干"**：

- **生**（支生干）——支气**直接**发挥到天干
  - 例：甲子（子水生甲木）——子水之气直接上透到甲木
  - 详见 §2.3 地生天
  - 实战强度：⭐⭐⭐⭐ **最利日主**

- **克**（支克干）——支气**反向**发挥到天干（截脚）
  - 例：甲申（申金克甲木）——申金之气反克甲木
  - 详见 §2.3 地克天
  - 实战强度：⭐⭐ **最不利日主**（同柱内最强力克）

- **合**——地支闭藏成完整一气，**藏干并力**发挥到天干
  - 六合：寅亥合木（亥壬甲并力归甲木）
  - 三合：申子辰合水（庚壬戊/癸并力归水）
  - 三会：寅卯辰会木（甲丙戊/乙并力归木）
  - 判定意义：**合化优先于一切生克**——先看是否成合/会，再论其他
  - 实战强度：⭐⭐⭐⭐（合化后成一气）

- **冲**——同级别对撞，**震出中余气**发挥
  - 例：子午冲（癸与丁己被冲散）——本气核心受冲击，中气余气被震出参与流通
  - 判定意义：冲不改变五行属性，只动荡藏干力量
  - 实战强度：⭐⭐⭐（藏干动荡）

- **刑**——循环累积伤害，**震出藏干**发挥
  - 例：寅巳申三刑（金长生位循环刑——藏干被持续震出）
  - 实战强度：⭐⭐⭐（藏干被迫流动）

- **破**——母子反目，**散藏干**（相生反噬）
  - 例：子酉破（金生水反向耗——本应金生水，结果互相消耗）
  - 实战强度：⭐⭐（藏干相耗）

- **害**——帝旺穿墓 + 长生对害，**暗耗藏干**
  - 例：子未害（水帝旺穿木墓——木气被水穿破消耗）
  - 实战强度：⭐⭐（暗耗，难察觉）

**核心口诀**：

> **生克是基础，合冲刑破害是流通调节器——7 种机制共同决定"地支哪些气发挥到天干"**

**判定优先级**（实战顺序）：

- 第一看：**合**（合化成功则整体看新五行，跳过一切单独生克）
- 第二看：**紧贴优先**——紧贴的支先作用，隔柱不直接论生克（只论冲合）
- 第三看：**藏干得势**——得月令、有生扶、有根的藏干比孤透天干还强

**反例——不许做**：

- ❌ 跳过"合"直接看生克——可能错过最关键的闭藏成气
- ❌ 看生克不看刑冲破害——错过藏干流动的关键机制
- ❌ 把孤透天干当绝对权威——得势藏干（午中丁火当旺）力大过孤透

### 2.2 天干作用规则

> **专属于天干与天干之间**——横向相邻柱的天干互相作用的 3 条规则。

#### 规则 1：合化优先于生克

- 若两干相合且**化神成立**，则**合化结果覆盖原有的生克关系**
- 例：甲己合土——化神成立→ 甲己合力**当土**，不再按木土相克算
- 例：丙辛合水——化神成立需条件→ 合化结果覆盖原有的火克金
- **判定意义**：合化是"特殊路径"，一旦成立就**替换**原本的生克

#### 规则 2：冲克优先于生扶

- 若两干相冲，则**冲力直接抵消被冲方的部分能量**，**冲力大于普通生克**
- 例：天干相冲，如丙-壬冲、辛-乙冲等→ 被冲方**部分能量被抵消**
- 例：原本丙-壬是火克水，但若有冲的格局 → 冲力大于克力
- **判定意义**：冲是"破坏性力量"，**比普通克更猛**，**优先抵消被冲方能量**

#### 规则 3：生克按紧贴计算 —— v3.4.0 重大修正

**v3.4.0 修正（老板拍板）**：**刑/破/害/生/克 = 只有临近——紧贴/相邻生效；隔柱不直接作用——不"减半"，根本不生效**

- **同柱，如年干与年支为最紧**——同柱内天干地支紧贴
- **相邻柱，如年干与月干次之**——相邻柱天干横向紧贴
- **隔柱不直接作用**——隔柱距离根本不生效（除非合/冲无视距离）
- 例：年干-月干 = 相邻——力强；年干-日干 = 隔柱——**不直接作用**；年干-时干 = 隔两柱——**不直接作用**
- **判定意义**：**只有临近生效**（紧贴/相邻），隔柱不直接作用（除非合/冲无视距离）

### 2.3 天干与地支的作用（同柱 5 种关系）

> **专属于同柱干支**——天干与地支在同柱内的 5 种作用模式。
> 由**五行生克 + 干支位置**决定。盖头 / 截脚 = 古名（天克地 / 地克天）。

**5 种基础关系**（按干-支 力量流向）：

- **天生地**（同柱干生支）
  - 干五行生支五行
  - 例：甲午（甲木生午火）、乙巳（乙木生巳火）、丙申（丙火生申金）、丁酉（丁火生酉金）、庚子（庚金生子水）、辛丑（辛金生丑土）、壬辰（壬水生辰土）、癸未（癸水生未中乙木）
  - **实战含义**：干泄气 + 支得力（**支受益最大**）

- **天克地**（同柱干克支 = 盖头）
  - 干五行克支五行
  - 例：甲辰（甲木克辰土）、乙丑（乙木克丑土）、丙寅（丙火克寅木）、丁卯（丁火克卯木）、戊申（戊土克申金）、己酉（己土克酉金）、庚午（庚金克午火）、辛巳（辛金克巳火）、壬寅（壬水克寅木）、癸卯（癸水克卯木）
  - **实战含义**：干损耗 + 支受制（**支受损**）
  - 注：**盖头 = 天克地的古名**，传统术语沿用

- **地生天**（同柱支生干）
  - 支五行生干五行
  - 例：甲子（子水生甲木）、乙亥（亥水生乙木）、丁卯（卯木生丁火）、戊寅（寅木生戊土）、己巳（巳火生己土）、庚辰（辰土生庚金）、辛午（午火生辛金）、壬申（申金生壬水）、癸酉（酉金生癸水）
  - **实战含义**：支泄气 + 干得力（**干受益，最利日主**）

- **地克天**（同柱支克干 = 截脚）
  - 支五行克支五行 → 实际为支五行克干五行
  - 例：甲申（申金克甲木）、乙酉（酉金克乙木）、丙子（子水克丙火）、丁亥（亥水克丁火）、戊寅（寅木克戊土）、己卯（卯木克己土）、庚巳（巳火克庚金）、辛巳（巳火克辛金）、壬辰（辰土克壬水）、癸未（未土克癸水）
  - **实战含义**：支损耗 + 干受制（**同柱内日主受损最严重**）
  - 注：**截脚 = 地克天的古名**，传统术语沿用

- **天地相同**（同柱干支五行相同）
  - 干五行 = 支五行
  - 例：甲寅、乙卯、丙午、丁巳、戊辰、己未、庚申、辛酉、壬子、癸亥
  - **实战含义**：同气帮身（同柱合力、专旺一行——类似比肩但发生在同柱）

**盖头 vs 截脚 古术语对照**（同属"克"的两类）：

- **盖头（天克地）**：主动方=天干，被动方=地支——天干主动压制/消耗地支
- **截脚（地克天）**：主动方=地支，被动方=天干——地支反制天干

**5 种关系的力量对比**（实战优先级）：

- **最利日主**：地生天（干直接得力）
- **最不利日主**：地克天（干被同柱支克——力量最强）
- **中性帮身**：天地相同（同气合力）
- **干损耗**：天克地（盖头）+ 天生地（干泄气）

**反例——不许做**：

- ❌ 把"天生地"归为"盖头"——盖头只指克，不指生
- ❌ 把"天地相同"当成"比肩"——比肩是**天干-天干**关系，不混同柱干支关系
- ❌ 60 甲子分类时漏掉 5 种之一——必覆盖全部
- ❌ 把"盖头"当成普通天干克地支——盖头是**同柱内**最强层次
- ❌ 把"截脚"当成普通地支克天干——截脚是**同柱内**地支反制

### 2.4 力量层级总表

| 层级 | 作用类型 | 力量 | 说明 |
|---|---|---|---|
| **1——最强** | 同柱干支 | 最大 | 地支生扶天干 > 天干作用地支 |

| ❌ | ~~隔柱横向~~ | **v3.4.0 已删** | **隔柱不直接作用**——不"减半"，根本不生效，除非合/冲无视距离 |

| **排序规则** | 生 vs 克 | 贪生忘克 | 同时生克时优先"生"；同柱生克优先同柱 |
