## 一、什么是流通

### 1.1 流通的概念

- **流通**：命局五行**相生流转**（木→火→土→金→水→木）
- **阻滞 / 堵点**：命中**某五行被克太过**，形成"卡顿"
- **流通顺畅** → 命局活泼、做事顺、好发挥
- **有堵点** → 命局卡顿、做事有阻力、才华施展不开

### 1.2 为什么流通独立成"步骤"

老板 2026-08-10 20:13 拍板"旺衰中的流通，独立出来"——三个理由：

1. **流通是独立分析步骤**（新九步走的 Step 4）—— 在旺衰之后、用神之前
2. **5 种堵点**值得专门讲，每种堵点对应不同化解
3. **与其他参考文档对齐**（正格 / 旺衰 / 神煞 / 用神都有独立 md）

### 1.3 ⭐ v2.0.0 核心转变：看作用，不数数量（老板拍板）

- ❌ **旧做法**：数五行个数（"火有 5 个所以火旺"）→ 只算数量，忽略位置和力量
- ✅ **新做法**：按**作用规则**判定——同柱干支优先、相邻柱力强、隔柱力减半、跨柱不直接作用
- **判定顺序**：先同柱 → 再横向（相邻>隔柱>隔两柱）→ 最后才考虑跨柱根
- **黄金法则**：**一个贴身的相邻作用 > 十个隔柱的数量**

## 二、流通作用规则（3 条核心）⭐⭐

> **老板 2026-08-15 19:46 拍板**：这是流通的核心，**不是数数量！**

### 2.1 规则 1：同柱干支优先作用（最核心，力最大）

**同柱干支上下对应**（年干-年支、月干-月支、日干-日支、时干-时支），关系最紧密：

- **地支为根、天干为苗**：
  - **地支作用天干为主（顺，力大）**（如地支子水生天干壬水）
  - **天干作用地支为次（逆，力小）**（如天干甲木克地支辰土）
- **地支藏干是天干能量来源**：
  - 力量排序：**本气根 > 中气根 > 余气根**
  - **仅同柱地支藏干可直接生扶天干**（如地支寅木藏甲木，助同柱天干甲木）
  - **非同柱藏干仅算"根"，不直接作用**

**判定顺序**：分析任何字，**先看同柱**（它的根/苗是谁，力量最大）

### 2.2 规则 2：柱间横向作用（干对干、支对支，近强远弱）

**同柱分析后**，横向**仅天干与天干、地支与地支作用**：

- **相邻柱力强**，**隔柱力减半**，**隔两柱力极微**
- **天干路线**：年干→月干→日干←时干
  - 相邻相生相克力强（如年干癸克月干丁、月干丁助日干丙）
  - 隔柱年干癸克日干丙力**减半**，年干癸生时干乙木力**再减半**
- **地支路线**：年支→月支→日支←时支
  - 相邻相冲相克力强（如年支亥克月支巳、月支巳克日支申）
  - 隔柱年支亥生时支未力**减半**，月支巳克时支未力**减半**
- **特殊合冲**：
  - **六合**：同柱/相邻力强（如月干丁与时干壬合），隔柱仅"象"无实
  - **六冲/刑害**：仅相邻有效，**隔柱无效**（如年支卯隔月支巳冲时支酉，仅象征矛盾，无实际力量）

**判定顺序**：同柱之后，看横向——**先看相邻，再看隔柱（减半），隔两柱基本忽略**

### 2.3 规则 3：跨柱干支不直接作用（仅同柱互通）

**年干与月支、时干与日支等跨柱干支无直接作用**，需通过"同柱中转"间接流通：

- **地支链**：年支亥水→月支巳火→日支申金→日干庚（逐柱横向传递）
- **天干-同柱地支-地支链**：时干乙木→日干甲木→日支寅木→月支巳火（天干先连自己同柱地支，再横向走地支链）
- **跨柱直接作用仅"根"例外**：日主可跨柱取地支藏干为根（如日干丙火取月支巳火本气根、日支戌土中气根），**但根仅增日主能量，不参与其他作用**

**判定顺序**：跨柱不直接作用，只走"同柱中转"的间接路径；唯一例外是日主取根

### 2.4 力量层级总表（判定优先级）

| 层级 | 作用类型 | 力量 | 说明 |
|---|---|---|---|
| **1（最强）** | 同柱干支 | **最大** | 地支生扶天干 > 天干作用地支；同柱藏干直接生扶 |
| **2** | 相邻柱横向 | **强** | 天干对天干、地支对地支，紧贴作用 |
| **3** | 隔柱横向 | **减半** | 距离一格，力量打折 |
| **4** | 隔两柱横向 | **极微** | 基本忽略（六冲/刑害隔柱无效）|
| **5** | 跨柱干支 | **不直接作用** | 只能走同柱中转；仅日主取根例外（根只增能量，不参与作用）|

**判定口诀**：**先同柱，再相邻，隔柱减半，跨柱中转，取根例外**

## 三、十神流通原理

### 3.1 五行生克循环

```
木 ─→ 火 ─→ 土 ─→ 金 ─→ 水 ─→ 木
     生       生      生      生
```

### 3.2 十神流转链

```
日主 → 食伤 → 财星 → 官杀 → 印星 → 日主
（木） （火） （土） （金） （水） （木）
```

- **完整流通**：上述链无阻滞，命主每一步都有人帮
- **部分阻滞**：链中某环节堵死 → 该环节对应的"生活领域"卡顿
- **完全流通** vs **完全阻滞** 都罕见；多数命局是**部分阻滞**

### 3.3 堵点的核心规律（按作用规则判定）

- **某五行过旺** → 必然克太过它克的对象 → 形成堵点（**按同柱/相邻实际作用算，不数数量**）
- **某五行过弱** → 必然被它克的反克 → 也可能形成堵点
- **堵点 = 被克太过的一方**（如印旺 → 食伤被克太过 → 食伤堵）
- **v2.0.0 判定顺序**：先确认该堵点涉及的"克"是否**同柱或相邻**（有力），隔柱/跨柱的"克"不算真堵点

## 四、五种堵点详解

### 4.1 印堵食伤（最常见）

| 项 | 内容 |
|---|---|
| **形成条件** | 印星过旺（旺 + 多 + 当令）——**印与食伤同柱或相邻** |
| **堵点** | 食伤（土）被印（木）克太过 |
| **表现** | 想到说不出 / 做了不显 / 表达受限 / 才艺施展不开 |
| **化解用神** | **财星制印**（金克木）|
| **生活映射** | 学习多但表达差 / 想法多但出不来 / 父母管太严 |
| **古籍口诀** | "枭神夺食"——偏印夺食神 |

### 4.2 比劫夺财

| 项 | 内容 |
|---|---|
| **形成条件** | 比劫过旺（多 + 旺）——**比劫与财同柱或相邻** |
| **堵点** | 财星（土 / 金）被比劫（木 / 火）克太过 |
| **表现** | 钱留不住 / 同辈争利 / 合伙散伙 / 来人去财 |
| **化解用神** | **官杀制比劫**（水克火）或 **食伤生财**（火生土，通关路线）|
| **生活映射** | 开销大 / 同事抢功 / 借钱要不回 |
| **古籍口诀** | "比劫争财" / "财来财去" |

### 4.3 食伤克官（伤官见官）

| 项 | 内容 |
|---|---|
| **形成条件** | 食伤过旺（多 + 当令）——**食伤与官杀同柱或相邻** |
| **堵点** | 官杀（水 / 金）被食伤（火 / 土）克太过 |
| **表现** | 嘴不饶人 / 与上级冲突 / 官非口舌 / 婚姻不顺 |
| **化解用神** | **印制食伤**（水克火 或 木克土 → 用印）|
| **生活映射** | 与领导不合 / 配偶间口角 / 法律纠纷 |
| **古籍口诀** | "伤官见官，为祸百端" |

### 4.4 财坏印

| 项 | 内容 |
|---|---|
| **形成条件** | 财星过旺（多 + 当令）——**财与印同柱或相邻** |
| **堵点** | 印星（木 / 水）被财星（土 / 金）克太过 |
| **表现** | 想太多 / 思考过度 / 学业中断 / 父母受累 |
| **化解用神** | **比劫帮身**（木帮木、火帮火）|
| **生活映射** | 思维奔逸停不下来 / 学历问题 / 与父母有冲突 |
| **注意** | 财坏印在"印为用神"时是好事（去忌神），在"印为喜神"时是坏事 |

### 4.5 官杀克身太过（身弱遇官杀）

| 项 | 内容 |
|---|---|
| **形成条件** | 日主弱 + 官杀旺——**官杀与日主相邻**（月干/时干/日支）|
| **堵点** | 日主被官杀克太过 → 受压 |
| **表现** | 被压得喘不过气 / 工作压力 / 抑郁倾向 |
| **化解用神** | **印化官杀**（印生日主 + 官生印，流通路线）或 **食伤制官**（食伤克官）|
| **生活映射** | 工作狂 / 压力山大 / 婚姻中受配偶管束 |

## 五、通关方法总表

| 堵点 | 形成条件 | 化解用神 |
|---|---|---|
| **印堵食伤** | 印旺 | 财制印 |
| **比劫夺财** | 比劫旺 | 官杀制劫 / 食伤生财 |
| **食伤克官** | 食伤旺 | 印制食伤 |
| **财坏印** | 财旺 | 比劫帮身 |
| **官克身太过** | 官旺 + 身弱 | 印化官 / 食伤制官 |

**通关的三种思路**：

- **制**（克）→ 削弱堵点源头（如财制印、官制劫）
- **泄**（生）→ 让堵点的能量有出路（如食伤生财）
- **化**（通关）→ A 生 B 生 C，让堵点的能量转到有用之处（如印化官、食伤生财通关比劫夺财）

**v2.0.0 补充**：通关用神也要按作用规则选——**优先选与堵点同柱/相邻的用神**，隔柱用神力量打折

## 六、实战案例

### 6.1 杨权（丙子 辛卯 丙午 丁酉 男）——按作用规则重判

**主堵点 1：印旺堵食伤**

- 月令卯木印旺（月支卯藏乙木本气，**同柱生月干辛金 → 辛金被卯泄**）
- 命中食伤（土）：午中己土一个（日支午藏己中气），**与日干丙同柱** → 己土可被丙生（火生土）
- 但**卯（月支）克己（日支藏）是隔柱（月→日相邻）** → 木克土相邻有力 → **印堵食伤成立**
- **表现**：想到说不出、做了不显（表达受限）
- **化解**：财星（金）制印——**辛酉金与卯相邻**（月干辛、时支酉），力量够

**主堵点 2：比劫夺财**

- 丙（年干）、丙（日干）、丁（时干）三火 → 比劫重重
- 财星：辛（月干）+ 酉（时支藏辛）
- **作用分析**：日干丙与月干辛**相邻**（丙克辛有力）→ **日主直接夺财**；时干丁与月支酉**相邻**（丁克酉有力）→ **劫财夺财**；年干丙与月干辛相邻（丙克辛）→ **比肩夺财**
- 三处相邻夺财 = **比劫夺财成立（贴身作用，力大）**
- **表现**：钱留不住、财来财去
- **化解**：官杀（水）制劫 + 食伤生财通关（子水在年支，与丙相邻？年支子克年干丙→同柱优先）

**整体通关**：**财制印（辛克卯）+ 官护财（水生金）**——用神金水正是通关钥匙。

### 6.2 王雅欣（戊寅 己未 甲子 己巳 女）——按作用规则重判

**主堵点**：财重压身

- 月干己土（财）**与日干甲木相邻**（甲克己？不对，甲木克己土 → 日主克财 = 财受制于身，但财多身弱）→ 己土财星贴身
- 月支未土（财）**与日支子水相邻**（未克子？土克水 → 财克印）⚠️ **财坏印**（未土克子水 = 财坏印，相邻有力）
- 时干己土（财）**与时支巳火同柱**（巳生己？火生土 → 财得生）
- **三处财星贴身/相邻** → 财重压身成立（不看数量看贴身）
- 比劫弱（寅禄被财克）
- **表现**：身偏弱但有印扶（子水生甲木，**子与甲相邻**？日支子水生日干甲木 = 同柱相邻 → 印扶身有力），需防财过重
- **化解**：比劫帮身（寅木、甲木）+ 食伤生财（火泄木）

## 七、与其他分析的关系

### 7.1 流通 ⊂ 用神融合（旺衰精化的一部分）

- **旺衰精化**（v1.0.0 起）= **调候 + 扶抑**（流通独立成 Step 4 后）
- **用神融合** = 正格方向 ∩ 旺衰精化（调候 + 扶抑）
- **流通** 作为**独立分析步骤**（Step 4），输出"堵点 + 通关用神"

### 7.2 流通 vs 用神

| 维度 | 用神 | 流通 |
|---|---|---|
| **解决** | 缺什么补什么 | 化解堵点 |
| **视角** | 补缺 | 通关 |
| **在分析中的位置** | Step 5 | Step 4（独立步骤）|

### 7.3 流通 vs 神煞

- **流通**：十神之间的**动态关系**（堵点 / 通关）
- **神煞**：命中吉星凶煞（助力 / 阻力）
- 两者**不混淆**——神煞是单独的"助缘"维度（Step 6），**不进入流通判定**

## 八、输出规范

### 8.1 标准输出结构（解读时）

```
### 📊 流通检查

- 堵点：[列出命盘所有堵点，含堵点类型 + 具体位置 + 作用关系（同柱/相邻/隔柱）]
- 通关：[每种堵点的化解用神 + 用神与堵点的位置关系]
- 整体评价：命局流通度（顺畅 / 部分阻滞 / 严重阻滞）
```

### 8.2 注意事项（v2.0.0 强化）

- **判定堵点先按作用规则**：同柱 > 相邻 > 隔柱（减半）> 隔两柱（忽略）> 跨柱（中转）
- **❌ 不数数量**：某五行个数多 ≠ 一定堵；要看它与被克对象**是否同柱/相邻**
- **堵点必有化解**：每个堵点都给出对应通关用神
- **不堆砌**：只列实际命局中存在的堵点，不要为了完整而凑数
- **结合用神**：流通检查的通关用神应与最终用神（Step 5）一致——流通步骤是为用神融合服务的
