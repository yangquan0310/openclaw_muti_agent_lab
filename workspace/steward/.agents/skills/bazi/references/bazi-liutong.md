## 一、流通核心原则（4 条铁律 + 4 条规则）

> **这是流通分析的"宪法层"**——所有具体的堵点判定都必须先经过这一层的过滤。
> **来源**：4 条铁律是老板 2026-08-16 22:37 拍板；4 条规则是 v2.0.0 起逐步沉淀。

### 1.1 地支流通 4 条铁律 ⭐⭐

> **老板 2026-08-16 22:37 拍板**："你记住地支流通原则。"

#### 第一条：合化优先

- 地支出现**六合 / 三合 / 三会**时，**按新五行算**
- 一旦"合"或"会"成立，整个组合**整体看新五行**，不再按各自本气算
- **例**：寅亥合木 → 寅亥合起来**整体当木**，不分别论寅的木和亥的水
- **例**：亥卯未三合木 → 整体当木
- **例**：巳申合水（成化）→ 整体当水
- **判定意义**：合化优先于一切生克——先看是否成合/会，再论其他

#### 第二条：冲刑破害

- **冲、刑、破、害**的作用 = **把中气和余气震出来或打掉**
- 本气是核心受冲击最大；中气余气被冲击会"散"或"被震出来"参与流通
- **例**：午酉相破 → 午中的中气丁、余气己被打掉，午的"凶"主要来自**中气层 + 余气层**
- **例**：子午冲 → 子午中的藏干被冲散
- **判定意义**：不要只看本气生克——冲刑破害真正改变的是中气和余气的力量分布

#### 第三条：通关与阻隔

- **通关**：当两个五行相克对峙时，**用中间五行化解**（如木土相克用火通关：木→火→土；金木相克用水通关：金→水→木）
- **阻隔**（最重要的判定原则）：
  - **地支作用，紧贴优先**——紧贴的两个地支先作用（如年支-月支、月支-日支、日支-时支）
  - **隔住只论冲合，不论生克**——如果两个地支中间隔着其他支，**不直接论生克，只看冲合关系**
- **例**：午-酉-子 → 午酉紧贴破（先论破），子午隔柱（隔住只论冲不论生克）
- **判定意义**：地支之间不直接论"隔柱生克"——这是非常硬性的规则，避免错误的"远距离生克"

#### 第四条：藏干透干 —— 藏干者得势

- **藏干得势**：藏在地支的藏干如果**得月令、有生扶、有根（地支有同类）**，可以与透干相比
- **不一定透干就比藏干强**——得势的藏干力大过孤透的天干
- **例**：午火虽不透，但午在月令当旺 = **午藏的丁火劫财得势**，可以影响日主
- **反例**：壬水透干但地支不藏壬 = **壬水力弱**
- **判定意义**：力量看"得势 + 根气 + 生扶"，不看"透干 vs 藏干"的表面地位

#### 4 条铁律的口诀

> **第一合化先算新五行**
> **第二冲刑破害震中余**
> **第三紧贴优先隔不论生克**
> **第四藏干得势与透争**

### 1.2 天干地支作用 4 条规则

> **老板 2026-08-15 19:46 拍板**："流通的核心，不是数数量！"
> **v2.0.0 起逐步沉淀，v2.1.0 加入规则 4**

#### 规则 1：同柱干支优先作用（最核心，力最大）

**同柱干支上下对应**（年干-年支、月干-月支、日干-日支、时干-时支），关系最紧密：

- **地支为根、天干为苗**：
  - **地支作用天干为主（顺，力大）**（如地支子水生天干壬水）
  - **天干作用地支为次（逆，力小）**（如天干甲木克地支辰土）
- **地支藏干是天干能量来源**：
  - 力量排序：**本气根 > 中气根 > 余气根**
  - **仅同柱地支藏干可直接生扶天干**（如地支寅木藏甲木，助同柱天干甲木）
  - **非同柱藏干仅算"根"，不直接作用**

**判定顺序**：分析任何字，**先看同柱**（它的根/苗是谁，力量最大）

#### 规则 2：柱间横向作用（干对干、支对支，近强远弱）

**同柱分析后**，横向**仅天干与天干、地支与地支作用**：

- **相邻柱力强**，**隔柱力减半**，**隔两柱力极微**
- **天干路线**：年干→月干→日干←时干
  - 相邻相生相克力强（如年干癸克月干丁、月干丁助日干丙）
  - 隔柱年干癸克日干丙力**减半**，年干癸生时干乙木力**再减半**
- **地支路线**：年支→月支→日支←时支
  - 相邻相冲相克力强（如年支亥克月支巳、月支巳克日支申）
  - 隔柱年支亥生时支未力**减半**，月支巳克时支未力**减半**
- **特殊合冲**：
  - **六合**：同柱/相邻力强（如月干丁与时干壬合），隔柱仅"象"无实
  - **六冲/刑害**：仅相邻有效，**隔柱无效**（如年支卯隔月支巳冲时支酉，仅象征矛盾，无实际力量）

**判定顺序**：同柱之后，看横向——**先看相邻，再看隔柱（减半），隔两柱基本忽略**

#### 规则 3：跨柱干支不直接作用（仅同柱互通）

**年干与月支、时干与日支等跨柱干支无直接作用**，需通过"同柱中转"间接流通：

- **地支链**：年支亥水→月支巳火→日支申金→日干庚（逐柱横向传递）
- **天干-同柱地支-地支链**：时干乙木→日干甲木→日支寅木→月支巳火（天干先连自己同柱地支，再横向走地支链）
- **跨柱直接作用仅"根"例外**：日主可跨柱取地支藏干为根（如日干丙火取月支巳火本气根、日支戌土中气根），**但根仅增日主能量，不参与其他作用**

##### 1.2.3.1 ⭐ 日支作用范围铁律（老板 2026-08-16 23:17 拍板）

> **每个地支的直接作用源 = 紧贴的同柱天干 + 横向相邻的地支**

**日支的 3 个直接作用源**：

[1] 同柱天干（日干）—— 同柱作用（规则 1）
[2] 月支（相邻地支）—— 横向作用（规则 2）
[3] 时支（相邻地支）—— 横向作用（规则 2）

**日支不受的 2 类作用**：

[4] 月干 → 日支 = **跨柱干支不直接作用**
[5] 时干 → 日支 = **跨柱干支不直接作用**

**间接路径**（必须走同柱地支中转）：

- 月干 → 月支（同柱） → 日支（横向） = 间接
- 时干 → 时支（同柱） → 日支（横向） = 间接

**所有地支都遵守这个规则**：

- 年支：月支 + 同柱年干
- 月支：年支 + 日支 + 同柱月干
- **日支：月支 + 时支 + 同柱日干** ⭐
- 时支：日支 + 同柱时干

**判定意义**：

- ❌ **错误**：看到"月干辛金盖头"就直接说"日支午火被辛金消耗"——**错！**
- ✅ **正确**：月干辛金**先消耗月支卯木**（同柱作用）→ 卯木残气**横向传递给日支午火**（横向作用）= 间接路径

#### 规则 4：同时生克 → 贪生忘克；同柱生克 → 同柱优先

> **老板 2026-08-15 19:49 拍板**："同时发生生克，贪生忘克；同柱生克两个，同柱优先。"

**贪生忘克**（某五行同时面对"生"与"克"两个对象时）：

- **优先"生"，"克"退居其次（甚至暂忘）**
- 例：日干丙火同时可生己土（食伤）、可克辛金（财）→ 丙火**先满足"生己土"**，"克辛金"暂缓
- 例：月干辛金同时可生子水（官）、可克卯木（印）→ 辛金**先"生子水"**，"克卯木"暂缓
- **判定含义**：堵点分析时，若某字同时生 A 克 B → **先看它对 A 的"生"**（能量先流向被生者），对 B 的"克"是次要路线

**同柱生克 → 同柱优先**（同一柱内同时存在"生"和"克"两种作用时）：

- **同柱内的作用最先成立**（呼应规则 1：同柱力最大），之后才轮到横向/跨柱
- 例：日柱丙午——午火藏丁（比劫）、己（食伤）→ 日干丙火与午火**同柱相互作用最先判定**，之后才看丙与其他柱
- **判定含义**：同柱内既有生又有克 → **同柱关系优先处理**，不先看隔柱

### 1.3 力量层级总表（判定优先级）

> **判定口诀**：**先同柱（生克同柱优先），再相邻，隔柱减半，跨柱中转，取根例外，贪生忘克**

| 层级 | 作用类型 | 力量 | 说明 |
|---|---|---|---|
| **1（最强）** | 同柱干支 | 最大 | 地支生扶天干 > 天干作用地支；同柱藏干直接生扶 |
| **2** | 相邻柱横向 | 强 | 天干对天干、地支对地支，紧贴作用 |
| **3** | 隔柱横向 | 减半 | 距离一格，力量打折 |
| **4** | 隔两柱横向 | 极微 | 基本忽略（六冲/刑害隔柱无效）|
| **5** | 跨柱干支 | 不直接作用 | 只能走同柱中转；仅日主取根例外（根只增能量，不参与作用）|
| **排序规则** | 生 vs 克 | 贪生忘克 | 同时生克时优先"生"；同柱生克优先同柱（v2.1.0）|

### 1.4 判定顺序总纲

分析任何命局的地支流通，按这个顺序判定：

[1] **看有没有合/会？**（§1.1 第一条：合化优先）→ 成则按新五行算
[2] **看有没有冲/刑/破/害？**（§1.1 第二条）→ 找中气余气震出/打掉的位置
[3] **看紧贴作用**（§1.1 第三条：紧贴优先）→ 紧贴的先作用
[4] **看隔位关系**（§1.1 第三条：隔住只论冲合不论生克）→ 隔位只论冲合
[5] **看透干 vs 藏干**（§1.1 第四条：藏干得势）→ 力量看"得势 + 根气 + 生扶"
[6] **看同柱作用**（§1.2 规则 1）→ 同柱干支最优先
[7] **看横向作用**（§1.2 规则 2）→ 相邻 > 隔柱（减半）
[8] **看跨柱是否直接作用**（§1.2 规则 3）→ 必须经同柱地支中转
[9] **看同时生克**（§1.2 规则 4）→ 贪生忘克 + 同柱优先
[10] **看力量层级**（§1.3）→ 综合判定堵点

## 二、十神流通原理

### 2.1 五行生克循环

```
木 ─→ 火 ─→ 土 ─→ 金 ─→ 水 ─→ 木
     生       生      生      生
```

### 2.2 十神流转链

```
日主 → 食伤 → 财星 → 官杀 → 印星 → 日主
（木） （火） （土） （金） （水） （木）
```

- **完整流通**：上述链无阻滞，命主每一步都有人帮
- **部分阻滞**：链中某环节堵死 → 该环节对应的"生活领域"卡顿
- **完全流通** vs **完全阻滞** 都罕见；多数命局是**部分阻滞**

### 2.3 堵点的核心规律（按作用规则判定）

- **某五行过旺** → 必然克太过它克的对象 → 形成堵点（**按同柱/相邻实际作用算，不数数量**）
- **某五行过弱** → 必然被它克的反克 → 也可能形成堵点
- **堵点 = 被克太过的一方**（如印旺 → 食伤被克太过 → 食伤堵）
- **判定顺序**：先确认该堵点涉及的"克"是否**同柱或相邻**（有力），隔柱/跨柱的"克"不算真堵点

## 三、五种堵点详解

### 3.1 印堵食伤（最常见）

| 项 | 内容 |
|---|---|
| **形成条件** | 印星过旺（旺 + 多 + 当令）——**印与食伤同柱或相邻** |
| **堵点** | 食伤（土）被印（木）克太过 |
| **表现** | 想到说不出 / 做了不显 / 表达受限 / 才艺施展不开 |
| **化解用神** | **财星制印**（金克木）|
| **生活映射** | 学习多但表达差 / 想法多但出不来 / 父母管太严 |
| **古籍口诀** | "枭神夺食"——偏印夺食神 |

### 3.2 比劫夺财

| 项 | 内容 |
|---|---|
| **形成条件** | 比劫过旺（多 + 旺）——**比劫与财同柱或相邻** |
| **堵点** | 财星（土 / 金）被比劫（木 / 火）克太过 |
| **表现** | 钱留不住 / 同辈争利 / 合伙散伙 / 来人去财 |
| **化解用神** | **官杀制比劫**（水克火）或 **食伤生财**（火生土，通关路线）|
| **生活映射** | 开销大 / 同事抢功 / 借钱要不回 |
| **古籍口诀** | "比劫争财" / "财来财去" |

### 3.3 食伤克官（伤官见官）

| 项 | 内容 |
|---|---|
| **形成条件** | 食伤过旺（多 + 当令）——**食伤与官杀同柱或相邻** |
| **堵点** | 官杀（水 / 金）被食伤（火 / 土）克太过 |
| **表现** | 嘴不饶人 / 与上级冲突 / 官非口舌 / 婚姻不顺 |
| **化解用神** | **印制食伤**（水克火 或 木克土 → 用印）|
| **生活映射** | 与领导不合 / 配偶间口角 / 法律纠纷 |
| **古籍口诀** | "伤官见官，为祸百端" |

### 3.4 财坏印

| 项 | 内容 |
|---|---|
| **形成条件** | 财星过旺（多 + 当令）——**财与印同柱或相邻** |
| **堵点** | 印星（木 / 水）被财星（土 / 金）克太过 |
| **表现** | 想太多 / 思考过度 / 学业中断 / 父母受累 |
| **化解用神** | **比劫帮身**（木帮木、火帮火）|
| **生活映射** | 思维奔逸停不下来 / 学历问题 / 与父母有冲突 |
| **注意** | 财坏印在"印为用神"时是好事（去忌神），在"印为喜神"时是坏事 |

### 3.5 官杀克身太过（身弱遇官杀）

| 项 | 内容 |
|---|---|
| **形成条件** | 日主弱 + 官杀旺——**官杀与日主相邻**（月干/时干/日支）|
| **堵点** | 日主被官杀克太过 → 受压 |
| **表现** | 被压得喘不过气 / 工作压力 / 抑郁倾向 |
| **化解用神** | **印化官杀**（印生日主 + 官生印，流通路线）或 **食伤制官**（食伤克官）|
| **生活映射** | 工作狂 / 压力山大 / 婚姻中受配偶管束 |

## 四、通关方法总表

| 堵点 | 形成条件 | 化解用神 |
|---|---|---|
| **印堵食伤** | 印旺 | 财制印 |
| **比劫夺财** | 比劫旺 | 官杀制劫 / 食伤生财 |
| **食伤克官** | 食伤旺 | 印制食伤 |
| **财坏印** | 财旺 | 比劫帮身 |
| **官克身太过** | 官旺 + 身弱 | 印化官 / 食伤制官 |

**通关的三种思路**：

- **制**（克）→ 削弱堵点源头（如财制印、官制劫）
- **泄**（生）→ 让堵点的能量有出路（如食伤生财）
- **化**（通关）→ A 生 B 生 C，让堵点的能量转到有用之处（如印化官、食伤生财通关比劫夺财）

**v2.0.0 补充**：通关用神也要按作用规则选——**优先选与堵点同柱/相邻的用神**，隔柱用神力量打折

## 五、实战案例

### 5.1 杨权（丙子 辛卯 丙午 丁酉 男）——按 4 条铁律 + 4 条规则重判（v2.1.0）

**同柱分析（规则 1）**：

- 丙子柱：子水克丙火（官克身，同柱）
- 辛卯柱：辛金克卯木（财坏印，同柱，天干作用地支 = 逆，力小）
- 丙午柱：午火与丙比和（同柱，力最大）+ 午中己土 = 丙的食神（火生土，同柱直接生扶）
- 丁酉柱：丁火克酉金（劫财克财，同柱，逆作用力小）；酉中辛金 = 丙的正财根

**横向分析（规则 2）**：

- 天干：年丙-月辛 **相邻丙辛合**；日丙-月辛 **相邻丙辛合 = 日主合财贴身**；日丙-时丁 相邻比劫帮身；时丁-月辛 隔柱克力减半
- 地支：子-卯 **相邻子水生卯木（官生印）**；卯-午 **相邻卯木生午火（印生身根）**；午-酉 **相邻午酉破**
- **⚠️ 隔柱无效**：子午冲（年支-日支隔月支）、卯酉冲（月支-时支隔日支）——仅象征矛盾，无实际力量

**跨柱分析（规则 3）**：

- 卯木不直接生日主丙（跨柱）→ 走中转：卯→午（相邻生）→丙（同柱帮）
- 子水不直接克日主丙（跨柱）→ 只同柱克年干丙 + 相邻生卯
- 己土食神（午中）不直接生辛金财（跨柱）→ **食伤生财路径不通**
- 日主丙取根：午火（同柱本气丁，力大）

**贪生忘克（规则 4）**：

- 子水：同时可生卯木（相邻）、克丙火（同柱）→ **先生卯木（官生印），克丙火退居** = 官不克身，官生印护身
- 午火：同时可生己土（同柱）、克酉金（相邻）→ **先生己土（食神），午酉破弱化** = 夺财力度大减
- 丙火：同时可生己土（同柱）、克辛金（合财）→ 先生己土，丙辛合六合特殊优先

**堵点判定（新判）**：

- ❌ 删旧判：子午冲（隔柱无效）、卯酉冲（隔柱无效）、印堵食伤（卯克己跨柱不直接作用，实际卯→午→己中转流通）、三火夺财（丙辛合是合财不是夺财）
- ✅ 新堵点 1：**食伤生财不通**（己土→辛金跨柱）= 才华难直接变现
- ✅ 新堵点 2：**丁火劫财隔柱克辛**（减半）+ 午酉破（相邻但被贪生忘克弱化）= 小夺财
- ✅ 新堵点 3：**财坏印**（辛克卯，同柱但逆作用力小）= 弱

**主流通链（顺畅）**：

```
子(官) —生→ 卯(印) —生→ 午(身) —生→ 己(食伤)
丙(身) —合→ 辛(财) 丙辛合 = 财贴身
```

**堵点清单（输出格式 · v2.3.0）**：

- 🔴 堵点 1（主）：**食伤生财不通**——午中己土（食神）→ 辛酉金（财）**跨柱**不直接作用（己土是日干丙的食神，本该从日干泄向财，但跨柱断了）
  - 表现：才华难直接变现、想法多但转化钱慢
- 🟡 堵点 2：**丁火劫财隔柱克辛**（力减半）+ 午酉破（相邻但被贪生忘克弱化）
  - 表现：偶有破财、同辈竞争
- 🟢 堵点 3：**财坏印**（辛克卯，同柱但逆作用力小）
  - 表现：轻微，为钱分心学习
- ✅ 通路（指向日干）：**子(官)→卯(印)→午(身)→丙(日干)**——官生印、印生身，气流直指日干；日干再**丙辛合**把财拉向自己（财贴身）
- 📌 总结：主堵点 = 食伤生财不通（日干的"泄"路断了）；通路顺畅 = 印星护身直达日干；整体偏顺畅但**日干泄路不畅**

### 5.3 老板实战：辛子 辛卯 丙午 丁酉（2026-08-16 23:14 拍板）

> **老板亲自分析**：月支卯木和时支酉金如何影响日支午火？

#### 第一步：卯木的受力与输出

**卯木承受的外部作用**（按紧贴顺序，§1.1 第三条）：

[1] 月干辛金盖头：天干辛金克地支卯木。金克木，直接压制，此为第一层消耗
[2] 年支子水紧贴相刑：子水与卯木构成子卯刑。水本生木，但此刑为"生中带泄"，水气被木吸收后反致木根腐烂。此为第二层消耗
[3] 时支酉金遥冲：卯酉冲，金克木。虽隔日支，冲力减半，但持续震动卯木根基。此为第三层消耗

**卯木的初始力量**：卯木当令，月令权重最高，先天能量储备为全局最强。但上述三层消耗直接作用于其本气（乙木），导致有效输出能量大幅折损。其残存能量仅够维持"木"的形态，无力转化为生发之气。

**卯木对午火的输出**（紧贴，§1.1 第三条：紧贴优先）：

- 卯木与午火紧贴，构成"卯午破"
- 输出机制：木生火
- 输出量：卯木的有效能量已近枯竭，其输出给午火的，是残余的、带有湿腐性质的木气
- 输出效果：这股残气注入午火后，不足以助长火势，却足以干扰午火的纯度

#### 第二步：酉金的受力与输出

**酉金承受的外部作用**：

[1] 时干丁火盖头：天干丁火克地支酉金。火克金，直接熔炼，此为第一层消耗
[2] 日支午火紧贴相破：午火与酉金构成"午酉破"。火克金，贴身施加压力
[3] 月支卯木遥冲：卯酉冲，金木相战。隔位力减，但持续震动酉金结构

**酉金的初始力量**：酉金囚于卯月，先天能量储备极低。叠加三层消耗后，其有效输出能量归零。酉金仅存"金"的虚名，无力执行任何生克指令。

**酉金对午火的输出**（紧贴，午酉破）：

- 输出机制：火克金。此关系中，午火为主动方，酉金为被动方
- 输出量：酉金有效能量归零，因此午火在克酉金的过程中，无法实现能量交换（**火不泄气，金不受损**）——老板提出的"空转"概念
- 输出效果：午火对酉金的作用等于空转，酉金对午火的实际影响力为零

#### 第三步：卯酉对午火的综合结果

**输入侧（卯木 → 午火）**：

- 性质：残存的湿腐木气
- 数量：微弱
- 效果：轻微污染午火纯度，**未改变其旺度**

**输出侧（午火 → 酉金）**：

- 性质：午火主动克酉金
- 数量：因酉金有效能量为零，此作用不发生能量交换
- 效果：午火未因克酉金而产生任何耗泄，其能量维持原状

**日支午火的最终状态**：午火接收了卯木的微弱残气（轻度干扰），但未消耗自身能量去克酉金（无损耗）。午火的有效能量既未增，亦未减，**保持其作为"丙火强根"的原始状态**。

#### 第四步：对日干丙火的最终影响

- 午火作为日支：是日干丙火最直接的根基来源
- 午火的状态：因其能量未受卯酉的有效调节（卯增之无效，酉泄之无效），故其向日干丙火提供的支持，**与无卯酉介入时完全一致**
- 结论：**卯酉的存在，未改变午火对日干丙火的实质支持力度**

#### 实战要点（老板实战总结的"空转"和"残气"概念）

- ✅ **"空转"概念**：火克金但金没有有效能量 = **不发生实际能量交换**（能量守恒视角）
- ✅ **"残气干扰纯度但不改旺度"**：定性分析的精准
- ✅ **"紧贴优先 / 隔位减力"** 的清晰区分 = §1.1 第三条的实战运用

> **注**：此案例也提醒——**日支的直接作用源只有 3 个（同柱日干 + 月支 + 时支）**，**不能直接论月干/时干对日支的作用**（§1.2.3.1 日支作用范围铁律）。
