# 大管家八字 · 流通（Bazi Liutong / Flow）

> **本文件定义八字命局"十神流通"分析。**
> 流通原属旺衰体系（`bazi-wangshuai.md` §四），现独立成文（v1.0.0, **2026-08-10 老板拍板"旺衰中的流通，独立出来"**）。
> **核心问题**：命局十神之间有没有"堵点"？气能否顺畅流转？

## 一句话定义

> **流通 = 十神之间气的流转。堵点 = 某五行被克太过。化解 = 通关用神。**

---

## 一、什么是流通

### 1.1 流通的概念

- **流通**：命局五行**相生流转**（木→火→土→金→水→木）
- **阻滞 / 堵点**：命中**某五行被克太过**，形成"卡顿"
- **流通顺畅** → 命局活泼、做事顺、好发挥
- **有堵点** → 命局卡顿、做事有阻力、才华施展不开

### 1.2 为什么流通独立成"步骤"

2. **5 种堵点**值得专门讲，每种堵点对应不同化解

## 二、十神流通原理

### 2.1 五行生克循环

```
木 ─→ 火 ─→ 土 ─→ 金 ─→ 水 ─→ 木
     生       生      生      生
```

### 2.2 十神流转链

```
日主 → 食伤 → 财星 → 官杀 → 印星 → 日主
（木） （火） （土） （金） （水） （木）
```

- **完整流通**：上述链无阻滞，命主每一步都有人帮
- **部分阻滞**：链中某环节堵死 → 该环节对应的"生活领域"卡顿
- **完全流通** vs **完全阻滞** 都罕见；多数命局是**部分阻滞**

### 2.3 堵点的核心规律

- **某五行过旺** → 必然克太过它克的对象 → 形成堵点
- **某五行过弱** → 必然被它克的反克 → 也可能形成堵点
- **堵点 = 被克太过的一方**（如印旺 → 食伤被克太过 → 食伤堵）

## 三、五种堵点详解

### 3.1 印堵食伤（最常见）

| 项 | 内容 |
|---|---|
| **形成条件** | 印星过旺（旺 + 多 + 当令）|
| **堵点** | 食伤（土）被印（木）克太过 |
| **表现** | 想到说不出 / 做了不显 / 表达受限 / 才艺施展不开 |
| **化解用神** | **财星制印**（金克木）|
| **生活映射** | 学习多但表达差 / 想法多但出不来 / 父母管太严 |
| **古籍口诀** | "枭神夺食"——偏印夺食神 |

### 3.2 比劫夺财

| 项 | 内容 |
|---|---|
| **形成条件** | 比劫过旺（多 + 旺）|
| **堵点** | 财星（土 / 金）被比劫（木 / 火）克太过 |
| **表现** | 钱留不住 / 同辈争利 / 合伙散伙 / 来人去财 |
| **化解用神** | **官杀制比劫**（水克火）或 **食伤生财**（火生土，通关路线）|
| **生活映射** | 开销大 / 同事抢功 / 借钱要不回 |
| **古籍口诀** | "比劫争财" / "财来财去" |

### 3.3 食伤克官（伤官见官）

| 项 | 内容 |
|---|---|
| **形成条件** | 食伤过旺（多 + 当令）|
| **堵点** | 官杀（水 / 金）被食伤（火 / 土）克太过 |
| **表现** | 嘴不饶人 / 与上级冲突 / 官非口舌 / 婚姻不顺 |
| **化解用神** | **印制食伤**（水克火 或 木克土 → 用印）|
| **生活映射** | 与领导不合 / 配偶间口角 / 法律纠纷 |
| **古籍口诀** | "伤官见官，为祸百端" |

### 3.4 财坏印

| 项 | 内容 |
|---|---|
| **形成条件** | 财星过旺（多 + 当令）|
| **堵点** | 印星（木 / 水）被财星（土 / 金）克太过 |
| **表现** | 想太多 / 思考过度 / 学业中断 / 父母受累 |
| **化解用神** | **比劫帮身**（木帮木、火帮火）|
| **生活映射** | 思维奔逸停不下来 / 学历问题 / 与父母有冲突 |
| **注意** | 财坏印在"印为用神"时是好事（去忌神），在"印为喜神"时是坏事 |

### 3.5 官杀克身太过（身弱遇官杀）

| 项 | 内容 |
|---|---|
| **形成条件** | 日主弱 + 官杀旺 |
| **堵点** | 日主被官杀克太过 → 受压 |
| **表现** | 被压得喘不过气 / 工作压力 / 抑郁倾向 |
| **化解用神** | **印化官杀**（印生日主 + 官生印，流通路线）或 **食伤制官**（食伤克官）|
| **生活映射** | 工作狂 / 压力山大 / 婚姻中受配偶管束 |

## 四、通关方法总表

| 堵点 | 形成条件 | 化解用神 |
|---|---|---|
| **印堵食伤** | 印旺 | 财制印 |
| **比劫夺财** | 比劫旺 | 官杀制劫 / 食伤生财 |
| **食伤克官** | 食伤旺 | 印制食伤 |
| **财坏印** | 财旺 | 比劫帮身 |
| **官克身太过** | 官旺 + 身弱 | 印化官 / 食伤制官 |

**通关的三种思路**：

- **制**（克）→ 削弱堵点源头（如财制印、官制劫）
- **泄**（生）→ 让堵点的能量有出路（如食伤生财）
- **化**（通关）→ A 生 B 生 C，让堵点的能量转到有用之处（如印化官、食伤生财通关比劫夺财）

## 五、实战案例

### 5.1 杨权（丙子 辛卯 丙午 丁酉 男）

**主堵点 1：印旺堵食伤**

- 月令卯木印旺 + 藏干癸水生印 → 印星极盛
- 命中食伤（土）只有午中己土一个，且被印泄
- **表现**：想到说不出、做了不显（表达受限）
- **化解**：财星（金）制印

**主堵点 2：比劫夺财**

- 丙、丙、丁 三火（年干、日干、时干）→ 比劫重重
- 只一个辛酉金（财）→ 三火围一金
- **表现**：钱留不住、财来财去
- **化解**：官杀（水）制劫 + 食伤生财通关

**整体通关**：**财制印（辛克卯）+ 官护财（水生金）**——用神金水正是通关钥匙。

### 5.2 王雅欣（戊寅 己未 甲子 己巳 女）

**主堵点**：财重压身

- 月令未土（财）+ 月干己土（财）+ 时干己土（财）→ 三财压日主甲木
- 比劫弱（寅禄被财克）
- **表现**：身偏弱但有印扶（子水生甲木），需防财过重
- **化解**：比劫帮身（寅木、甲木）+ 食伤生财（火泄木）

## 六、与其他分析的关系

### 6.1 流通 ⊂ 用神融合（旺衰精化的一部分）

- **旺衰精化**（v1.0.0 起）= **调候 + 扶抑**（流通独立成 Step 4 后）
- **用神融合** = 正格方向 ∩ 旺衰精化（调候 + 扶抑）
- **流通** 作为**独立分析步骤**（Step 4），输出"堵点 + 通关用神"

### 6.2 流通 vs 用神

| 维度 | 用神 | 流通 |
|---|---|---|
| **解决** | 缺什么补什么 | 化解堵点 |
| **视角** | 补缺 | 通关 |
| **在分析中的位置** | Step 5 | Step 4（独立步骤）|

### 6.3 流通 vs 神煞

- **流通**：十神之间的**动态关系**（堵点 / 通关）
- **神煞**：命中吉星凶煞（助力 / 阻力）
- 两者**不混淆**——神煞是单独的"助缘"维度（Step 6），**不进入流通判定**

## 七、输出规范

### 7.1 标准输出结构（解读时）

```
### 📊 流通检查

- 堵点：[列出命盘所有堵点，含堵点类型 + 具体位置]
- 通关：[每种堵点的化解用神]
- 整体评价：命局流通度（顺畅 / 部分阻滞 / 严重阻滞）
```

### 7.2 注意事项

- **堵点必有化解**：每个堵点都给出对应通关用神
- **不堆砌**：只列实际命局中存在的堵点，不要为了完整而凑数
- **结合用神**：流通检查的通关用神应与最终用神（Step 5）一致——流通步骤是为用神融合服务的
