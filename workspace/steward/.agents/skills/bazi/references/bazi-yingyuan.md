# 八字姻缘专题

> **本文档是八字技能姻缘分析的内部参考。**
> 适用于：所有八字解读中的"姻缘/婚姻/配偶"判断——**单盘**。
> **核心问题**：一个人的姻缘好坏、配偶是谁、什么时候结婚、婚后怎么样。
> **不是**合盘分析 ——合盘见 [`bazi-hehun.md`](bazi-hehun.md)。

---

## 〇、设计原则

> **这 6 条是整个文档的灵魂，违背一条就废了**

- **以对象为中心**——不是流程：3 个对象 = 家 + 人 + 关系
- **夫妻宫 = 看家**：配偶在你生命里的"位置"
- **夫妻星 = 看人**：配偶作为"人"的属性
- **只看异位关系**——不自比：不与日干、不与所在干支
- **关系 > 字本身**：字无意义，关系才是一切
- **隐晦必断**：多个候选必须用 5 规则选 1

> **婚姻 =一个人住进你的家**
> - 家是**位置**——日支
> - 人是**角色**——财/官杀

## 一、夫妻宫

> **这一章只讲"家"是什么**

### 1.1 家是什么字

**操作**：

- 取**日柱的地支**
- 定**五行属性**
- 定**十神**——与日干对照
- 看**基础性质**——五行主什么

**大白话**：先认清楚**这个家是什么材质**

### 1.2 家里稳不稳

#### 1.2.1 位置含义速查

| 位置 | 代表什么 |
|---|---|
| **年柱** | 祖辈、出身、童年底色、社会大环境 |
| **月柱** | 父母、事业、成长环境——最关键的能量|
| **日柱** | **自己**、配偶、内心世界 |
| **时柱** | 子女、晚年、未来、归宿 |

**天干** = 外在表现、别人看到的你
**地支** = 内在世界、家、隐藏的你

**异位关系 = 不同位置的字互相作用**
**位置含义 = 这个作用会影响到"什么领域"**

#### 1.2.2 7 大关系

- **冲**：公开打架 → **动荡**
- **合**：黏住 → **绑定**
- **刑**：暗伤 → **冷战**
- **害**：阴损 → **暗算**
- **破**：慢性消耗 → **慢损**
- **生**：帮忙 → **滋养**
- **克**：压制 → **管束**

#### 1.2.3 暗含内容速查

> **这是判断"实际会发生什么"的关键**

**夫妻宫被冲/破/克的暗含**：

- **年支冲**——出身冲击家庭→ 父母反对、门户冲突、出身差异
- **月支冲/破**——父母/事业冲击家庭→ 婆媳问题、工作太忙
- **时支冲/破**——子女/晚年冲击家庭→ 子女不省心、晚年孤独
- **年干克**——祖辈/外在克家→ 家族压力、外界干涉
- **月干克**——父母/社交克家→ 父母管制、配偶抢话语权——好事
- **时干生**——子女/未来生家→ 子女让家热闹——好或坏看五行
- **时干克**——子女/未来克家→ 子女带来压力

**夫妻宫被合/生的暗含**：

- **年干合**——祖辈与家融合→ 家族传承、家风延续
- **月干合**——父母与家融合→ 婆媳和睦
- **时干生**——子女养家→ 子女孝顺

#### 1.2.4 操作步骤

- **先看位置**——这个异位涉及哪个领域
- **再看关系**——冲/合/刑/害/破/生/克
- **最后看暗含**——这个作用可能影响什么具体事件

**大白话**：看这个**家**稳不稳、有没有被冲破、**冲破会带来什么实际问题**

### 1.3 家在你命局里的角色

**喜忌**：家对你来说是**喜**——顺还是**忌**——别扭
- 看家与你旺衰的关系——极旺 vs 极弱

**流通位置**：家在五行流转中扮演什么角色
- 是**堵点**——断水管的地方？
- 是**枢纽**——水流过的地方？
- 是**末梢**——没人管的边？

**大白话**：看这个**家**在你整个命局里**起什么作用**

### 1.4 一句话：这**家**是什么样的？

**格式**：
> **这家是 [材质] 做的，[状态]，在你命局里 [角色]。**

## 二、夫妻星

> **这一章只讲"配偶这个人"是什么**

### 2.1 怎么找人

**为什么需要这一节**：

- 命局里可能同时出现**多个候选**
- 例如：辛——月干正财+ 酉——时支偏财
- 必须用 5 规则选 1

**5 大规则——按优先级**：

- **① 透干 > 藏支**——露在外面的优先
- **② 与日干紧贴**——同柱 > 隔柱
- **③ 与日干合化**——**天作之合** = 最强证据
- **④ 与日干直接生克**——直接关系 > 间接
- **⑤ 配合夫妻宫**——看哪个贴近日支

**打分示例**：

- 候选 A：透干 ✓ + 紧贴 ✓ + 丙辛合 ✓ + 克家 ✓ + 隔 1 柱 ✓ = **5/5**
- 候选 B：藏支 ✗ + 远 ✗ + — + — + 隔 2 柱 ✗ = **0/5**
- **结论：A 胜出**

**3 大兜底——难断时用**：

- **大运激活**：谁**先被引动** = 真星
- **实际婚史**：验证理论 vs 现实
- **格局配合**：谁参与格局 = 真星

**5 大陷阱**：

- **只看数量**——多不一定好，看**质量**
- **只看位置**——近不一定真，看**合化**
- **只看透藏**——透不一定强，看**根气**
- **只看强旺**——旺不一定真，看**与日主关系**
- **只看十神**——正偏都有 = 必须**5 规则打分**

### 2.2 人是什么字

**操作**：

- 用 §2.1 选出的**真夫妻星**
- 定**五行属性**
- 定**十神**——男=财星；女=官杀
- **强度判断**——4 维度：
  - **得令**：月份罩不罩
  - **有根**：有没有根据地
  - **得生**：有没有长辈帮
  - **得助**：有没有同类帮
- **打分**：4/4 极旺 / 3/4 偏旺 / 2/4 中和 / 1/4 偏弱 / 0/4 极弱

**大白话**：认清楚配偶这个**人**的材质和强度

#### 2.3.1 位置含义

#### 2.3.2 7 大关系

#### 2.3.3 暗含内容速查

- **年干克**——祖辈/外在克配偶→ 家族不接受配偶
- **月支冲/克**——父母/事业克配偶→ **婆媳问题**——财坏印、配偶与父母不和

**关键暗含——5 大重点**：

## 三、关系

> **这一章只讲"人和家怎么相处"**

### 3.1 人在哪里

**落位分析**：

- 夫妻星——人在**哪一柱**
- 夫妻宫——家在**日支**
- **距离**：人在年柱 vs 月柱 vs 时柱 → 离家多远
- **解读**：
  - 同柱——人紧贴日支= **天天见面**
  - 邻柱——隔 1 柱= **中等距离**
  - 远柱——隔 2-3 柱= **聚少离多**

**大白话**：配偶这个**人**在你生活里**出现得多不多**

### 3.2 人能不能住进家

**核心问题**：人住进家 = 夫妻星落夫妻宫
- 夫妻星**在**日支 = **人住进家** → 婚姻稳定
- 夫妻星**不在**日支 = **人不在家** → 聚少离多

**人 + 家的关系**——5 大关系：

- **合**：人被家黏住 → **绑定**——好或坏看喜忌
- **冲**：人和家公开打架 → **动荡**
- **刑**：人和家有暗伤 → **冷战**
- **害**：人和家有阴损 → **暗算**
- **克**：人克家——配偶管家或家克人——家压制配偶

**大白话**：配偶这个**人**能不能**住进这个家**

### 3.3 婚姻的流通

**5 行流转图**：

```
    印 → 身 → 食伤 → 财 → 官
    木 → 火 → 土 → 金 → 水
    ↓
    ——回到印，形成闭环
```

**找堵点**：

- **哪个水管断了**？——堵点位置
- **哪个水管最堵**？（主堵点）
- **哪个水管是唯一通的**？——化解路径

**5 大堵点类型**：

- **食伤缺**——没渠道泄
- **财被劫**——配偶被抢
- **印太重**——母亲/学习过载
- **官过弱**——没规矩
- **身过旺**——4/4 极旺

**大白话**：看**人和家**放在一起，整个婚姻的**五行流转**顺不顺

### 3.4 一句话：这**婚姻**整体怎么样？

**格式**：
> **这婚姻 = [家]+[人]+[关系]，[整体评级]，堵点 = [主堵点]。**

## 四、大运流年

> **核心问题**：这婚姻什么时候来？什么时候动？什么时候稳？
>
> **方法**：大运看 10 年一档的基调，流年看 1 年一档的事件，两个叠加判断婚期。

### 4.1 大运看婚姻阶段

**操作**：

- **大运地支 vs 夫妻宫——日支** = 这 10 年婚姻的"家"状态
- **大运天干 vs 夫妻星** = 这 10 年配偶的"人"状态

**6 种大运地支关系**：

- **伏吟**——大运地支 = 日支→ **婚姻宫被引动** = 婚动关键期——结/离都看这 10 年
- **六合**——大运地支合日支→ **婚稳** = 感情升温、适合定下来
- **六冲**——大运地支冲日支→ **婚变** = 吵架/分居/闪婚闪离
- **刑害破**——大运地支刑害破日支→ **慢性消耗** = 磨人的 10 年
- **比和**——同五行→ **平稳** = 没大事
- **无特殊** → **无关** = 这 10 年婚姻不是主线

**大运天干透夫妻星** = 这 10 年正缘出现——财星/官星透干

### 4.2 流年看婚姻事件

**操作**：

- **流年地支 vs 夫妻宫——日支** = 这一年婚姻的状态
- **流年天干透夫妻星** = 这一年遇到对象

**婚期叠加信号——3 个同时看**：

- **信号 1**：大运地支合/冲/伏吟夫妻宫
- **信号 2**：流年地支合/冲/伏吟夫妻宫
- **信号 3**：流年天干透夫妻星

**判定**：3 个信号满足 ≥2 个 = **婚期强信号**；满足 1 个 = 留意；0 个 = 平常年

**流年地支关系**——同 §4.1 六种

> **这婚姻 = 躁家 + 弱配偶 + 聚少离多 + 食伤缺——堵点。配偶能管家，但流通堵在"食伤缺"和"财被劫"。**

---

### 5.4 综合化解方案

- **子午冲** → **远离出生地**——减少年支影响
- **食伤缺** → **多表达、多创作、多倾诉**
- **财被劫** → **不花配偶钱**——避免激发劫财
- **印太重** → **少堆证书/学习**，**给配偶空间**
- **卯午破** → **避免家里大事由母亲决定**——让配偶主导家里

## 六、应用 v3.3.1 流通框架

> **本节按新流通框架**（v3.3.0 路径分析 + v3.3.1 距离规则）应用婚姻分析。
> **v3.3.1 框架核心**：
> - 流通 = 递归结构——**不是固定日干为中心**
> - 递归中心随场景变化——**婚姻宫 = 日支**；**婚姻星 = 夫星/妻星**
> - 距离规则：**合/冲无视距离**——结构性关系；**生/克/刑/破/害紧贴/相邻**——力量性关系

### 6.1 婚姻场景的递归中心

**场景 1：婚姻宫模式**

- **递归中心：日支**——婚姻宫 = 日支本身
- **分析目标**：命局所有元素对日支的影响——家稳不稳
- **路径树**——以日支为根：
  - 日支 ← 月支、时支——相近地支，无视距离+ 日干——同柱
  - 月支 ← 年支、日支——无视距离
  - 时支 ← 日支——无视距离
  - 其他天干——年干、月干、时干→ 通过月支/时支影响日支——间接路径

**场景 2：婚姻星模式**

- **递归中心：夫星/妻星**——女命官杀、男命财星所在位置
- **分析目标**：命局所有元素对夫星/妻星的影响——人稳不稳
- **路径树**——以夫星/妻星为根：
  - 夫星/妻星所在位置 ← 相邻天干 + 同柱地支 + 相邻地支——无视距离
  - 上游递归类似场景 1，但中心换成夫星/妻星位置

### 6.2 距离规则的实战应用

**无视距离的场景**——合/冲：

- 任何柱的合/冲关系都可以直接分析——不受紧贴/相邻限制
- 例：年支与时支六合 = **无视距离**——结构性关系
- 例：年干与月干合化 = **无视距离**——结构性合化
- 例：日支与时支冲 = **无视距离**——结构性冲

**紧贴/相邻的场景**——生/克/刑/破/害：

- 必须按紧贴/相邻判定——按 §二.4 力量层级
- 同柱 > 相邻 > 隔柱减半 > 跨柱中转
- 例：日支与月支生克 = **相邻**——按紧贴判定
- 例：日支与年支生克 = **隔柱**——力减半
- 例：日支与时支生克 = **相邻**——按紧贴判定

### 6.3 实战模板

分析任何婚姻问题，按以下流程：

[1] **确定场景**：婚姻宫模式——家稳不稳或 婚姻星模式——人稳不稳
[2] **画路径树**：以中心元素为根，向上游递归展开（参考 §1.5 场景与递归对象）
[3] **判定距离**：每条路径上按距离规则判定——合/冲无视距离 vs 生/克/刑/破/害紧贴/相邻
[4] **输出堵点**：按力量层级排序，输出主堵点、次堵点、唯一通路

### 6.4 与旧框架的区别

| 维度 | 旧框架——v2.x| 新框架——v3.3.1|
|------|-------------|----------------|
| **结构** | 按对象分类——家+人+关系| 场景化递归——婚姻宫/婚姻星|
| **距离规则** | 全部按紧贴/相邻 | **合/冲无视距离 + 生克刑破害紧贴/相邻** |
| **路径分析** | 单一分析——每个对象分别看| 递归路径树——以中心元素为根|
| **实战输出** | 异位关系清单 | 路径分析 + 堵点清单 |
