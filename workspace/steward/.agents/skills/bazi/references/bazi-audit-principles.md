# bazi 技能核查原则

> **本文档定义 bazi 技能文档体系的核查原则**——用于自查 / reviewer 审阅 / 版本发布前检查。
> 创建背景：2026-08-08 老板 16:18 拍板"整理核查原则，创建 workboard 让 reviewer 进行完整审阅"。
> 来源：v1.7.0 系列修复中实际发现的问题。

---

## 一、职责边界核查

| 层 | 文档 | 职责 | 违规信号 |
|----|------|------|----------|
| **内容层** | rules / shensha / zhengge / wangshuai / yongshen | 具体内容唯一权威 | 出现流程步骤 / 输出格式 |
| **应用层** | paipan/ hehun| 具体应用| 出现内容层理论细节|
| **输出层** | style | 输出独占| 出现内容 / 流程定义 |

**核查规则**：
- 内容层文档 = 内容唯一权威，应用层 / 输出层**只引用不重复**
- 应用层文档 = 流程唯一权威，其他文档**不得重复定义流程**
- 输出层文档 = 美学 + 示例，应用层**不得重复美学规则**
- 冗余判定：同一内容在两个文档出现 → 保留职责归属方，另一方改引用

## 二、版本一致性核查

| # | 核查项 | 方法 |
|---|--------|------|
| V1 | SKILL.md YAML version | 与当前迭代版本一致 |
| V2 | README 文件树 / 关键文档表版本号 | 与各文档自报版本一致 |
| V3 | 各文档版本历史最后一条 | 与文档实际内容一致 |
| V4 | 交叉引用版本号 | 引用处版本 ≥ 被引文档当前版本|

**核查规则**：
- 版本号**先更新文档，再更新引用**
- 版本历史条目中的旧版本号是**历史记录**，不得当"过时引用"误改
- 全文检索 `v[0-9]+\.[0-9]+\.[0-9]+`，逐一确认每个版本号是"当前"还是"历史"

## 三、流程一致性核查

| # | 核查项 | 方法 |
|---|--------|------|
| P1 | SKILL.md 流程摘要 vs 应用层权威流程 | 两处 Step 定义完全一致 |
| P2 | 应用层正文 vs 应用层案例 | 案例 Step 结构 = 正文 Step 结构 |
| P3 | 各文档引用同一流程的编号 | 全库 Step 编号统一 |
| P4 | 章节编号连续 | 无跳变|

**核查规则**：
- **同一流程只允许定义一次**，其余引用
- 案例 / 示例必须跟随正文流程版本
- 编号跳变 = 合并后遗症，必须重排连续

## 四、引用完整性核查

| # | 核查项 | 方法 |
|---|--------|------|
| R1 | 引用目标文件存在 | 每个 `bazi-*.md` 引用有实际文件 |
| R2 | 引用章节存在 | 每个 `§X` / `Step X` 引用有实际章节 |
| R3 | 新增内容被引用 | 新增章节被 SKILL / README 引用 |
| R4 | 删除内容无残留引用 | 删除章节后全库搜旧引用 |

**核查规则**：
- 新增内容 → 必须更新入口文档引用
- 删除内容 → 必须全库搜残留引用并清理
- 引用必须带版本号，版本升级后引用同步

## 五、残留与边界核查

| # | 核查项 | 方法 |
|---|--------|------|
| N1 | 旧文件名残留 | 重命名后全库搜旧名 |
| N2 | 旧版本流程残留 | 升级后搜旧版本号 + 旧 Step 结构 |
| N3 | 行号引用漂移 | 引用用章节号不用行号 |
| N4 | 职责越界 | 内容层无流程、应用层无美学、输出层无内容 |

## 六、核查执行方式

1. **自查**：
   ```bash
   cd ~/.openclaw/workspace/steward/.agents/skills/bazi
   grep -rn "旧名\|旧版本\|§X" README.md SKILL.md references/*.md
   wc -l README.md SKILL.md references/*.md   # 行数变化可接受
   ```
2. **reviewer 审阅**：按本清单逐项核查，输出报告
3. **发布检查**：README 版本历史 + SKILL YAML + 文件树三者一致

## 七、美学核查

| # | 核查项 | 方法 |
|---|--------|------|
| **A1** | 标题不带括号副标题 / Step 后缀 / 比喻注解 | `grep -nE '^###+ .*[（(]'` SKILL.md references/*.md reports/*.md |
| **A2** | 🆕 v1.1.0 正文括号补充说明密度 ≤ 3 处/文件 | `grep -nE '（' references/*.md reports/*.md \| grep -vE '（含|（主|（参考|（v[0-9]\|v[0-9]+\.[0-9]+'` 规则见 `bazi-style.md` v3.17.0 |
