## 一、势局的定义

### 1.1 什么情况下走势局？

正格成立 → 用正格判定
正格不成立 → 走势局

**正格不成立的 4 种情况**：

1. **月令本气不透**：月支藏干未透出天干
2. **月令气势成局**：三会方 / 三合局 / 一行得气
3. **月令被冲破**：月支被冲，无法定格
4. **化气格**：月干与日干相合化出另一种五行

### 1.2 势局分析的核心问题

- **身旺 vs 身弱**？
- **命中五行流通吗**？
- **用神是什么**（基于旺衰）？
- **调候到位吗**？

### 1.3 势局与正格的关系

- **正格** = 用神方向（基于格局类型）
- **势局** = 用神精化（基于旺衰流通）
- **两者融合** = 最终用神

## 二、特殊格局分类

### 2.1 从强格

- **条件**：日主**极旺**（4/4 维度都得），**无比劫 / 印星以外**的克制十神
- **用神**：**印星 + 比劫**（助旺日主）
- **忌神**：官杀、食伤、财星（克制日主的十神）
- **古籍口径**：「从强不可破，破则倒」
- **大运喜忌**：行印比运大吉，行财官食伤运大凶

### 2.2 从弱格

- **条件**：日主**极弱**（4/4 维度都失），**无印星 / 比劫**扶助
- **用神**：**财星 + 官杀**（耗泄日主，让其安静）
- **忌神**：印星、比劫（助日主的十神）
- **古籍口径**：「从弱有气，运行财官方为美」
- **大运喜忌**：行财官运大吉，行印比运大凶

### 2.3 化气格

- **条件**：月干与日干**天干五合**，且**月令之气与化出五行一致**
- 化气格成立后，**日主变为他五行**，按新五行重新推十神

| 天干合 | 化出五行 | 化气格条件 |
|---|---|---|
| 甲己 | 土 | 己土日主 + 甲己合化土 + 月令土旺 |
| 乙庚 | 金 | 庚金日主 + 乙庚合化金 + 月令金旺 |
| 丙辛 | 水 | 辛金日主 + 丙辛合化水 + 月令水旺 |
| 丁壬 | 木 | 壬水日主 + 丁壬合化木 + 月令木旺 |
| 戊癸 | 火 | 癸水日主 + 戊癸合化火 + 月令火旺 |

### 2.4 一行得气格

- **条件**：命中**某五行占 4 个以上**（天干 + 地支 + 藏干），其他五行极弱
- 用神 = 该五行所喜（视具体情况）

### 2.5 两神成象格

- **条件**：命中**两种五行各占一半**（如木火各 3 个），其他五行极少
- 如：木火成象 → 用神可能为木火；金水成象 → 用神可能为金水

### 2.6 三奇格

- **条件**：天干三字**特定组合**：
  - **天上三奇**：甲戊庚（顺序不拘）
  - **地上三奇**：乙丙丁
  - **人中三奇**：壬癸辛
- 用神 = 三奇所化五行

## 三、旺衰四维度（滴天髓核心）

### 3.1 旺衰判定

日主旺衰由 4 维度判定：

| 维度 | 含义 | 判定 |
|---|---|---|
| **得令** | 月令是否生日主 | ✓（月令五行生日主或同五行）|
| **得地** | 日支是否生日主或日主禄位 | ✓（日支五行生日主或日主禄位）|
| **得生** | 命中是否有印星 | ✓（印星透出或藏支有根）|
| **得助** | 命中是否有比劫 | ✓（比劫透出或藏支有根）|

### 3.2 旺衰分级矩阵

| 得令 | 得地 | 得生 | 得助 | 总和 | 旺衰 |
|---|---|---|---|---|---|
| ✓ | ✓ | ✓ | ✓ | 4/4 | **极旺**（考虑从强）|
| ✓ | ✓ | ✓ | ✗ | 3/4 | **旺** |
| ✓ | ✓ | ✗ | ✓ | 3/4 | **旺** |
| ✓ | ✗ | ✓ | ✓ | 3/4 | **旺** |
| ✗ | ✓ | ✓ | ✓ | 3/4 | **中偏旺** |
| ✓ | ✓ | ✗ | ✗ | 2/4 | **中等偏旺** |
| ✓ | ✗ | ✗ | ✓ | 2/4 | **中等** |
| ✗ | ✓ | ✗ | ✓ | 2/4 | **中等** |
| ✓ | ✗ | ✓ | ✗ | 2/4 | **中等偏弱** |
| ✗ | ✗ | ✓ | ✓ | 2/4 | **中等偏弱** |
| ✗ | ✓ | ✓ | ✗ | 2/4 | **中等偏弱** |
| ✗ | ✓ | ✗ | ✗ | 1/4 | **弱** |
| ✗ | ✗ | ✓ | ✗ | 1/4 | **弱** |
| ✗ | ✗ | ✗ | ✓ | 1/4 | **弱** |
| ✗ | ✗ | ✗ | ✗ | 0/4 | **极弱**（考虑从弱）|

### 3.3 旺衰与用神方向

| 旺衰 | 用神方向 |
|---|---|
| **极旺** | 印 + 比劫（从强格）|
| **旺** | 克泄（食伤 / 财星 / 官杀）|
| **中等偏旺** | 财星 / 食伤 |
| **中等** | 看具体配合（调候优先）|
| **中等偏弱** | 印星 / 比劫 |
| **弱** | 生扶（印星 / 比劫）|
| **极弱** | 财 + 官杀（从弱格）|

## 四、五行流通分析

### 4.1 流通的概念

- **流通**：命局五行**相生流转**（木→火→土→金→水→木）
- **阻滞**：命中**某五行被克太过**，形成"堵点"

### 4.2 阻滞点识别

| 阻滞类型 | 表现 | 化解 |
|---|---|---|
| **印太旺** | 印克食伤 → 食伤阻滞（不能表达）| 财制印 |
| **财太旺** | 财克印 → 印阻滞（不能思考）| 比劫夺财（注意分寸）|
| **官杀太旺** | 官杀克身 → 日主受压（不能自主）| 食伤制官 |
| **食伤太旺** | 食伤克官杀 → 官杀阻滞 | 印制食伤 |
| **比劫太旺** | 比劫克财 → 财阻滞 | 官杀制比劫 |

### 4.3 流通的判断

```
日主 → 食伤 → 财星 → 官杀 → 印星 → 日主
（木   火     土     金     水     木）
```

- **完整流通**：上述链无阻滞
- **部分阻滞**：找到阻滞点，**制化**

### 4.4 流通 vs 用神

- **用神**是"补缺"（缺什么补什么）
- **流通**是"通关"（化解阻滞）
- 两者结合 → 完整势局判断

## 五、调候（穷通宝鉴）

### 5.1 调候的概念

- **调候**：基于出生**季节**（月令），调节**寒暖燥湿**
- **春月**多寒 → 用**丙火**暖
- **夏月**多燥 → 用**壬癸水**润
- **秋月**多金寒 → 用**丁火**炼
- **冬月**多寒 → 用**丙火**暖

### 5.2 五日主调候速查表

| 日主 | 春月（寅卯辰）| 夏月（巳午未）| 秋月（申酉戌）| 冬月（亥子丑）|
|---|---|---|---|---|
| **甲** | 庚金 + 壬水 | 癸水 + 庚金 | 丁火 + 壬水（先丁后壬）| 庚金 + 丁火 + 戊土 |
| **乙** | 丙火 + 癸水 | 癸水 + 丙火 | 丁火 + 丙火 | 丙火 + 戊土 |
| **丙** | **壬水**（第一）| 壬水 + 庚金 | 壬水 + 戊土 | 壬水 + 甲木 |
| **丁** | 甲木 + 庚金 | 壬水 + 庚金 | 辛亥 + 甲木 | 甲木 + 庚金 |
| **戊** | 丙火 + 乙木 | 壬水 + 甲木 | 丙火 + 甲木 + 癸水 | 丙火 + 甲木 |
| **己** | 丙火 + 甲木 + 癸水 | 壬水 + 丙火 + 甲木 | 丙火 + 甲木 + 癸水 | 丙火 + 甲木 + 戊土 |
| **庚** | 壬水 + 丁火 | 壬水 + 戊土 | 丁火 + 壬水（先丁后壬）| 丁火 + 甲木 |
| **辛** | 壬水 + 乙木 | 壬水 + 庚金 | 丁火 + 壬水 | 壬水 + 戊土 + 丙火 |
| **壬** | 庚金 + 丙火 | 壬水 + 辛金 | 丁火 + 甲木 | 丙火 + 甲木 + 戊土 |
| **癸** | 庚金 + 辛金 | 丙火 + 庚金 | 丁火 + 甲木 + 戊土 | 丙火 + 辛金 |

> **核心原则**：调候**优先于扶抑**（滴天髓 + 穷通宝鉴）

### 5.3 调候与扶抑的优先级

- **调候 vs 扶抑冲突** → 调候优先
- 但调候不能完全取代扶抑，需**融合**
- 例：身弱 + 春月丙火 → 调候壬水（克身）+ 扶抑印比 → **融合 = 用神金水（兼顾调候与护身）**

## 六、实战案例

### 6.1 杨权（丙子 辛卯 丙午 丁酉）

#### 旺衰四维度

| 维度 | 判定 | 解读 |
|---|---|---|
| 得令 | ✓ | 卯月印当令（木生火）|
| 得地 | ✓ | 日支午 = 劫财（丙火帝旺）|
| 得生 | ✓ | 月支卯 = 印星 |
| 得助 | ✓ | 年干丙 + 时干丁 = 比劫双助 |

→ **4/4 维度都得 → 极旺**（不走从强，因还有官杀可制）

#### 调候

- 春月（卯月）丙火 → **壬水**为先
- 调候用神：**壬水第一**

#### 流通分析

```
丙火（日主）→ 丁火（劫财，比劫帮身）→ 阻滞（比劫旺）
月支卯印 → 生丙火 → 助身太过
月干辛（正财）→ 克卯（正印）→ 财破印 → **关键通关**
日支午 + 时支酉 → 半合金局 → 助财
```

→ **财破印**是命局的关键制化机制

#### 融合

- 扶抑（极旺 → 克泄）：**金水**
- 调候（春月丙火）：**壬水**
- 流通（财破印制印）：**金水**
- 融合：**金水**（壬水为核，庚辛金为辅）

### 6.2 王雅欣（戊寅 己未 甲子 己巳）

#### 旺衰四维度

| 维度 | 判定 | 解读 |
|---|---|---|
| 得令 | ✗ | 未月土不生甲木（土为财，失令）|
| 得地 | ✗ | 日支子 = 印星（非日主禄位）|
| 得生 | ✓ | 年支寅 = 比肩 |
| 得助 | ✓ | 日主甲 + 寅比肩双助 |

→ 2/4 维度 → **身中等**（按 §3.1 定义：未月土不生甲木 → 失令，2/4）

#### 调候

- 夏末（未月）甲木 → **癸水 + 庚金**
- 调候用神：**癸水 + 庚金**

#### 流通分析

```
甲木（日主）→ 食伤火 → 财星土 → 阻滞（财太多）
寅木（比肩）+ 子水（印星）→ 比劫夺财
巳火（食神）+ 未土（财星）→ 食伤生财
```

→ **食伤生财**是命局的关键制化机制

#### 融合

- 扶抑（中等 → 平衡）：**火金**
- 调候（夏末甲木）：**癸水 + 庚金**
- 流通（食伤生财）：**火金**
- 融合：**火金**（食伤泄秀 + 官杀护财）
