# 八字财专题

> **本文档是八字技能财分析的内部参考。**
> 适用于：所有八字解读中的"财运/钱/财富"判断——**单盘**。
> **核心问题**：你的财运怎么样？适合什么赚钱方式？什么时候有大钱？
> **不是**合盘分析 ——合盘见 [`bazi-hehun.md`](bazi-hehun.md)。

---

## 〇、设计原则

- **以对象为中心**——不是流程为中心：3 个对象 = 工资 + 横财 + 关系
- **正财 = 看工资**——稳定收入
- **偏财 = 看横财**——投资/意外之财
- **只看异位关系**——不自比
- **关系 > 字本身**：字无意义，关系才是一切
- **隐晦必断**：多个候选必须用 5 规则选 1

> **财 =工资——正财 + 横财——偏财 + 关系——财-我-家庭**

---

## 一、正财

> **这一章只讲"工资"是什么**

### 1.1 怎么找正财

**男命**：**我克之异性** = **正财**——正财 = 妻，也是工资

- 甲己 → 乙为正财——不对，正财应该是**阴见阳**：甲阳见己阴 → 己是**正财**
- 实际上：日干是阳 = 克阴 = 正财；日干是阴 = 克阳 = 正财
- 看四干 + 地支藏干

**大白话**：先认清楚**工资是什么属性**

### 1.2 正财的强度

- **得令**：月支是否生扶正财
- **有根**：地支有无同类
- **得生**：有无食伤生财
- **得助**：有无同类帮

### 1.3 正财的异位关系

#### 位置含义速查

- 年柱 = 祖辈、出身、童年底色
- 月柱 = 父母、事业、成长环境——最关键的能量
- 日柱 = **自己 + 配偶**
- 时柱 = 子女、晚年、未来

#### 🆕 1.3.0 宫星交互：财星落各宫的含义

> **星落宫位 = 人进家**——财星落在哪个宫，钱就“住进”哪个领域。

- 财星落**年支**（祖上宫）= **祖辈财**——家底/出身带来的钱
- 财星落**月支**（父母宫·事业宫）= **事业财**——工资归位，最正 ✅
- 财星落**日支**（夫妻宫）= **配偶管钱**/配偶带财——家财归配偶
- 财星落**时支**（子女宫·晚年宫）= **晚年财**/子女带来财——末运聚财

#### 🆕 1.3.0 宫层：财星所在宫被作用 = 财运环境状态

- 财星所在宫被**冲** = 财路**动荡**——收入大起大落
- 财星所在宫被**合** = 钱被**绑定**——合作/婚姻锁财
- 财星所在宫被**刑** = 财路**暗伤**——隐性破财
- 财星所在宫被**害** = 财被**阴损**——被人骗/暗耗
- 财星所在宫被**破** = 财**慢性消耗**——慢慢漏财
- 财星所在宫被**生** = 财路**滋养**——有人帮你聚财
- 财星所在宫被**克** = 财被**压制**——比劫夺财

#### 7 大关系 + 暗含

- **冲**：动荡，如出身冲击财运
- **合**：绑定——配偶影响财运
- **刑**：暗伤
- **害**：阴损
- **破**：慢性消耗
- **生**：帮忙，如食伤生财
- **克**：压制，如比劫克财 = 兄弟抢钱

### 1.4 喜忌+流通位置

- **喜忌**：极旺喜财——钱来压你/ 极弱忌财——扛不住
- **流通位置**：正财是**身→财**的起点

### 1.5 一句话：这**工资**是什么样的？

> **这工资——正财是 [材质] 做的，强度 [评分]，与你 [喜/忌]，在公司/职业中 [角色]。**

## 二、偏财

> **这一章只讲"横财能力"是什么**

### 2.1 怎么找偏财

**男命**：

- **偏财**——我克之同性= **偏财** = 投资财、意外之财、父亲
- 多个候选时用 **5 规则**——透干 > 藏支 / 紧贴 / 合化 / 生克 / 配合体用

**大白话**：偏财是**正财的同类兄弟**，但**性质不同**——更机动、更波动

### 2.2 偏财的强度

**同 §1.2**——4 维度打分

### 2.3 偏财的异位关系

**重点暗含**：

- **偏财冲正财** = 横财破工资——投资破正业
- **偏财冲印** = 财坏印——为钱不学习
- **偏财合比劫** = 钱被兄弟分走
- **偏财生官杀** = 财能买权

#### 🆕 2.3.0 宫星交互：偏财落各宫的含义

- 偏财落**年支** = **祖上横财**——遗产/家族投资
- 偏财落**月支** = 事业中**投资机会**——工作带偏财
- 偏财落**日支** = 配偶带**外财**——配偶有投资能力
- 偏财落**时支** = **晚年横财**——末运偏财起（实战：酉时支偏财 = 横财晚年才有）

### 2.4 喜忌+流通位置

- **喜忌**：身旺喜偏财——可承担投资风险/ 身弱忌偏财——扛不住
- **流通位置**：偏财是**身→财**的**额外渠道**

### 2.5 一句话：这**横财能力**是什么样的？

> **你的偏财是 [材质] 做的，强度 [评分]，与你 [喜/忌]，投资风格 [十神特质]。**

## 三、关系

> **这一章只讲"财和我、和家"怎么相处**

### 3.1 钱能不能留住

- **比劫夺财**——兄弟抢钱= 钱**留不住**
- **财生官杀**——财去生官= 财用来**投资自己/求学**
- **财生印**——印旺= 财来**养长辈/学习**

### 3.2 赚钱方式

- **体用 = 赚钱方式的五行**
- 金 = 工资/金融/银行
- 木 = 知识/教学/写作
- 水 = 流通/中介/物流
- 火 = 创意/科技/服务
- 土 = 房地产/农业/实业

### 3.3 财运流通

```
印 → 身 → 食伤 → 财 → 官
木 → 火 → 土 → 金 → 水
```

**找堵点**：

- **比劫夺财** = 兄弟/朋友抢钱 ⚠️⚠️⚠️
- **食伤弱** = 没法生财
- **财生官过旺** = 钱都拿去投资体制/学习
- **身旺无财** = 找不到赚钱的渠道

**大运配合**：

- 财运大运 = 财星当令 → **有钱**
- 比劫大运 = 抢钱
- 食伤大运 = 生财有道

### 3.4 一句话：这**财**整体怎么样？

> **这财 = [工资]+[横财]+[关系]，[整体评级]，堵点 = [主堵点]。**

## 四、综合判断实战

> **把前三章的框架实战跑通一遍**

### 4.1 这**工资**是什么 → 辛

**字本身**：

- **辛** = 金 = **正财**——工资
- 位置：**月干**——紧贴日干
- 强度：**1/4 偏弱**——失令，有根，没生没助

**异位关系——不自比**：

- 年干丙 → **丙辛合** ✅——**配偶与工资合化**
- 日干丙 → **丙辛合——双合** ✅✅
- 时干丁 → **丁克辛** ⚠️⚠️——**子女/未来克工资**
- 年支子 → **辛生子** ✅——**金生水**，工资滋生官星
- 月支卯 → **辛克卯** ⚠️⚠️——**财坏印**，工资破学习
- 日支午 → **午克辛** ⚠️⚠️⚠️——**家克工资**
- 时支酉 → **辛比酉**——同类，工资力量加强

**位置含义暗含**：

- 正财在**月干**——父母场域/事业→ 工资**与事业紧密相关**
- 丙辛合 → 工资**与你深度绑定**
- 丁克辛 → **未来/子女克工资**

**喜忌+流通**：

- 喜忌：4/4 极旺喜金水 → **辛是你的喜神** ✅
- 流通：辛生子 ✅ 但**被劫财丁克**

**一句话工资**：

> **这工资——辛正财是金做的，1/4 偏弱但被双丙辛合深度绑定，是你的喜神但被子女/未来克——丁克辛，且财坏印——破学习。**

---

### 4.2 这**横财能力**是什么 → 酉

**字本身**：

- **酉** = 金 = **偏财**——横财
- 位置：**时支**——子女/晚年
- 强度：0/4 极弱——藏辛金

**异位关系——不自比**：

- 年干丙 → 丙克酉 ⚠️——**劫财克偏财**
- 月干辛 → 辛比酉——同类，横财力量加强
- 日干丙 → **丙克酉** ⚠️——**劫财克偏财**
- 时干丁 → 丁克酉 ⚠️——**劫财克偏财**
- 年支子 → 金生水 ✅
- 月支卯 → **卯酉冲** ⚠️⚠️⚠️——**横财冲印/学习**
- 日支午 → 午酉破——暗藏破
- 时支酉 → 酉酉自刑 ⚠️

**位置含义暗含**：

- 偏财在**时支**——晚年/子女→ 横财**晚年才有**
- **三丙克酉**——年/日/时三干都克偏财→ **你抢自己的横财**
- **卯酉冲** = 横财**冲掉印/学习**

**喜忌+流通**：

- 喜忌：4/4 极旺 → **偏财也是喜神**——但被劫
- 流通：被**3 个丙丁克** = **被抢**

**一句话横财**：

> **这横财——酉偏财是金做的，0/4 极弱藏时支，被 3 个劫财克——年日时丙丁，横财冲印——卯酉冲，投资必亏。**

---

### 4.3 这**财**整体怎么样 → 关系 + 流通

**钱能不能留住**：

- **比劫夺财**——3 个丙丁克辛酉= **钱留不住** ⚠️⚠️⚠️
- 财生官——辛生子✅ 但被身旺堵

**赚钱方式**：

- 体用 = **金水**
- 金 = 工资/金融/银行
- 水 = 流通/中介/物流
- **适合**：打工 + 金融 + 物流

**财运流通**：

```
印——卯→ 身——丙+丁+午= 生 → 身极旺
 ↓
 食伤——己= 弱——藏支⚠️
 ↓
 财——辛+酉→ 身 = 被劫 ⚠️⚠️⚠️
 ↓
 官——子→ 印 = 通 ✅
```

**3 大堵点**：

- **堵点 1**：身旺 → **食伤弱**——没法生财⚠️⚠️⚠️
- **堵点 2**：**3 个劫财克财** = **你抢自己的钱** ⚠️⚠️⚠️
- **堵点 3**：印克食伤 ⚠️——学习压力

**唯一流通**：

```
财——辛+酉→ 官——癸→ 印——卯→ 身——丙
钱 → 给你事业 → 让你学习 → 你做事
```

### 4.4 一句话财

> **这财 = 极旺身 + 弱工资 + 弱横财 + 3 个劫财克财 + 钱留不住 + 财坏印。适合打工+金融，不适合投资/合伙。**

---

### 4.5 化解方案

- **比劫夺财** → **不投资、不合伙、不借钱给人**
- **财坏印** → **别为钱不学习**
- **丁克辛** → **子女教育早规划**——避免拖累工资
- **卯午破 + 子午冲** → **避免工作和家庭冲突**
- **大运配合** → **等金水大运，财运上升**
