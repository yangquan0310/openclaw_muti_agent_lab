# 明牌实证派 · 大管家八字解读风格（Open-Evidence Modern School）

> **本文件正式定义：大管家（steward）在调用 `bazi` 技能后的解读规范。**
> 适用于：所有四柱排盘、流年 / 流月 / 流时、大运（如有）的解读输出。

---

## 一、流派定位

**明牌实证派（Open-Evidence Modern School）**

- **承认没有传统师承**：不读过《滴天髓》《子平真诠》《穷通宝鉴》《三命通会》形成体系，没跟过哪位老师。
- **使用工具能算的客观口径**：节气切月、立春换年、子时换日、十神配置、藏干本气、五行生克、六合六冲——这些都是工具层（`bazi.py`）能直接验证的，作为派别的"硬底盘"。
- **不仿古，不假托师承**：不写"古贤云"，不模仿"派别味道"。

> 一句话定位：**有据则断，无据不强解，明牌给老板看。**

---

## 二、五条核心立场

| # | 立场 | 反例（不许做） |
|---|------|----------------|
| 1 | **每句话标依据** —— 每一句断言后用 `[依据: 类别]` 标明来源 | "暗合生水"（混用术语） |
| 2 | **术语洁净不混用** —— 暗合是暗合，相生是相生，合冲是合冲 | "酉子暗合"（子酉不合，是普通关系）|
| 3 | **不强解** —— 工具/资料不支持的（神煞主气、紫白飞星、奇门、六壬）直接说"信息不足" | 神煞不堆砌 |
| 4 | **不仿古不假托** —— 不编"古贤云"，不写"某派认为" | 不假装有师承 |
| 5 | **综合而非偏** —— 天干地支同等看，藏干取本气，不偏"天派"也不偏"地派" | 不一边倒 |

### 依据类目（合法标签）

```
[依据: 节气切月]      -- 月柱定在哪个月
[依据: 立春换年]      -- 年柱是哪个干支
[依据: 子时换日]      -- 日柱是否取次日
[依据: 十神配置]      -- 比肩/劫财/食神/伤官/偏财/正财/七杀/正官/偏印/正印
[依据: 藏干本气]      -- 地支藏干本气判定十神
[依据: 五行生克]      -- 木火土金水相生相克
[依据: 六合六冲]      -- 地支六合（子丑、寅亥、卯戌、辰酉、巳申、午未）/ 六冲（子午、丑未、寅申、卯酉、辰戌、巳亥）
[依据: 三合方合]      -- 三合局 / 方合半会
[依据: 藏干中余气]    -- 必要时展开中气/余气（默认只用本气）
[依据: 流时推算]      -- 流年 / 流月 / 流时柱的叠加
[依据: 节气神煞]      -- 仅在工具实现时使用（如驿马、桃花、华盖等工具层有实现）
[依据: 不强解]        -- 工具/资料不支持
```

## 三、看盘侧重

| 维度 | 做法 | 备注 |
|------|------|------|
| **天干** | 看（十神从日主正向推） | 阴阳同性 = 偏，异性 = 正 |
| **地支** | 看（藏干取本气） | 默认不展开中余气，除非工具层做了 |
| **节气** | 严格按节气切月（惊蛰前/后、清明前/后 …） | 子平术通用口径 |
| **立春** | 严格按立春换年 | 子平术通用口径 |
| **子时** | 23:00–00:59 视为子时且日柱取次日 | 主流口径 |
| **藏干** | 默认本气 | 必要时说明展开理由 |

**不强调也不回避**：神煞、紫白飞星、奇门、六壬——工具没实现就**不强解**，在"不强解"小节里说明。

## 四、输出美学（一眼格局的固定模板）

每次解读用三段式：**盘 → 断 → 注**。

### 4.1 排盘数据（盘）

使用 Markdown 表格，不用 ASCII art（QQ / 飞书渲染友好）：

```markdown
| 柱位 | 天干 | 地支 | 藏干 | 天干十神 | 地支本气十神 |
|------|------|------|------|----------|--------------|
| 年柱 | 丙 | 子 | 癸 | 比肩 | 正官 |
| 月柱 | 辛 | 卯 | 乙 | 正财 | 正印 |
| 日柱 | **丙** | **午** | 丁、己 | — | 劫财 |
| 时柱 | 丁 | 酉 | 辛 | 劫财 | 正财 |

**日主：丙（火）**

公历：1996-03-10 18:00
农历：一九九六年 正月小 廿一
生肖：午（马）   节气：惊蛰后、清明前
```

### 4.2 一眼格局（断）

```markdown
## 一眼格局（明牌实证派）

### 强证据（工具可直接验证）
1. [依据: 十神配置] 年日同干丙，日主自坐比肩，凡事靠自扛。
2. [依据: 藏干本气] 时柱酉本气辛为正财，但天干丁为劫财，劫财坐财位，需注意。

### 弱提示（仅作参考）
1. [依据: 藏干本气] 日支午藏丁己，丁为劫财、己为伤官。
2. [依据: 五行生克] 年支子癸水正官，时支酉辛金正财；酉金生子水，五行相生（不是"暗合"）。

### 不强解（信息不足）
- 神煞（驿马/桃花/华盖）—— 工具未实现
- 紫白飞星 / 奇门 / 六壬 —— 工具未实现
```

### 4.3 注（不强解项 / 待澄清项）

如果出生时间不明确（如只知道日不知时），列在"注"小节，说明影响：

```markdown
## 注
- 本盘时柱可信度取决于出生时间精度
- 未做真太阳时修正（输入即为"北京时间"）
- 节气精度 < 1 天（cnlunar 内置）
```
