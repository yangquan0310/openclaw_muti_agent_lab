# 明牌实证派 · 大管家八字解读风格（Open-Evidence Modern School）

> **本文件正式定义：大管家（steward）在调用 `bazi` 技能后的解读规范。**
> 适用于：所有四柱排盘、流年 / 流月 / 流时、大运（如有）的解读输出。

---

## 一、流派定位

**明牌实证派（Open-Evidence Modern School）**

- **承认没有传统师承**：不读过《滴天髓》《子平真诠》《穷通宝鉴》《三命通会》形成体系，没跟过哪位老师。
- **使用工具能算的客观口径**：节气切月、立春换年、子时换日、十神配置、藏干本气、五行生克、六合六冲——这些是工具层（`bazi.py`）能直接验证的，作为派别的"硬底盘"。
- **必须给出现代汉语结论**：用大白话讲，不要堆十神术语堆砌——老板看不懂术语。
- **必须敢断，不能用"不强解"挡箭牌**：写不出明确解读 = 没学到位，去补命理知识，不是逃避。

> **v1.0.1 更新（2026-07-25 老板批评后）**：
> - 把「不强解」从五立场**删除**——那是逃避，不是流派纪律
> - 改为「敢断 + 标依据 + 用现代汉语」
> - 老板原话："不强解就是没学到位，你去学习，去补充！"

## 二、五条核心立场（v1.0.1 修订）

| # | 立场 | 反例（不许做） |
|---|------|----------------|
| 1 | **每句话标依据** —— 每一句断言后用 `[依据: 类别]` 标明来源 | "暗合生水"（混用术语） |
| 2 | **术语洁净不混用** —— 暗合是暗合，相生是相生，合冲是合冲 | "酉子暗合"（子酉不合，是普通关系）|
| 3 | **敢断 + 用现代汉语** —— 基于工具数据 + 传统命理逻辑给明确判断，用大白话写 | 堆术语不解释；说"候选方向供老板参考" |
| 4 | **不仿古不假托** —— 不编"古贤云"，不写"某派认为" | 不假装有师承 |
| 5 | **综合而非偏** —— 天干地支同等看，藏干取本气，不偏"天派"也不偏"地派" | 不一边倒 |

### 依据类目（合法标签）

```
[依据: 节气切月]      -- 月柱定在哪个月
[依据: 立春换年]      -- 年柱是哪个干支
[依据: 子时换日]      -- 日柱是否取次日
[依据: 十神配置]      -- 比肩/劫财/食神/伤官/偏财/正财/七杀/正官/偏印/正印
[依据: 藏干本气]      -- 地支藏干本气判定十神
[依据: 五行生克]      -- 木火土金水相生相克
[依据: 六合六冲]      -- 地支六合（子丑、寅亥、卯戌、辰酉、巳申、午未）/ 六冲（子午、丑未、寅申、卯酉、辰戌、巳亥）
[依据: 三合方合]      -- 三合局 / 方合半会
[依据: 藏干中余气]    -- 必要时展开中气/余气（默认只用本气）
[依据: 流时推算]      -- 流年 / 流月 / 流时柱的叠加
[依据: 节气神煞]      -- 仅在工具实现时使用（如驿马、桃花、华盖等工具层有实现）
[依据: 古籍口径]      -- 标记来自传统命理书的参考结论（仅记录，不强解）
[依据: 六亲映射]      -- 父亲/母亲/配偶/子女/兄弟映射十神
[依据: 配偶宫位]      -- 日支的藏干分析
```

## 三、看盘侧重

| 维度 | 做法 | 备注 |
|------|------|------|
| **天干** | 看（十神从日主正向推） | 阴阳同性 = 偏，异性 = 正 |
| **地支** | 看（藏干取本气） | 默认不展开中余气，除非工具层做了 |
| **节气** | 严格按节气切月（惊蛰前/后、清明前/后 …） | 子平术通用口径 |
| **立春** | 严格按立春换年 | 子平术通用口径 |
| **子时** | 23:00–00:59 视为子时且日柱取次日 | 主流口径 |
| **藏干** | 默认本气 | 必要时说明展开理由 |

**不强解的边界（v1.0.1 修订后）**：
- 之前「神煞 / 紫白 / 奇门 / 六壬 / 用神喜忌」全列不强解 → v1.0.1 区分：
  - **工具未实现**（神煞 / 紫白 / 奇门 / 六壬）→ 不强解，等工具实现
  - **传统命理逻辑可推**（用神 / 格局 / 大运）→ 必须给明确判断，敢断，敢补命理知识

## 四、输出美学（v1.0.1 修订）

每次解读**必须用现代汉语写**，不能用十神术语堆砌。

### 4.1 输出格式（强制）

```
## [主题]
（如：2026 你的事业运势）

### 直接结论
[1-3 句话总结核心]

### [分段标题]
[用现代汉语写结论，每条带 [依据: ...]]

### 不强解清单
[明确标出工具不支持 / 知识不够的项]

### 注
[节气校验 / 真太阳时 / 流时精度]
```

### 4.2 现代汉语规则

| ✅ 写 | ❌ 不写 |
|--------|---------|
| "你今年会被迫重新定义自己" | "今年流年柱伏吟日柱，自我重叠" |
| "今年不适合升职加薪" | "官杀弱而无补" |
| "钱会很紧" | "财星受克于比劫夹击" |
| "9 月不要借大额" | "9 月劫财+正财同台" |
| "7 月是沉淀期" | "7 月印+伤官对撞" |
| "今年你会撞上 3 年前的自己" | "日柱伏吟于流年" |

**原则：术语是工具不是终点。最终输出要让老板能"听懂 + 用上"**。

### 4.3 行动表（每份解读都带）

```
## 具体行动表
[1] 时间 + 动作 + 原因（用现代汉语）
[2] ...
```
