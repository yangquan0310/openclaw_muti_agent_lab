# 大管家八字 · 输出风格

> **本文档是八字技能（bazi skill）输出风格的内部参考。**
> 适用于：所有解读输出（单盘 / 合盘 / 流年 / 大运 / 日报）。
> **核心问题**：解读结果怎么呈现？老板能"听懂 + 用上"？
> **不是**框架或技术规范 —— 框架见 `bazi-paipan.md` + `bazi-hehun.md`。

---

## 一句话定义

> **解读输出要让老板能"听懂 + 用上"——直接结论先行 + 现代汉语 + 大白话 + 适配渠道。**

---

## 一、排版美学

| 原则 | 做法 |
|------|------|
| **直接结论先行** | 第一段就 3 句话总结核心，老板不用读完就知道结论 |
| **节标题简洁** | 节标题不带括号副标题（如 ❌ `三、用神判定(三书融合,敢断)`）|
| **重复信息合并** | 一张表搞定全部信息；事业+姻缘一表联合 |
| **篇幅减半** | 原 11 节模板 → 7-8 节精华版 |

---

## 二、标签美学

| 标签类型 | 使用频率 |
|----------|----------|
| `[依据: 类别]` | **只在关键处** —— 有争议 / 敢断 / 用户问"凭什么"时贴 |
| 工具 bug 标注 | **只在第一次** + **新场景**首次出现时提，后续默默用正确值 |
| 节气精度 / 真太阳时 / 早子时 | **只在用户问"为什么"** 或边界情况时写 |
| 不强解清单 | **只在用户主动问"还有什么强解"** 时列 |
| 神煞阴阳两面 | **v2.1.0 起强制** —— 阳面 + 阴面同列，禁止单面贴吉凶 |

## 六、输出示例 + 专用格式（排盘 / 合盘 / 姻缘）★ v3.2.0

### 6.1 排盘输出示例（单盘 · 杨权 1996-03-10 18:00 男）

```
# 2026 丙午年 · 杨权全年运势

### 🎯 直接结论
今年是事业爆发 + 财务重压并存的一年——适合升职 / 换赛道，但钱会很紧，9 月不要借大额。感情方面今年会撞上 3 年前的自己，需要重新定义关系。

### 👤 排盘（Step 1）
- 四柱：丙子 辛卯 丙午 丁酉（丙火日主）
- 格局：印绶格（月令卯木正印）
- 用神：金水（壬水为核，庚辛金次之）
- 神煞：桃花（午）、天乙（酉）

### 🔍 正格（Step 2 · 骨）
- 印绶格 —— 财星制印，官杀护财

### 🔍 势局（Step 3 · 肉）
- 4/4 极旺 + 壬水调候

### 📊 流通（Step 4 · 气血 · 🆕 v2.0.0）
- **印堵食伤**：月令卯木印旺，食伤只有午中己土 → 想到说不出（化解：财金制印）
- **比劫夺财**：丙丙丁三火克一金辛酉 → 钱留不住（化解：官水制劫）

### 🎯 用神融合（Step 5 · 药方）
**金水**（壬水第一，庚辛金次之）—— 神煞不进入用神判定

### 🌟 神煞（Step 6 · 助缘）
- 桃花阳面=异性缘佳；阴面=烂桃花需辨
- 天乙贵人：有人帮
- 羊刃：身旺大贵之刃，但逢冲易刚烈

### 📅 大运（Step 7 · 时间框架）
- 当前 甲午（偏印+劫财）28-37：比劫旺上加旺——务实落袋、以财破印
- 下一站 乙未（正印+伤官）38-47：伤官泄秀生财，表达力变现期
- 再下站 丙申（比肩+偏财）48-57：财星得地，主积蓄与置业

### 💼 事业（Step 8 · 五维）
今年上层会给你机会（官杀有气），适合升职 / 换赛道。命中食伤 + 比劫 → 适合表达 + 创业。

### 💰 财
钱会很紧（财星受克于比劫夹击）。9 月不要借大额。

### 💕 姻缘
今年你会撞上 3 年前的自己（日柱伏吟于流年），需要重新定义关系。

### 🎭 性格
硬骨头，能扛事（羊刃 + 身旺）。今年尤其要稳住脾气。

### 💪 健康
重点关注心脏 / 眼睛（丙火过旺）。夏季少熬夜。

### 📋 具体行动表（Step 9 · 落地）
[1] 3 月前：准备升职材料（官杀有气，时机好）
[2] 7 月：推进关键项目（用神当令）
[3] 9 月：避免借贷 / 大额支出（劫财+正财同台）
[4] 全年：稳脾气，别因小事伤和气（羊刃）
```

### 6.2 合盘输出示例（杨权 1996-03-10 18:00 男 × 王雅欣 1998-07-16 09:00 女）

```
# 💕 姻缘合盘 · 杨权 × 王雅欣

### 🎯 直接结论
高度匹配，适合深度合作 / 婚嫁——男财 = 女夫满分契合 ✅，用神互补良好 ✅，格局互动以连续相生为主 ✅。注意日支子午冲在日常相处中的体现 + 2027 年错位共振需要预案。

### 👤 双方命盘
- 男：丙子 辛卯 丙午 丁酉（丙火 · 印绶格）
- 女：戊寅 己未 甲子 己巳（甲木 · 正财格）

### 🔍 各自分析
- 男：印绶格，用神金水（壬水为核）
- 女：正财格，用神火金（食伤泄秀 + 官杀护财）

### 🎯 用神互补（最核心）
- 男用神金水，女命甲木 + 己土财 → 女正好是男要的补给品 ⭐
- 女用神火金，男命丙火 + 辛金财 → 男正好是女要的补给品 ⭐
- **结论**：双向互补，最佳组合 ⭐

### 🔗 格局互动
- 印绶格（男）→ 正财格（女）：木生火、火生土 —— 连续相生 ✅
- 日支子午冲：日常摩擦点，需要包容（男午 vs 女子）

### 📅 流年共振
- ✅ 2025 / 2028 / 2030：互补共振
- ⚠️ 2027：错位共振年（男压力大、女平稳），需要预案

### 🧿 神煞互见
- 桃花煞互见：未出现 ✅
- 天乙贵人互见：无冲突（中性）
- 主要风险：日常摩擦（子午冲），无重大神煞冲突

### 📋 具体行动表
[1] 2027 年前：提前沟通事业节奏（避免错位共振）
[2] 日常：子午冲 → 说话留三分，避免硬碰硬
[3] 婚嫁：2025 / 2028 年时机最佳（互补共振年）
```

### 6.3 姻缘深度解读专用格式（8 节 · 不精简）

> **应用触发条件见** `bazi-paipan.md` §7.6（何时用 / do 型规则 / 例外）。此处只定义输出格式。

**格式结构**（8 节,必备,**不精简**）:

| # | 章节 | 内容 |
|---|------|------|
| 1 | **# 🎯 直接结论** | 3 条要点(动荡年 / 婚期 / 配偶类型)|
| 2 | **# 👤 命中"妻星"配置** | 男命正财位 + 偏财位 + 财破印结构 + 古籍口径引用 |
| 3 | **# 💕 姻缘吉面** | 4 条结构性优势(妻星显 / 财可用 / 婚恋单一 / 配偶特征)|
| 4 | **# 💔 姻缘凶面** | 4 条结构性挑战(财破印 / 比劫情敌 / 压配偶 / 调候弱)|
| 5 | **# 👤 配偶画像** | 5 条推测(性格 / 管钱 / 事业 / 大小 / 恋爱史)+ 不强解清单 |
| 6 | **# 📅 婚期推测** | 按大运 + 流年阶段分析(早 / 中 / 晚)|
| 7 | **# 📅 流年选择** | 大运吉凶流年选择(印运 / 财运 / 避比肩运)|
| 8 | **# 📅 当年姻缘专项** | 当前年份(如 2026)的姻缘深度分析 |

**输出元素**(必备,**不要砍**):

| 元素 | 用法 |
|------|------|
| **大量 emoji 图标** | ⚠️ 风险 / 📅 时间 / 💼 事业 / ⚙️ 金/财 / 🚫 忌神 / 💪 强 / 💔 弱 / 👤 人 / 🏛️ 印 / 📐 形 / ✅ 适合 / 🎯 目标 / 💕 姻缘 / 💰 财星 |
| **古籍口径引用** | `[依据: 古籍口径]` + 古诀原文(如"印绶逢财,如月缺")|
| **配偶画像 5 条编号** | `[1] [2] [3] [4] [5]` 编号列表(**保留 5 条,不精简到 3 条**)|
| **婚期按阶段分析** | "25-30 岁前" / "28-32 岁" / "35-40 岁" 这种年龄段 |
| **流年吉凶标记** | ✅ 行到 / ⚠️ 避开 |
| **不强解清单** | 配偶外貌 / 行业精确 / 婚期(**不强解**)|
| **大量 ⚠️ 警告图标** | 结构性挑战用 ⚠️ 标 |
