# 大管家八字 · 输出风格

> **本文档是八字技能——bazi skill输出风格的内部参考。**
> 适用于：所有解读输出——单盘 / 合盘 / 流年 / 大运 / 日报。
> **核心问题**：解读结果怎么呈现？老板能"听懂 + 用上"？
> **不是**框架或技术规范 —— 框架见 `bazi-paipan.md` + `bazi-hehun.md`。

---

## 一句话定义

> **解读输出要让老板能"听懂 + 用上"——直接结论先行 + 现代汉语 + 大白话 + 适配渠道。**
>
> **🚫 铁律（v3.18.0 老板拍板）：任何输出不出现表格**。所有渠道——QQ / 飞书 / 微信 / 完整文档一律用 bullet list —— `- xxx：xxx` 格式或编号 list `[1] [2] [3]`。

---

## 一、排版美学

**5 条原则**：

- **直接结论先行**：第一段就 3 句话总结核心，老板不用读完就知道结论
- **节标题简洁**：节标题不带括号副标题，如 � `三、施药判定(三书融合,敢断)`
- **重复信息合并**：用 list 合并同类项；事业+姻缘一节连讲——不堆表格
- **篇幅减半**：原 11 节模板 → 7-8 节精华版
- **正文括号零补充说明**：🆕 v3.17.0——正文中不用括号塞补充说明；用 `——` / `。` / 独立 bullet / 独立标题替代

---

## 二、标签美学

**5 类标签用法**：

- **`[依据: 类别]`**：**只在关键处** —— 有争议 / 敢断 / 用户问"凭什么"时贴
- **工具 bug 标注**：**只在第一次** + **新场景**首次出现时提，后续默默用正确值
- **节气精度 / 真太阳时 / 早子时**：**只在用户问"为什么"** 或边界情况时写
- **不强解清单**：**只在用户主动问"还有什么强解"** 时列

---

## 三、渠道美学

**🚫 v3.18.0 铁律：所有渠道一律不出现表格，统一用 bullet list**。

- **所有渠道**：bullet list——`- xxx：xxx`或编号 list——`[1] [2] [3]`—— 包括 QQ、飞书、微信、完整文档——Markdown / PDF
- **原因**：
  - QQ 表格会拆成独立窗口——富文本卡片，体验差
  - 飞书 / 微信虽然支持表格，但表格 ≠ 易读 —— 老板扫一眼 list 比扫表格快
  - 完整文档——PDF / 排版文档走 Quarto 渲染，list 在所有终端都好看
- **例外**：暂无——之前飞书/微信/文档可用表格的规则作废

- **正负类**：✅ 适合 / ❌ 避免 / ⭐ 最佳 / ⚠️ 风险
- **五行类**：🔥 火 / 💧 水 / 🪵 木 / ⚙️ 金 / 🌍 土

- **六维类**：💼 事业 / 💕 姻缘 / 💰 财星 / 📖 学习 / 👤 日主 / 🏛️ 印绶

- **化解类**：✅ 化解盘 / ⚠️ 风险盘

**do 型规则**：

## 五、术语正统化 + 现代汉语翻译

### 5.1 术语正统化铁律（v3.19.0 老板拍板）

> **分析层术语必须正统**——一切命理判断 / 堵点 / 施药 / 结论中的术语，必须用正统命理词汇，禁止自造口语词。

**❌ 禁止自造口语词 → ✅ 正统词汇**：

- ❌ "财星空转" → ✅ **比劫夺财** / **财星受制**
- ❌ "空转" → ✅ **克之无力**（火不泄气、金不受损）
- ❌ "克为虚克" → ✅ **克之无力**
- ❌ "财被合走" → ✅ **财星被合绊**
- ❌ "身旺得根" → ✅ **得令得地** / **日主有根**

**原则**：术语本体必须正统——**翻译层**（§5.2 现代汉语对照表）可以把正统术语翻成大白话让老板听懂，但**分析层**（判断依据 / 堵点命名 / 施药结论）必须用正统词汇。

### 6.3 一段话介绍范式 v3.8.0

> **应用触发条件**：用户要求"一段话介绍"/"一句话介绍"/"一段话讲讲"/"用现代汉语介绍"等。
> **核心思路**：一段话 = **1 句格局定义 + 1 个工程/物理比喻 + 5-6 段现代汉语解释**——bullet 形式

**结构——3 段式，必备**：

- **段落 1 · 格局定义**：直接给格局名 + 月令日主 + 干支关键透藏 + 工具验证——旺衰分
- **段落 2 · 工程/物理比喻**——callout box `>`：1 句话定比喻主体 + 1 段拆解：把印/比/食伤/财/官 分别对应到 1 个工程/物理部件 + 1 句"比喻收束"
- **段落 3 · 现代汉语解释**——5-6 bullet：核心一句话定性 + 5-6 段 bullet —— ① 五行气重——基调② 硬件/配置——资源位③ 堵点/瓶颈——弱项④ 性别关键项——女命姻缘/男命妻财⑤ 施药方案——具体路径⑥ 落地建议——行动方向

**主语规则**——**强制**，2026-08-12 老板拍板 + **v3.11.0 强化「明示主语」**：

- ❌ **不用** "她"/"他" 做主语
- ✅ **必须明示主语**——用 "**这个命局**" / "**这张命局**" / "**命局**" / "**八字**" / "**比喻主体**"——"小树苗"/"水洼"/"电站" 等做主语
- ❌ **🆕 v3.11.0 反例**：不要只用 "**这**" 代词做主语——例如 "这是一洼浅水" / "这是一棵小树" / "这是一台机房" ❌；"这"指代不明，读者搞不清主语到底是什么
- ✅ **🆕 v3.11.0 正例**："**这个命局**是一洼浅水..." / "**这张命局**是一棵寒冬里的小树苗..." / "**这张命局**是一台机房..."

**比喻规则**——**强制**，2026-08-12 老板拍板 + **v3.9.0 强化「具体事物」** + **v3.10.0 强制「日干五行主喻」** + **v3.11.0 强化「明示主语」** + **v3.15.0 隐喻构造三步法哲学框架**：

- ✅ **🆕 隐喻构造三步法**——**v3.15.0 哲学框架**，老板 2026-08-12 19:14 拍板"看一个人的八字。要有画面感。先要确定他是山川草木，是什么东西？然后再去看他和其他的东西之间的相互关系。所以这个隐喻一定非常重要。一定要确定它是什么。然后再确定他和其他的关系。所以格局、旺衰、流通就是在去告诉你怎么隐喻。一段话隐喻你一定一定要精确"：

  1. **画面感** — 比喻必须有画面感，让人闭眼就能看到
  2. **先定主喻** — 先确定日干是什么具体东西——山/水/火/树/金器
  3. **再看关系** — 用格局/旺衰/流通告诉你"它"和其他元素怎么互动
  4. **隐喻精确** — 一段话比喻必须精确，不能模糊

  **格局/旺衰/流通 → 隐喻的对应关系**：

  | 分析层 | 决定隐喻的什么 |
  |--------|--------------|
  | **格局** | "它是什么类别"——旺格/弱格/从格/化格/特殊组合|
  | **旺衰** | "它是什么状态"——极旺/中等/偏弱/从强|
  | **流通** | "它和其他元素怎么互动"——通畅/堵点/断裂/枯竭|

  **完整流程**：**格局定类别 → 旺衰定状态 → 流通定互动 → 综合形成精确比喻**

  **比喻前自查 4 件事**：①"它是什么"——画面感②"它处于什么状态"——旺衰③"它和其他怎么互动"——流通④"这个隐喻够精确吗"

## 用现代汉语解释

**先给命局打个比喻：**

> **这张命局是烈日下越烧越旺的篝火——火苗到处乱窜、柴火不断往里塞，但没人拿瓷器窑来吸收火热量、没水来浇、金属也没被火锻炼成形。**
> 火焰(丙火比劫)到处乱窜、火势极旺；柴火(卯木正印)不断往里塞，让火烧得更猛；火堆本身(午火根)又是个大火炉，烧得通红。**但没人拿瓷器窑来吸收火热量、转化为产出**(土，食伤太小——午中只藏一个己，火没法转成瓷器/陶器)、**没水来浇**(火势无法降温，水=官杀太小——癸水藏子中)、**金属也没被火锻炼成形**(金，财星虽透但被克——辛酉被丙丁火克，金属还是原料、没锻成器)。再烧下去，**火势失控，可能烧到自己**。

这就是这张命局的样子——**火太盛，没人管，火势要失控**。

具体说：

- **火气极重**。丙火是太阳之火，年干+日干双丙并列、时干丁劫财透出、午火坐日支为根、卯木正印当令源源生火——等于"两团主火+地下火炉+柴火不断"——**热情、明亮、有活力、有领袖气质**，但火势太旺没人管就容易烧焦自己。

- **硬件配置其实不差**。卯中乙木正印当令，辛金正财透月干+酉金正财坐时支，午中己土食神藏根，癸水正官藏子中——**印、财、官、食四类资源都各有其位**，不算寒酸。

- **但火力太猛，没人管**。印比成势、旺衰 4/4 极旺，这堆"篝火"火力极大；然而**拿瓷器窑吸收火热量(土，食伤)只午中一个己**——火没法转成有用的产出；**浇水灭火的水(官杀)太小**(癸水藏子中)；**金属也没被火锻炼成形**(金，财星虽透但被丙丁比劫克夺——火克金，原料还是原料)。**典型"火旺但没产出"**。

- **妻缘有，但易争财**。辛金正财(男命妻星)透月干+坐时支，**妻缘不差、婚姻本身有基础**；但比肩双透+劫财透时干，**比劫夺财的风险大**——事业上能赚钱，但花销、损耗、合作分利也会同步跟上，**得小心"赚得不少但留不住"**。

- **施药是土、金、水，简单说就是：瓷器窑吸收火热量 + 把金属锻成器 + 浇水灭火**。**土**(食神伤官)= 瓷器窑/陶吸收火热量、泄秀、慢节奏、稳情绪，**第一施药**；**金**(财星)= 把金属原料锻成器、理财、规则、节制，**第二施药**；**水**(官杀)= 浇水灭火、外部约束、调候降温，**第三施药兼调候**。**这张命局最适合往土(稳、慢、细)和金(财务、规则、合作)的方向发展，而不是拼命加柴(学习/考证)或加火(扩张/竞争)**。

- **事业能跑得快，身体要养散热**。丙火旺的人通常事业心强、节奏快，但印比成势又无食伤泄秀，**容易着急、上火、失眠、心血管压力**；男命比肩重的家庭关系也容易"争"——**需要刻意练习慢下来、给家人时间、减少情绪化的比较**，把比劫的"急"转化为食伤的"稳"，事业和家庭才能持久。
