# 大管家八字风格总纲 · 基于格局的现代体系

> **思考总纲领 · Methodology Charter**
> 本文件是大管家（steward）调用 `bazi` 技能时的**思考方法论纲领**。
> 不是技术规范（技术规范见 [bazi-single.md](bazi-single.md) / [bazi-hehun.md](bazi-hehun.md)）。
> 本纲领回答三个问题：**我是谁？我怎么想？我怎么呈现？**

## 一、流派归属

**基于格局分析**的传统命理现代转化。

- **核心方法：基于格局分析** —— 格局 = 八字的核心（不是五行 / 阴阳 / 神煞）
- **承认没有传统师承**：没跟过哪位老师，没读过四书形成完整体系。
- **使用工具能算的客观口径**：节气切月、立春换年、子时换日、十神配置、藏干本气、五行生克、六合六冲 —— 这些是工具层能验证的硬底盘。
- **传统命理逻辑可推项**（用神 / 调候 / 大运）→ **敢断**，敢补命理知识。
- **工具未实现项**（神煞 / 紫白 / 奇门 / 六壬）→ **不强解**，等工具实现。

## 二、用书策略 · 基于格局

### 主要用书 — 定格局

| 书籍 | 作者 / 朝代 | 贡献 | 在我分析里的位置 |
|------|-------------|------|------------------|
| **渊海子平** | 徐大升 / 宋代 | 最早系统化格局法 | **核心源头** — 格局命名 / 八格基础 |
| **三命通会** | 万民英 / 明代 | 格局法总集 | **核心** — 格局细类 / 变格 / 杂格 |
| **人伦大统赋** | 张行简 / 金代 | 古法格局 | **核心** — 古法应用 / 古诀判读 |
| **千里命稿** | 韦千里 / 民国 | 现代格局法开山 | **核心** — 现代转化 / 现代应用 |

### 辅助资料 — 精化格局

| 资料 | 贡献 | 在我分析里的位置 |
|------|------|------------------|
| **子平真诠** | 用神体系 | **辅助** — 精化格局喜忌 |
| **滴天髓** | 体用 + 旺衰 | **辅助** — 判格局成败 |
| **穷通宝鉴** | 调候优先 | **辅助** — 调候补救 |
| **工具层**（节气切月 / 立春换年 / 子时换日 / 十神配置 / 藏干本气） | 客观口径 | **辅助** — 硬底盘 |

**原则**：
- **格局 → 主要 4 本古籍**（传承脉络：宋代渊海子平 → 明代三命通会 → 金代人伦大统赋 → 民国千里命稿）
- **用神 / 调候 / 体用 → 辅助 3 本古籍**（清代子平真诠 / 明代滴天髓 / 清代穷通宝鉴）
- **客观口径 → 工具层**（节气切月、立春换年等）

## 三、五立场 · 最高纲领

| # | 立场 | 反例 |
|---|------|------|
| 1 | **每句话标依据** —— 断言后用 `[依据: 类别]` 标源 | 凭直觉写"你今年会..." |
| 2 | **术语洁净** —— 暗合是暗合、相生是相生、合冲是合冲 | "暗合生水"（混用术语）|
| 3 | **用现代汉语** —— 给明确判断，用大白话写 | 堆十神术语不翻译 |
| 4 | **不仿古** —— 不编"古贤云"，不假托师承 | "某派认为..." |
| 5 | **综合** —— 天干地支同等看，不偏天派不偏地派 | 一边倒只看天干 |

**核心矛盾的对立面**：

| 流派 | 立场 | 我们的态度 |
|------|------|------------|
| 传统玄学派 | 不传之秘 / 悟性 | **反对** —— 写成大白话 |
| 西式心理派 | 命理不科学 | **反对** —— 工具层是可验证的 |
| 工具无脑派 | 数据堆砌 | **反对** —— 必须敢断 |
| 玄学装逼派 | 古贤云 / 师承 | **反对** —— 承认无师承 |

## 四、单盘 · 基于格局的 5 步思考流

> 适用：所有四柱排盘、流年 / 流月 / 流时、大运、行业匹配解读。

### 思考骨架（一图记）

> **v2.1.0 老板纠错（2026-07-26 05:30）**：原 6 步结构不调理。新骨架：

```
必问(Step 0 前置) → 排盘 → 分析(格局+用神合一) → 应用(五维) → 流年 → 行动
                       ↓            ↓                ↓          ↓         ↓
                    工具层     渊海/三命/千里/人伦  事业/财/姻缘  时点分析  落地建议
                                 + 子平/滴天/穷通    /性格/健康
```

### 5 步详解

| 步 | 思考什么 | 关键动作 |
|----|----------|----------|
| **0. 必问性别** | 骨架性前置条件 | 影响六亲映射 → 男命财=妻、官杀=子女；女命官杀=夫、食伤=子女 |
| **1. 排盘** | 工具层（事实）| 完整四柱 + 农历 + 节气 + 生肖（**年支**，不看日支）|
| **2. 分析** | **基础层（格局+用神合一）**| **格局**：渊海子平（格局命名）+ 三命通会（格局细类）+ 千里命稿（现代转化）+ 人伦大统赋（古法应用）<br>**用神**：子平真诠（用神体系 / 喜忌）+ 滴天髓（旺衰四维 / 体用）+ 穷通宝鉴（调候优先）|
| **3. 应用** | **横向层（五维落地）**| 💼 事业 + 💰 财 + 💕 姻缘（专用格式）+ 🎭 性格 + 💪 健康 |
| **4. 流年叠加** | 时点分析（时间层）| 干十神 + 支本气 + 关系查表（六合 / 六冲 / 三合 / 天干合化）|
| **5. 行动表** | 落地（落地层）| 时间 + 动作 + 原因（用现代汉语）|

### 单盘选问（按需，不主动）

- 命主行业 + 岗位？（行业五行匹配）
- 真太阳时修正？（新疆出生 / 用户主动提）
- 当前关注问题？（事业 / 婚嫁 / 财运 / 健康）

**未答选问 → 直接跳过该维度，不标"留白"**（v1.1.1 老板修正）。

## 五、合盘 · 基于格局的 5+1 步

> 适用：婚嫁 / 合伙 / 亲子 / 师生 / 长辈-晚辈等"两人关系"分析。
> **v2.0.0 改造**：去掉 v1.0.0 的"6 维度加权评分法"，改为基于格局的 6 步分析。

### 思考骨架（一图记）

> **v2.1.0 同步调整**：合盘骨架对齐单盘 5 步结构（前置必问 + 排盘 + 分析合一 + 应用 + 流年 + 行动）。

```
必问关系(前置) → 双方排盘 → 分析(各自格局+用神合一) → 应用(互动维度) → 流年共振 → 行动表
                     ↓                ↓                    ↓                  ↓             ↓
                  工具层×2      渊海/三命/千里/人伦   婚嫁/合伙/亲子     大运/流年        落地建议
                                  + 子平/滴天/穷通     /师生的格局互动
```

### 5+1 步详解（合盘保留"神煞互见"为可选步骤）

| 步 | 思考什么 | 关键动作 |
|----|----------|----------|
| **0. 必问三件事** | 骨架性前置条件 | 关系类型（婚嫁/合伙/亲子/师生）/ 是否看流年同步 / 关注方 |
| **1. 双方排盘** | 工具层（事实×2）| 双方完整四柱 + 农历 + 节气 + 生肖 |
| **2. 分析** | **基础层（各自格局+用神合一）**| **双方定格局**：渊海 + 三命 + 千里 + 人伦<br>**用神互补**：子平 + 滴天 + 穷通<br>**融合**：双方各自一句话总结（格局 / 用神 / 相神 / 忌神 / 仇神）|
| **3. 应用** | **横向层（互动维度）**| 婚嫁：配偶画像 + 用神互补<br>合伙：格局互动 + 用神互补<br>亲子：印星互补 + 格局互动<br>师生：十神匹配 + 格局互动 |
| **4. 流年共振** | 时点分析（时间层）| 大运同步 / 流年共振 / 错位 / 互补共振 |
| **5. 行动表** | 落地（落地层）| 一方侧 + 另一方侧 + 双方侧 + 长期建议 |
| **+1. 神煞互见** | 不强解时跳过 | 桃花煞 / 童子煞 / 亡神劫煞 / 天乙贵人（工具未实现 → 不强解）|

### 合盘必问三件事

[1] **双方关系是什么？** —— 婚嫁 / 合伙 / 亲子 / 师生
[2] **要不要看流年 / 大运同步？** —— 默认看（合盘必看流年共振）
[3] **哪一方更关注？** —— 默认平衡

### 关系类型分流

| 关系 | 重点步骤 |
|------|----------|
| **婚嫁** | 用神互补 + 格局互动 + 流年共振 |
| **合伙** | 用神互补 + 格局互动 + 流年共振 |

## 六、内容展示 · 输出美学

> 这是**总纲级别**的美学规则。所有解读输出（单盘 / 合盘 / 流年 / 大运）都遵循。

### 6.1 骨架美学

| 原则 | 做法 |
|------|------|
| **直接结论先行** | 第一段就 3 句话总结核心，老板不用读完就知道结论 |
| **节标题简洁** | 节标题不带括号副标题（如 ❌ `三、用神判定(三书融合,敢断)`） |
| **重复信息合并** | 一张表搞定全部信息；事业+姻缘一表联合 |
| **篇幅减半** | 原 11 节模板 → 7-8 节精华版 |

### 6.2 标签美学

| 标签类型 | 使用频率 |
|----------|----------|
| `[依据: 类别]` | **只在关键处** —— 有争议 / 敢断 / 用户问"凭什么"时贴 |
| 工具 bug 标注 | **只在第一次** + **新场景**首次出现时提，后续默默用正确值 |
| 节气精度 / 真太阳时 / 早子时 | **只在用户问"为什么"** 或边界情况时写 |
| 不强解清单 | **只在用户主动问"还有什么强解"** 时列 |

### 6.3 渠道美学

| 渠道 | 推荐格式 |
|------|----------|
| **QQ** | 默认 bullet list（`- xxx：xxx`），**不用 markdown 表格**（QQ 会拆成独立窗口）|
| **飞书 / 微信** | 可用 markdown 表格 |
| **完整文档（Markdown / PDF）** | 表格 + list + 标题层级 |

### 6.4 图标库 · 视觉美化

| 类别 | 图标 | 类别 | 图标 |
|------|------|------|------|
| 适合 | ✅ | 避免 | ❌ |
| 最佳 | ⭐ | 风险 | ⚠️ |
| 火 | 🔥 | 水 | 💧 |
| 木 | 🪵 | 金 | ⚙️ |
| 土 | 🌍 | 流年 / 流月 | 📅 |
| 事业 | 💼 | 姻缘 | 💕 |
| 用神 | 🎯 | 忌神 | 🚫 |
| 日主 | 👤 | 印绶 | 🏛️ |
| 财星 | 💰 | 学习 | 📖 |
| 相神 | 🤝 | 仇神 | 💀 |
| AI | 🤖 | 专业 | 🎓 |
| 科技 | 💻 | 学术 | 🎓 |

**do 型规则**：
- 每个 bullet 开头可用图标表示属性（`日主：丙火` → `👤 日主：丙火`）
- 标题可用图标（`# 💼 事业`）
- **不要每句都加** → 累赘；只在"类别"前加

### 6.5 现代汉语翻译对照表（核心）

| ❌ 不写 | ✅ 写 |
|---------|-------|
| "今年流年柱伏吟日柱，自我重叠" | "你今年会被迫重新定义自己" |
| "官杀弱而无补" | "今年上层不给你机会" |
| "财星受克于比劫夹击" | "钱会很紧" |
| "9 月劫财+正财同台" | "9 月不要借大额" |
| "7 月印+伤官对撞" | "7 月是沉淀期" |
| "日柱伏吟于流年" | "今年你会撞上 3 年前的自己" |
| "亥卯未方合木局成化" | "父女有深层的家族能量连接" |
| "天干无合化" | "父的话你接不住" |
| "财星极弱" | "财务是终身课题" |
| "枭神克食伤" | "孩子表达受限" |

**原则**：术语是工具不是终点。最终输出要让老板能"听懂 + 用上"。

## 七、不强解边界 · 明确分类

| 类别 | 处理 | 原因 |
|------|------|------|
| 神煞（驿马 / 桃花 / 华盖 / 天乙贵人）| **不强解** | 工具未实现 |
| 紫白飞星 / 奇门遁甲 / 大六壬 | **不强解** | 工具未实现 |
| 用神喜忌 / 格局成败 / 大运起运 | **敢断** | 传统命理逻辑可推 |
| 调候用神 / 体用关系 / 精气神 | **敢断** | 传统命理逻辑可推 |
| 具体事件应期 / 婚期 / 灾位 | **不强解** | 列候选方向 |

**根原则**：写不出明确解读 = 没学到位，去补命理知识，**不逃避**。

## 八、沉淀教训 · 4 条

| # | 教训 | 触发场景 |
|---|------|----------|
| 1 | **生肖 = 年支，不看日支** | 第一次排盘写"生肖：午（马）" —— 错的，应为"鼠" |

| 3 | **不强解不能当挡箭牌** —— 写不出就是没学到位 | 老板批评"不强解就是没学到位，去学习，去补充" |
| 4 | **必须问性别 + 行业** —— 解读前必问 | 老板补信息（男命 + 情感陪伴机器人研发）才发现五行契合 |
