# 八字性格专题

> **本文档是八字技能性格分析的内部参考。**
> 适用于：所有八字解读中的"性格/自我/表达"判断——**单盘**。
> **核心问题**：你是什么样的人？怎么改进性格短板？
> **不是**合盘分析 ——合盘见 [`bazi-hehun.md`](bazi-hehun.md)。

---

## 〇、设计原则

- **以对象为中心**——不是流程为中心：3 个对象 = 自我 + 思维 + 关系
- **比劫 = 看自我**——自我认同/兄弟姐妹
- **印 = 看思维**——学习方式/思维模式
- **只看异位关系**——不自比
- **关系 > 字本身**：字无意义，关系才是一切
- **隐晦必断**：多个候选必须用 5 规则选 1

> **性格 =自我——比劫 + 思维——印 + 关系——自我-他者-世界**

## 一、比劫

> **这一章只讲"自我"是什么**

### 1.1 怎么找比劫

**所有命局都看**：

- **比肩**——同五行 + 同阴阳= **自己**
- **劫财**——同五行 + 异阴阳= **兄弟姐妹/竞争者**

**操作**：

- 看四干 + 地支藏干
- 同五行——日干五行的天干 = 比劫
- 阴阳判断：与日干**同阴阳** = 比肩，**异阴阳** = 劫财

**大白话**：先认清楚**你自己是什么属性**

### 1.2 比劫的强度

- **得令**：月支是否同类/生扶
- **有根**：地支有无同类
- **得生**：有无印生比劫
- **得助**：有无同类帮

### 1.3 比劫的异位关系

#### 位置含义速查

- 年柱 = 祖辈、出身、童年底色
- 月柱 = 父母、事业、成长环境
- 日柱 = **自己 + 配偶**
- 时柱 = 子女、晚年、未来

#### 🆕 1.3.0 宫层：自我宫（日支）与其他交互

> **自我宫 = 日支**——日支是“体”的家，比劫坐日支 = 自我扎根最深。

- 日支被**冲** = 自我**动荡**——被环境/配偶动摇
- 日支被**合** = 自我被**绑定**——被关系/配偶改变
- 日支被**刑** = 自我**暗伤**——内心冲突
- 日支被**害** = 自我**阴损**——内耗
- 日支被**破** = 自我**慢性消耗**——慢慢磨平
- 日支被**生** = 自我被**滋养**——有根
- 日支被**克** = 自我被**压制**——被体制/规矩磨棱角

#### 🆕 1.3.0 宫星交互：比劫星落各宫的含义

> **星落宫位 = 人进家**——比劫落在哪个宫，自我就“住进”哪个领域。

- 比劫落**年支** = 自我与**祖辈认同**绑定——家族基因里的性格
- 比劫落**月支** = **自我在事业场最亮**——工作中好胜/争
- 比劫落**日支** = **自我在家最强**——家里我说了算（实战：比劫在日柱 = 自我在家最强）
- 比劫落**时支** = 自我在**晚年/子女场**显——末运自我表达

#### 7 大关系 + 暗含

- **冲**：自我动荡，如出身改变自我认知
- **合**：自我绑定，如配偶改变自己
- **刑**：自我暗伤
- **害**：自我阴损
- **破**：自我慢性消耗
- **生**：自我被滋养
- **克**：自我被压制，如官杀克比劫 = 被体制磨平棱角

### 1.4 喜忌+流通位置

- **喜忌**：极旺喜比劫——增加自我/ 极弱忌比劫——扛不住
- **流通位置**：比劫是**身→食伤**的起点——身旺才能泄

### 1.5 一句话：这**自我**是什么样的？

> **这自我——比劫是 [材质] 做的，强度 [评分]，与你 [喜/忌]，自我认同 [十神特质]。**

## 二、印

> **这一章只讲"思维模式"是什么**

### 2.1 怎么找印

**所有命局都看**：

- **正印**——生日主 + 异阴阳= **母亲/学习**
- **偏印**——生日主 + 同阴阳= **继母/独特思维**

**5 规则判定真印**——多个候选时：

- **① 透干 > 藏支**
- **② 与日干紧贴**——同柱 > 隔柱
- **③ 与日干合化**
- **④ 与日干直接生克**
- **⑤ 配合体用方向**

### 2.2 印的强度

**同 §1.2**——4 维度打分

### 2.3 印的异位关系

**重点暗含**：

- **印克食伤** = 想法压制表达——想说但不敢说
- **印生身** = 学习滋养你——适合读书
- **印冲财** = 财坏印——为钱不学习
- **印生日主过旺** = 想太多、行动力弱

#### 🆕 2.3.0 宫星交互：印星落各宫的含义

> **星落宫位 = 人进家**——印落在哪个宫，思维就“住进”哪个领域。

- 印落**年支** = 思维受**祖辈影响深**——家族观念/家风
- 印落**月支** = **思维与事业绑定**——工作中想太多（实战：印在月支 = 思维与事业紧密相关）
- 印落**日支** = **思维影响婚姻**——想太多影响家
- 印落**时支** = 晚年**学习/开悟**——末运思维升华

### 2.4 喜忌+流通位置

- **喜忌**：身旺忌印——印生身更旺/ 身弱喜印——印生身扶身
- **流通位置**：印是**身的前置**——印→身→食伤

### 2.5 一句话：这**思维**是什么样的？

> **你的思维——印是 [材质] 做的，强度 [评分]，与你 [喜/忌]，学习方式 [十神特质]。**

## 三、关系

> **这一章只讲"性格和他者"怎么相处**

### 3.1 自我与他者的关系

- **比劫旺** = 自我强 → 可能**自我中心/好胜**
- **印旺** = 思维强 → 可能**想太多/行动力弱**
- **食伤旺** = 表达强 → 可能**口才好/冲动**
- **财旺** = 务实强 → 可能**太现实/缺理想**
- **官旺** = 规矩强 → 可能**太保守/压抑**

### 3.2 性格短板

- 体用 = **性格优化的方向**
- 体用金 = **要更果断/直接**
- 体用木 = **要更好学/有想法**
- 体用水 = **要更灵活/变通**
- 体用火 = **要更热情/主动**
- 体用土 = **要更稳重/踏实**

### 3.3 性格流通

```
印 → 身 → 食伤 → 财 → 官
木 → 火 → 土 → 金 → 水
```

**找堵点**：

- **印堵食伤** = 想太多说不出 ⚠️⚠️
- **身旺无泄** = 能量堵死——暴躁/压抑
- **财坏印** = 为钱不学习/不思考
- **官杀克身** = 被体制/规矩压垮

**大运变化**——性格演变：

- 青年大运 = 激进/锐利
- 中年大运 = 稳重/承担
- 老年大运 = 平和/放下

### 3.4 一句话：这**性格**整体怎么样？

> **这性格 = [自我]+[思维]+[关系]，[整体评级]，短板 = [主堵点]。**

## 四、综合判断实战

> **把前三章的框架实战跑通一遍**

### 4.1 这**自我**是什么 → 丙+丁+午

**字本身**：

- **丙**——年干= **比肩**
- **丙**——日干= 日主
- **丁**——时干= **劫财**
- **午**——日支= **劫财**

- 强度：**4 个比劫** → 4/4 **极旺**
- 你 = **太阳之火**——丙+ **灯芯之火**——丁+ **火焰本身**——午= 极旺

**异位关系——不自比**：

- 比肩**不透干** → 自我**没完全显化**
- 比劫被**印生**——卯生丙→ 自我**有长辈帮**
- 比劫被**财**克——丙克辛→ 自我**压配偶**
- 比劫**冲/破/害** → 自我**有动荡**

**位置含义暗含**：

- 比劫在**日柱**——家/自己→ 自我**在家最强**
- 丙火——比肩在**年/日**→ 自我**有传承**
- 丁火——劫财在**时**→ 自我**有未来**

**喜忌+流通**：

- 喜忌：4/4 极旺 → **比劫是忌神** ⚠️
- 流通：比劫旺 → 需要**食伤/财/官**来克泄

**一句话自我**：

> **这自我——丙丁午是火做的，4/4 极旺，是忌神——太旺，但有印生——长辈帮和财克——配偶管，自我极强但需要刻意泄。**

---

### 4.2 这**思维**是什么 → 卯

**字本身**：

- **卯** = 木 = **正印**——思维
- 位置：**月支**——紧贴日干
- 藏干：乙
- 强度：**2 个印**——月支卯 + 日支午藏己的偏印→ 印偏旺

**异位关系——不自比**：

- 卯**双现** → 印**双倍** = 想太多
- **印生身**——卯生丙✅ → 学习滋养你
- **印克食伤**——卯克己⚠️ → 想法压制表达
- **财坏印**——辛克卯⚠️⚠️ → 为钱不学习

**位置含义暗含**：

- 印在**月支**——父母/事业→ 思维**与事业紧密相关**
- 双印 → **过度思考**、**缺乏行动**
- 印克食伤 → **想到说不出**

**喜忌+流通**：

- 喜忌：4/4 极旺 → **印是忌神**——印生身更旺
- 流通：印→身 → 身更旺 = **堵点**

**一句话思维**：

> **这思维——卯印是木做的，2 个印偏旺，印生身让你更旺——堵点，印克食伤让你表达不出。**

---

### 4.3 这**性格**整体怎么样 → 关系 + 流通

**自我与他者的关系**：

- **比劫旺** → **自我中心/好胜**——需要刻意收敛
- **印旺** → **想太多/行动力弱**——需要刻意表达
- **食伤弱** → 表达不出来
- **财被劫** → 现实感不足——被理想/情感压

**性格短板**——体用反推：

- 体用 = **金水**
- **金** = 更果断/直接 → 你需要
- **水** = 更灵活/变通 → 你需要

**性格流通**：

```
印——卯×2→ 身——丙+丁+午= 生 → 身极旺
 ↓
 食伤——己= 弱——藏支⚠️
 ↓
 财——辛+酉→ 身 = 被劫 ❌
 ↓
 官——癸→ 印 = 通 ✅
```

**3 大堵点**：

- **堵点 1**：印旺 → **想太多、行动力弱** ⚠️⚠️⚠️
- **堵点 2**：食伤弱 → **表达不出** ⚠️⚠️⚠️
- **堵点 3**：比劫极旺 → **自我中心/好胜** ⚠️⚠️

### 4.4 一句话性格

> **这性格 = 极旺自我——4 个比劫+ 印旺想太多 + 食伤弱表达不出 + 财被劫现实感不足。需要刻意练习：果断 + 灵活 + 表达。**

---

### 4.5 化解方案

- **比劫极旺** → **刻意收敛，练习倾听**
- **印旺想太多** → **做决策时设"48小时冷静期"**
- **食伤弱表达不出** → **多写作、多演讲、多练习表达**
- **财被劫** → **多接触现实/财务**
- **大运配合** → 等**食伤/财/官**大运，性格会外放
