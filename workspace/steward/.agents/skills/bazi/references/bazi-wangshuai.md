## 一、旺衰的定义

### 1.1 什么情况下走旺衰？

正格成立 → 用正格判定
正格不成立 → 走旺衰

**正格不成立的 4 种情况**：

1. **月令本气不透**：月支藏干未透出天干
2. **月令气势成局**：三会方 / 三合局 / 一行得气
3. **月令被冲破**：月支被冲，无法定格
4. **化气格**：月干与日干相合化出另一种五行

### 1.2 旺衰分析的核心问题

- **身旺 vs 身弱**？
- **命中五行流通吗**？
- **体用是什么**——基于旺衰？

### 1.3 旺衰与正格的关系

- **正格** = 体用方向——基于格局类型
- **旺衰** = 体用精化——基于旺衰流通
- **两者融合** = 最终体用

## 二、特殊格局分类

### 2.1 从强格

- **条件**：日主**极旺**——4/4 维度都得，**无比劫 / 印星以外**的克制十神
- **体用**：**印星 + 比劫**——助旺日主
- **忌神**：官杀、食伤、财星——克制日主的十神
- **古籍口径**：「从强不可破，破则倒」
- **大运喜忌**：行印比运大吉，行财官食伤运大凶

### 2.2 从弱格

- **条件**：日主**极弱**——4/4 维度都失，**无印星 / 比劫**扶助
- **体用**：**财星 + 官杀**——耗泄日主，让其安静
- **忌神**：印星、比劫——助日主的十神
- **古籍口径**：「从弱有气，运行财官方为美」
- **大运喜忌**：行财官运大吉，行印比运大凶

### 2.3 化气格

- **条件**：月干与日干**天干五合**，且**月令之气与化出五行一致**
- 化气格成立后，**日主变为他五行**，按新五行重新推十神

| 天干合 | 化出五行 | 化气格条件 |
|---|---|---|
| 甲己 | 土 | 己土日主 + 甲己合化土 + 月令土旺 |
| 乙庚 | 金 | 庚金日主 + 乙庚合化金 + 月令金旺 |
| 丙辛 | 水 | 辛金日主 + 丙辛合化水 + 月令水旺 |
| 丁壬 | 木 | 壬水日主 + 丁壬合化木 + 月令木旺 |
| 戊癸 | 火 | 癸水日主 + 戊癸合化火 + 月令火旺 |

### 2.4 一行得气格

- **条件**：命中**某五行占 4 个以上**——天干 + 地支 + 藏干，其他五行极弱
- 体用 = 该五行所喜——视具体情况

### 2.5 两神成象格

- **条件**：命中**两种五行各占一半**，如木火各 3 个，其他五行极少
- 如：木火成象 → 体用可能为木火；金水成象 → 体用可能为金水

### 2.6 三奇格

- **条件**：天干三字**特定组合**：
 - **天上三奇**：甲戊庚——顺序不拘
 - **地上三奇**：乙丙丁
 - **人中三奇**：壬癸辛
- 体用 = 三奇所化五行

## 三、旺衰四维度

### 3.1 旺衰判定

日主旺衰由 **3 维度**判定（v2.2.3 重大修正——按 2026-08-18 20:18 拍板"身旺怎么是4/4 不应该分析得令，得地，得助三点？"）：**去掉"得生"独立维度**——**印星并入"得助"**——因为印星与比劫都是"帮身"性质，4 维度有重叠。

| 维度 | 含义 | 判定 |
|---|---|---|
| **得令** | 日干在月支的 **12 长生状态**（2026-08-20 20:41 拍板"长生到帝旺肯定是得令啊！"）| ✓——12 长生 ∈ {**长生, 沐浴, 冠带, 临官, 帝旺**}；✗——衰, 病, 死, 墓, 绝, 胎, 养 |
| **得地** | 日支是否生日主或日主禄位 | ✓——日支五行生日主或日主禄位 |
| **得助** | 命中是否有印星 + 比劫 | ✓——印星透出或藏支有根 + 比劫透出或藏支有根 |

> **🆕 v2.4.0 得令口径变更**：从"月令五行生日主或同五行"（印比当令）→ **12 长生口径**（日干五行在月支的生长阶段）——表见 `bazi-rules.md` §4.1.1。**长生到帝旺 = 得令**；衰病死墓绝胎养 = 不得令。

> **传统三维度派**（子平真诠/滴天髓 主流口径）= **得令 + 得地 + 得助**——印证星与比劫合并为「得助」一类。v2.2.3 起采用此口径。

### 3.2 旺衰分级——加权打分 v2.2.5

> **v2.2.5 重大修正（2026-08-18 21:07 拍板「不是中偏旺，就是中偏弱。令占主导60，地占30，助占10」）**：
> 抛弃 v2.2.3-v2.2.4 的「3 维度等权计数」——改为**加权打分**——令占主导 60%、地 30%、助 10%。

**加权公式**：

```
旺衰总分 = 得令×60% + 得地×30% + 得助×10%
```

| 维度 | 权重 | 解读 |
|:---|:---:|:---|
| **得令** | **60%** | 月令力量——主导因素 |
| **得地** | **30%** | 日支根基——次要因素 |
| **得助** | **10%** | 印星 + 比劫——辅助因素 |

**总分分级矩阵**：

| 得令 | 得地 | 得助 | 总分 | 旺衰 |
|:---:|:---:|:---:|:---:|:---|
| ✓ | ✓ | ✓ | **100%** | **极旺**——考虑从强 |
| ✓ | ✓ | ✗ | **90%** | **旺** |
| ✓ | ✗ | ✓ | **70%** | **旺** |
| ✓ | ✗ | ✗ | **60%** | **中偏旺**（仅得令）|
| ✗ | ✓ | ✓ | **40%** | **中偏弱**（地+助——原话『不是中偏旺，就是中偏弱』）|
| ✗ | ✓ | ✗ | **30%** | **弱** |
| ✗ | ✗ | ✓ | **10%** | **弱** |
| ✗ | ✗ | ✗ | **0%** | **极弱**——考虑从弱 |

**实战示例**：
- （丙子辛卯丙午丁酉）= 60%×1 + 30%×1 + 10%×1 = **100%** → **极旺**
- （戊寅己未甲子己巳）= 60%×0 + 30%×1 + 10%×1 = **40%** → **中偏弱** ← 纠正

### 3.3 旺衰与体用方向

| 旺衰 | 体用方向——指引 |
|---|---|
| **极旺** | 印 + 比劫——从强格|
| **旺** | 克泄——食伤 / 财星 / 官杀|
| **中等偏旺** | 财星 / 食伤 |
| **中等** | 看具体配合——精化见体用判定|
| **中等偏弱** | 印星 / 比劫 |
| **弱** | 生扶——印星 / 比劫|
| **极弱** | 财 + 官杀——从弱格|

## 五、实战案例

### 5.1 

#### 旺衰四维度

| 维度 | 判定 | 解读 |
|---|---|---|
| 得令 | ✓ | 丙火在**卯月** = **沐浴**——12 长生 ∈ 长生~帝旺区间 ✓ |
| 得地 | ✓ | 日支午 = 劫财——丙火帝旺|
| 得生 | ✓ | 月支卯 = 印星 |
| 得助 | ✓ | 年干丙 + 时干丁 = 比劫双助 |

→ **100% 极旺**（60%×1 + 30%×1 + 10%×1）——不走从强，因还有官杀可制

#### 流通核心堵点（v2.2.2 同步）

> **克泄耗三路全断**（按 [`bazi-case.md` 案例一](bazi-case.md) 重构）：
> - 克（官杀水）：子水被午冲 + 被卯刑 → 官星不稳 ❌
> - 泄（食伤土）：午中己土被午冲 + 卯午破 → 泄路断 ❌
> - 耗（财星金）：辛被丙合绊、酉被丁午克 + 被卯酉冲 → 财星全废 ❌
>
> **结果**：只剩午丁劫财帮身 → 比劫夺财终身课题。

> 📚 **完整实战存档**：[`bazi-case.md` 案例一（）](bazi-case.md)——按统一流程（定格 → 旺衰 → 流通核心堵点）+ 用神推导 + 大运应期。

### 5.2 

#### 旺衰四维度

| 维度 | 判定 | 解读 |
|---|---|---|
| 得令 | ✗ | 甲木在**未月** = **墓**——12 长生 ∈ 衰~绝区间 ✗ |
| 得地 | ✗ | 日支子 = 印星——非日主禄位|
