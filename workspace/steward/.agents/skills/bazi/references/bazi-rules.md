## 一、历法基础

> **本节定义八字排盘的时间坐标体系**——什么时候算哪柱、怎么换年换日。
> 是后续所有元素（天干地支 / 干支关系 / 流时）的**前置基础**。

### 1.1 节气切月

月柱按 **节气**——不是农历月切：

| 月柱 | 节气区间——近似公历 | 月份编号 |
|------|-------------------|---------|
| 寅月 | 立春 → 惊蛰 | 1 |
| 卯月 | 惊蛰 → 清明 | 2 |
| 辰月 | 清明 → 立夏 | 3 |
| 巳月 | 立夏 → 芒种 | 4 |
| 午月 | 芒种 → 小暑 | 5 |
| 未月 | 小暑 → 立秋 | 6 |
| 申月 | 立秋 → 白露 | 7 |
| 酉月 | 白露 → 寒露 | 8 |
| 戌月 | 寒露 → 立冬 | 9 |
| 亥月 | 立冬 → 大雪 | 10 |
| 子月 | 大雪 → 小寒 | 11 |
| 丑月 | 小寒 → 立春 | 12 |

> 节气日期每年略有差异——±1–2 天。`cnlunar.getSolarTermsDateList(year)` 返回年内 24 节气日期。

### 1.2 立春换年

- 年柱以**立春**为界，不是正月初一
- 立春之后出生 → 新年干支
- 立春之前出生 → 上一年干支——即便公历已跨年

> ⚠️ **cnlunar 库局限**：cnlunar 把立春视为"日级"边界——整个立春当天算同一侧。
> 对于立春恰好在当天上午的日期，出生时间在立春之后仍可能被算作上一年干支。
> 需要天文精确时，请用 `sxtwl` 校验。

**实测边界案例**（v1.12.0 补充，P1-7 修复）：

- 2000-02-04 22:30 出生——立春 11:32 已过近 11 小时，按 cnlunar = `己卯年戊寅月`——日级边界偏差，按 sxtwl = `庚辰年戊寅月`。
- 涉及 `2000-02-04 11:32 ± 12h` 这个全日敏感边界的用例，强烈建议用 sxtwl 校验。

### 1.3 子时换日

- 23:00–00:59 出生 → 日柱按 **次日** 计算
- 其他时辰 → 日柱按出生当日计算

> cnlunar 默认已处理子时换日。

**v1.13.0 补充——P2-9—— cnlunar 早子时 / 晚子时口径差异**：

- **本技能严格跟随 cnlunar 默认行为**：早子时——00:00–00:59+ 晚子时——23:00–23:59**均取次日**。
- **子平术主流口径**：早子时——00:00–00:59= 当日，晚子时——23:00–23:59= 次日。
- **差异影响**：早子时出生的命盘——特别是 00:00–00:30 这种边界，本技能会比子平术口径"早一天"——日柱差 1 天可能影响配偶、子女、甚至终身格局判定。
- **如需严格依子平术**：请在 CLI 提供真太阳时校正，或自行用 `--reverse` 反查调整出生时刻。

### 1.4 真太阳时修正

> **本节定义真太阳时修正规则**——所有古代天文历法术数的**高精度需求**必须遵守。

- **修正范围**：中国境内出生 → 真太阳时与北京时间相差 **±30 ~ ±90 分钟**（视经度）
- **修正公式**（粗略估算）：
 - 每经度 1° = 真太阳时差 4 分钟
 - 真太阳时 = 北京时间 + (出生地经度 - 120°) × 4 分钟
 - 例：上海（121.5°E）→ 真太阳时 = 北京时间 + 6 分钟
- **计算工具**：高精度场景**必须**使用 `sxtwl` 天文库——`sxtwl.fromSolar(year, month, day, hour, minute, second)` 可达 ±秒级精度
- **本技能默认行为**：v1.x **不自动修正**——出生地经度未给出时按北京时间排盘
- **触发修正**：用户明确要求"精度排盘"或输入了经纬度时启用
- **典型边界用例**：
 - 立春精确时刻（见 §一.2）—— `sxtwl` 解决 cnlunar 日级边界
 - 日月五星 / 十一曜坐标（见 §六.6）—— 必须用 `sxtwl`

> ⭐ **本节是所有术数的共同历法基础**——八字 / 紫微 / 奇门等都需遵守。

## 三、天干层关系

> **本节定义天干之间的关系**——按"天干-天干"层次组织：

### 3.1 五行基础

> **本节定义五行之间的底层规则**——五行相生相克、纳音五行。

#### 3.1.1 五行生克

```
木 → 火 → 土 → 金 → 水 → 木 (相生)
木 → 土 → 水 → 火 → 金 → 木 (相克)
```

**判定口诀**：
- 同我——比和→ 比肩 / 劫财——按阴阳
- 我生——食伤→ 食神 / 伤官——按阴阳
- 我克——财星→ 偏财 / 正财——按阴阳
- 生我——印星→ 偏印 / 正印——按阴阳
- 克我——官杀→ 七杀 / 正官——按阴阳

**阴阳判定**：
- 同性——阳阳 / 阴阴→ 偏位——劫财 / 伤官 / 偏财 / 偏印 / 七杀
- 异性——阳阴 / 阴阳→ 正位——比肩 / 食神 / 正财 / 正印 / 正官

> 注意：比肩是"同我 + 同阴阳"，劫财是"同我 + 异阴阳"。
> 其余四组同理。

#### 3.1.2 纳音五行

干支组合 → 纳音五行——60 组：

| 纳音 | 干支 |
|------|------|
| 海中金 | 甲子 乙丑 |
| 炉中火 | 丙寅 丁卯 |
| ... | ... |

> 纳音在传统命理中地位次于五行十神，仅在某些特殊流派中使用。本技能默认不输出。

### 3.2 十神

#### 3.2.1 十神规则（核心——适用于所有日主）

> ⭐ **核心规则**（v1.6.5 修复——2026-08-19 22:23 拍板）：**同=偏，异=正**——日主与天干星的阴阳对比决定偏正标签。

#### 4.2.1.1 六合合化判定 5 条件（v1.6.6 补——2026-08-19 22:36 拍板）

> **核心**：六合化神要成立，**月令 + 地支 + 天干 + 距离 + 不被破坏** 5 条件齐备。

**5 条件判定流程**：

1. **月令支持**（最关键）
 - 化神五行 = 当令月令 > 化力强
 - 例：巳酉合金 > 酉月/申月/戌月（秋）> 易化
 - 巳酉合金 > 巳月/午月/未月（夏）> 难化

2. **地支成局**
 - 命局有化神同五行支助势 > 化力强
 - 例：巳酉合金 > 有申/酉/戌 等金支 > 易化

3. **天干配合**
 - 透化神同五行 > 引化
 - 透生神 > 助化
 - 忌透克化神或助被化方
 - 例：巳酉合金 > 透庚/辛 > 引化；透戊/己 > 土生金助化
 - 忌透丙/丁（助巳火）、壬/癸（泄金）

4. **距离相近**
 - 同柱 或 紧贴（年-月、月-日、日-时）> 化力强
 - 隔柱（年-日、年-时）> 化力弱，多"合而不化"

5. **不被破坏**
 - 不被冲：合化中被他支冲（例：卯冲酉）> 合化失败
 - 不被刑：合化中被他支刑 > 合化失败
 - 不与他局冲突：同时有三合/三会/六合并存 > 取最强者

> **口诀**：**化神旺 + 月令助 + 天干透 + 距离近 + 不被破**——五者齐备才化。
> **缺一即合而不化**——只有"合的意向"，各按本气算。

| 子未 | 子（癸）+ 未（己丁乙） | 癸水被未土克制（印受克） | 水帝旺 vs 木墓 |
| 丑午 | 丑（己癸辛）+ 午（丁己） | 丑中辛金克午中丁火 | 金墓 vs 火帝旺 |
| 寅巳 | 寅（甲丙戊）+ 巳（丙戊庚） | 相邻相害——藏干混杂，本气受摇 | 火长生 vs 金长生 |
| 卯辰 | 卯（乙）+ 辰（戊乙癸） | 卯中乙木被辰中戊土克制 | 木帝旺 vs 水墓 |
| 申亥 | 申（庚壬戊）+ 亥（壬甲） | 申中庚金克亥中甲木 | 金长生 vs 木长生 |
| 酉戌 | 酉（辛）+ 戌（戊辛丁） | 辛金被戌中丁火克制 | 金帝旺 vs 火墓 |

> **判定要点**：相害是**暗中的持续克制**——不直接对冲，但日积月累地削弱藏干。
> ⭐ **长生对位规律**：**帝旺穿墓**（子未、丑午、卯辰、酉戌）+ **长生对害**（寅巳、申亥）

#### 4.5.1 六害生成原理（v1.6.8 新增——2026-08-23 拍板）

> **核心**：六害 = **六合被六冲破**——合的一字被冲走，剩下的合伴与冲者结成「暗害」。

**推导表**（六合 × 六冲 的交叉产物，12 个交叉去重后剩 6 对）：

| 六合 | 被谁冲 | 产生六害 |
|---|---|---|
| 子丑合 | 午冲子 | **丑午害** |
| 子丑合 | 未冲丑 | **子未害** |
| 寅亥合 | 申冲寅 | **申亥害** |
| 寅亥合 | 巳冲亥 | **寅巳害** |
| 卯戌合 | 酉冲卯 | **酉戌害** |
| 卯戌合 | 辰冲戌 | **卯辰害** |
| 辰酉合 | 戌冲辰 | 酉戌害（同上）|
| 辰酉合 | 卯冲酉 | 卯辰害（同上）|
| 巳申合 | 亥冲巳 | 申亥害（同上）|
| 巳申合 | 寅冲申 | 寅巳害（同上）|
| 午未合 | 子冲午 | 子未害（同上）|
| 午未合 | 丑冲未 | 丑午害（同上）|

**本质**：合是亲和，冲是破坏——**合被冲破后残留的暗损关系 = 害**。

- 害的每一对 = 原合对中的一字 + 冲走另一字的那个字
- 12 个交叉去重后正好剩 6 对：**子未、丑午、寅巳、卯辰、申亥、酉戌**

**与六破的关系**（同一「合」体系派生的两种破坏）：

- **六害 = 六合被六冲破**（合 × 冲 → 害）
- **六破 = 六合之间交叉拆散**（合 × 合 → 破，见 §4.6.1）
- 水生木（水局申子辰 × 木局亥卯未）同位相撞 = 申亥、子卯、辰未——**申亥恰是六害之一**（来源是寅亥合被申冲寅，与水木相撞无关）、子卯是三刑、辰未无直接关系 → **水生木不产生破**（但含害/刑，非空白）

### 4.6 六破（地支-地支破）

| 六破 | 涉及藏干 | 对藏干发挥的影响 | 长生对位 |
|------|----------|----------------|---|
| 子酉 | 子（癸）+ 酉（辛） | 酉中辛金冲散子中癸水之阴气 | 水帝旺 vs 金帝旺 |
| 丑辰 | 丑（己癸辛）+ 辰（戊乙癸） | 二土相破，湿土乱 | 金墓 vs 水墓 |
| 寅亥 | 寅（甲丙戊）+ 亥（壬甲） | 二水生木但破，寅亥合木之象被打破 | 火长生 vs 木长生 |
| 卯午 | 卯（乙）+ 午（丁己） | 卯中乙木泄午中丁火 | 木帝旺 vs 火帝旺 |
| 巳申 | 巳（丙戊庚）+ 申（庚壬戊） | 巳申合水之象被破——火金交战 | 金长生 vs 金长生 |
| 未戌 | 未（己丁乙）+ 戌（戊辛丁） | 二土相破，燥湿交战 | 木墓 vs 火墓 |

> **判定要点**：相破 = 六合 / 三合 / 三会之象被破坏——藏干之间本来合聚的力被打散。
> ⭐ **长生对位规律**：**相生关系的反向耗损**——但**只有金生水、木生火两局见破**（水生木 → 申亥害 / 子卯刑；火生土 → 土无三合局）

#### 4.6.1 六破生成原理（v1.6.7 新增——2026-08-23 拍板）

> **核心**：六破 = **相生两局（金生水、木生火）的同位相撞**——**2 组 × 3 同位 = 6 破**。

**生成表**：

| 相生局对 | 同位相撞 | 破 |
|---|---|---|
| **金局**（巳酉丑）× **水局**（申子辰）| 长生：巳撞申 | **巳申破** |
| | 帝旺：酉撞子 | **子酉破** |
| | 墓：丑撞辰 | **丑辰破** |
| **木局**（亥卯未）× **火局**（寅午戌）| 长生：亥撞寅 | **寅亥破** |
| | 帝旺：卯撞午 | **卯午破** |
| | 墓：未撞戌 | **未戌破** |

**破的三类机制**（相撞点落在对方衰败位）：

1. **生入败地/死地**：酉金生子水，酉 = 水之沐浴（败地）→ 子酉破；卯木生午火，午 = 木之死地 → 卯午破
2. **生入绝地**：巳申合水，巳 = 水之绝地 → 巳申破；寅亥合木，亥 = 火之绝地 → 寅亥破
3. **墓库互穿**：丑 = 金墓、辰 = 水墓，两库相撞 → 丑辰破；未 = 木墓、戌 = 火墓 → 未戌破

**为什么偏偏是金水、木火两组？**（根本判据 = 六合交叉，v1.6.7 修正版）

- **六破 = 六合的跨类交叉**：六合按间距分 3 类——**1 位类**（子丑、午未）× **5 位类**（辰酉、卯戌）交叉 → 子酉、丑辰、卯午、未戌（4 破）；**3 位类**（寅亥、巳申）自交 → 寅亥、巳申（2 破）。合计 6 破。
- **金水、木火两局的同位相撞恰好全部落在这些交叉对上** → 全成破。
- **水生木**（水局申子辰 × 木局亥卯未）同位相撞 = 申亥、子卯、辰未——**不在六合交叉的破对集合内**（申亥 = 六害、子卯 = 三刑、辰未 = 无直接关系）→ 不成破。
- ⚠️ **注意**：「衰败位」是破的**破坏表现**，不是选择判据——水生木的申亥中，申也是木之绝地（衰败位），但申亥是六害而非六破；真正决定破的是**六合交叉结构**（见上）。

## 五、大运 / 流年 / 流月 / 流日 / 流时

> - **§5.2 流年**（1 年，看年柱层面影响）
> - **§5.3 流月**（1 月，看月柱层面影响）

> - **§5.5 流时**（1 时，看时柱层面影响）

### 5.1 大运

> **大运**是命局最重要的时间维度——每 10 年一运，共 8-10 步，主宰人生大节奏。
> 大运天干地支对日主的关系（用神/忌神）+ 大运与命局的作用（合冲刑害）= 人生大运走势。

#### 5.1.1 起运岁数计算

| 顺逆排 | 计算规则 |
|:---:|---|
| **顺排**（阳男 / 阴女）| **数到出生到下一个节气（节）的天数** |
| **逆排**（阴男 / 阳女）| **数到出生到上一个节气（节）的天数** |

- 起运岁数 = 天数 ÷ **3**（1 天 = 4 个月 ≈ 0.33 岁）
- 注：数的是**节**（如立春、惊蛰、清明），**不是气**（雨水、春分）

> **节气与节的区别**：节 = 月初（如立春、惊蛰、清明、立夏...）；气 = 月中（如雨水、春分、谷雨、小满...）。**起运岁数只用"节"**。

#### 5.1.2 顺排 / 逆排规则

| 年干阴阳 | 性别 | 顺/逆排 |
|:---:|:---:|:---:|
| 阳（甲丙戊庚壬）| 男 | **顺排** |
| 阴（乙丁己辛癸）| 女 | **顺排** |
| 阳 | 女 | **逆排** |
| 阴 | 男 | **逆排** |

> **口诀**：**阳男阴女顺排，阴男阳女逆排**——4 种组合记忆法：
> - 阳年 → 男顺女逆
> - 阴年 → 女顺男逆

#### 5.1.3 大运干支推排

| 顺逆排 | 起点 | 推排方向 |
|:---:|---|---|
| **顺排** | 从月柱**后一位**起 | 天干地支**都顺推** |
| **逆排** | 从月柱**前一位**起 | 天干地支**都逆推** |

- 每 10 年一运，**天干和地支同时推进 1 位**
- 共排 8-10 步大运——多数排到 80-100 岁
- 排满 60 甲子则重新循环（罕见）

> **示例**：丙午年男命，月柱辛卯。
> - 阳男 → 顺排
> - 月柱后一位 = 壬辰 → 第 1 步大运（壬辰）
> - 第 2 步：癸巳、第 3 步：甲午、...

#### 5.1.4 大运十神

- 大运天干对日主 → **十神**（按 §3.2 查表）
- 大运地支**本气藏干**对日主 → **十神**
- 同时天干地支联合看（盖头/截脚）

> 例：大运甲午 + 日主己土
> - 大运天干甲（阳木）克己土（阴土）→ 异阴阳 = **正官**
> - 大运地支午本气丁（阴火）生己土（阴土）→ 异阴阳 = **正印**
> - 联合：正官盖正印 → **官印相生**

#### 5.1.5 大运与命局关系

| 关系类型 | 判定 | 影响 |
|---|---|---|
| **大运十神** | 大运天干地支对日主是什么十神 | 直接判断用神 / 忌神 |
| **大运引动** | 大运地支与命局某柱地支**合/冲/刑/害/破** | 该柱代表的十神 / 宫位被激活 |
| **大运与命主同位置柱** | 大运与年/月/日/时柱的关系 | 见 §5.2.2 同源规则 |

> ⭐ **大运吉凶判定** = **大运十神（用神/忌神）+ 大运与命局作用关系**

### 5.2 流年

#### 5.2.1 为何要按"年中断点"取年柱？

流年柱推算依赖 **立春换年**（§一.2）。cnlunar 库有个"日级边界"精度限制：立春
如果落在了"立春日"的几点几分，cnlunar 可能把整个立春日全侧子都
判为同一侧。为保证一致性，流年函数取 `——year, 6, 1, 12, 0` 作为
参考点——6 月只在立春后，绝不应出现"跨立春"歧义。

#### 5.2.2 与命主同位置柱的关系

流年与**命主年柱**的关系——看姻缘、祖上、童年 —— **姻缘细节判断见 [`bazi-yingyuan.md`](bazi-yingyuan.md)**

> 传统上：**流年动年柱的影响、流月动月柱、流日动日柱、流时动时柱**。
> 日柱是命主本身的"体"——这是主流口径，本技能以此实现。

月柱依赖节气切月（§一.1）。某个月的上旬可能在节气之前、中下旬在节气之后。
取 `(year, month, 15, 12, 0)` 几乎100%在稳定的那侧。
