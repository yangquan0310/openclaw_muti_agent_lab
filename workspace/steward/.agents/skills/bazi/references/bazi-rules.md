## 二、五行生克

```
木 → 火 → 土 → 金 → 水 → 木      (相生)
木 → 土 → 水 → 火 → 金 → 木      (相克)
```

**判定口诀**：
- 同我（比和）→ 比肩 / 劫财（按阴阳）
- 我生（食伤）→ 食神 / 伤官（按阴阳）
- 我克（财星）→ 偏财 / 正财（按阴阳）
- 生我（印星）→ 偏印 / 正印（按阴阳）
- 克我（官杀）→ 七杀 / 正官（按阴阳）

**阴阳判定**：
- 同性（阳阳 / 阴阴）→ 偏位（劫财 / 伤官 / 偏财 / 偏印 / 七杀）
- 异性（阳阴 / 阴阳）→ 正位（比肩 / 食神 / 正财 / 正印 / 正官）

> 注意：比肩是"同我 + 同阴阳"，劫财是"同我 + 异阴阳"。
> 其余四组同理。

## 四、立春换年

- 年柱以**立春**为界，不是正月初一
- 立春之后出生 → 新年干支
- 立春之前出生 → 上一年干支（即便公历已跨年）

> ⚠️ **cnlunar 库局限**：cnlunar 把立春视为"日级"边界（整个立春当天算同一侧）。
> 对于立春恰好在当天上午的日期，出生时间在立春之后仍可能被算作上一年干支。
> 需要天文精确时，请用 `sxtwl` 校验。

**实测边界案例**（v1.12.0 补充，P1-7 修复）：

- 2000-02-04 22:30 出生（立春 11:32 已过近 11 小时），按 cnlunar = `己卯年戊寅月`（日级边界偏差），按 sxtwl = `庚辰年戊寅月`。
- 涉及 `2000-02-04 11:32 ± 12h` 这个全日敏感边界的用例，强烈建议用 sxtwl 校验。

## 五、子时换日

- 23:00–00:59 出生 → 日柱按 **次日** 计算
- 其他时辰 → 日柱按出生当日计算

> cnlunar 默认已处理子时换日。

**v1.13.0 补充（P2-9）—— cnlunar 早子时 / 晚子时口径差异**：

- **本技能严格跟随 cnlunar 默认行为**：早子时（00:00–00:59）+ 晚子时（23:00–23:59）**均取次日**。
- **子平术主流口径**：早子时（00:00–00:59）= 当日，晚子时（23:00–23:59）= 次日。
- **差异影响**：早子时出生的命盘（特别是 00:00–00:30 这种边界），本技能会比子平术口径"早一天"——日柱差 1 天可能影响配偶、子女、甚至终身格局判定。
- **如需严格依子平术**：请在 CLI 提供真太阳时校正，或自行用 `--reverse` 反查调整出生时刻。

## 七、地支十神

地支十神按**本气藏干**与日干算十神：

```
例：日主甲木
- 年支子：癸水 → 正印（生我，异阴阳）
- 月支卯：乙木 → 劫财（同我，异阴阳）
- 日支午（本气丁火）：丁火 → 伤官（我生，异阴阳）
- 时支未（本气己土）：己土 → 正财（我克，异阴阳）
```

> 主流子平术以本气为主；少数流派兼顾中气/余气。本技能默认取本气。

## 十、流年 / 流月 / 流时 参考使用指引

### 10.1 为何要按"年中断点"取年柱？

流年柱推算依赖 **立春换年**。cnlunar 库有个"日级边界"精度限制：立春
如果落在了"立春日"的几点几分，cnlunar 可能把整个立春日全侧子都
判为同一侧。为保证一致性，流年函数取 `（year, 6, 1, 12, 0）` 作为
参考点（6 月只在立春后），绝不应出现“跨立春”歧义。

### 10.2 为何流月取 (year, month, 15)？

同理，月柱依赖节气切月。某个月的上旬可能在节气之前、中下旬在节气之后。
取 `(year, month, 15, 12, 0)` 几乎100%在稳定的那侧。

### 10.3 子时换日与早晚子时

| 出生时间 | 日柱取 | 时柱 |
|---------|--------|------|
| 23:00–23:59 | 次日 | 子时（晚子时）|
| 00:00–00:59 | 次日 | 子时（早子时）|
| 01:00 始 | 当日 | 丑时 |

> 早/晚子时都是子时，但日柱不同。一律取次日是 cnlunar 与主流子平术的默认。

### 10.4 实战中“与命主同位置柱”的含义

| 推算类型 | 命主位置柱 |
|---------|------------|
| 流年 | 命主年柱（看姻缘、祖上、童年） —— **姻缘细节判断见 [`bazi-yingyuan.md`](bazi-yingyuan.md)** |
| 流月 | 命主月柱（看事业、父母、手足） |
| 流时 | 命主时柱（看子女、晚年、末运） |

为什么是“同位置”？传统上：**流年动年柱的影响、流月动月柱、流时动时柱**，
日柱是命主本身的“体”不变。这不是严格规则，只是子平术推荐的主流口径。
本技能以这个口径实现。

### 10.5 输出关系优先级

按影响力（主流口径）：

1. **天克地冲** （大忌，须重点看）
2. **六合 / 三合 / 三会**（喜，合多是极好时机）
3. **六冲**（冲是动，动中事）
4. **六害 / 六破**（坏事，下个台阶看）
5. **天干合 / 合化** （中看，重点看化五行与日主关系）
6. **天干相生** （生我为恩，生他为泄）
7. **天干无关系** （占位看十神为主）

> 代码不排优，只完整列出所有关系；解读顺序交给使用者（可选后期加权重排序）。

## 十一、古代天文历法术数范畴定位

### 11.2 范畴识别（先判哪一术）

> **首要规则**：任何解读前**先**识别命主问的是哪一术，**不混用**。

| 命主典型问法 | 对应术数 | 工具 |
|--------------|----------|------|
| "我的生辰八字" / "我的命" / "排盘" / "算命" | 八字 | `bazi` |
| "我的紫微命盘" / "迁移宫" / "夫妻宫" / "四化" | 紫微斗数 | `ziwei` |
| "大六壬" / "天地盘" / "三传" | 大六壬 | `bazi --daliuren` |
| "奇门局" / "八门" / "九星" | 奇门遁甲 | `qimen` |
| "七政四余" / "罗睺" / "计都" | 七政四余 | `qizhengsiyu` |
| "我的 X 宫 / X 曜" | **须先识别是紫微还是八字** | 对应工具 |

**反例（不许做）**：
- ❌ 用八字"用神"概念讲紫微盘 → 紫微看宫位 + 四化，**不用"用神"**
- ❌ 用八字"格局"概念讲奇门局 → 奇门看九宫 + 格局，**不是普通格局**
- ❌ 用八字"日主"概念讲大六壬 → 大六壬看天地盘 + 三传，**不用"日主"**

### 11.3 统一硬约束（所有术的共同边界）

下列规则**所有古代天文历法术数都必须遵守**：

| # | 边界规则 | 适用范围 | 备注 |
|---|---------|---------|------|
| 1 | **节气切月** | 八字 / 紫微 / 大六壬 | 月柱按**节气**（不是农历月）切 |
| 2 | **立春换年** | 八字 / 紫微 / 大六壬 | 年柱以**立春**为界，**不是正月初一** |
| 3 | **子时换日** | 八字 / 紫微 / 大六壬 | 23:00–00:59 出生，日柱取**次日** |
| 4 | **真太阳时修正** | 高精度需求 | 境内出生 ±30–90 分钟，使用 `sxtwl` |
| 5 | **五虎遁起月** | 八字流月 | 详见 **§十二 起月口诀表**（v1.12.0 补充） |
| 6 | **五鼠遁起时** | 八字流时 / 子平术 | 详见 **§十三 起时口诀表**（v1.12.0 补充） |
| 7 | **早晚子时** | 八字流时 | 23:00–23:59 vs 00:00–00:59 不同处理 |

### 11.4 流派归属（统一立场）

> **本技能（含解读）归属于「基于格局分析的传统命理现代化」**（v8.47.0）。

**五立场**：
1. **每句话标依据** —— 断言后用 `[依据: 类别]` 标源
2. **术语洁净** —— 暗合是暗合、相生是相生，不混用
3. **用现代汉语** —— 基于工具数据 + 传统命理逻辑给**明确判断**，用大白话写
4. **不仿古** —— 不编"古贤云"，不假托师承
5. **综合** —— 天干地支同等看，不偏天派不偏地派

### 11.7 术语洁净 + 依据标源

> **所有解读必须遵守**：

- **暗合是暗合**（如：地支暗合 ≠ 六合 ≠ 三合）
- **相生是相生**（如：日主生食伤 ≠ 印生比劫）
- **每句话标依据**：`[依据: 类别]` 格式，例如：
  - `[依据: 五行生克]` —— 五行相生相克规则
  - `[依据: 十神对照]` —— 十神查表
  - `[依据: 节气切月]` —— 节气换月
  - `[依据: 立春换年]` —— 立春换年
  - `[依据: 子平术主流]` —— 传统命理主流
  - `[依据: 流派归属]` —— 流派立场
  - `[依据: sxtwl 天文库]` —— 天文实测

**反例（不许做）**：
- ❌ "X 宫 X 曜 X 大限" 混着八字术语讲
- ❌ 不标依据或标"个人理解"
- ❌ 仿古、假托师承、乱堆术语
