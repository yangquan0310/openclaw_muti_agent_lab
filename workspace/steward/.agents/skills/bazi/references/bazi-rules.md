## 一、历法基础

> **本节定义八字排盘的时间坐标体系**——什么时候算哪柱、怎么换年换日。
> 是后续所有元素（天干地支 / 干支关系 / 流时）的**前置基础**。

### 1.1 节气切月

月柱按 **节气**——不是农历月切：

| 月柱 | 节气区间——近似公历 | 月份编号 |
|------|-------------------|---------|
| 寅月 | 立春 → 惊蛰       | 1       |
| 卯月 | 惊蛰 → 清明       | 2       |
| 辰月 | 清明 → 立夏       | 3       |
| 巳月 | 立夏 → 芒种       | 4       |
| 午月 | 芒种 → 小暑       | 5       |
| 未月 | 小暑 → 立秋       | 6       |
| 申月 | 立秋 → 白露       | 7       |
| 酉月 | 白露 → 寒露       | 8       |
| 戌月 | 寒露 → 立冬       | 9       |
| 亥月 | 立冬 → 大雪       | 10      |
| 子月 | 大雪 → 小寒       | 11      |
| 丑月 | 小寒 → 立春       | 12      |

> 节气日期每年略有差异——±1–2 天。`cnlunar.getSolarTermsDateList(year)` 返回年内 24 节气日期。

### 1.2 立春换年

- 年柱以**立春**为界，不是正月初一
- 立春之后出生 → 新年干支
- 立春之前出生 → 上一年干支——即便公历已跨年

> ⚠️ **cnlunar 库局限**：cnlunar 把立春视为"日级"边界——整个立春当天算同一侧。
> 对于立春恰好在当天上午的日期，出生时间在立春之后仍可能被算作上一年干支。
> 需要天文精确时，请用 `sxtwl` 校验。

**实测边界案例**（v1.12.0 补充，P1-7 修复）：

- 2000-02-04 22:30 出生——立春 11:32 已过近 11 小时，按 cnlunar = `己卯年戊寅月`——日级边界偏差，按 sxtwl = `庚辰年戊寅月`。
- 涉及 `2000-02-04 11:32 ± 12h` 这个全日敏感边界的用例，强烈建议用 sxtwl 校验。

### 1.3 子时换日

- 23:00–00:59 出生 → 日柱按 **次日** 计算
- 其他时辰 → 日柱按出生当日计算

> cnlunar 默认已处理子时换日。

**v1.13.0 补充——P2-9—— cnlunar 早子时 / 晚子时口径差异**：

- **本技能严格跟随 cnlunar 默认行为**：早子时——00:00–00:59+ 晚子时——23:00–23:59**均取次日**。
- **子平术主流口径**：早子时——00:00–00:59= 当日，晚子时——23:00–23:59= 次日。
- **差异影响**：早子时出生的命盘——特别是 00:00–00:30 这种边界，本技能会比子平术口径"早一天"——日柱差 1 天可能影响配偶、子女、甚至终身格局判定。
- **如需严格依子平术**：请在 CLI 提供真太阳时校正，或自行用 `--reverse` 反查调整出生时刻。

## 三、天干层关系

> **本节定义天干之间的关系**——按"天干-天干"层次组织：
> - **§3.1 五行基础**：底层相生相克 + 纳音
> - **§3.2 十神**：天干-天干的生克关系（加阴阳）
> - **§3.3 天干合冲**：天干-天干的合/冲关系
>
> ⭐ **本节完整覆盖"天干之间的关系"——五行生克 / 十神 / 天干合冲**

### 3.1 五行基础

> **本节定义五行之间的底层规则**——五行相生相克、纳音五行。

#### 3.1.1 五行生克

```
木 → 火 → 土 → 金 → 水 → 木      (相生)
木 → 土 → 水 → 火 → 金 → 木      (相克)
```

**判定口诀**：
- 同我——比和→ 比肩 / 劫财——按阴阳
- 我生——食伤→ 食神 / 伤官——按阴阳
- 我克——财星→ 偏财 / 正财——按阴阳
- 生我——印星→ 偏印 / 正印——按阴阳
- 克我——官杀→ 七杀 / 正官——按阴阳

**阴阳判定**：
- 同性——阳阳 / 阴阴→ 偏位——劫财 / 伤官 / 偏财 / 偏印 / 七杀
- 异性——阳阴 / 阴阳→ 正位——比肩 / 食神 / 正财 / 正印 / 正官

> 注意：比肩是"同我 + 同阴阳"，劫财是"同我 + 异阴阳"。
> 其余四组同理。

#### 3.1.2 纳音五行

干支组合 → 纳音五行——60 组：

| 纳音 | 干支 |
|------|------|
| 海中金 | 甲子 乙丑 |
| 炉中火 | 丙寅 丁卯 |
| ...  | ... |

> 纳音在传统命理中地位次于五行十神，仅在某些特殊流派中使用。本技能默认不输出。

### 3.2 十神

> **本节定义日主视角的"天干-天干"关系映射**——十神查表 + 地支十神。
> 十神本质 = **天干之间的生克关系** + **阴阳判定**。

#### 3.2.1 十神查表

| 日主五行 | 同我 | 我生 | 我克 | 生我 | 克我 |
|---------|------|------|------|------|------|
| 木      | 比肩(木阳) 劫财(木阴) | 食神(火阳) 伤官(火阴) | 偏财(土阳) 正财(土阴) | 偏印(水阳) 正印(水阴) | 七杀(金阳) 正官(金阴) |
| 火      | 比肩(火阳) 劫财(火阴) | 食神(土阳) 伤官(土阴) | 偏财(金阳) 正财(金阴) | 偏印(木阳) 正印(木阴) | 七杀(水阳) 正官(水阴) |
| 土      | 比肩(土阳) 劫财(土阴) | 食神(金阳) 伤官(金阴) | 偏财(水阳) 正财(水阴) | 偏印(火阳) 正印(火阴) | 七杀(木阳) 正官(木阴) |
| 金      | 比肩(金阳) 劫财(金阴) | 食神(水阳) 伤官(水阴) | 偏财(木阳) 正财(木阴) | 偏印(土阳) 正印(土阴) | 七杀(火阳) 正官(金阴) |
| 水      | 比肩(水阳) 劫财(水阴) | 食神(木阳) 伤官(木阴) | 偏财(火阳) 正财(火阴) | 偏印(金阳) 正印(金阴) | 七杀(土阳) 正官(土阴) |

> 十神查表 = 五行关系 × 阴阳同异。**不要反向查表**——即"日干查年干"vs"年干查日干"会反。
> 本技能从日主正向推算。

#### 3.2.2 地支十神

地支十神按**本气藏干**与日干算十神：

```
例：日主甲木
- 年支子：癸水 → 正印——生我，异阴阳
- 月支卯：乙木 → 劫财——同我，异阴阳
- 日支午——本气丁火：丁火 → 伤官——我生，异阴阳
- 时支未——本气己土：己土 → 正财——我克，异阴阳
```

> 主流子平术以本气为主；少数流派兼顾中气/余气。本技能默认取本气。

### 3.3 天干合冲

> **本节定义天干-天干之间的合与冲**——天干五合 + 天干相克。
> 与 §3.2 十神并列——都是"天干层关系"，但十神是生克、天干合冲是合冲。

#### 3.3.1 天干五合

| 天干合 | 化五行 |
|--------|--------|
| 甲己 | 土 |
| 乙庚 | 金 |
| 丙辛 | 水 |
| 丁壬 | 木 |
| 戊癸 | 火 |

#### 3.3.2 天干相克

木克土，土克水，水克火，火克金，金克木。

> 代码中由 `KE_PAIRS` 生成——动态枚举五对。同时有些官方要求项目中
> 會另外加 `SHENG_PAIRS`——五行相生以供主动脉补。

## 四、干支关系表

> **本节定义干支之间的关系**——按三个关系层次组织：
> - **§4.1 十二长生**（天干-地支关系）
> - **§4.2-§4.6**（地支-地支关系：合/冲/刑/害/破）
> - **§4.7 柱-柱综合关系**（综合判定）
>
> ⭐ **本节完整覆盖"干支之间的关系"**——所有上层分析（格局 / 旺衰 / 流通）都基于本节。

### 4.0 关系层次总论

> **核心结构**：三个关系层次——所有命理分析都在这三个层次上展开

| 层次 | 关系类型 | 节号 | 描述 |
|:---:|---|---|---|
| **第一层** | 天干-天干关系 | §3.2 十神 / §3.3 天干合冲 | **天干之间的生克、合、冲** |
| **第二层** | 天干-地支关系 | §4.1 十二长生 | **天干的生命周期投影到地支上** |
| **第三层** | 地支-地支关系 | §4.2-§4.6 | **地支之间的合、冲、刑、害、破** |

> ⭐ **核心原则**：**刑冲破害合 = 五行在十二长生阶段上的五种"社交语言"**——
> - **冲** = 同级别长生位直接对撞（帝旺 vs 帝旺、长生 vs 长生、墓 vs 墓）
> - **刑** = 相邻长生位的循环累积
> - **破** = 相生关系的反向耗损
> - **害** = 帝旺穿墓 + 长生对害
> - **合** = 长生阶段的互补闭藏

#### 4.1.3 长生与地支相互作用

> **长生阶段是地支之间"相互作用模式"的底层逻辑**——见 §4.2-§4.6

| 模式 | 长生对位 | 力量 |

| **破** | 相生关系的反向耗损 | ⭐⭐ |
| **害** | 帝旺穿墓 + 长生对害 | ⭐⭐ |

### 5.1 大运

> **大运**是命局最重要的时间维度——每 10 年一运，共 8-10 步，主宰人生大节奏。
> 大运天干地支对日主的关系（用神/忌神）+ 大运与命局的作用（合冲刑害）= 人生大运走势。

#### 5.1.1 起运岁数计算

| 顺逆排 | 计算规则 |
|:---:|---|
| **顺排**（阳男 / 阴女）| **数到出生到下一个节气（节）的天数** |
| **逆排**（阴男 / 阳女）| **数到出生到上一个节气（节）的天数** |

- 起运岁数 = 天数 ÷ **3**（1 天 = 4 个月 ≈ 0.33 岁）
- 注：数的是**节**（如立春、惊蛰、清明），**不是气**（雨水、春分）

> **节气与节的区别**：节 = 月初（如立春、惊蛰、清明、立夏...）；气 = 月中（如雨水、春分、谷雨、小满...）。**起运岁数只用"节"**。

#### 5.1.2 顺排 / 逆排规则

| 年干阴阳 | 性别 | 顺/逆排 |
|:---:|:---:|:---:|
| 阳（甲丙戊庚壬）| 男 | **顺排** |
| 阴（乙丁己辛癸）| 女 | **顺排** |
| 阳 | 女 | **逆排** |
| 阴 | 男 | **逆排** |

> **口诀**：**阳男阴女顺排，阴男阳女逆排**——4 种组合记忆法：
> - 阳年 → 男顺女逆
> - 阴年 → 女顺男逆

#### 5.1.3 大运干支推排

| 顺逆排 | 起点 | 推排方向 |
|:---:|---|---|
| **顺排** | 从月柱**后一位**起 | 天干地支**都顺推** |
| **逆排** | 从月柱**前一位**起 | 天干地支**都逆推** |

- 每 10 年一运，**天干和地支同时推进 1 位**
- 共排 8-10 步大运——多数排到 80-100 岁
- 排满 60 甲子则重新循环（罕见）

> **示例**：丙午年男命，月柱辛卯。
> - 阳男 → 顺排
> - 月柱后一位 = 壬辰 → 第 1 步大运（壬辰）
> - 第 2 步：癸巳、第 3 步：甲午、...

#### 5.1.4 大运十神

- 大运天干对日主 → **十神**（按 §3.2 查表）
- 大运地支**本气藏干**对日主 → **十神**
- 同时天干地支联合看（盖头/截脚）

> 例：大运甲午 + 日主己土
> - 大运天干甲（阳木）克己土（阴土）→ 异阴阳 = **正官**
> - 大运地支午本气丁（阴火）生己土（阴土）→ 异阴阳 = **正印**
> - 联合：正官盖正印 → **官印相生**

#### 5.1.5 大运与命局关系

| 关系类型 | 判定 | 影响 |
|---|---|---|
| **大运十神** | 大运天干地支对日主是什么十神 | 直接判断用神 / 忌神 |
| **大运引动** | 大运地支与命局某柱地支**合/冲/刑/害/破** | 该柱代表的十神 / 宫位被激活 |
| **大运与命主同位置柱** | 大运与年/月/日/时柱的关系 | 见 §5.2.2 同源规则 |

> ⭐ **大运吉凶判定** = **大运十神（用神/忌神）+ 大运与命局作用关系**

### 5.2 流年

#### 5.2.1 为何要按"年中断点"取年柱？

流年柱推算依赖 **立春换年**（§一.2）。cnlunar 库有个"日级边界"精度限制：立春
如果落在了"立春日"的几点几分，cnlunar 可能把整个立春日全侧子都
判为同一侧。为保证一致性，流年函数取 `——year, 6, 1, 12, 0` 作为
参考点——6 月只在立春后，绝不应出现"跨立春"歧义。

#### 5.2.2 与命主同位置柱的关系

流年与**命主年柱**的关系——看姻缘、祖上、童年 —— **姻缘细节判断见 [`bazi-yingyuan.md`](bazi-yingyuan.md)**

> 传统上：**流年动年柱的影响、流月动月柱、流日动日柱、流时动时柱**。
> 日柱是命主本身的"体"——这是主流口径，本技能以此实现。

### 5.3 流月

#### 5.3.1 为何流月取节后？

月柱依赖节气切月（§一.1）。某个月的上旬可能在节气之前、中下旬在节气之后。
取 `(year, month, 15, 12, 0)` 几乎100%在稳定的那侧。

|------|------|------|------|------|------|------|------|------|------|------|------|------|
| **甲 / 己** | 丙寅 | 丁卯 | 戊辰 | 己巳 | 庚午 | 辛未 | 壬申 | 癸酉 | 甲戌 | 乙亥 | 丙子 | 丁丑 |
| **乙 / 庚** | 戊寅 | 己卯 | 庚辰 | 辛巳 | 壬午 | 癸未 | 甲申 | 乙酉 | 丙戌 | 丁亥 | 戊子 | 己丑 |
| **丙 / 辛** | 庚寅 | 辛卯 | 壬辰 | 癸巳 | 甲午 | 乙未 | 丙申 | 丁酉 | 戊戌 | 己亥 | 庚子 | 辛丑 |

| **戊 / 癸** | 甲寅 | 乙卯 | 丙辰 | 丁巳 | 戊午 | 己未 | 庚申 | 辛酉 | 壬戌 | 癸亥 | 甲子 | 乙丑 |

> **使用方式**：已知年柱天干，如丙午年 = 丙，查表得正月寅月 = 庚寅，之后每月天干顺序顺推。

#### 5.3.3 与命主同位置柱的关系

流月与**命主月柱**的关系——看事业、父母、手足。

### 5.4 流日

#### 5.4.1 日柱推算：60 甲子循环

- 流日 = 60 甲子顺推，每日不同
- 推算起点 = 命主出生日 + 经过天数（mod 60）

#### 5.4.2 与命主同位置柱的关系

- 流日与命主**日柱**的关系——看当下"体"的状态
- 流日与其他三柱的关系——按 §四 判定

> 注：**主流口径下流日较少用**——日主是"体"，流日变动太快，影响反而小；流年/月/时已能覆盖大部分应期。本技能默认不主动输出流日，仅在用户明确要求时提供。

## 六、古代天文历法术数范畴定位

> **本节定义 bazi 技能在「古代天文历法术数」这一更大范畴中的位置与边界**，
> 避免八字技法误用到紫微 / 奇门 / 六壬等其他术数。
> 老板 2026-08-13 14:40 拍板"你把古代天文历法术数更新到 rule 中"。

### 6.1 总范畴

### 6.2 范畴识别

> **首要规则**：任何解读前**先**识别命主问的是哪一术，**不混用**。

| 命主典型问法 | 对应术数 | 工具 |
|--------------|----------|------|
| "我的生辰八字" / "我的命" / "排盘" / "算命" | 八字 | `bazi` |
| "我的紫微命盘" / "迁移宫" / "夫妻宫" / "四化" | 紫微斗数 | `ziwei` |
| "大六壬" / "天地盘" / "三传" | 大六壬 | `bazi --daliuren` |
| "奇门局" / "八门" / "九星" | 奇门遁甲 | `qimen` |
| "七政四余" / "罗睺" / "计都" | 七政四余 | `qizhengsiyu` |
| "我的 X 宫 / X 曜" | **须先识别是紫微还是八字** | 对应工具 |

**反例——不许做**：
- ❌ 用八字"施药"概念讲紫微盘 → 紫微看宫位 + 四化，**不用"施药"**
- ❌ 用八字"格局"概念讲奇门局 → 奇门看九宫 + 格局，**不是普通格局**
- ❌ 用八字"日主"概念讲大六壬 → 大六壬看天地盘 + 三传，**不用"日主"**

### 6.3 统一硬约束

下列规则**所有古代天文历法术数都必须遵守**：

| # | 边界规则 | 适用范围 | 备注 |
|---|---------|---------|------|
| 1 | **节气切月** | 八字 / 紫微 / 大六壬 | 月柱按**节气**——不是农历月切——见 §一.1 |
| 2 | **立春换年** | 八字 / 紫微 / 大六壬 | 年柱以**立春**为界，**不是正月初一**——见 §一.2 |
| 3 | **子时换日** | 八字 / 紫微 / 大六壬 | 23:00–00:59 出生，日柱取**次日**——见 §一.3 |
| 4 | **真太阳时修正** | 高精度需求 | 境内出生 ±30–90 分钟，使用 `sxtwl` |
| 5 | **五虎遁起月** | 八字流月 | 详见 **§5.3.2 流月·五虎遁起月表**——v1.12.0 补充 |
| 6 | **五鼠遁起时** | 八字流时 / 子平术 | 详见 **§5.5.2 流时·五鼠遁起时表**——v1.12.0 补充 |

### 6.4 流派归属

> **本技能——含解读归属于「基于格局分析的传统命理现代化」**——v8.47.0。

**五立场**：
1. **每句话标依据** —— 断言后用 `[依据: 类别]` 标源
2. **术语洁净** —— 暗合是暗合、相生是相生，不混用
3. **用现代汉语** —— 基于工具数据 + 传统命理逻辑给**明确判断**，用大白话写
4. **不仿古** —— 不编"古贤云"，不假托师承
5. **综合** —— 天干地支同等看，不偏天派不偏地派

### 6.7 术语洁净 + 依据标源

> **所有解读必须遵守**：

- **相生是相生**，如：日主生食伤 ≠ 印生比劫
- **每句话标依据**：`[依据: 类别]` 格式，例如：
  - `[依据: 五行生克]` —— 五行相生相克规则——见 §三.1

  - `[依据: 立春换年]` —— 立春换年——见 §一.2
  - `[依据: 子平术主流]` —— 传统命理主流
  - `[依据: 流派归属]` —— 流派立场——见 §六.4
  - `[依据: sxtwl 天文库]` —— 天文实测

**反例——不许做**：
- ❌ "X 宫 X 曜 X 大限" 混着八字术语讲
- ❌ 不标依据或标"个人理解"
- ❌ 仿古、假托师承、无散
