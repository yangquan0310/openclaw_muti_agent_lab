### Step 1：双方排盘

每个命盘都按 v1.7.0 单盘 5+1 步流程完整排盘——正格 + 旺衰分析，输出双方完整四柱 + 农历 + 节气 + 生肖——年支。

### Step 2：一方加入另一方——合盘流通分析

> **v1.4.0 重大改造（老板 2026-08-18 22:34 拍板"合盘也需要更新了，要以一方加入另一方对天干地支的影响，和单盘一样的思路，分析流通"）**：
> - ❌ 旧思路（v1.3.0）：双方**各自分析**（正格/旺衰）→ 施药互补
> - ✅ 新思路（v1.4.0）：**一方加入另一方** → 看加入方对原局天干地支的影响 → **按单盘统一流程（定格→旺衰→流通核心堵点）分析流通**
> - 核心 = 合盘后的流通——加入方是"通堵"还是"添堵"、是"帮身"还是"耗身"——与单盘完全同思路（`bazi-liutong.md` §1.1 应用聚焦层 + 流通方法层）

#### 2a：确定合盘中心 + 加入方

> **应用聚焦层**（`bazi-liutong.md` §1.1.1）：以**关注方**为中心（默认 = 日主/日支），**另一方 = 加入方**。

| 项 | 说明 |
|:---|:---|
| **中心方** | 关注方——以谁的命局为基础（如看婚嫁 = 女方为中心 / 看合伙 = 双方轮流）|
| **加入方** | 另一方——其干支加入中心方命局，看影响 |

#### 2b：加入方对中心方**天干**的影响

> 加入方 4 天干 vs 中心方 4 天干——合 / 冲 / 克 / 生：

| 作用 | 判定 | 影响 |
|:---|:---|:---|
| **天干五合** | 甲己 / 乙庚 / 丙辛 / 丁壬 / 戊癸 | 合绊 / 合化——改变原局天干关系 |
| **天干相冲** | 甲庚 / 乙辛 / 丙壬 / 丁癸 | 冲克——原局天干受伤 |
| **生克** | 加入方生/克中心方天干 | 扶抑变化 |

#### 2c：加入方对中心方**地支**的影响

> 加入方 4 地支 vs 中心方 4 地支——按 `bazi-rules.md` §5 距离规则：

| 作用 | 判定 | 影响 |
|:---|:---|:---|
| **六合** | 子丑 / 寅亥 / 卯戌 / 辰酉 / 巳申 / 午未 | 合化——改变地支性质 |
| **六冲** | 子午 / 丑未 / 寅申 / 卯酉 / 辰戌 / 巳亥 | 冲散——原局地支动荡 |
| **三合** | 申子辰 / 亥卯未 / 寅午戌 / 巳酉丑 | 成局——加强某一五行 |
| **三会** | 寅卯辰 / 巳午未 / 申酉戌 / 亥子丑 | 会方——专旺 |
| **刑 / 害 / 破** | 按 §5.5 / §5.6 | 暗中破坏 |

#### 2d：合盘后**定格**（按单盘流程）

- 以中心方月令为主——加入方天干若透出月令藏干 → 可能**改变格局**
- 例：中心方无官透，加入方透官 → 合盘后格局多一官

#### 2e：合盘后**旺衰**（按单盘流程）

- 加入方对中心方是**帮身**（印比）还是**耗身**（财官食）？
- 例：中心方身弱，加入方多印比 → **身转旺**——合盘后旺衰变化

#### 2f：合盘后**流通核心堵点**（按单盘流程）

> **核心**：加入方是"**通堵**"还是"**添堵**"？

```
中心方原局堵点 + 加入方干支
├ 加入方合去堵点之神 → 通堵 ✅
├ 加入方冲开堵点 → 通堵 ✅
├ 加入方再生堵点（如再添忌神）→ 添堵 ❌
└ 加入方克用神 → 添堵 ❌
```

| 判定 | 含义 |
|:---|:---|
| **加入方通堵** | 合/冲掉中心方原局堵点 → 合盘流通变顺 ✅ |
| **加入方添堵** | 加入方加重原局堵点（忌神叠加）→ 合盘流通变堵 ❌ |

#### 2g：合盘后**用神融合**（按单盘流程）

- 单盘思路：合盘后定格 → 旺衰 → 堵点 → 用神——**用神 = 合盘后命局的需要**
- 加入方若为合盘用神 → **互补**（对方是你要的）
- 加入方若为合盘忌神 → **冲突**（对方给你添堵）

> **与 v1.3.0 施药互补的关系**：v1.4.0 的"合盘用神融合"取代 v1.3.0"双方各自施药再互补"——因为**加入后的命局是一个整体**，用神应从合盘整体看，而非分开看再拼。

## 四、关系类型分流

### 4.1 婚嫁合盘

- 重点：**施药互补 + 格局互动 + 流年共振**
- 男命财星 ↔ 女命夫星——财官匹配
- 男命食伤 ↔ 女命食伤——表达同频
- 男命日支 ↔ 女命日支——婚位互读

### 4.2 合伙合盘

- 重点：**施药互补 + 格局互动 + 流年共振**
- 双方财星是否互补
- 双方决策位——七杀 / 食伤是否匹配
- 一方旺财 / 一方旺决策 = 经典的"商业搭档"

### 4.3 亲子合盘

- 重点：**施药互补 + 格局互动——印星互补+ 流年共振**
- 双方印星是否一致——家庭文化一致
- 父 / 母 ↔ 子 / 女的**性格投射**——父食伤 → 子日主
- 印星互补 = 文化传承；财星互补 = 财务支持

### 4.4 师生 / 长辈-晚辈合盘

- 重点：**格局互动 + 十神匹配**
- 长辈格局 vs 晚辈格局能否承继
- 长辈印星 vs 晚辈印星——学习能力是否承继

### Step 2：一方加入另一方——合盘流通分析（v1.4.0 新框架）

> **以女方为中心（关注方）**，男方加入——看男方干支对女方天干地支的影响 + 按单盘思路（定格→旺衰→流通核心堵点→用神）分析流通。

#### 2a：确定中心 + 加入方

- **中心方 = 女**（王雅欣 戊寅 己未 甲子 己巳）——关注姻缘
- **加入方 = 男**（杨权 丙子 辛卯 丙午 丁酉）——加入女方命局

#### 2b：加入方（男）对中心方（女）**天干**的影响

| 女天干 | 男天干加入 | 关系 | 影响 |
|:---|:---|:---|:---|
| 戊（偏财）| 丙（比肩）| 丙火生戊土——财得源 | 女财有生 ✅ |
| 己（正财）| 辛（正财）| 同气——财星叠加 | 财更旺 |
| 甲（日主）| 丙（比肩）| 甲木生丙火——泄身 | 女日主泄气 ⚠️ |
| 己（正财）| 丁（劫财）| 丁火生己土——财得源 | 女财有生 ✅ |

**天干结论**：男加入后——女财星（戊己）得火生（丙丁）——**财有源**；但女日主甲木生丙火——**日主泄气**（身弱更弱）。

#### 2c：加入方（男）对中心方（女）**地支**的影响

| 女地支 | 男地支加入 | 关系 | 影响 |
|:---|:---|:---|:---|
| 寅（比肩）| 子（正官）| 子水生寅木 | 比肩得生 ✅ |
| 未（正财）| 卯（正印）| **卯未半合木局** | 合木——女比肩得助 ✅ |
| 子（正印）| 午（劫财）| **子午冲** ⚠️ | **冲女印星**——女身更弱 ❌ |
| 巳（食神）| 酉（正财）| **巳酉半合金局** | 合财——女财有根 ✅ |

**地支结论**：
- ✅ 卯未半合木——女比肩（寅）得助
- ✅ 巳酉半合金——女财得根
- ⚠️ **子午冲**——男午冲女子（印星）——**女身弱加剧**——日支子午冲 = 婚位摩擦

#### 2d：合盘后定格

- 女方原格：正财格（未月己土当令）
- 男方加入后：未变化——**合盘仍以女正财格为主体**（加入方不改变中心方月令定格）

#### 2e：合盘后旺衰

- 女方原局：**40% 中偏弱**（v2.2.5 加权打分——得令✗ 得地✓ 得助✓）
- 男方加入后：
  - 子午冲 → 女印星（子）被冲 → 得地打折 ⚠️
  - 卯未合木 → 女比肩得助 → 得助增强 ✅
- **合盘后旺衰 ≈ 40% 中偏弱**（印被冲 vs 比得合——对冲，变化不大）

#### 2f：合盘后流通核心堵点（通堵 vs 添堵）

```
女原局堵点：印生路径被堵（子巳暗合枭神夺食 + 子未害）
+ 男加入：
├ 子午冲 → 午冲子 → 女印星再受冲 → 印生身更堵 ❌ 添堵
├ 卯未合木 → 未土被合 → 子未害减轻 → 印略透气 ✅ 通堵
├ 巳酉合金 → 巳被合 → 子巳暗合减轻 → 枭神夺食缓解 ✅ 通堵
└ 丙丁生戊己 → 财有源 → 财旺不堵（财是原局主流）
↓
合盘后：男加入 = 半通半堵——巳酉合缓解枭神夺食 ✅ + 子午冲加重印堵 ❌
```

**核心判定**：**男方加入女方 = 通堵与添堵并存**——巳酉合（缓解枭神夺食）✅ 对冲 子午冲（加重印星受伤）❌——**总体中性偏弱**。

#### 2g：合盘后用神融合

- 女用神：火金（食伤+官杀）——需寅（比肩）扶身 + 火金泄秀护财
- 男加入后：
  - **巳酉合金** → 女财（金）得根——**合盘用神金增强** ✅
  - **丙丁火** → 女调候（火）满足——**合盘用神火增强** ✅
  - **子午冲** → 女印星受伤——身更弱——**需比肩（木）扶身**
- **合盘用神融合 = 火金 + 木**——男方（丙丁火 + 辛酉金）恰好补女用神 → **男方是女方的补给品** ⭐

> **与 v1.3.0 对比**：v1.3.0 说"双方各自施药再互补"；v1.4.0 直接看**男方加入女方后**——巳酉合补金、丙丁补火、子午冲伤印——**结论更具体**：男方补女用神（火金），但冲印是隐患。
