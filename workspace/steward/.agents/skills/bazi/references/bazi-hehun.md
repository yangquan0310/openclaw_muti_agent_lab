# 合盘风格（Synastry / Compatibility Reading）

> **本文件正式定义：大管家（steward）在做合盘分析时的解读规范。**
> 适用于：婚嫁合盘、合伙匹配、亲子合盘、师生合盘等"两人关系"分析。

---

## 一、流派归属

**明牌实证派衍生 · 合盘专项**
- 与单盘风格一致：敢断 + 标依据 + 用现代汉语
- **加入 6 维度评分法** —— 不靠单一"六合大吉"判断
- **区分关系类型** —— 不同关系用不同维度

---

## 二、必问三件事（解读前必问）

[1] **双方关系是什么？**
   - 婚嫁（夫妻 / 恋爱）
   - 合伙（商业 / 事业）
   - 亲子（父女 / 母子 / 兄弟姐妹）
   - 师生 / 长辈-晚辈

[2] **要不要看流年 / 大运同步？**
   - 默认：不看（除非老板明确要求）
   - 看流年同步 = 共同生活的"节奏"是否一致
   - 看大运同步 = 长期轨迹是否一致

[3] **哪一方更关注？**
   - 默认：双方平衡
   - 如不对称（如单方面关心），调整评分口径

## 三、合盘 6 步流程

### Step 1：必问三件事（缺一不可）

```
问题 1: 双方关系是什么？
问题 2: 要不要看流年 / 大运同步？
问题 3: 哪一方更关注？
```

### Step 2：分别排盘（用 v1.1.0 单盘流程）

每个命盘都按"必问性别+行业 → 排盘 → 一眼格局 → 用神判定"完整流程。

### Step 3：6 维度加权评分

**核心 6 维度**：

| 维度 | 评分依据 | 权重 |
|------|----------|------|
| **天干合化** | 甲己 / 乙庚 / 丙辛 / 丁壬 / 戊癸 五合 | 15% |
| **地支六合** | 双方年/月/日/时支六合（子丑、寅亥、卯戌、辰酉、巳申、午未） | 20% |
| **地支六冲** | 同上（**减分项** — 双方命局间六冲越多越减分） | 10% |
| **三合方合** | 三合局（申子辰 / 亥卯未 / 寅午戌 / 巳酉丑）/ 方合半会 | 10% |
| **用神互补** | 一方用神 = 另一方喜用 / 一方忌神 ≠ 另一方忌神 | 20% |
| **十神匹配** | 男命财=女命夫 / 食伤互补 / 印互补（按关系类型调整） | 15% |
| **格局互补** | 双方格局能否相互成就 | 10% |

**总分 = 加权平均 → 1-10 分评级**

### Step 4：流年 / 大运同步（如老板要求）

- 双方当前大运五行是否相生
- 共同生活的"节奏"是否一致
- **危机年是否同步**（同步危机 = 加深危机）

### Step 5：明确不强解

| 不强解项 | 原因 |
|----------|------|
| 神煞 / 紫白 | 工具未实现 |
| 具体事件时间（离婚 / 分手 / 合伙破裂） | 不强解 |
| 古籍判语（"六合大吉" / "六冲大凶"） | 仅记录 |

### Step 6：现代汉语行动表

```
## 行动表
### 一方侧
[1] ...
### 另一方侧
[1] ...
### 双方侧
[1] ...
### 长期建议
[1] ...
```

## 四、关系类型分流

### 4.1 婚嫁合盘

- 重点维度：**用神互补** + **十神匹配** + **地支六合**
- 男命财星 ↔ 女命夫星（财官匹配）
- 男命食伤 ↔ 女命食伤（表达同频）
- 男命日支 ↔ 女命日支（婚位互读）

### 4.2 合伙合盘

- 重点维度：**用神互补** + **格局互补** + **三合方合**
- 双方财星是否互补
- 双方决策位（七杀 / 食伤）是否匹配
- 一方旺财 / 一方旺决策 = 经典的"商业搭档"

### 4.3 亲子合盘

- 重点维度：**十神匹配**（印星互补）+ **用神互补** + **地支六合**
- 双方印星是否一致（家庭文化一致）
- 父 / 母 ↔ 子 / 女的**性格投射**（父食伤 → 子日主）
- 印星互补 = 文化传承；财星互补 = 财务支持

### 4.4 师生 / 长辈-晚辈合盘

- 重点维度：**格局互补** + **十神匹配**
- 长辈格局 vs 晚辈格局能否承继
- 长辈印星 vs 晚辈印星（学习能力是否承继）

## 五、评分评级标准

| 分数 | 评级 | 解读 |
|------|------|------|
| **8-10 分** | 高度匹配 | 适合深度合作 / 婚嫁 |
| **6-7 分** | 基本匹配 | 需要磨合 |
| **4-5 分** | 匹配偏低 | 需要刻意经营 |
| **1-3 分** | 匹配度低 | 谨慎 |

## 八、案例（实战参考）

**第一份实战**：老板（父）1996-03-10 18:00 男命 × 她（女）2007-07-24 01:34 女命 —— 父女合盘

**按 6 维度评分结果**：

| 维度 | 评分 | 依据 |
|------|------|------|
| 天干合化 | 4 | 双方日干无五合 |
| 地支六合 | 7 | 父卯 + 女亥 = 卯亥合木 |
| 地支六冲 | 9（无冲） | 双方命局间无冲 |
| 三合方合 | 8 | 父卯+女亥+女未 = **亥卯未三合木局完整** |
| 用神互补 | 5 | 父食伤↔女食伤 OK；父用财↔女财极弱（弱）|
| 十神匹配 | 8 | 双方印重爱平台，性格投射强 |
| 格局互补 | 8 | 父印绶 + 女枭神 = 都需平台支撑 |

**总分**：6.7 / 10 —— **基本匹配，需要磨合**

**核心匹配 / 风险**：
- ✅ 亥卯未三合木 = **深层的家族能量连接**
- ✅ 双方都印重 = **家庭文化和谐**
- ⚠️ 天干合化弱 = **表层沟通有距离**
- ⚠️ 双方都缺财 = **财务是共同课题**
