## 二、必问三件事（解读前必问）

[1] **双方关系是什么？**
   - 婚嫁（夫妻 / 恋爱）
   - 合伙（商业 / 事业）
   - 亲子（父女 / 母子 / 兄弟姐妹）
   - 师生 / 长辈-晚辈

[2] **要不要看流年 / 大运同步？**
   - 默认：**看**（合盘必看流年共振，缺一半分析）
   - 看流年同步 = 共同生活的"节奏"是否一致
   - 看大运同步 = 长期轨迹是否一致

[3] **哪一方更关注？**
   - 默认：双方平衡
   - 如不对称（如单方面关心），调整分析口径

## 三、分析合盘格局 5+1 步

> **v2.0.0 改造**（决策 2 同步 · bazi-style-da-guan-jia.md v2.1.0）：从 **6 步 → 5+1 步**。
> - Step 0：必问三件事（前置，已在 §二 详述）
> - Step 1：双方排盘（事实层）
> - Step 2：分析（基础层 · 各自格局+用神合一）
> - Step 3：应用（横向层 · 互动维度）
> - Step 4：流年共振（时间层）
> - Step 5：行动表（落地层）
> - **+1**：神煞互见（不强解时跳过）

### Step 0：必问三件事（前置）

详见 §二。骨架性前置条件：关系类型 / 是否看流年同步 / 关注方。

### Step 1：双方排盘（事实层）

每个命盘都按 v1.6.0 单盘 5+1 步流程完整排盘（三种分析并列：正格 + 势局 + 神煞），输出双方完整四柱 + 农历 + 节气 + 生肖（年支）。

### Step 2：分析（基础层 · 三种分析并列）

> **v1.2.0 升级**（老板 2026-08-08 14:58 拍板）：合盘分析对齐单盘框架，改为**三种分析并列** = **正格 + 势局 + 神煞**。
> - **正格**：各自格局（月令定格 + 八格标准 + 用神方向）
> - **势局**：各自旺衰（得令 / 得地 / 得生 / 得助 + 调候 + 流通）
> - **神煞**：各自命中神煞（按柱归位 + 阴阳两面 + 一体两面）
> - **核心是互动维度**：用神互补 + 神煞互见（见 §四 + +1）
> - 详细理论见 `bazi-zhengge.md` + `bazi-shiju.md` + `bazi-shensha.md`

#### 2a：各自正格

确定每个人的格局类型（食神格 / 正印格 / 从强格 / 化格 等），这是格局互动的基础。

参考：`bazi-zhengge.md` v1.0.0

#### 2b：各自势局

- 旺衰四维度（得令 / 得地 / 得生 / 得助）
- 调候判定（春/夏/秋/冬）
- 流通分析（阻滞 + 制化）

参考：`bazi-shiju.md` v1.0.0

#### 2c：各自神煞

- 按柱归位 + 阴阳两面同列
- 激活条件 + 制化机制
- 详见 `bazi-shensha.md` v2.1.1

#### 2d：用神互补（最核心 · 合盘专属）

| 情况 | 大白话 | 含义 |
|------|--------|------|
| 甲方用神 = 乙方八字里多 | 你是他的补给品 | 你恰好补他 |
| 甲方用神 = 乙方忌神 | 你给的恰好是他不需要的 | 你们冲突 |
| 甲方用神被乙方克 | 你需要的被他压着 | 他拖你后腿 |
| 甲方用神被乙方生 | 你需要的他来补 | 他帮你 |

#### 2e：融合（双方一句话总结）

正格 + 势局 + 神煞 + 用神互补 → 双方一句话总结。

### Step 3：应用（横向层 · 互动维度）

按关系类型分流（详见 §四）：

| 关系 | 重点步骤 |
|------|----------|
| 婚嫁 | 配偶画像 + 用神互补 + 格局互动 |
| 合伙 | 格局互动 + 用神互补 |
| 亲子 | 印星互补 + 格局互动 |
| 师生 | 十神匹配 + 格局互动 |

### Step 4：流年共振（时间层）

| 类型 | 大白话 | 含义 |
|------|--------|------|
| 大运同步 | 大运走势一致 | 长期同频 |
| 流年共振 | 同年同吉/同凶 | 那年一起起伏 |
| 错位 | 同年吉凶相反 | 一进一退 |
| 互补共振 | 甲走财时乙走事业 | 各自发挥所长 |

### Step 5：行动表（落地层）

按"一方侧 + 另一方侧 + 双方侧 + 长期建议"四档输出（详见实战案例）。

### +1：神煞互见（不强解时跳过）

| 神煞 | 大白话 | 影响 |
|------|--------|------|

| 童子煞互见 | 子女运冲突 | 子女缘浅 |

## 四、关系类型分流

### 4.1 婚嫁合盘

- 重点：**用神互补 + 格局互动 + 流年共振**
- 男命财星 ↔ 女命夫星（财官匹配）
- 男命食伤 ↔ 女命食伤（表达同频）
- 男命日支 ↔ 女命日支（婚位互读）

### 4.2 合伙合盘

- 重点：**用神互补 + 格局互动 + 流年共振**
- 双方财星是否互补
- 双方决策位（七杀 / 食伤）是否匹配
- 一方旺财 / 一方旺决策 = 经典的"商业搭档"

### 4.3 亲子合盘

- 重点：**用神互补 + 格局互动（印星互补）+ 流年共振**
- 双方印星是否一致（家庭文化一致）
- 父 / 母 ↔ 子 / 女的**性格投射**（父食伤 → 子日主）
- 印星互补 = 文化传承；财星互补 = 财务支持

### 4.4 师生 / 长辈-晚辈合盘

- 重点：**格局互动 + 十神匹配**
- 长辈格局 vs 晚辈格局能否承继
- 长辈印星 vs 晚辈印星（学习能力是否承继）

## 七、案例（实战参考）

### 直接结论

**高度匹配，适合深度合作 / 婚嫁**——男财（辛金）= 女夫（辛金）满分契合 ✅，用神互补良好 ✅，格局互动以"连续相生"为主 ✅。注意日支子午冲在日常相处中的体现 + 2027 年错位共振需要预案。

### 实战

**老板（男）1996-03-10 18:00 丙火 × 她（女）1998-07-16 09:00 甲木**——**姻缘合盘**

### 双方命盘

| 位置 | 👤 男（1996-03-10 18:00 丙火）| 👤 女（1998-07-16 09:00 甲木）|
|------|-------------------------------|-------------------------------|
| 年柱 | 丙子（比肩 / 正官）| 戊寅（偏财 / 比肩）|
| 月柱 | 辛卯（正财 / 正印）| 己未（正财 / 正财）|
| 日柱 | 丙午（比肩 / 劫财）| 甲子（比肩 / 正印）|
| 时柱 | 丁酉（劫财 / 正财）| 己巳（正财 / 食神）|

### Step 1：分别排盘

按 v1.1.0 单盘流程已排（见上表）。

### Step 2：定各自格局

| 维度 | 👤 男 | 👤 女 |
|------|-------|-------|
| 日主 | 丙火 | 甲木 |
| 月令 | 卯月（正印）| 未月（正财）|
| 格局 | **印绶格** | **正财格** |
| 用神 | 木（印绶）| 土（财星）|

### Step 3：用神互补（最核心）

- 男用神 = **木**。女命甲木日主 + 时柱己巳食神 → **女就是男要补的** ⭐
- 女用神 = **土**。男命月柱辛卯 + 时柱丁酉（劫财 + 正财）→ **男财星丰富，正补女需要** ⭐

**结论**：**用神高度互补**——男需要的木正好是女，女需要的土正好是男。

### Step 4：格局互动关系

| 互动 | 大白话 | 含义 |
|------|--------|------|
| 印绶格（男）→ 正财格（女） | 男"理想文化"养女"务实财务" | **木生火，火生土——连续相生** ✅ |
| 正财格（女）→ 印绶格（男） | 女的"务实"反过来帮男的"理想" | 女正财星恰好是男需要的 ✅ |
| **比和** | 都强 + 都柔 | 都旺但都对 ✅ |

**结论**：**木火土连续相生链** + 比和，经典的"理想 + 务实"结构。

### Step 5：流年共振

- 男当前大运：**戊申**（偏财 + 七杀）—— 偏财运 + 七杀压力
- 女当前大运：**庚午**（正财 + 比肩）—— 正财运旺
- **2025-2030 年对比**：

| 年份 | 男流年 | 女流年 | 关系 |
|------|--------|--------|------|
| 2025 | 乙巳（正印）| 庚午（正财）| **互补共振** ✅ |
| 2026 | 丙午（比肩）| 辛未（正财）| 比和 |
| 2027 | 丁未（劫财）| 壬申（偏印）| **错位**（男压力大、女平稳） ⚠️ |
| 2028 | 戊申（偏财）| 癸酉（偏印）| **大运同步** ✅ |
| 2029 | 己酉（正财）| 甲戌（比肩）| 互补共振 ✅ |
| 2030 | 庚戌（正财）| 乙亥（正印）| **大运同步** ✅ |

**结论**：**2025-2030 整体看好**，**2027 年是错位共振年**（男压力大、女平稳），需要预案。

### Step 6：神煞互见

| 神煞 | 双方情况 | 影响 |
|------|----------|------|
| 桃花煞互见 | **未出现** ✅ | 无 |
| 童子煞互见 | **未出现** ✅ | 无 |
| 天乙贵人互见 | 男酉时柱自带天乙，女时柱巳不与之冲突 | **无贵人互见**（中性）|
| 亡神劫煞 | **未出现** ✅ | 无 |

**结论**：**神煞无重大冲突**——主要风险在日常摩擦（子午冲）。

### 核心优势

- ✅ **用神高度互补**（木-土双向）
- ✅ **格局互动连续相生**（木火土链）
- ✅ **2025-2030 流年错位 + 互补共振**——长期看好
- ✅ **神煞无重大冲突**

### 真实挑战

- ⚠️ **日支子午冲** —— 婚位不稳，日常相处易摩擦
- ⚠️ **2027 年错位共振** —— 男压力大、女平稳，需预案
- ⚠️ **男命缺食伤 vs 女食伤旺** —— 男内敛，女表达欲强
- ⚠️ **双方都涉及"财"** —— 财务分配需协商

### 行动表

#### 👨 男方侧

[1] **学表达（食伤训练）** —— 火旺缺土，话不说出来女方感受不到
[2] **财务上提前沟通预期** —— 避免婚后因钱吵架
[3] **2027 年提前预案** —— 那年压力大，提前和女方沟通

#### 👩 女方侧

[1] **降低表达预期** —— 男方不是不爱你，是真的不会说
[2] **用印星（学习 / 思考）跟他沟通** —— 比直球有效
[3] **2027 年稳住** —— 那年你是他的"压舱石"

#### 👫 双方侧

[1] **避开子日和午日**办重要事（冲日支）
[2] **共同学一项新技能** —— 双方印都强，文化学习是你们的"语言"
[3] **2025-2030 看好，2030 后再评估**

#### 🏛️ 长期建议

[1] **婚前同居 6 个月** —— 验证子午冲在日常的体现
