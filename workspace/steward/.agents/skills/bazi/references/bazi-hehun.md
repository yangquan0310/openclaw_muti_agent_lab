# 合盘风格（Synastry / Compatibility Reading）

> **本文件正式定义：大管家（steward）在做合盘分析时的解读规范。**
> 适用于：婚嫁合盘、合伙匹配、亲子合盘、师生合盘等"两人关系"分析。

## 一、流派归属

**基于格局分析的传统命理现代化 · 合盘专项**（v8.47.0 起原"明牌实证派衍生"改名）

- 与单盘风格一致：敢断 + 标依据 + 用现代汉语
- **核心方法：分析合盘格局**（v1.0.2 改造：取代"6 维度加权评分法"）
- **用书策略**（老板 2026-07-26 04:56 拍板）：
  - **主要用书（定各自格局）**：渊海子平 + 三命通会 + 人伦大统赋 + 千里命稿
  - **辅助资料（精化用神互补 / 格局互动）**：子平真诠 + 滴天髓 + 穷通宝鉴
- **区分关系类型** —— 不同关系用不同维度

## 二、必问三件事（解读前必问）

[1] **双方关系是什么？**
   - 婚嫁（夫妻 / 恋爱）
   - 合伙（商业 / 事业）
   - 亲子（父女 / 母子 / 兄弟姐妹）
   - 师生 / 长辈-晚辈

[2] **要不要看流年 / 大运同步？**
   - 默认：**看**（合盘必看流年共振，缺一半分析）
   - 看流年同步 = 共同生活的"节奏"是否一致
   - 看大运同步 = 长期轨迹是否一致

[3] **哪一方更关注？**
   - 默认：双方平衡
   - 如不对称（如单方面关心），调整分析口径

## 三、分析合盘格局 5+1 步

> **v1.3.0 改造**（老板 2026-08-08 15:30 拍板）：从 **6 步 → 5+1 步**（三种分析并列 + 用神互补）。
> - Step 0：必问三件事（前置，已在 §二 详述）
> - Step 1：双方排盘（事实层）
> - Step 2：分析（基础层 · 各自格局+用神合一）
> - Step 3：应用（横向层 · 互动维度）
> - Step 4：流年共振（时间层）
> - Step 5：行动表（落地层）
> - **+1**：神煞互见（不强解时跳过）

### Step 0：必问三件事（前置）

详见 §二。骨架性前置条件：关系类型 / 是否看流年同步 / 关注方。

### Step 1：双方排盘（事实层）

每个命盘都按 v1.7.0 单盘 5+1 步流程完整排盘（三种分析并列：正格 + 旺衰 + 神煞），输出双方完整四柱 + 农历 + 节气 + 生肖（年支）。

### Step 2：分析（基础层 · 三种分析并列 + 用神互补）

> **v1.3.0 升级**（老板 2026-08-08 15:30 拍板"现在更新"）：合盘分析升级为**三种分析 + 用神互补**。
> - **三种分析并列**（Layer 1）：正格 + 旺衰 + 神煞（每方各自做）
> - **用神互补**（合盘专属 · Layer 2）：基于双方各自用神 → 互补判定
> - **核心是互动维度**：用神互补 + 神煞互见（见 §四 + +1）
> - 详细理论见 `bazi-zhengge.md` v1.0.1 + `bazi-wangshuai.md` v1.0.0 + `bazi-shensha.md` v2.1.1
> - 用神判定基础见 `bazi-yongshen.md` v1.0.0（新增）

#### 2a：各自正格

确定每个人的格局类型（食神格 / 正印格 / 从强格 / 化格 等），这是格局互动的基础。

参考：`bazi-zhengge.md` v1.0.1

#### 2b：各自旺衰

- 旺衰四维度（得令 / 得地 / 得生 / 得助）
- 调候判定（春/夏/秋/冬）
- 流通分析（阻滞 + 制化）

参考：`bazi-wangshuai.md` v1.0.0

#### 2c：各自神煞

- 按柱归位 + 阴阳两面同列
- 激活条件 + 制化机制
- 详见 `bazi-shensha.md` v2.1.1

#### 2d：用神互补（最核心 · 合盘专属 · 基于双方各自用神）★ v1.3.0 升级

> **理论依据**：`bazi-yongshen.md` v1.0.0（用神判定子流程参考）

**前提**：先用 2a + 2b 各自判定双方用神 → 再做互补判定。

##### 2d.1：互补的 4 种情况

| 情况 | 大白话 | 含义 |
|------|--------|------|
| 甲方用神 = 乙方八字里多 | 你是他的补给品 | 你恰好补他 ✅ |
| 甲方用神 = 乙方忌神 | 你给的恰好是他不需要的 | 你们冲突 ❌ |
| 甲方用神被乙方克 | 你需要的被他压着 | 他拖你后腿 ❌ |
| 甲方用神被乙方生 | 你需要的他来补 | 他帮你 ✅ |

##### 2d.2：错位的 4 种情况

| 情况 | 大白话 | 含义 |
|------|--------|------|
| 双方用神一致 | 你们五行喜忌相同 | 容易同频 ✅ |
| 双方用神错位 | 你们五行喜忌不同 | 各有方向，互相独立 |
| 双方用神互补 | 你是他的用神，反之亦然 | **最佳** ⭐ |
| 双方用神相克 | 你们用神相克 | 互相损耗 ❌ |

##### 2d.3：实战示例（杨权 vs 老板女儿）

```
杨权（丙火）：
  正格：印绶格 → 用神方向 = 金水
  旺衰：4/4 极旺 + 壬水调候 → 用神精化 = 金水（壬水为核）
  融合 → 最终用神：金水（壬水为核）

女儿（庚金）：
  正格：正财格 → 用神方向 = 火金（食伤 + 官杀）
  旺衰：3/4 身偏旺 → 用神精化 = 火金
  融合 → 最终用神：火金

用神互补判定：
  杨权用神金水 ⊂ 女儿八字（女儿有金 → 互补杨权）
  女儿用神火金 ⊂ 杨权八字（老板丙丁火 → 互补女儿）
  结论：⭐ **双向互补 · 最佳**
```

## 四、关系类型分流

### 4.1 婚嫁合盘

- 重点：**用神互补 + 格局互动 + 流年共振**
- 男命财星 ↔ 女命夫星（财官匹配）
- 男命食伤 ↔ 女命食伤（表达同频）
- 男命日支 ↔ 女命日支（婚位互读）

### 4.2 合伙合盘

- 重点：**用神互补 + 格局互动 + 流年共振**
- 双方财星是否互补
- 双方决策位（七杀 / 食伤）是否匹配
- 一方旺财 / 一方旺决策 = 经典的"商业搭档"

### 4.3 亲子合盘

- 重点：**用神互补 + 格局互动（印星互补）+ 流年共振**
- 双方印星是否一致（家庭文化一致）
- 父 / 母 ↔ 子 / 女的**性格投射**（父食伤 → 子日主）
- 印星互补 = 文化传承；财星互补 = 财务支持

### 4.4 师生 / 长辈-晚辈合盘

- 重点：**格局互动 + 十神匹配**
- 长辈格局 vs 晚辈格局能否承继
- 长辈印星 vs 晚辈印星（学习能力是否承继）

## 七、案例（实战参考）

### 直接结论

**高度匹配，适合深度合作 / 婚嫁**——男财（辛金）= 女夫（辛金）满分契合 ✅，用神互补良好 ✅，格局互动以"连续相生"为主 ✅。注意日支子午冲在日常相处中的体现 + 2027 年错位共振需要预案。

### 实战

**老板（男）1996-03-10 18:00 丙火 × 她（女）1998-07-16 09:00 甲木**——**姻缘合盘**

### 双方命盘

| 位置 | 👤 男（1996-03-10 18:00 丙火）| 👤 女（1998-07-16 09:00 甲木）|
|------|-------------------------------|-------------------------------|
| 年柱 | 丙子（比肩 / 正官）| 戊寅（偏财 / 比肩）|
| 月柱 | 辛卯（正财 / 正印）| 己未（正财 / 正财）|
| 日柱 | 丙午（比肩 / 劫财）| 甲子（比肩 / 正印）|
| 时柱 | 丁酉（劫财 / 正财）| 己巳（正财 / 食神）|

### Step 1：分别排盘

按 v1.7.0 单盘流程已排（见上表）。

### Step 2a：各自正格

| 维度 | 👤 男 | 👤 女 |
|------|-------|-------|
| 日主 | 丙火 | 甲木 |
| 月令 | 卯月（正印）| 未月（正财）|
| 格局 | **印绶格** | **正财格** |
| 用神方向 | 金水（官杀 / 财星）| 火金（食伤 / 官杀）|

### Step 2b：各自旺衰

- 男：4/4 极旺（卯月日支午 + 比劫帮身）—— 调候用壬水
- 女：3/4 偏旺（甲木得寅禄 + 子印）—— 喜火金泄秀护财

### Step 2c：各自神煞

- 男：桃花（午）、天乙（酉）—— 阳面异性缘佳，阴面需辨烂桃花
- 女：文昌（巳）、天乙（子）—— 阳面聪慧学习佳

### Step 2d：用神互补（最核心）

- 男用神 = **金水**。女命甲木日主 + 时柱己巳食神 → **女就是男要补的** ⭐
- 女用神 = **火金**。男命月柱辛卯 + 时柱丁酉（劫财 + 正财）→ **男财星丰富，正补女需要** ⭐

**结论**：**用神高度互补**——男需要的金水正好是女，女需要的火金正好是男。

### Step 2e：融合（双方一句话总结）

- 男：印绶格 + 极旺 → 需壬水调候润局
- 女：正财格 + 偏旺 → 需火金泄秀护财
- **融合**：金水（壬水为核）× 火金（食伤+官杀）—— 互补无冲突

### Step 3：应用（互动维度）

| 互动 | 大白话 | 含义 |
|------|--------|------|
| 印绶格（男）→ 正财格（女） | 男"理想文化"养女"务实财务" | **木生火，火生土——连续相生** ✅ |
| 正财格（女）→ 印绶格（男） | 女的"务实"反过来帮男的"理想" | 女正财星恰好是男需要的 ✅ |
| **比和** | 都强 + 都柔 | 都旺但都对 ✅ |

**结论**：**木火土连续相生链** + 比和，经典的"理想 + 务实"结构。

### Step 4：流年共振

- 男当前大运：**戊申**（偏财 + 七杀）—— 偏财运 + 七杀压力
- 女当前大运：**庚午**（正财 + 比肩）—— 正财运旺
- **2025-2030 年对比**：

| 年份 | 男流年 | 女流年 | 关系 |
|------|--------|--------|------|
| 2025 | 乙巳（正印）| 庚午（正财）| **互补共振** ✅ |
| 2026 | 丙午（比肩）| 辛未（正财）| 比和 |
| 2027 | 丁未（劫财）| 壬申（偏印）| **错位**（男压力大、女平稳） ⚠️ |
| 2028 | 戊申（偏财）| 癸酉（偏印）| **大运同步** ✅ |
| 2029 | 己酉（正财）| 甲戌（比肩）| 互补共振 ✅ |
| 2030 | 庚戌（正财）| 乙亥（正印）| **大运同步** ✅ |

**结论**：**2025-2030 整体看好**，**2027 年是错位共振年**（男压力大、女平稳），需要预案。

> **神煞互见**（v1.3.0 并入 Step 2c 各自神煞 + Step 3 应用）：桃花煞互见 **未出现** ✅ / 童子煞互见 **未出现** ✅ / 天乙贵人互见 **无冲突**（中性）/ 亡神劫煞 **未出现** ✅ —— 神煞无重大冲突，主要风险在日常摩擦（子午冲）。

### 核心优势

- ✅ **用神高度互补**（木-土双向）
- ✅ **格局互动连续相生**（木火土链）
- ✅ **2025-2030 流年错位 + 互补共振**——长期看好
- ✅ **神煞无重大冲突**

### 真实挑战

- ⚠️ **日支子午冲** —— 婚位不稳，日常相处易摩擦
- ⚠️ **2027 年错位共振** —— 男压力大、女平稳，需预案
- ⚠️ **男命缺食伤 vs 女食伤旺** —— 男内敛，女表达欲强
- ⚠️ **双方都涉及"财"** —— 财务分配需协商
