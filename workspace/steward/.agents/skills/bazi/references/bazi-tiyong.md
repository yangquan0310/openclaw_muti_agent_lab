### 1.1 优先级规则

| 优先级 | 规则 | 依据 |
|---|---|---|
| **1. 正格** | 体用方向基于格局类型，**不依赖旺衰** | 渊海子平 / 三命通会 / 子平真诠 |
| **2. 调候** | **调候优先于扶抑**——调候缺失则格局失衡 | 穷通宝鉴 / 滴天髓 |

> **核心**：**正格 ≠ 调候 ≠ 扶抑**。三层各司其职，融合得出最终体用。

## 四、扶抑

> **🆕 v2.0.0 新增独立章节**：扶抑从旺衰精化层移入体用判定。扶抑基于旺衰判定，旺衰由旺衰——Step 3给出。

### 4.1 扶抑的概念

- **扶抑**：根据**日主旺衰**，选择**克泄耗**——抑或**生扶**——扶
- **极旺 / 旺** → 抑——克 / 泄 / 耗
- **中等偏旺** → 抑 + 平衡
- **中等** → 看具体配合——调候优先
- **中等偏弱 / 弱** → 扶——生 / 助
- **极弱** → 扶 + 护——财 + 官杀可适度

### 4.2 旺衰 ↔ 扶抑对照表

| 旺衰 | 扶抑方向 | 体用倾向 |
|---|---|---|
| **极旺** | 扶——从强格| 印 + 比劫 |
| **旺** | 抑——克泄| 食伤 / 财星 / 官杀 |
| **中等偏旺** | 抑——轻度| 财星 / 食伤 |
| **中等** | 看配合 | 调候优先 |
| **中等偏弱** | 扶——轻度| 印星 / 比劫 |
| **弱** | 扶——生助| 印星 / 比劫 |
| **极弱** | 扶 + 护——从弱格| 财 + 官杀 |

### 4.3 扶抑的边界

- **扶抑 ≠ 调候**：扶抑解决"日主强不强"，调候解决"出生季节适不适合"
- **扶抑精化**必须基于旺衰旺衰判定——不能脱离旺衰谈扶抑
- 扶抑结果**与调候融合**才能得出最终体用

### 4.4 输出

**一句话扶抑体用**，如"极旺 → 金水——克泄"。

## 五、调候 vs 扶抑优先级

### 5.1 核心原则

**调候优先于扶抑**——穷通宝鉴。

### 5.2 理由

- **调候缺失** → 命局失衡，如冬月丙火无壬水 = 寒滞
- **扶抑失衡** → 体用可补救，如身旺可用克泄

### 5.3 调候体用的特殊处理

| 情况 | 处理 |
|---|---|
| 调候体用 = 扶抑体用 | 强化体用 |
| 调候体用 ≠ 扶抑体用 | **调候优先** |
| 调候体用与正格方向冲突 | 以正格方向为主 + 调候体用作补充 |

### 5.4 实战示例

```
调候：春月丙火 → 壬水第一
扶抑：4/4 极旺 → 金水——克泄
 ↓
融合：金水——壬水为核，庚辛次之
 ↓
最终体用：金水
```

## 六、融合 → 最终体用

### 6.1 融合公式

```
最终体用 = 正格方向 ∩ 旺衰精化
 = 方向优先——正格 + 精化补强——旺衰
```

### 6.2 三种融合情况

| 情况 | 处理 | 举例 |
|---|---|---|
| **方向 = 精化** | 直接用 | 正格"金水" + 旺衰"金水" = "金水" |
| **方向 ⊂ 精化** | 取精化补强 | 正格"财" + 旺衰"金水" = "金水" |
| **方向 ≠ 精化** | **以正格方向为主**——正格权威，旺衰补充调候体用 | 正格"火" + 旺衰"水" = "火——兼用水调候" |

### 6.3 反例

| ❌ 误解 | ✅ 正确 |
|---|---|
| "正格体用必须等旺衰定了才能选" | "正格给方向，旺衰精化，**两者并行**" |
| "调候与正格冲突时调候优先" | "调候在旺衰内部优先于扶抑，**不是**与正格冲突" |
| "体用只看扶抑" | "体用 = 正格方向 + 旺衰精化——调候+扶抑融合"（v1.1.0 起流通独立）|

### 6.4 输出

**一句话最终体用**，如"金水——壬水为核，庚辛次之"。

## 七、四大治法总览 v1.3.0 2026-08-17 03:30 拍板

> **核心观点**：命局有问题，**4 大治法按优先级找解决方案**——调候 → 扶抑 → 通关 → 增旺。**对症 = 治疗命局具体问题（单独方法，不进优先级序列）**。克泄是扶抑的子项——身旺抑，不是独立大类。

> **v1.3.1 补充（2026-08-17 03:51 拍板"治病体用属于体用。不是在流通"）**：**治病体用 = 体用环节的事**（流通只做分析找问题）。**治病体用三目标**：
>
> - **强弱得当**——命局五行平衡（调候 + 扶抑 + 增旺）
> - **流通起来**——能量路径顺畅（通关）
> - **生生不息**——循环不竭（整体循环）
>
> **本质**：体用不是死板的"某个五行"，而是**让命局活起来的那股力量**——强弱得当是基础，流通起来是关键，生生不息是终极状态。

### ① 调候

**治什么**：季节大气候——过冷/过热

**调候速查**：

| 季节 | 调候主神 | 调候辅神 |
|---|---|---|
| **春——寅卯** | **丙火**——太阳| 癸水 |
| **夏——巳午** | **壬水** | 庚金 |
| **秋——申酉** | **丁火** | 甲木 |
| **冬——亥子** | **丙火** | 戊土 |

**判定**：命局**有**调候神 → OK；命局**缺** → **缺调候**

### ② 扶抑

**治什么**：日主太旺/太弱——抑强扶弱

**两套方向**：
- **极旺 → 抑**——克泄：食伤 / 财 / 官
- **极弱 → 扶**——生扶：印 / 比劫

**旺衰四维度**：

| 得分 | 强度 | 抑/扶 |
|---|---|---|
| 4/4 | 极旺 | 抑 |
| 3/4 | 偏旺 | 抑 |
| 2/4 | 中和 | 看配置 |
| 1/4 | 偏弱 | 扶 |
| 0/4 | 极弱 | 扶 |

### ③ 通关

**治什么**：两个五行**对冲/相克**时

**通关口诀**——在两个相克五行之间架一个桥：

| 冲突 | 通关五行 | 原理 |
|---|---|---|
| **金克木** | **水** | 金→水→木 |
| **木克土** | **火** | 木→火→土 |
| **土克水** | **金** | 土→金→水 |
| **水克火** | **木** | 水→木→火 |
| **火克金** | **土** | 火→土→金 |

**例子**：印绶夺食——金克木太重→ 用**水**通关——金生水、水生木

### ④ 增旺

**治什么**：某种五行力量不足——**增强所需五行**，使其由弱转旺

**适用场景**：
- 体用五行太弱 → **增旺体用**（生扶/汇气）
- 通关五行不足 → **增旺通关五行**（使桥更稳固）
- 调候神不足 → **增旺调候神**（使气候真正改善）

**判定**：命局所需五行**力量不足** → 增旺之；足够则不需要

### ⑤ 对症——治疗命局（单独方法，不进优先级序列）

> **v1.3.2 修正**：**对症**不是第 4 大治法，是**单独的治疗命局的方法**——命局有"病"（破格/失衡点）时，对症下药。

**治什么**：命局有"病"——破格，对症下药

**常见 4 症 + 对症**：

| 症 | 大白话 | 对症 |
|---|---|---|
| **印绶夺食** | 印太重克食伤——想法被压| **财**——坏印 |
| **比劫争财** | 比劫太多分财——钱留不住| **官杀**——制比劫 |
| **食伤生财过旺** | 泄身太过——自己累死| **印**——生身止泄 |
| **官杀混杂** | 官杀太乱——心不定| **食**——制杀留官/ **合杀** |

### 4 大治法优先级

> **调候 → 扶抑 → 通关 → 增旺**
>
> 优先级：**调候**——活下来> **扶抑**——活着> **通关**——活得顺> **增旺**——活得强

**大白话**：先解决"**活下来**"的问题——调候+扶抑→ 再解决"**活得顺**"——通关+增旺

> **对症 = 单独方法**——治疗命局的具体问题（破格/失衡点），**不进优先级序列**。4 大治法解决"整体平衡"，对症解决"具体病症"。

## 八、实战案例

### 7.1 

```
[Step 1] 正格 → 体用方向
 - 格局：**正印格**（v1.3.3 修正：原「印绶格」按 bazi-rules.md §2.2 标准化为「正印格」）

[Step 2] 旺衰 → 精化体用
 - 旺衰：4/4 极旺 → 扶抑 = 金水——克泄
 - 调候：春月丙火 → 壬水第一
 - 流通：**克泄耗三路全断**（v1.3.3 重构：原"财破印——辛克卯是关键制化"表述不够准确——按 [`bazi-case.md` 案例一](bazi-case.md) 重构）
```
