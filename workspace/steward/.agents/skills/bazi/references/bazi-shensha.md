> 本文档是八字技能——`bazi` skill神煞模块的内部参考。
> 收录主流 **34 种** 神煞（v2.2.0 由 28 神煞扩展），按功能分 10 类，给出查表依据、查表规则、大白话解释、吉凶倾向与组合影响。

### 0.4 核心原则：一体两面 v2.1.0 新增

> **神煞从来都是一体两面的。好坏同体。** —— 老板 2026-08-08 04:53 拍板

- 任何神煞**无绝对吉凶**——同一颗星同时具备**阳面——正向**与**阴面——负向**，二者互为表里
- 传统断吉凶——贴"吉/凶"标签是**断章取义**——只看一面
- 实际吉凶取决于**激活条件 + 制化机制 + 命局组合**，不取决于神煞本身
- 本原则贯穿全文：§2 各神煞详解、§4 用法约束、工具输出规范均须遵守
- 详见 §4.0 一体两面原则

## 二、各神煞详解

### 2.A 贵人星类

#### 2.A.1 天乙贵人
- **查表依据**：日干
- **吉凶**：吉——最强的贵人星
- **大白话**：命里遇到天乙贵人，相当于自带"高级人脉"。遇急难时有人出手相助，适合靠关系办大事的人。**最忌刑冲**——天乙遇冲则贵人失力。
- **阳贵阴贵**：阳日——甲丙戊庚壬取阳贵——前一字，阴日——乙丁己辛癸取阴贵——后一字。实务中二者皆可用。

#### 4.0.1 原则核心

每颗神煞都同时具备 **阳面——正向** 与 **阴面——负向** 两种属性，二者一体两面、互为表里：

- **阳面**：该神煞的吉象表现
- **阴面**：该神煞的凶象表现

#### 4.0.2 传统断吉凶的误区

传统命理习惯直接给神煞贴"吉/凶"标签，如"羊刃 = 大凶"、"天乙 = 大吉"，这是**断章取义**——只看了一面。

正确看法：
- 神煞本身**无绝对吉凶**
- 吉凶取决于：**激活条件 + 制化机制 + 命局组合**
- 例：羊刃 + 身旺 = 大贵——将军之刃；羊刃 + 身弱 = 大凶
- 例：桃花 + 贵人带 = 艺术天赋；桃花 + 煞星同临 = 烂桃花
- 例：驿马 + 食伤生财 = 动则得财；驿马 + 身弱 = 奔波劳碌

#### 4.0.3 解读规范

任何神煞解读**必须两面同列**，禁止单面断吉凶：

1. **列出阳面**：该神煞的吉象表现
2. **列出阴面**：该神煞的凶象表现
3. **说明激活条件**：什么情况下触发阳面 / 阴面
4. **说明制化机制**：施药 / 食神 / 贵人对冲凶力

### 4.1 神煞与格局的优先级

> **神煞是辅助参考，格局才是核心。** —— `bazi-style.md` §一 排版美学

- 神煞不能用来"判定吉凶"——必须**结合格局、施药、十神组合**才有意义
- 例：身旺者逢驿马 = 动则得财；身弱者逢驿马 = 奔波劳碌
- 例：正官格逢天乙 = 大贵；伤官格逢天乙 = 助力减弱
- 例：羊刃 + 身旺 = 大贵；羊刃 + 身弱 = 大凶

### 4.2 神煞与流年 / 流月的互动

- 神煞在原局——命主四柱出现 = 先天禀赋
- 流年 / 流月命主位置柱遇到神煞位 = **该年 / 月**该神煞被激活
- 例：原局无桃花，流年日支走到桃花位 = 该年异性缘突增——"桃花年"
- 例：原局无丧门，流年日支走到丧门位 = 该年易有丧事
