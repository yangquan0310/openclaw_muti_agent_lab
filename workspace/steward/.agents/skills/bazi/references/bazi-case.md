## 案例统一流程（2026-08-18 19:08 拍板）

> **每一个 case 都必须走这个流程**：

```
① 定格 → ② 旺衰 → ③ 流通核心堵点
```

| 阶段 | 内容 |
|:---|:---|
| **① 定格** | 先定格局——月令透干定格（正格/七杀格/财格等）|
| **② 旺衰** | 再看旺衰——四维度判定身强/身弱 |
| **③ 流通核心堵点** | 最后看流通——找核心堵点 |

**具体事项聚焦**（流通阶段）：

- 如果需要解决**具体事项**——**分析该事项的堵点**，其他事项同理：

| 事项 | 聚焦堵点 | 依据 |
|:---|:---|:---|
| **姻缘** | 分析**姻缘堵点**（日支/夫妻宫 + 夫妻星）| `bazi-liutong.md` §1.1.1 应用聚焦层 |
| **事业** | 分析**事业堵点**（月支/事业宫 + 官杀）| 同上 |
| **财运** | 分析**财堵点**（财星 + 财库）| 同上 |
| **健康** | 分析**健康堵点**（对应脏腑五行）| 同上 |
| **性格** | 分析**性格堵点**（日主 + 十神组合）| 同上 |
| **无具体事项** | 分析**命局核心堵点**（日主整体）| 默认模式 |

> **流程不变，只有聚焦点变**——定格/旺衰固定，流通阶段按事项换中心（应用聚焦层）。

## 案例一：（丙子 辛卯 丙午 丁酉）——身旺无克泄，比劫夺财终身课题

- **日期**：2026-08-18
- **来源**：实战提问——"分析一下我的"（19:23）→ 19:28 "地支一团刑冲破" → 19:44 "身旺需克泄，年干辛金和日支土需要发挥！但辛金被比肩克，酉金被丁午克。午被子冲，被卯破。只能被午和丁劫财。这是我最大的问题" → 19:58/19:59 "用神？" → 20:04 "更新相关内容"

### 1. 排盘

```
年柱 丙子 月柱 辛卯 日柱 丙午 时柱 丁酉
比肩 正官 正财 正印 日主 劫财 劫财 正财
```

- **日主**：丙火（太阳之火）
- **月令**：卯（春月，惊蛰后 5 天）
- **地支藏干**：
 - 年支子：癸（正官）
 - 月支卯：乙（正印）
 - 日支午：丁（劫财）己（食神）
 - 时支酉：辛（正财）

### 2. 分析顺序

#### 2.1 先定格：**正印格**

- 月支卯本气乙木（正印）当令 → **正印格**（本气未透干，主流口径）
- 体用方向：**金水**（财 + 官）
- 相神：财星 · 忌神：木火 · 仇神：水
- 破格隐患：丙丙丁三比劫帮身 → **印太旺无制**
- 救应：辛卯正财 → 财星生扶格局

#### 2.2 再看旺衰：**3/3 极旺**（v2.2.3 起改为 3 维度——得令/得地/得助；考虑从强但不取）

- 得令 ✅（丙火在**卯月** = **沐浴**——12 长生 ∈ 长生~帝旺区间 ✓）
- 得地 ✅（午为丙火羊刃）
- 得助 ✅（卯木印星 + 丙丙丁三比劫——v2.2.3 起印星并入得助）
- **不取从强**：命中官杀/食伤有根（子中癸水官、酉中辛金财、午中己土食伤）——有克泄不从

#### 2.3 最后看流通核心堵点：**克泄耗三路全断**

> **原话**："身旺需克泄，年干辛金和日支土需要发挥！但辛金被比肩克，酉金被丁午克。午被子冲，被卯破。只能被午和丁劫财。这是我最大的问题。"

**核心堵点**：身旺（3/3）需克泄，但克泄耗三路全断：

| 路 | 本应发挥 | 被谁破坏 | 结果 |
|:---|:---|:---|:---|
| **克**（官杀水）| 子水制午丁劫财 | 子午冲（自损）+ 子卯刑（被木耗）| 官星自身不稳，制劫力打折 |
| **泄**（食伤土）| 午中己土泄身 | 午**被子冲 + 被卯破**（论破不论生）| 泄路断 |
| **耗**（财星金）| 辛酉金耗身 | 辛**被丙合绊**、酉**被丁午克 + 被卯酉冲** | 财星全废 |

**5 个生效地支破坏点**（按 `bazi-rules.md` §5 距离规则）：

|:---|:---|:---:|:---|

| — | **子酉破**（年-时）| 隔两柱 | 破只临近生效——**不直接作用** |

**+ 2 个天干破坏点**：

| # | 关系 | 效果 |
|:---|:---|:---|

**结果链**：

```
身旺（3/3）需克泄
　├ 克（官杀水）→ 子水被冲刑 → 官星不稳 ❌
　├ 泄（食伤土）→ 午中己土被冲破 → 泄路断 ❌
　└ 耗（财星金）→ 辛合、酉克冲 → 财星全废 ❌
　　↓
　　只剩午丁劫财帮身 → 比劫夺财终身课题
```

### 3. 用神推导

#### 3.1 调候（`bazi-tiyong.md` §3.2 速查表）——丙火春月

### 5. 一句话结论

> **用神 = 金水，壬水第一（调候+制劫双用），庚辛次之（耗身聚财）；忌木火。命中金水被合克冲破，全靠大运流年补——金水运发，木火运破财。**
