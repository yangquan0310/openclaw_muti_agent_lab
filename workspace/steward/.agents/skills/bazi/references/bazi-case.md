## 案例一：庚辰 甲申 甲子 庚午——杀印相生 + 子午冲（调候被灭）

- **日期**：2026-08-18
- **来源**：老板实战提问——"庚辰 甲申 甲子 庚午，辰申子三合水，年柱杀印相生，子水冲了午，庚杀身，调候喜丁火，子午冲需用木通关，你觉得应该怎么施药？"

### 1. 排盘

```
年柱 庚辰    月柱 甲申    日柱 甲子    时柱 庚午
七杀 偏印库  比肩 七杀    日主 偏印    七杀 伤官
```

- **日主**：甲木，生申月（失令）
- **藏干**：
  - 年支辰：戊（本气）乙（中气）癸（余气）
  - 月支申：庚（本气）壬（中气）戊（余气）
  - 日支子：癸（独藏）
  - 时支午：丁（本气）己（中气）

### 2. 结构分析

| # | 结构 | 性质 |
|:---|:---|:---|
| ① | **申子辰三合水局**（年辰 + 月申 + 日子）| 印旺化杀 ✅ 但水寒木漂 ⚠️ |
| ② | **年柱杀印相生**（庚 → 辰中癸 → 甲）| 杀有化，不攻身 ✅ |
| ③ | **子午冲**（日子 vs 时午）| 印冲伤官——**丁火调候被灭** ❌ |
| ④ | **两庚夹甲**（年时双七杀）| 杀重——制杀力靠午火，但午被子冲 |

> **核心死结**：午火（调候 + 制杀）被子水冲掉 → 杀无制、局无暖 → 全盘靠水局化杀，但水多木漂。

### 3. 调候

| 项 | 值 | 依据 |
|:---|:---|:---|
| 甲木申月（秋月）| **丁火 + 壬水——先丁后壬** | `bazi-shiyao.md` §3.2 速查表 |
| 命局实际 | 丁火在午中，**被子水冲灭**；壬水由三合水局自备 | — |

> **关键**：调候第一丁火被冲——救丁火 = 施药第一目标。

### 4. 施药链（老板拍板方向 + 推演）

#### 第一用神：**木（寅 / 卯 / 甲）**

```
子水 ──生──→ 木 ──生──→ 午火
(印)         (通关)       (伤官/调候)
```

| 木的三重作用 | 效果 |
|:---|:---|
| **通关** | 化解子午冲——水不直冲火，改生木、木生火 |
| **帮身** | 甲木失令身弱——比劫助身 |
| **生火** | 午火恢复 → 丁火暖局 + 伤官制杀都活了 |

#### 第二用神：**火（丙 / 丁）**

- 木生火后，**丁火制杀 + 暖局**——补足调候
- 但火不能直接加（再遇水仍冲）——**必须先有木，火才有根**

#### 忌神

| 忌 | 原因 |
|:---|:---|
| **金**（庚辛申酉）| 杀更重，两庚已夹身 |
| **水**（亥子）| 三合已旺——再添更寒更漂 |
| **燥土**（戌）| 戌冲辰——破水局又晦火 |

### 5. 一句话结论

> **用木通关（第一），木生火制杀（第二）——"木火"为用；忌金水再添，慎燥土冲辰。**

### 6. 大运应期

| 大运 | 吉凶 | 理由 |
|:---|:---:|:---|
| **寅卯木运** | ✅ 最佳 | 通关帮身 |
| **丙丁巳午火运** | ✅ | 制杀暖局（午运是调候应期，子午冲在此运应事）|
| **庚辛申酉运** | ❌ | 杀重 |
| **亥子运** | ❌ | 水泛木漂 |
