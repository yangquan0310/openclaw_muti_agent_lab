## 案例统一流程（老板 2026-08-18 19:08 拍板）

> **每一个 case 都必须走这个流程**：

```
① 定格 → ② 旺衰 → ③ 流通核心堵点
```

| 阶段 | 内容 |
|:---|:---|
| **① 定格** | 先定格局——月令透干定格（正格/七杀格/财格等）|
| **② 旺衰** | 再看旺衰——四维度判定身强/身弱 |
| **③ 流通核心堵点** | 最后看流通——找核心堵点 |

**具体事项聚焦**（流通阶段）：

- 如果需要解决**具体事项**——**分析该事项的堵点**，其他事项同理：

| 事项 | 聚焦堵点 | 依据 |
|:---|:---|:---|
| **姻缘** | 分析**姻缘堵点**（日支/夫妻宫 + 夫妻星）| `bazi-liutong.md` §1.1.1 应用聚焦层 |
| **事业** | 分析**事业堵点**（月支/事业宫 + 官杀）| 同上 |
| **财运** | 分析**财堵点**（财星 + 财库）| 同上 |
| **健康** | 分析**健康堵点**（对应脏腑五行）| 同上 |
| **性格** | 分析**性格堵点**（日主 + 十神组合）| 同上 |
| **无具体事项** | 分析**命局核心堵点**（日主整体）| 默认模式 |

> **流程不变，只有聚焦点变**——定格/旺衰固定，流通阶段按事项换中心（应用聚焦层）。

## 案例一：杨权（丙子 辛卯 丙午 丁酉）——身旺无克泄，比劫夺财终身课题

- **日期**：2026-08-18
- **来源**：老板实战提问——"分析一下我的"（19:23）→ 19:28 "地支一团刑冲破" → 19:44 "身旺需克泄，年干辛金和日支土需要发挥！但辛金被比肩克，酉金被丁午克。午被子冲，被卯破。只能被午和丁劫财。这是我最大的问题" → 19:58/19:59 "用神？" → 20:04 "更新相关内容"

### 1. 排盘

```
年柱 丙子    月柱 辛卯    日柱 丙午    时柱 丁酉
比肩 正官    正财 正印    日主 劫财    劫财 正财
```

- **日主**：丙火（太阳之火）
- **月令**：卯（春月，惊蛰后 5 天）
- **地支藏干**：
  - 年支子：癸（正官）
  - 月支卯：乙（正印）
  - 日支午：丁（劫财）己（食神）
  - 时支酉：辛（正财）

### 2. 分析顺序

#### 2.1 先定格：**正印格**

- 月支卯本气乙木（正印）当令 → **正印格**（本气未透干，主流口径）
- 施药方向：**金水**（财 + 官）
- 相神：财星 · 忌神：木火 · 仇神：水
- 破格隐患：丙丙丁三比劫帮身 → **印太旺无制**
- 救应：辛卯正财 → 财星生扶格局

#### 2.2 再看旺衰：**3/3 极旺**（v2.2.3 起改为 3 维度——得令/得地/得助；考虑从强但不取）

- 得令 ✅（卯月印当令，木生火）
- 得地 ✅（午为丙火羊刃）
- 得助 ✅（卯木印星 + 丙丙丁三比劫——v2.2.3 起印星并入得助）
- **不取从强**：命中官杀/食伤有根（子中癸水官、酉中辛金财、午中己土食伤）——有克泄不从

#### 2.3 最后看流通核心堵点：**克泄耗三路全断**

> **老板原话**："身旺需克泄，年干辛金和日支土需要发挥！但辛金被比肩克，酉金被丁午克。午被子冲，被卯破。只能被午和丁劫财。这是我最大的问题。"

**核心堵点**：身旺（3/3）需克泄，但克泄耗三路全断：

| 路 | 本应发挥 | 被谁破坏 | 结果 |
|:---|:---|:---|:---|
| **克**（官杀水）| 子水制午丁劫财 | 子午冲（自损）+ 子卯刑（被木耗）| 官星自身不稳，制劫力打折 |
| **泄**（食伤土）| 午中己土泄身 | 午**被子冲 + 被卯破**（论破不论生）| 泄路断 |
| **耗**（财星金）| 辛酉金耗身 | 辛**被丙合绊**、酉**被丁午克 + 被卯酉冲** | 财星全废 |

**5 个生效地支破坏点**（按 `bazi-rules.md` §5 距离规则）：

| # | 关系 | 距离 | 依据 |
|:---|:---|:---:|:---|
| ① | **子午冲**（年-日）| 隔一柱（冲无视距离）| §5.2 六冲 |
| ② | **卯酉冲**（月-时）| 隔一柱（冲无视距离）| §5.2 六冲 |
| ③ | **子卯刑**（年-月）| 相邻 | §5.5 无礼之刑 |
| ④ | **卯午破**（月-日）| 相邻 | §5.6 六破——论破不论生 |
| ⑤ | **午火克酉金**（日-时）| 相邻 | §5.6 普通相克（v3.4.3 修正）|
| — | **子酉破**（年-时）| 隔两柱 | 破只临近生效——**不直接作用** |

**+ 2 个天干破坏点**：

| # | 关系 | 效果 |
|:---|:---|:---|
| ⑥ | **丙辛合绊**（年干丙 ↔ 月干辛）| 天干五合，财星被合走 |
| ⑦ | **丁火盖头克酉金**（时干丁克时支酉）| 同柱劫财克财 |

**结果链**：

```
身旺（3/3）需克泄
　├ 克（官杀水）→ 子水被冲刑 → 官星不稳 ❌
　├ 泄（食伤土）→ 午中己土被冲破 → 泄路断 ❌
　└ 耗（财星金）→ 辛合、酉克冲 → 财星全废 ❌
　　↓
　　只剩午丁劫财帮身 → 比劫夺财终身课题
```

### 3. 用神推导（调候 × 扶抑 融合）

#### 3.1 调候（`bazi-shiyao.md` §3.2 速查表）——丙火春月

| 日主 | 春月——寅卯辰 |
|:---|:---|
| **丙** | **壬水——第一** |

#### 3.2 扶抑——身旺需克泄

| 治法 | 五行 | 命中有 |
|:---|:---|:---|
| 克 | 水（官杀）| 子水——但被冲刑 |
| 泄 | 土（食伤）| 午中己土——但被冲破 |
| 耗 | 金（财星）| 辛酉——但被合克 |

#### 3.3 融合用神

> **用神 = 金水——壬水第一（调候 + 官杀制比劫双满足），庚辛次之（财星耗身）**

| 用神 | 作用 |
|:---|:---|
| **壬水**（第一）| 调候暖局 + 官杀制比劫——一神两用，**核心用神** |
| **庚辛金**（次之）| 财星耗身 + 制印（金克木）|
| **土**（辅助）| 食伤泄身生财——但命中无明土，借大运 |

#### 3.4 忌神

- **木火**（印比）——助身更旺，大忌
- 卯木印星、午丁劫财——原局已是忌，大运再遇木火 = 凶

### 4. 🚨 用神"命中有但全废"——死结与突破

```
用神 = 金水（壬水 + 庚辛）
但命中的金水：辛被合、酉被克冲、子被冲刑
→ 原局用神无力
→ 只能靠大运流年补金水
```

| 应期 | 吉凶 |
|:---|:---|
| **金水大运**（申酉亥子 + 庚辛壬癸）| ✅ 用神到位——制比劫、耗身、聚财 |
| **木火大运**（寅卯巳午 + 甲乙丙丁）| ❌ 忌神——比劫更旺，破财 |
| **土运**（辰戌丑未）| ⚠️ 食伤泄身——吉中带滞（土生金可通关）|

### 5. 一句话结论

> **用神 = 金水，壬水第一（调候+制劫双用），庚辛次之（耗身聚财）；忌木火。命中金水被合克冲破，全靠大运流年补——金水运发，木火运破财。**

## 案例二：王雅欣（戊寅 己未 甲子 己巳）——身弱不担财，印生路径被枭神夺食

- **日期**：2026-08-18
- **来源**：老板实战分析——"王雅欣的案例先分析"（20:28）→ "今占60%，地占30，助找10%，她是身中等偏弱。财太多，身弱不担财。她需要生扶，需要印，需要比肩。你分析下地支相互作用，她的生扶路径是否被堵？"（20:34）→ "枭神夺食的重点是印去克财，影响印生身，尤其在她身弱时候"（20:37）→ "而且因为子巳暗合，所以发生的枭神夺食！"（20:39）→ "按照这个逻辑整理 / 她身中等偏弱，需要生扶 / 印生路径被枭神夺食加未破子。只有年支根帮生。所以她的问题是身弱不担财"（20:42）→ "你把案例一同样的逻辑改成案例三 / 杨权案例一 / 王雅欣案例二"（20:43）

### 1. 排盘

```
年柱 戊寅    月柱 己未    日柱 甲子    时柱 己巳
偏财 比肩    正财 正财    日主 正印    正财 食神
```

- **日主**：甲木（小暑后 9 天）
- **地支藏干**：
  - 年支寅：甲（本气）丙 戊
  - 月支未：己（本气）丁 乙
  - 日支子：癸（独藏）
  - 时支巳：丙（本气）戊 庚

### 2. 分析顺序

#### 2.1 先定格：**正财格**

- 月支未本气己土（正财）当令 → **正财格**
- 施药方向：**火金**（食伤泄秀 + 官杀护财）
- 三己土财星透干（月干+时干），正财格成立

#### 2.2 再看旺衰：**40% 中偏弱**（v2.2.5 加权打分——令 60%×0 + 地 30%×1 + 助 10%×1 = 40%）

| 维度 | 判定 | 解读 |
|:---|:---:|:---|
| 得令 | ✗ | 未月土旺当令，不生甲木——**失令** |
| 得地 | ✓ | **日支子水生日主甲木**（水生木）——**日支生日主也算得地**（v2.2.3.bug 修） |
| 得助 | ✓ | 年支寅（比肩）+ 子水（印星）扶身——**印比合并为得助** |

→ **40% 中偏弱**（按 v2.2.5 加权打分——老板原话『不是中偏旺，就是中偏弱』）——综合判定：身中等偏弱（印生路径被枭神夺食 + 子未害双重折扣，比肩寅木独木难支）

#### 2.3 最后看流通核心堵点：**印生路径被枭神夺食 + 子未害**

> **老板原话**："她身中等偏弱，需要生扶。印生路径被枭神夺食加未破子。只有年支根帮生。所以她的问题是身弱不担财。"

**核心问题结构**（按杨权核心问题同款框架）：

```
身中等偏弱（1/3）需生扶
├ 生（印水）→ 子被子巳暗合枭神夺食 + 子未害 → 印生身路径全废 ❌
├ 扶（比肩木）→ 寅本气甲直接帮身，寅克未（财）也算制衡 ✅
└ 调候用癸水（藏子中）也受波及 ❌
↓
只剩寅（年支根）帮生扶 → 身弱不担财
```

**核心堵点：印生身路径被三重破坏**

| 层 | 破坏 | 启动条件 | 影响 |
|:---|:---|:---|:---|
| **第 1 层** | **子巳暗合**（盲派/部分流派）| 印与食"亲缘建立" | **枭神夺食的启动条件** |
| **第 2 层** | **子克巳**（印克食神）| 子水（印）克巳火（食神/丙）| 食神被夺取——食伤系统瘫痪 |
| **第 3 层** | **子未害** | 未中正财暗中克印 | 印的总量被消耗——扶身能量折扣 |

> **老板核心洞察**："枭神夺食的重点是印去克财，影响印生身，尤其在她身弱时候"——子克巳中丙（食神）+ 戊（偏财）+ 庚（七杀）——**印被分流去克财/克食，不能专一扶身**。

**5 个生效地支作用 + 1 个不生效**：

| # | 关系 | 距离 | 性质 | 对生扶的影响 |
|:---|:---|:---:|:---|:---|
| ① | **子未害**（日-月）| 相邻 | 印被财暗中克制 | ⚠️ 印扶身路径被暗中破坏 |
| ② | **子克巳**（日-时）| 相邻 | **枭神夺食** | ⚠️⚠️ 食伤被堵——食伤不能生财泄秀 |
| ③ | 寅克未（年-月）| 相邻 | 比劫克财 | ✅ 财多反得制——比肩发挥 |
| ④ | 寅生子（年-日）| 隔一柱 | 比生印 | ✅ 印得微弱扶助 |
| ⑤ | 巳生未（月-时）| 隔一柱 | 食生财 | ✅ 食伤生财通路 |
| — | **寅巳刑**（年-时）| 隔两柱 | 刑只临近 | ❌ **不直接作用**（寅巳申缺申不成刑）|

### 3. 用神推导（调候 × 扶抑 融合）

#### 3.1 调候（`bazi-shiyao.md` §3.2 速查表）——甲木夏月

| 日主 | 夏月——巳午未 |
|:---|:---|

| 用神 | 作用 | 状态 |
|:---|:---|:---|

### 4. 大运应期

## 案例三：庚辰 甲申 甲子 庚午——杀印相生 + 子午冲（调候被灭）

- **日期**：2026-08-18
- **来源**：老板实战提问——"庚辰 甲申 甲子 庚午，辰申子三合水，年柱杀印相生，子水冲了午，庚杀身，调候喜丁火，子午冲需用木通关，你觉得应该怎么施药？"

### 1. 排盘

```
年柱 庚辰    月柱 甲申    日柱 甲子    时柱 庚午
七杀 偏印库  比肩 七杀    日主 偏印    七杀 伤官
```

- **日主**：甲木，生申月（失令）
- **藏干**：
  - 年支辰：戊（本气）乙（中气）癸（余气）
  - 月支申：庚（本气）壬（中气）戊（余气）
  - 日支子：癸（独藏）
  - 时支午：丁（本气）己（中气）

### 2. 分析顺序（先格局 → 再旺衰 → 后流通核心堵点）

> **老板 2026-08-18 19:05 拍板分析顺序**：先定格局，再看旺衰，最后看流通核心堵点。

#### 2.1 先定格局：**七杀格**

- 月令申中**庚金七杀当令** + 年干庚 + 时干庚——**七杀双透**，格成七杀
- 依据：`bazi-zhengge.md`——月令透干定格

#### 2.2 再看旺衰：**身弱**

- 甲木生申月**失令** + 两庚七杀克身 → **身弱**
- 依据：`bazi-wangshuai.md` §3.1 得令判定

#### 2.3 最后看流通核心堵点：**两个**

| # | 堵点 | 性质 |
|:---|:---|:---|
