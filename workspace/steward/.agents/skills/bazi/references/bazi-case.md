# 八字案例库

> **本文件按案例一个一个存储**——每个实战命例一个独立章节，含完整排盘、结构分析、调候、施药链。
>
> **案例来源**：老板实战提问 / 真实命例解读 / 方法论验证。
>
> **与 references 其他文档的关系**：
> - 规则依据 → `bazi-rules.md`（内容层）
> - 解读流程 → `bazi-paipan.md`（应用层主入口）
> - 施药逻辑 → `bazi-shiyao.md`（调候/抑扶/通关/对症）

## 案例统一流程（老板 2026-08-18 19:08 拍板）

> **每一个 case 都必须走这个流程**：

```
① 定格 → ② 旺衰 → ③ 流通核心堵点
```

| 阶段 | 内容 |
|:---|:---|
| **① 定格** | 先定格局——月令透干定格（正格/七杀格/财格等）|
| **② 旺衰** | 再看旺衰——四维度判定身强/身弱 |
| **③ 流通核心堵点** | 最后看流通——找核心堵点 |

**具体事项聚焦**（流通阶段）：

- 如果需要解决**具体事项**——**分析该事项的堵点**，其他事项同理：

| 事项 | 聚焦堵点 | 依据 |
|:---|:---|:---|
| **姻缘** | 分析**姻缘堵点**（日支/夫妻宫 + 夫妻星）| `bazi-liutong.md` §1.1.1 应用聚焦层 |
| **事业** | 分析**事业堵点**（月支/事业宫 + 官杀）| 同上 |
| **财运** | 分析**财堵点**（财星 + 财库）| 同上 |
| **健康** | 分析**健康堵点**（对应脏腑五行）| 同上 |
| **性格** | 分析**性格堵点**（日主 + 十神组合）| 同上 |
| **无具体事项** | 分析**命局核心堵点**（日主整体）| 默认模式 |

> **流程不变，只有聚焦点变**——定格/旺衰固定，流通阶段按事项换中心（应用聚焦层）。

## 案例一：庚辰 甲申 甲子 庚午——杀印相生 + 子午冲（调候被灭）

- **日期**：2026-08-18
- **来源**：老板实战提问——"庚辰 甲申 甲子 庚午，辰申子三合水，年柱杀印相生，子水冲了午，庚杀身，调候喜丁火，子午冲需用木通关，你觉得应该怎么施药？"

### 1. 排盘

```
年柱 庚辰    月柱 甲申    日柱 甲子    时柱 庚午
七杀 偏印库  比肩 七杀    日主 偏印    七杀 伤官
```

- **日主**：甲木，生申月（失令）
- **藏干**：
  - 年支辰：戊（本气）乙（中气）癸（余气）
  - 月支申：庚（本气）壬（中气）戊（余气）
  - 日支子：癸（独藏）
  - 时支午：丁（本气）己（中气）

### 2. 分析顺序（先格局 → 再旺衰 → 后流通核心堵点）

> **老板 2026-08-18 19:05 拍板分析顺序**：先定格局，再看旺衰，最后看流通核心堵点。

#### 2.1 先定格局：**七杀格**

- 月令申中**庚金七杀当令** + 年干庚 + 时干庚——**七杀双透**，格成七杀
- 依据：`bazi-zhengge.md`——月令透干定格

#### 2.2 再看旺衰：**身弱**

- 甲木生申月**失令** + 两庚七杀克身 → **身弱**
- 依据：`bazi-wangshuai.md` §3.1 得令判定

#### 2.3 最后看流通核心堵点：**两个**

| # | 堵点 | 性质 |
|:---|:---|:---|
| ① | **子冲午**（日子 vs 时午）| 印冲伤官——**丁火调候被灭** ❌ |
| ② | **时干杀身**（时庚贴身克甲）| 七杀贴身无制 ❌ |

> **核心死结**：午火（调候 + 制杀）被子水冲灭 + 时干杀身 → 杀无制、局无暖 → 全盘靠水局化杀，但水多木漂。

#### 2.4 施药：**用木通关**

```
子水 ──生──→ 木 ──生──→ 午火
(印)         (通关)       (伤官/调候)
```

| 木的三重作用 | 效果 |
|:---|:---|
| **通关** | 化解子午冲——水不直冲火，改生木、木生火 |
| **帮身** | 甲木身弱——比劫助身 |
| **生火** | 午火恢复 → 丁火暖局 + 伤官制杀都活了 |

### 3. 调候

| 项 | 值 | 依据 |
|:---|:---|:---|
| 甲木申月（秋月）| **丁火 + 壬水——先丁后壬** | `bazi-shiyao.md` §3.2 速查表 |
| 命局实际 | 丁火在午中，**被子水冲灭**；壬水由三合水局自备 | — |

> **关键**：调候第一丁火被冲——救丁火 = 施药第一目标。

### 4. 施药链（老板拍板方向 + 推演）

#### 第一用神：**木（寅 / 卯 / 甲）**

```
子水 ──生──→ 木 ──生──→ 午火
(印)         (通关)       (伤官/调候)
```

| 木的三重作用 | 效果 |
|:---|:---|
| **通关** | 化解子午冲——水不直冲火，改生木、木生火 |
| **帮身** | 甲木失令身弱——比劫助身 |
| **生火** | 午火恢复 → 丁火暖局 + 伤官制杀都活了 |

#### 第二用神：**火（丙 / 丁）**

- 木生火后，**丁火制杀 + 暖局**——补足调候
- 但火不能直接加（再遇水仍冲）——**必须先有木，火才有根**

#### 忌神

| 忌 | 原因 |
|:---|:---|
| **金**（庚辛申酉）| 杀更重，两庚已夹身 |
| **水**（亥子）| 三合已旺——再添更寒更漂 |
| **燥土**（戌）| 戌冲辰——破水局又晦火 |

### 5. 一句话结论

> **用木通关（第一），木生火制杀（第二）——"木火"为用；忌金水再添，慎燥土冲辰。**

### 6. 大运应期

| 大运 | 吉凶 | 理由 |
|:---|:---:|:---|
| **寅卯木运** | ✅ 最佳 | 通关帮身 |
| **丙丁巳午火运** | ✅ | 制杀暖局（午运是调候应期，子午冲在此运应事）|
| **庚辛申酉运** | ❌ | 杀重 |
| **亥子运** | ❌ | 水泛木漂 |

## 案例二：杨权（丙子 辛卯 丙午 丁酉）——身旺无克泄，比劫夺财终身课题

- **日期**：2026-08-18
- **来源**：老板实战提问——"分析一下我的"（19:23）→ 19:28 "地支一团刑冲破" → 19:44 "身旺需克泄，年干辛金和日支土需要发挥！但辛金被比肩克，酉金被丁午克。午被子冲，被卯破。只能被午和丁劫财。这是我最大的问题" → 19:58/19:59 "用神？" → 20:04 "更新相关内容"

### 1. 排盘

```
年柱 丙子    月柱 辛卯    日柱 丙午    时柱 丁酉
比肩 正官    正财 正印    日主 劫财    劫财 正财
```

- **日主**：丙火（太阳之火）
- **月令**：卯（春月，惊蛰后 5 天）
- **地支藏干**：
  - 年支子：癸（正官）
  - 月支卯：乙（正印）
  - 日支午：丁（劫财）己（食神）
  - 时支酉：辛（正财）

### 2. 分析顺序

#### 2.1 先定格：**正印格**

- 月支卯本气乙木（正印）当令 → **正印格**（本气未透干，主流口径）
- 施药方向：**金水**（财 + 官）
- 相神：财星 · 忌神：木火 · 仇神：水
- 破格隐患：丙丙丁三比劫帮身 → **印太旺无制**
- 救应：辛卯正财 → 财星生扶格局

#### 2.2 再看旺衰：**3/3 极旺**（v2.2.3 起改为 3 维度——得令/得地/得助；考虑从强但不取）

- 得令 ✅（卯月印当令，木生火）
- 得地 ✅（午为丙火羊刃）
- 得助 ✅（卯木印星 + 丙丙丁三比劫——v2.2.3 起印星并入得助）
- **不取从强**：命中官杀/食伤有根（子中癸水官、酉中辛金财、午中己土食伤）——有克泄不从

#### 2.3 最后看流通核心堵点：**克泄耗三路全断**

> **老板原话**："身旺需克泄，年干辛金和日支土需要发挥！但辛金被比肩克，酉金被丁午克。午被子冲，被卯破。只能被午和丁劫财。这是我最大的问题。"

**核心堵点**：身旺（3/3）需克泄，但克泄耗三路全断：

| 路 | 本应发挥 | 被谁破坏 | 结果 |
|:---|:---|:---|:---|
| **克**（官杀水）| 子水制午丁劫财 | 子午冲（自损）+ 子卯刑（被木耗）| 官星自身不稳，制劫力打折 |
| **泄**（食伤土）| 午中己土泄身 | 午**被子冲 + 被卯破**（论破不论生）| 泄路断 |
| **耗**（财星金）| 辛酉金耗身 | 辛**被丙合绊**、酉**被丁午克 + 被卯酉冲** | 财星全废 |

**5 个生效地支破坏点**（按 `bazi-rules.md` §5 距离规则）：

| # | 关系 | 距离 | 依据 |
|:---|:---|:---:|:---|
| ① | **子午冲**（年-日）| 隔一柱（冲无视距离）| §5.2 六冲 |
| ② | **卯酉冲**（月-时）| 隔一柱（冲无视距离）| §5.2 六冲 |
| ③ | **子卯刑**（年-月）| 相邻 | §5.5 无礼之刑 |
| ④ | **卯午破**（月-日）| 相邻 | §5.6 六破——论破不论生 |
| ⑤ | **午火克酉金**（日-时）| 相邻 | §5.6 普通相克（v3.4.3 修正）|
| — | **子酉破**（年-时）| 隔两柱 | 破只临近生效——**不直接作用** |

**+ 2 个天干破坏点**：

| # | 关系 | 效果 |
|:---|:---|:---|
| ⑥ | **丙辛合绊**（年干丙 ↔ 月干辛）| 天干五合，财星被合走 |
| ⑦ | **丁火盖头克酉金**（时干丁克时支酉）| 同柱劫财克财 |

**结果链**：

```
身旺（3/3）需克泄
　├ 克（官杀水）→ 子水被冲刑 → 官星不稳 ❌
　├ 泄（食伤土）→ 午中己土被冲破 → 泄路断 ❌
　└ 耗（财星金）→ 辛合、酉克冲 → 财星全废 ❌
　　↓
　　只剩午丁劫财帮身 → 比劫夺财终身课题
```

### 3. 用神推导（调候 × 扶抑 融合）

#### 3.1 调候（`bazi-shiyao.md` §3.2 速查表）——丙火春月

| 日主 | 春月——寅卯辰 |
|:---|:---|
| **丙** | **壬水——第一** |

#### 3.2 扶抑——身旺需克泄

| 治法 | 五行 | 命中有 |
|:---|:---|:---|
| 克 | 水（官杀）| 子水——但被冲刑 |
| 泄 | 土（食伤）| 午中己土——但被冲破 |
| 耗 | 金（财星）| 辛酉——但被合克 |

#### 3.3 融合用神

> **用神 = 金水——壬水第一（调候 + 官杀制比劫双满足），庚辛次之（财星耗身）**

| 用神 | 作用 |
|:---|:---|
| **壬水**（第一）| 调候暖局 + 官杀制比劫——一神两用，**核心用神** |
| **庚辛金**（次之）| 财星耗身 + 制印（金克木）|
| **土**（辅助）| 食伤泄身生财——但命中无明土，借大运 |

#### 3.4 忌神

- **木火**（印比）——助身更旺，大忌
- 卯木印星、午丁劫财——原局已是忌，大运再遇木火 = 凶

### 4. 🚨 用神"命中有但全废"——死结与突破

```
用神 = 金水（壬水 + 庚辛）
但命中的金水：辛被合、酉被克冲、子被冲刑
→ 原局用神无力
→ 只能靠大运流年补金水
```

| 应期 | 吉凶 |
|:---|:---|
| **金水大运**（申酉亥子 + 庚辛壬癸）| ✅ 用神到位——制比劫、耗身、聚财 |
| **木火大运**（寅卯巳午 + 甲乙丙丁）| ❌ 忌神——比劫更旺，破财 |
| **土运**（辰戌丑未）| ⚠️ 食伤泄身——吉中带滞（土生金可通关）|

### 5. 一句话结论

> **用神 = 金水，壬水第一（调候+制劫双用），庚辛次之（耗身聚财）；忌木火。命中金水被合克冲破，全靠大运流年补——金水运发，木火运破财。**
