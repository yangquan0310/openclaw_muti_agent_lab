## 〇、分析思维总纲（五步链）

> **🆕 v1.3.0 新增——2026-08-21 00:28-00:33 拍板**：旺衰并入第 1 步；总纲写入健康文档。
> **总纲（《滴天髓》）**："五行和者，一世无灾；血气乱者，平生多疾"——**健康 = 五行失衡 + 部位定位 + 应期触发**。

### 第 1 步 · 定五行全局 + 旺衰（星层：哪个系统有病）

**① 五行分布**：十天干 + 十二地支藏干全部折算五行，数出五大系统分布。

**② 每行旺衰**（12 长生 + 得令）：

- **过旺**（帝旺/临官 + 比劫多）→ 功能亢进
- **过弱**（绝/死/墓 + 无根）→ 功能不足
- **被克**（如金被火克）→ 系统受伤
- **被泄**（如木生火太多）→ 消耗过度
- **缺**（天干地支全无）→ 先天薄弱

**③ 日主强弱**（同套旺衰）：

- 身强 = 底子厚、能扛病，但过旺五行仍亢进
- 身弱 = 底子薄、易病，被克系统更虚

**④ 用神被冲克** = 直接发病（《滴天髓》"用神受伤则病"）
**⑤ 调候**：过寒 = 阳虚，过热 = 阴虚

→ **锁定"病五行"**：过旺/过弱/被克/被泄/缺的 + 用神受损的——**都是病**

> 文献：《金匮真言论》五行-脏腑-病位表（肝筋/心脉/脾肉/肺皮毛/肾骨）

### 第 2 步 · 定位（宫层：病在哪个部位）

- **四支定躯干**：年支=头 / 月支=胸肋 / 日支=腰腹（核心）/ 时支=下肢
- **天干定表里外显**：《三命通会》"甲头乙项丙肩求…壬胫癸足一身由"
- **地支定内藏**：《三命通会》"子属膀胱水道耳…酉中精血小肠藏"
- **阴阳分层**（《金匮真言论》）：外阳内阴 / 背阳腹阴 / 脏阴腑阳

### 第 3 步 · 宫星交互（核心：星落支 + 被作用 = 具体病）

对每个病五行：

1. **星落哪宫**：该行落在哪个地支 → 病位在哪段身体
2. **该支被什么作用**：冲=突发/合=锁定/刑=暗伤/害=阴损/破=消耗/克=压制/生=滋养（生太过=过旺病）
3. **关联开窍 + 病位**（《金匮真言论》）：病之在筋/脉/肉/皮毛/骨 + 开窍目/耳/口/鼻/二阴
4. **关联俞穴**（《金匮真言论》）：肝俞颈项 / 心俞胸胁 / 肺俞肩背 / 肾俞腰股 / 脾俞脊

### 第 4 步 · 应期（大运流年：何时病发）

- 大运/流年**冲**到病支 = 病发
- **合**动病支 = 病灶被引动（伏吟 = 部位被反复敲）
- **刑害破**到病支 = 慢性恶化期
- 病五行被**生扶** = 加重；被**制化** = 缓解
- 大运管 10 年基调，流年管当年触发

### 第 5 步 · 综合输出 + 不强解

**输出格式**（按 `bazi-style.md` §6.6 七节）：① 直接结论 → ② 宫层 → ③ 星层 → ④ 宫星交互 → ⑤ 过往 → ⑥ 大运流年应期 → ⑦ 当年专项（**无行动表**——2026-08-21 00:45 拍板）。

**不强解边界**：命理给倾向/体质/应期，不给医学诊断；具体病名/指标 → 正规体检；每条判断标依据（[依据: 内经] / [依据: 三命通会] / [依据: 滴天髓]）。

## 一、脏腑

> **这一章讲"星"——五行对应 5 大系统（星=脏腑系统）**

### 1.1 五行-脏腑-系统（星）

| 五行 | 脏腑 | 系统 | 易感疾病 |
|---|---|---|---|
| **木** | 肝胆 | 筋、眼睛、情绪 | 肝火旺、易怒、眼睛疲劳、抑郁 |
| **火** | 心脏、小肠 | 舌头、血液循环 | 心火旺、失眠、心血管、口舌生疮 |
| **土** | 脾胃 | 皮肤、肌肉、消化 | 脾胃虚、湿气、消化不良、皮肤病 |
| **金** | 肺、大肠 | 呼吸系统、皮肤 | 肺虚、咳嗽、皮肤病、便秘 |
| **水** | 肾、膀胱 | 泌尿、生殖系统 | 肾虚、水肿、泌尿问题、妇科/男科 |

**大白话**：先认清楚**你的 5 个系统哪个最弱**

### 1.1.1 天干-脏腑映射（《三命通会》口诀）

> **天干对应脏腑**（星的具体表达）——"以干为象（系统），以支为位（部位）"：

- **甲胆乙肝丙小肠，丁心戊胃己脾乡，庚是大肠辛属肺，壬系膀胱癸肾藏**
- 外肢：**甲头乙项丙肩求，丁心戊肋己属腹，庚是脐轮辛属股，壬胫癸足一身由**
- 例：癸水**日干** = 肾/泌尿/生殖核心信号区；丁火**月干** = 心脏/血液直接信号区

### 1.1.2 十二地支-脏腑映射（《三命通会》口诀）

> **地支对应具体器官**（部位内的细分）——宫星交互的底层：

- **子属膀胱水道耳，丑为胞肚及脾乡，寅胆发脉并两手，卯本十指内肝方**
- **辰土为脾肩胸肋，巳面咽齿下尻肛，午火精神司眼目，未土胃腕膈脊梁**
- **申金大肠经络肺，酉中精血小肠藏，戌土命门腿踝足，亥水为头及肾囊**

### 1.2 五行的健康权重

**操作**：

- 看命局中**五行分布**
- **最少的五行** = 身体最薄弱的地方
- **被克的五行** = 健康风险点
- **过旺的五行** = 也会有问题，如火旺 → 心火旺

**大白话**：哪一行少 = 哪里弱；哪一行被克 = 哪里病

### 1.3 宫层：地支 = 身体部位（宫定部位）

> **宫 = 地支**（本系统铁律）——宫是容器，定"问题在身体哪一段"。**不是"年柱/月柱"**（天干不参与宫位）。

| 宫（地支） | 身体部位 | 涵盖 |
|:---:|:---|:---|
| **年支** | 头部 | 脑、发、面、眼耳鼻舌、牙、颈——肩以上 |
| **月支** | 胸肋 | 心肺、肝胆、乳腺、臂——肩至腰 |
| **日支** | 腰腹 | 肠胃、肾、膀胱、泌尿生殖、心——腰至胯（**核心区⚠️**）|
| **时支** | 下肢 | 腿、脚、踝、膝、胯部、精血——腰以下 |

> **方位细分**：天干=体表/前/上，地支=体内/后/下；年支月支=左，日支时支=右（《滴天髓》）。

### 1.4 宫星交互：五行落支 × 脏腑 = 具体病位

> **星落宫位 = 病进家**——五行（星）落在哪个宫（地支=部位），就是那个部位的对应脏腑出问题；**再被冲克合破 = 具体病态**。

**判定三步**：

1. **定宫**：星落在哪个地支 → 身体哪一段（年支头/月支胸/日支腹/时支下肢）
2. **定星**：该地支五行/藏干 → 哪个系统（火心/水肾/木肝胆/金肺/土脾胃）
3. **定态**：该支被什么**冲合刑害破生克** → 具体病态（旺而冲=过载，弱而克=亏虚）

**例（实战·丙子辛卯丙午丁酉）**：

- **火（心）落日支午**（腰腹/心脏宫）：火极旺 + **子午冲** → 心脏高压泵、血热、高血压倾向
- **水（肾）落年支子**（头部宫）：唯一真水被**午火冲** → 肾阴亏虚 + 脑供血波动、偏头痛、睡眠浅
- **木（肝）落月支卯**（胸肋宫）：被**酉冲（卯酉冲）+ 午破（卯午破）** → 肝胆代谢压力、肝气郁结、筋骨劳损
- **金（肺）落时支酉**（下肢宫）：被**午克（火克金）** → 肺阴不足、皮肤干、便秘、精血受损
- **土（脾）藏日支午中**：仅一丝己土 + **火旺土焦** → 胃强脾弱、消谷善饥、腹胀

### 1.5 7 大关系 + 暗含

- **冲**：动荡，如健康突发问题
- **合**：绑定，如配偶健康影响你
- **刑**：暗伤，如慢性病
- **害**：阴损，如隐藏的健康问题
- **破**：慢性消耗，如长期亚健康
- **生**：滋养，如某个脏腑养另一个
- **克**：压制，如某个脏腑被压制

### 1.6 喜忌+流通位置

- **喜忌**：极旺**对应脏腑过旺**也病 / 极弱**对应脏腑最弱**也病
- **流通位置**：五行**流通** vs **堵死** = 健康 vs 病

### 1.7 一句话：这**脏腑**是什么样的？

> **你的 [材质] [脏腑] 是 [评分]，与你 [喜/忌]，健康风险 [位置]。**

### 4.5 养生方案

- **脾胃最弱——土缺** → **黄色食物**——小米、南瓜、红薯+ **规律饮食** + **少吃生冷**
