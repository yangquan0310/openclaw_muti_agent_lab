# 八字健康专题

> **本文档是八字技能健康分析的内部参考。**
> 适用于：所有八字解读中的"健康/养生/疾病风险"判断——**单盘**。
> **核心问题**：你的健康怎么样？哪个脏腑最弱？怎么养生？
> **不是**合盘分析 ——合盘见 [`bazi-hehun.md`](bazi-hehun.md)。

---

## 〇、设计原则

- **以对象为中心**——不是流程为中心：3 个对象 = 脏腑 + 流通 + 关系
- **五行对应 5 脏腑**——必背
- **流通堵点 = 五行失衡的病灶**
- **只看异位关系**——不自比
- **关系 > 字本身**：字无意义，关系才是一切
- **隐晦必断**：多个候选必须用 5 规则选 1

> **健康 = 脏腑——五行 + 流通——堵点 + 关系——健康-生活-工作**

---

## 一、脏腑

> **这一章只讲"5 个脏腑"是什么**

### 1.1 五行-脏腑-系统

| 五行 | 脏腑 | 系统 | 易感疾病 |
|---|---|---|---|
| **木** | 肝胆 | 筋、眼睛、情绪 | 肝火旺、易怒、眼睛疲劳、抑郁 |
| **火** | 心脏、小肠 | 舌头、血液循环 | 心火旺、失眠、心血管、口舌生疮 |
| **土** | 脾胃 | 皮肤、肌肉、消化 | 脾胃虚、湿气、消化不良、皮肤病 |
| **金** | 肺、大肠 | 呼吸系统、皮肤 | 肺虚、咳嗽、皮肤病、便秘 |
| **水** | 肾、膀胱 | 泌尿、生殖系统 | 肾虚、水肿、泌尿问题、妇科/男科 |

**大白话**：先认清楚**你的 5 个系统哪个最弱**

### 1.2 五行的健康权重

**操作**：

- 看命局中**五行分布**
- **最少的五行** = 身体最薄弱的地方
- **被克的五行** = 健康风险点
- **过旺的五行** = 也会有问题，如火旺 → 心火旺

**大白话**：哪一行少 = 哪里弱；哪一行被克 = 哪里病

### 1.3 五行的异位关系

#### 位置含义速查

- 年柱 = 祖辈、出身、童年底色
- 月柱 = 父母、事业、成长环境
- 日柱 = **自己 + 配偶**
- 时柱 = 子女、晚年、未来

#### 7 大关系 + 暗含

- **冲**：动荡，如健康突发问题
- **合**：绑定，如配偶健康影响你
- **刑**：暗伤，如慢性病
- **害**：阴损，如隐藏的健康问题
- **破**：慢性消耗，如长期亚健康
- **生**：滋养，如某个脏腑养另一个
- **克**：压制，如某个脏腑被压制

### 1.4 喜忌+流通位置

- **喜忌**：极旺**对应脏腑过旺**也病 / 极弱**对应脏腑最弱**也病
- **流通位置**：五行**流通** vs **堵死** = 健康 vs 病

### 1.5 一句话：这**脏腑**是什么样的？

> **你的 [材质] [脏腑] 是 [评分]，与你 [喜/忌]，健康风险 [位置]。**

## 二、流通堵点

> **这一章只讲"5 行堵在哪里" = 哪里病**

### 2.1 5 行流通图

```
印 → 身 → 食伤 → 财 → 官
木 → 火 → 土 → 金 → 水
↓——回到印，闭环
```

### 2.2 5 大堵点对应的健康风险

| 堵点 | 病位 | 病象 |
|---|---|---|
| **木堵** | 肝胆 | 肝气郁结、易怒、抑郁、眼睛疲劳 |
| **火堵** | 心脏 | 心火旺、失眠、心血管、口舌生疮 |
| **土堵** | 脾胃 | 脾胃虚弱、湿气重、消化不良、皮肤病 |
| **金堵** | 肺 | 肺气虚、咳嗽、便秘、皮肤病 |
| **水堵** | 肾 | 肾虚、水肿、泌尿问题、妇科/男科 |

### 2.3 5 大健康风险类型

- **过旺型**：某五行过旺 → 对应脏腑**过亢**
- **过弱型**：某五行过弱 → 对应脏腑**虚**
- **被克型**：某五行被克 → 对应脏腑**受压制**
- **被泄型**：某五行被泄 → 对应脏腑**功能下降**
- **被合型**：某五行被合走 → 对应脏腑**能量被锁**

### 2.4 喜忌+养生方向

- **喜忌**：用神 = **最缺的五行** = **最该补的脏腑**
- 用神木 = 补肝——绿色食物、户外运动
- 用神火 = 养心——红色食物、静心
- 用神土 = 健脾——黄色食物、规律饮食
- 用神金 = 润肺——白色食物、呼吸训练
- 用神水 = 补肾——黑色食物、规律作息

### 2.5 一句话：这**堵点**在哪里？

> **你的健康堵点 = [位置]，[病象]，[养生方向]。**

## 三、关系

> **这一章只讲"健康和生活工作"怎么平衡**

### 3.1 健康与事业的关系

- **印旺 + 食伤弱** = **用脑过度** + 不运动 → 健康风险
- **比劫旺 + 财弱** = **过度劳累** + 不进财 → 健康风险
- **官杀克身** = **工作压力** → 健康风险

### 3.2 健康与家庭的关系

- **配偶健康**影响你——合/冲
- **母亲健康**影响你——印的状态
- **子女健康**影响你——食伤的状态

### 3.3 健康大运

- 用神大运 = **身体好**
- 忌神大运 = **身体差**
- **冲克日支大运** = 健康**动荡**
- **合走日支大运** = 健康**被锁**

### 3.4 一句话：这**健康**整体怎么样？

> **这健康 = [脏腑]+[堵点]+[关系]，[整体评级]，风险期 = [大运/流年]。**

## 四、综合判断实战

> **把前三章的框架套到老板身上，跑通一遍**

### 4.1 这**脏腑**是什么 → 5 行分布

**五行分布**：

| 五行 | 数量 | 位置 |
|---|---|---|
| 火 | **5** | 丙年+丙日+丁时+午日 |
| 木 | **2** | 卯月 |
| 金 | **2** | 辛月+酉时 |
| 水 | **1** | 子年 |
| 土 | **0** | **缺** ❌ |

**最弱的五行**：

- **土 = 0**——**脾胃**最弱⚠️⚠️⚠️
- **水 = 1**——**肾/泌尿**偏弱
- **最旺的五行**：火 = 5——**心脏**过旺

**异位关系**——重点看火和土的关系：

- 火生土——**丙生己**藏在午里✅ 流通存在
- 木克土——**卯克己**⚠️ **印克食伤** = **想法压脾胃**
- 水克火——**子克丙/丁**✅ 财滋官

**位置含义暗含**：

- 火在**年/日/时**——全柱分布→ 心脏过旺
- 土**无** → **脾胃弱**
- 木在**月** → 肝气旺——但克土
- 金在**月/时** → 肺偏弱
- 水在**年** → 肾偏弱

**一句话脏腑**：

> **这脏腑：火旺——心脏过亢+ 土缺——脾胃最弱+ 水弱——肾偏弱+ 木克土——肝压脾+ 金弱——肺虚。**

---

### 4.2 这**堵点**在哪里 → 5 行流通

**流通图**：

```
印——卯→ 身——丙+丁+午= 生 → 身极旺
                          ↓
                       食伤——土= 缺 ❌⚠️⚠️⚠️
                          ↓
                 财——辛+酉→ 身 = 被劫 ⚠️
                          ↓
                     官——子→ 印 = 通 ✅
```

**堵点对应健康**：

| 堵点 | 病位 | 病象 | 严重度 |
|---|---|---|---|
| **食伤——土缺** | 脾胃 | 脾胃虚弱、湿气重、消化不良、皮肤病 | ⚠️⚠️⚠️ |
| 财被劫——金| 肺 | 肺气虚、咳嗽、便秘、皮肤病 | ⚠️⚠️ |
| 印旺克食伤——木克土| 肝脾 | 肝气犯脾——生气伤胃、抑郁 | ⚠️⚠️ |
| 火过旺 | 心 | 心火旺、失眠、心血管、口舌生疮 | ⚠️⚠️ |

**最严重的堵点**：**食伤——土缺** = **脾胃最弱** ⚠️⚠️⚠️

### 4.3 这**健康**整体怎么样 → 关系 + 大运

**健康与事业的关系**：

- 印旺 + 食伤弱 = **用脑过度** + 不运动 → 健康风险 ⚠️
- 比劫旺 + 财弱 = **过度劳累** + 不进财 → 健康风险 ⚠️
- 官杀弱 = 工作压力**扛得住**——因为身旺

**健康与家庭的关系**：

- 配偶——辛克午——家= 配偶**帮你管家** → 但**家——脾胃被压**
- 母亲——印卯克食伤——己= **母亲影响你脾胃** ⚠️
- 子女——食伤己弱 = 子女**拖累你脾胃**

**大运健康风险**：

- 印大运——卯= **克食伤** = **脾胃受压**
- 财大运——辛酉= **劫财得力** = **更累**
- 官大运——子= **水克火** = **心脏受压**

### 4.4 一句话健康

> **这健康 = 火旺心脏过亢 + 土缺脾胃最弱 + 水弱肾偏弱 + 木克土肝压脾 + 金弱肺虚。** ⚠️ **重点关注脾胃 + 心脏 + 肾**。

---

### 4.5 养生方案

- **脾胃最弱——土缺** → **黄色食物**——小米、南瓜、红薯+ **规律饮食** + **少吃生冷**
- **心脏过旺——火旺** → **红色食物**——红枣、番茄+ **静心冥想** + **避免熬夜**
- **肾偏弱——水弱** → **黑色食物**——黑豆、黑芝麻+ **早睡** + **节制房事**
- **肝压脾——木克土** → **绿色食物**——菠菜、青菜+ **少生气** + **疏肝理气**
- **肺弱——金弱** → **白色食物**——白萝卜、银耳+ **深呼吸训练**

**季节养生**：

- 春——寅卯月= 肝旺 → **养脾**
- 夏——巳午月= 火旺 → **养心 + 养肾**
- 秋——申酉月= 金旺 → **养肺 + 养肝**
- 冬——亥子月= 水旺 → **养肾 + 养心**
