## 五、一段话介绍范式（v3.8.0-v3.16.0 ★）

> **触发条件**：用户要求"一段话介绍"/"一句话介绍"/"用现代汉语讲讲"等
> **核心结构（3 段式）**：**1 句格局定义 + 1 个隐喻 + 5-6 段现代汉语解释**

### 隐喻构造三步法（v3.15.0）

1. **画面感** — 比喻必须有画面感，让人闭眼就能看到
2. **先定主喻** — 先确定日干是什么具体东西（山/水/火/树/金器）
3. **再看关系** — 用格局/势局/流通告诉你"它"和其他元素怎么互动
4. **隐喻精确** — 一段话比喻必须精确，不能模糊

**完整流程**：**格局定类别 → 势局定状态 → 流通定互动 → 综合形成精确比喻**

### 隐喻规则全图（v3.8.0-v3.16.0）

| 版本 | 规则 | 一句话总结 |
|------|------|----------|
| v3.8.0 | 一段话范式 | 1 句格局定义 + 1 个隐喻 + 5-6 段现代汉语解释 |
| v3.9.0 | 具体事物优先 | 日常物件（灶台/水壶/锅/房子/仓库/电池/货车/水龙头）|
| v3.10.0 | 日干五行主喻 | 丙丁火→火意象，甲乙木→木意象，壬癸水→水意象，戊己土→土意象，庚辛金→金意象 |
| v3.11.0 | 主语明示 | "这个命局"/"这张命局"，不用"这"代词 |
| v3.12.0 | 喻体=五行本体 | 喻体不是装着五行的容器（丙火不用"炖锅"，壬水不用"水壶"）|
| v3.13.0 | 五行+物理双重正确 | 比喻部件对应必须五行正确 + 物理正确（风≠土，扇风助燃不灭火）|
| v3.14.0 | 五行业务逻辑映射 | 木(印)=生火 / 火(比劫)=火焰本身 / 土(食伤)=吸收火热量(瓷器窑) / 金(财)=需要锻炼(金属锻造) / 水(官)=降火(浇水灭火) |
| v3.15.0 | 隐喻构造哲学框架 | 格局定类别 → 势局定状态 → 流通定互动 → 综合形成精确比喻 |
| v3.16.0 | 不要总结句 | 比喻段不要写"这就是这张命局的样子——..." |

## 七、核心立场（5 条 · 最高纲领）

[1] **每句话标依据** —— `[依据: 类别]` 标明来源
[2] **术语洁净** —— 暗合是暗合、相生是相生、合冲是合冲
[3] **用现代汉语** —— 基于工具数据 + 传统命理逻辑给**明确判断**，用大白话写
[4] **不仿古** —— 不编"古贤云"，不假托师承
[5] **综合** —— 天干地支同等看，不偏天派不偏地派

> 完整定义见 [`references/bazi-paipan.md`](references/bazi-paipan.md) §二

## 八、神煞核心原则（一体两面 · v2.1.0）

> **神煞从来都是一体两面的。好坏同体。**

- 每颗神煞同时具备 **阳面**（正向）+ **阴面**（负向）
- **禁止单面贴吉凶**（如"羊刃 = 大凶"）
- 吉凶取决于：激活条件 + 制化机制 + 命局组合
- 详细见 [`references/bazi-shensha.md`](references/bazi-shensha.md) §0.4
