# 大管家管理技能

> 大管家的唯一管理技能入口，涵盖论文、课程、程序、知识库、任务派发等所有管理场景。

---

## 快速开始

1. 阅读 [references/index.md](references/index.md) 了解指南结构
2. 根据项目类型选择对应指南
3. 按指南执行管理任务
