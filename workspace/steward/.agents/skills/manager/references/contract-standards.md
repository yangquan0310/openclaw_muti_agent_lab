# 契约文件规范

> 项目根目录的四个契约文件的标准格式

---

## 一、契约文件的本质

契约文件是项目与管理者之间的**约定**。它们的位置固定、内容有规范，是大管家快速理解项目现状的入口。

任何项目都有且仅有这四个契约文件，它们描述了项目是什么、做什么、谁来做、做到哪了。

---

## 二、四个契约文件

| 文件 | 用途 | 位置 |
|------|------|------|
| README.md | 项目总览、目标、参与人员 | 根目录 |
| AGENTS.md | 本项目专用的操作手册 | 根目录 |
| TODO.md | 任务看板、进度追踪 | 根目录 |
| metadata.json | 机器可读的项目元数据 | 根目录 |

---

## 三、README.md

项目入口文件，让任何人都能快速了解这个项目是做什么的。

```markdown
# 项目名称

> 一句话描述

## 项目目标

## 参与人员

## 目录结构

## 使用说明
```

---

## 四、AGENTS.md

本项目专用的操作手册，定义项目的触发条件和操作规范。

```markdown
---
name: 项目标识
description: >
  触发条件说明（当用户提到XX时使用本项目）
version: 1.0.0
---

# 项目名称

## 触发条件

## 目录规范

## 操作指南
```

---

## 五、TODO.md

任务看板，记录所有任务的进度和状态。

```markdown
# 任务看板

| 任务ID | 任务描述 | 状态 | 创建时间 | 最后更新 |
|--------|----------|------|----------|----------|
```

---

## 六、metadata.json

机器可读的项目元数据，供程序读取项目信息。

```json
{
  "name": "项目名称",
  "version": "1.0.0",
  "type": "thesis|course|program|project",
  "created_at": "2026-01-01",
  "updated_at": "2026-01-01"
}
```

---

## 七、契约文件检查清单

- [ ] README.md 在根目录
- [ ] AGENTS.md 在根目录
- [ ] TODO.md 在根目录
- [ ] metadata.json 在根目录
- [ ] 四个文件内容格式正确
