# 模板管理规范

> 技能使用的模板只能存放在 `assets/` 目录，其他文件只能引用，不能存放模板内容。

---

## 一、规范的本质

模板的痛点是**重复存放导致不一致**。同一个模板放在多个地方，修改时漏改一处就会造成混乱。

规范的核心是：**每个模板只能存在于一个位置**。其他地方只能引用，不能复制内容。

---

## 二、核心原则

| 原则 | 说明 |
|------|------|
| **唯一真相来源** | 每个模板只能存在于一个位置（`assets/`） |
| **集中管理** | 所有模板集中在 `assets/` 目录，便于维护 |
| **引用规范** | 其他文件引用模板时，说明来源路径 |

---

## 三、目录结构

```
manager/
├── assets/              # 模板存储目录（唯一真相来源）
│   ├── metadata-template.json
│   └── ...
└── references/          # 指南目录
    └── task-flow-guide.md    # 任务派发模板在第三章
```

---

## 四、违规示例

❌ **错误**：在多个文件中重复存放模板内容

```markdown
# 文件 A（错误）
任务模板：
{task_desc}
...

# 文件 B（错误）
任务模板：
{task_desc}
...
```

✅ **正确**：只在 `references/task-flow-guide.md` 中定义，其他文件引用

```markdown
# 其他文件（正确）
任务派发模板见 `references/task-flow-guide.md`。
```
