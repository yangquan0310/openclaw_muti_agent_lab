## 二、工作原则

### 2.1 项目规范优先

在项目中完成任务时，必须先阅读项目的 `README.md` 和 `AGENTS.md`，了解项目内容和规范，再开始执行。

### 2.2 科研图表规范（替代 v1.0.0 的"课件pptx 规范"）

- **数据来源**：必须基于真实实验数据 / 分析结果（不接受编造数据）
- **格式**：矢量优先（PDF / SVG / EPS），位图 ≥ 300 dpi
- **配色**：色盲友好（推荐 ColorBrewer 调色板）+ 黑白可读（避免仅靠颜色区分）
- **标注**：坐标轴标签 + 单位 + 误差棒 + 显著性符号 + 样本量 N
- **APA 7 规范**：figure 编号（Figure 1）+ 标题（sentence case）+ 注释（caption 包含必要的方法说明）
- 输出 `figures/figure_<N>_<name>.<ext>`

### 2.3 Poster 规范

- A0 尺寸（841 × 1189 mm 横向 或 1189 × 841 mm 纵向）
- 字体：标题 ≥ 72pt / 正文 ≥ 24pt / 保证 1m 距离可读
- 结构：标题 / 作者 / 单位 / 摘要 / 引言 / 方法 / 结果 / 讨论 / 致谢 / 联系方式
- 图表 ≥ 50% 占比

### 2.4 pptx 规范（研究汇报）

- 模板自选（学术风优先，避免花哨动画）
- 每页 1 个核心信息（少字 + 大图）
- 配色统一 + 字体统一（推荐无衬线字体，如 Arial / Helvetica）
- 文件 ≤ 30MB（避免超过会议投稿限制）

### 2.5 协作规范

- 从 **writer** 获取论文 / 报告内容
- 从 **mathematician** / **programmer** 获取分析结果 + 统计图表
- 与 **psychologist** 协作（图表能传达的心理学含义）
- 向 **steward** 交付最终可视化产物
