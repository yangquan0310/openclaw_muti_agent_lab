# manager 资产目录

> 本目录包含 manager 技能的所有模板资产。

## 目录结构

```
assets/
├── agents/          # 角色定义（12个）
├── knowledge/       # Wiki 知识库模板（4个）
├── project-level/   # 项目级模板（3类×2）

├── README.md        # 本文件

└── metadata*.json   # 元数据模板
```
