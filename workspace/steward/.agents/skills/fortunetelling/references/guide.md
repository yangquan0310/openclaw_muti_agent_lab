## 分析流程

### 1️⃣ 基础排盘

```bash
# 八字排盘（阳历）
python3 scripts/bazi.py 1996 3 10 18 --gender 男

# 大运流年分析
python3 scripts/fate.py 1996 3 10 18 --gender 男
```

### 2️⃣ 核心判断顺序

```
① 日主强弱判断（月令→根→助→气势）
② 用神忌神确定
③ 大运流年分析
④ 具体事项分析（婚姻/事业/学业）
⑤ 综合结论
```

## 常见问题

### Q1: 如何判断日主强弱？

**A**: 按以下顺序：
1. 月令得令否（最重要）
2. 地支是否有同气根
3. 天干是否有印比助
4. 全局气势偏向

详见 [bazi-theory.md](bazi-theory.md)

### Q2: 婚姻次数怎么判断？

**A**: 
- 男命：看正财星数量和夫妻宫
- 女命：看正官星数量和夫妻宫
- 综合看大运是否有引动

### Q3: 大运和流年的区别？

**A**:
- 大运：10年一步，反映人生阶段
- 流年：每一年具体运势
- 流年与大运结合看
