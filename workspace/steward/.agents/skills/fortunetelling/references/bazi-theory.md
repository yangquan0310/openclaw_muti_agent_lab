## 一、我判断八字的核心原则

### ⚠️ 判断日主强弱三大禁忌

| 禁忌 | 错误做法 | 正确做法 |
|------|----------|----------|
| **只看印星** | 看到印星生扶就断身强 | 必须先看**月令是否得令** |
| **忽略月令** | 只看天干地支表面五行 | **月令是判断强弱的first priority** |
| **单点思维** | 看到一个因素就下结论 | 必须综合**得令+得势+得地+得助**四项 |

### 🔑 我的判断顺序（按重要性排列）

```
第一步：月令是否得令（最重要）
    ↓
第二步：地支是否有同气根
    ↓
第三步：天干是否有印比助身
    ↓
第四步：全局气势偏向
```

## 三，五行学说

### 2.1 五行基本属性

| 五行 | 代表色 | 方位 | 季节 | 脏腑 | 五味 | 特性 |
|------|-------|------|------|------|------|------|
| 木 | 青绿 | 东 | 春 | 肝胆 | 酸 | 生发、条达 |
| 火 | 红 | 南 | 夏 | 心小肠 | 苦 | 炎热、向上 |
| 土 | 黄 | 中央 | 长夏 | 脾胃 | 甘 | 生化、承载 |
| 金 | 白 | 西 | 秋 | 肺大肠 | 辛 | 收敛、肃杀 |
| 水 | 黑 | 北 | 冬 | 肾膀胱 | 咸 | 流动、向下 |

### 2.2 五行相生

```
木 → 火 → 土 → 金 → 水 → 木
```

**木生火**：木燃烧产生火
**火生土**：火燃烧后成灰
**土生金**：土中蕴藏金属
**金生水**：金属表面凝结水珠
**水生木**：水滋润树木生长

### 2.3 五行相克

```
木 → 土 → 水 → 火 → 金 → 木
```

**木克土**：树木破土而出
**土克水**：土能阻挡水流
**水克火**：水能熄灭火焰
**火克金**：火能熔化金属
**金克木**：金属能砍伐树木

### 2.4 五行平衡的误区

> **重要**：五行并非"平衡最好"，有些极不平衡的格局反而是极品格局。

| 格局类型 | 说明 |
|----------|------|
| 从强格 | 日主极旺，顺从木气，反而应该加木水 |
| 从财格 | 日主极弱，财星极旺，顺从财富能量 |
| 专旺格 | 五行极度专一，能量集中 |

### 4.2 十神心性详解

#### 比肩
- **正面**：独立、自主、刚毅、勇敢、积极进取
- **负面**：孤僻、固执、缺乏合群、自负
- **六亲**：朋友、兄弟、同辈

#### 劫财
- **正面**：热情、义气、果断、行动力强
- **负面**：冲动、投机、争夺、不服输
- **六亲**：姐妹、亲密兄弟

#### 食神
- **正面**：温和、善良、聪明、口才好、福气
- **负面**：空想、挑剔、不切实际
- **六亲**：女婿(男)、女儿(女)
- **职业**：餐饮、服务、教育

#### 伤官
- **正面**：才华、创意、悟性高、恃才傲物
- **负面**：叛逆、尖刻、气量狭小
- **六亲**：祖母(男)、儿子(女)
- **职业**：艺术、创新行业、演艺

#### 正财
- **正面**：勤俭、踏实、稳重、诚实
- **负面**：保守、吝啬、计较
- **六亲**：妻子(男)、父亲
- **职业**：财务、会计、稳定职业

#### 偏财
- **正面**：慷慨、大方、理财能力强
- **负面**：投机、挥霍、好色
- **六亲**：父亲、小妾、情人
- **职业**：投资、贸易、金融

#### 正官
- **正面**：正直、有责任心、守规矩、重信用
- **负面**：保守、优柔寡断、压力感
- **六亲**：女儿(男)、丈夫(女)
- **职业**：公务员、管理层、政府工作
