# fortunetelling - 命理排盘技能

> 根据八字推算大运、流年、学业、婚姻、事业等人生运势。
> 
> **分析风格**：月令优先、综合判断、实战导向、有错必改。

---

## 功能说明

### 1. 阴历转八字

将阴历出生日期转换为天干地支八字，包含：
- 年柱：出生年的天干地支
- 月柱：出生月的天干地支（根据二十四节气定月）
- 日柱：出生日的干支
- 时柱：出生时辰的干支

### 2. 大运排盘

每10年一大运，计算：
- 起运年龄（阳男顺行/阴男逆行/阳女逆行/阴女顺行）
- 每一步大运的天干地支及十神
- 该大运期间的总体运势

### 3. 流年分析

逐年分析每年的具体运势，包括：
- 流年干支
- 与八字的关系
- 该年的吉凶判断

### 4. 十神分析

分析八字中的十神关系：
- 比肩、劫财（同类助身）
- 食神、伤官（泄秀生财）
- 正财、偏财（克泄日主）
- 正官、七杀（克制日主）
- 正印、偏印（生扶日主）

### 5. 五行分析

分析八字中的五行强弱：
- 金、木、水、火、土的数量
- 日主的强弱判断（得令→根气→助身→气势）
- 用神忌神确定

## 我的分析框架

### 🔑 核心原则

| 原则 | 说明 |
|------|------|
| 月令优先 | 月令是判断强弱的第一要素 |
| 综合判断 | 不单凭一个因素下结论 |
| 动态分析 | 大运流年需结合命局看 |
| 留有余地 | 不说绝对，给出概率评估 |

### 📊 日主强弱五步判断

```
第一步：月令得令否（权重50%）
第二步：地支同气根（权重20%）
第三步：天干印比助（权重15%）
第四步：全局气势断（权重10%）
第五步：调候是否有（权重5%）
```

### ⚖️ 四种结果

| 类型 | 用神 | 忌神 |
|------|------|------|
| 身强 | 官杀、财、食伤 | 印比劫 |
| 身弱 | 印比劫 | 财官杀食伤 |
| 从强格 | 印比（顺其势） | 官杀（逆其势） |
| 从弱格 | 财官杀（顺其势） | 印比（逆其势） |

## 使用方式

### 基本命令

```bash
# 八字排盘（公历）
python3 scripts/bazi.py 1996 3 10 18 --gender 男

# 大运流年分析
python3 scripts/fate.py 1996 3 10 18 --gender 男

# 指定时间点分析
python3 scripts/fate.py 1996 3 10 18 --gender 男 --type timing --target 2026-5-21-14
```

### 输入格式

| 参数 | 说明 | 示例 |
|------|------|------|
| 年 | 4位数年份 | 1996 |
| 月 | 月份(1-12) | 3 |
| 日 | 日期(1-31) | 10 |
| 时 | 小时(0-23) | 18 |
