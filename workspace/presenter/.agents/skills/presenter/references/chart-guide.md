# 图表设计指南

> 流程图、思维导图、知识图谱

---

## 一、适用场景

| 类型 | 适用场景 |
|------|----------|
| **流程图** | 操作步骤、实施程序、时间发展 |
| **思维导图** | 概念关系、层级结构、头脑风暴 |
| **知识图谱** | 课程知识结构、学科体系 |

---

## 二、流程图设计

### 2.1 基本符号

| 符号 | 含义 |
|------|------|
| 圆角矩形 | 开始/结束 |
| 矩形 | 操作/步骤 |
| 菱形 | 判断/决策 |
| 箭头 | 流程方向 |

### 2.2 设计原则

| 原则 | 说明 |
|------|------|
| **简洁** | 避免过于复杂的流程 |
| **清晰** | 每步一个核心动作 |
| **方向** | 保持统一的流向（左到右或上到下） |

### 2.3 布局建议

```
方案1：水平流程
[步骤1] → [步骤2] → [步骤3] → [步骤4]

方案2：垂直流程
  ↓
[步骤1]
  ↓
[步骤2]
  ↓

方案3：决策分支
      [判断]
     ↙    ↘
   [是]    [否]
     ↘    ↙
    [结果]
```

## 三、思维导图设计

### 3.1 基本结构

| 层级 | 说明 |
|------|------|
| 中心主题 | 核心概念（最突出） |
| 一级分支 | 主要类别 |
| 二级分支 | 具体内容 |
| 更多分支 | 细节补充 |

### 3.2 设计原则

| 原则 | 说明 |
|------|------|
| **层级清晰** | 同级元素视觉权重相近 |
| **颜色区分** | 不同分支用不同颜色 |
| **简洁** | 每节点一个关键词 |
| **平衡** | 分支分布均匀 |

---

## 四、知识图谱设计

### 4.1 适用场景

| 场景 | 示例 |
|------|------|
| 课程结构 | 章节→单元→知识点 |
| 概念体系 | 上位→下位→并列 |
| 学科体系 | 领域→分支→专题 |

### 4.2 设计原则

| 原则 | 说明 |
|------|------|
| **层级分明** | 不同层级用大小/颜色区分 |
| **关系清晰** | 用箭头/连线标注关系 |
| **简洁** | 核心概念优先，避免信息过载 |
