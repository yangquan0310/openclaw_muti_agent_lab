# 文档排版指南

> 文档排版与视觉呈现优化规范

---

## 核心原则

| 优先级 | 原则 | 说明 |
|--------|------|------|
| 1 | **可读性** | 文字清晰，结构分明 |
| 2 | **一致性** | 全文档排版风格统一 |
| 3 | **层次感** | 信息层级通过视觉区分 |
| 4 | **专业性** | 符合行业排版标准 |

---

## 页面设置

### 基本参数
| 参数 | 值 |
|------|------|
| 页面方向 | 纵向 / 横向（根据内容） |
| 页边距 | 上 2.54cm，下 2.54cm，左 3.17cm，右 2.54cm |
| 字号 | 正文 12pt / 14pt，标题按层级 |
| 行距 | 1.15-1.5 倍行距 |
| 页码 | 底部居中或右下角 |

### A4 文档
```
+----------------------------------+
|  左 3.17cm          右 2.54cm    |
| +------------------------------+ |
| |                              | | 上 2.54cm
| |                              | |
| |         正文区域             | |
| |                              | |
| |                              | | 下 2.54cm
| +------------------------------+ |
|           第 1 页 / 共 N 页       |
+----------------------------------+
```

## 字体规范

### 中文字体
| 用途 | 推荐字体 |
|------|----------|
| 标题 | 黑体 / 微软雅黑 / 方正黑体 |
| 正文 | 宋体 / 微软雅黑 / Arial |
| 代码 | Source Code Pro / Consolas |

### 英文字体
| 用途 | 推荐字体 |
|------|----------|
| 标题 | Arial / Helvetica / Roboto |
| 正文 | Times New Roman / Georgia |
| 代码 | Courier New / Source Code Pro |

### 字号层级
| 元素 | 字号 | 字重 | 例子 |
|------|------|------|------|
| 一级标题 | 22-24pt | Bold | 第一章 |
| 二级标题 | 18-20pt | Bold | 1.1 节 |
| 三级标题 | 16pt | SemiBold | 1.1.1 小节 |
| 正文 | 12-14pt | Regular | 段落文字 |
| 辅助文字 | 10-11pt | Regular | 脚注、图注 |

## 段落规范

### 段落格式
- 首行缩进：2 字符（或 0.74cm）
- 段后间距：8-12pt
- 对齐方式：两端对齐（正文）、居中（标题）
- 字间距：正常（避免过疏或过密）

### 段落间距
```
【标题】
↓ 段前 12pt，段后 6pt

【正文段落】
↓ 段前 0pt，段后 8pt

【列表项】
↓ 段前 0pt，段后 4pt
```

## 标题层级

```
第一章（Chapter）
├── 1.1 节（Section）
│   ├── 1.1.1 小节（ Subsection）
│   │   ├── （正文内容）
│   │   └── 1.1.2 小节
│   └── 1.1.2 小节
└── 1.2 节
```

### 标题样式
| 级别 | 格式 | 示例 |
|------|------|------|
| 一级 | 居中、Bold、18-20pt | **第一章 绪论** |
| 二级 | 左对齐、Bold、16pt | **1.1 研究背景** |
| 三级 | 左对齐、SemiBold、14pt | **1.1.1 国内研究** |
| 四级 | 左对齐、Italic、13pt | **(1) 理论框架** |

## 列表规范

### 有序列表
1. 第一步
2. 第二步
3. 第三步

### 无序列表
- 主要项
  - 次要项
    - 细节项
- 另一个主要项

### 列表格式
- 缩进：层次分明
- 项目符号：统一风格（圆点/方块/短横线）
- 编号：1 / 1.1 / 1.1.1 层级

### 表格结构

## 图片与图表

### 图片规范
- 分辨率：打印 300dpi，屏幕 72dpi
- 格式：PNG（透明）/ JPG（照片）/ SVG（图标）
- 对齐：居中或左对齐
- 图注：居中、12pt、段前 6pt

### 图表规范
- 配色：与文档整体配色协调
- 字体：图表内文字 ≤ 10pt
- 边框：简洁，去除不必要的边框
