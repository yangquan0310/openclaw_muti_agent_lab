# 配色方法论

> 如何为可视化选择合适的配色方案

---

## 核心原则

### 1. 主导色原则

**一个颜色占 60-70% 视觉权重**，其余颜色为辅助。

| 角色 | 比例 | 作用 |
|------|------|------|
| 主导色 | 60-70% | 背景、大面积色块 |
| 支持色 | 20-30% | 内容区域、卡片 |
| 强调色 | 5-10% | 关键信息、CTA |

### 2. 对比原则

**文字与背景必须有足够对比度**：
- 深色文字 → 浅色背景
- 浅色文字 → 深色背景
- 避免低对比度组合（浅灰 on 白）

### 3. 主题匹配原则

**配色必须匹配内容主题**。如果一套配色可以用于任何主题，说明选色不够具体。

## 配色决策框架

```
内容主题是什么？
├── 专业/商务 → 蓝色系、灰色系
├── 自然/环保 → 绿色系、棕色系
├── 活力/创意 → 橙色、黄色、珊瑚色
├── 学术/教育 → 蓝色、绿色、紫色
├── 医疗/健康 → 蓝色、绿色、白色
└── 温暖/人文 → 橙色、红色、暖灰色
```

## 深浅对比结构

### 三明治结构（推荐）

| 位置 | 背景 | 示例 |
|------|------|------|
| 标题幻灯片 | 深色 | 藏蓝背景 + 白字 |
| 内容幻灯片 | 浅色 | 白底 + 深色文字 |
| 结尾幻灯片 | 深色 | 藏蓝背景 + 白字 |

### 全深色结构

适合高端、电影感、戏剧性场景：
- 全程深色背景
- 浅色文字和图形
- 更强的视觉冲击力

## 常见错误

| 错误 | 问题 | 正确做法 |
|------|------|----------|
| 所有颜色等权重 | 视觉混乱，无重点 | 一个主导色 + 少量辅助 |
| 默认蓝色 | 缺乏主题相关性 | 根据内容选择配色 |
| 低对比度文字 | 难以阅读 | 确保对比度 ≥ 4.5:1 |
| 背景渐变滥用 | 干扰内容 | 谨慎使用，仅标题/结尾 |

---

## 判断标准

**如何判断配色是否合格？**

1. **问自己**：这套配色能用于其他主题吗？如果是，配色不够具体。
2. **问自己**：文字在背景上清晰可读吗？测试对比度。
3. **问自己**：视觉重心是否在核心信息上？辅助色不应抢夺注意力。
