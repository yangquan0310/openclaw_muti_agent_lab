# 图片制作指南

> 信息图、插图、海报设计

---

## 一、适用场景

| 场景 | 示例 |
|------|------|
| 数据可视化 | 统计图表、信息图 |
| 概念解释 | 流程图、示意图 |
| 宣传物料 | 海报、封面图 |
| 教学素材 | 插图、图解 |

## 三、设计规范

### 3.1 配色原则

| 原则 | 说明 |
|------|------|
| **主导色** | 一个颜色占 60-70% 视觉权重 |
| **支持色** | 1-2 个辅助色 |
| **强调色** | 1 个突出色用于关键信息 |

### 3.2 排版原则

| 原则 | 说明 |
|------|------|
| **留白** | 信息密度与呼吸感同样重要 |
| **层级** | 标题 > 核心信息 > 辅助说明 |
| **对齐** | 相同类型元素对齐一致 |

### 3.3 字体规范

| 元素 | 字号 |
|------|------|
| 主标题 | 标题字号的 1.5-2 倍 |
| 正文 | 适中字号，确保可读 |
| 注释 | 较小字号，辅助信息 |

## 四、图片生成提示词

### 4.1 信息图提示词结构

```
[类型]：简洁描述
风格：[写实/扁平/手绘/科技感]
配色：[颜色描述]
内容：[核心信息]
```

### 4.2 示例

**信息图**：
```
信息图：教学流程图
风格：扁平化、干净
配色：蓝色系，专业教育风格
内容：输入→处理→输出 三步流程
```

**插图**：
```
插图：心理学概念图
风格：简约现代
配色：暖色调，和谐舒适
内容：人与人之间的互动关系
```
