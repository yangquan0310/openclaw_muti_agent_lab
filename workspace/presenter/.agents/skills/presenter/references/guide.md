# presenter 使用指南

> presenter 技能的核心使用说明

---

## 一、概述

presenter 是**唯一可视化技能**，负责：
- PPT/幻灯片制作
- 图片制作（信息图、插图、海报）
- 图表设计（流程图、思维导图）
- 课程可视化（教学图表、知识图谱）

---

## 二、触发条件

当用户提到以下场景时触发：
- "制作 PPT"、"制作幻灯片"、"做课件"
- "制作图片"、"设计信息图"、"做个图"
- "可视化"、"图表设计"
- "流程图"、"思维导图"
- "课程可视化"、"知识图谱"

---

## 三、选择正确的可视化类型

### 3.1 内容类型判断

| 内容类型 | 推荐可视化 |
|----------|------------|
| 教学流程、步骤操作 | **PPT 幻灯片** |
| 概念关系、层级结构 | **思维导图** |
| 流程/步骤/阶段 | **流程图** |
| 数据对比、统计分析 | **信息图/图表** |
| 课程整体呈现 | **PPT 课件** |

### 3.2 快速决策

```
内容是"课程"吗？
├── 是 → 使用 PPT 制作流程
└── 否 → 内容是"流程/步骤"吗？
    ├── 是 → 流程图
    └── 否 → 内容是"概念关系"吗？
        ├── 是 → 思维导图
        └── 否 → 信息图/图片
```
