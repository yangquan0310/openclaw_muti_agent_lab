# 图片生成方法论

> 如何使用 AI 图片生成模型创建高质量可视化素材

---

## 核心问题

**什么内容适合用图片生成？什么内容不适合？**

| 适合 | 不适合 |
|------|--------|
| 概念图、示意图、插图 | 需要精确数据可视化 |
| 抽象概念可视化 | 精确的文字排版 |
| 创意素材、封面图 | 需要严格品牌规范的设计 |

---

## 提示词结构

### 基本结构

```
[类型]：简洁描述
风格：[写实/扁平/手绘/科技感/极简/插画]
配色：[颜色描述或色系]
内容：[核心元素描述]
```

### 示例

**信息图**：
```
信息图：教学流程图
风格：扁平化、干净
配色：蓝色系，专业教育风格
内容：输入→处理→输出 三步流程
```

**插图**：
```
插图：心理学概念图
风格：简约现代、温暖色调
配色：暖色系，和谐舒适
内容：两个人对话，象征人际沟通
```

**封面图**：
```
封面：在线教育平台
风格：现代简约、科技感
配色：深蓝+橙色点缀
内容：笔记本电脑、书本、咖啡杯
```

## 风格选择决策

### 风格匹配主题

| 主题 | 推荐风格 |
|------|----------|
| 学术/教育 | 扁平化、干净、图表式 |
| 商务/专业 | 极简、科技感、高端 |
| 创意/艺术 | 插画、手绘、独特 |
| 温暖/人本 | 暖色调、柔和、亲切 |
| 科技/未来 | 霓虹、几何、深色背景 |

### 风格特征表

| 风格 | 特点 | 适用场景 |
|------|------|----------|
| **扁平化** | 无阴影、简洁色块 | 教学、信息图 |
| **写实** | 照片级细节 | 海报、背景 |
| **插画** | 手绘感、线条感 | 故事性内容 |
| **科技感** | 几何、光效、深色 | 技术演示 |
| **极简** | 大量留白、少元素 | 高端品牌 |

## 质量控制

### 分辨率与尺寸

| 用途 | 推荐尺寸 | 分辨率 |
|------|----------|--------|
| 社交媒体 | 1080x1080 | 1K |
| PPT 插图 | 1920x1080 | 2K |
| 海报/印刷 | 2048x2048+ | 4K |

### 质量参数

| 参数 | 说明 |
|------|------|
| `--size` | 尺寸：1024x1024, 1536x1024, 1024x1536 |
| `--aspect-ratio` | 宽高比：1:1, 2:3, 3:2, 16:9 |
| `--quality` | 质量：low, medium, high |
| `--output-format` | 格式：png, jpeg, webp |

### 避免常见问题

| 问题 | 解决方式 |
|------|----------|
| 文字扭曲/错误 | 避免在图片中生成文字，改用后期添加 |
| 风格不一致 | 同一项目保持相同提示词风格 |
| 版权风险 | 避免生成带真实商标、名人形象 |

## 迭代优化流程

```
生成初版 → 检查问题 → 调整提示词 → 生成修正版 → 验证
    ↓
主要问题：
- 风格不对？
- 颜色不对？
- 构图不对？
- 元素缺失/多余？
```

### 调整策略

| 问题 | 调整方式 |
|------|----------|
| 风格偏了 | 在"风格"字段更具体描述 |
| 颜色不对 | 明确指定颜色或色系 |
| 构图不好 | 调整宽高比或重写构图描述 |
| 元素多余 | 明确"不要包含 XXX" |

## 提示词模板

### 模板1：概念解释图

```
[类型]：概念解释插图
风格：[风格描述]
配色：[主色调 + 辅助色]
内容：[核心概念简单描述]
布局：[单图/多图/图+文]
```

### 模板2：流程/步骤图

```
[类型]：流程示意图
风格：扁平化、清晰
配色：[品牌色系]
内容：[步骤数] 步流程：[起点] → [过程] → [终点]
要求：每步有清晰标识，箭头连接
```

### 模板3：对比图

```
[类型]：对比图
风格：简洁、专业
配色：左右使用不同色调区分
内容：
- 左侧：[对比项A] 特点...
- 右侧：[对比项B] 特点...
要求：视觉对比清晰，避免文字过多
```

### 模板4：数据可视化

```
[类型]：数据图表
风格：扁平化、信息图风格
配色：[数据色系，如蓝绿橙红]
内容：[数据类型]：柱状/饼图/折线
要求：图例清晰，数据点标注
```

## 组合使用

**AI 图片 + PPT 制作**

```
AI 图片生成 → 下载保存 → 插入 PPT
     ↓
优势：
- 获得独特、契合主题的配图
- 避免通用图库的千篇一律
- 节省寻找素材的时间
```

---

## 判断标准

**如何判断生成的图片是否可用？**

1. **主题契合**：图片是否准确表达核心概念？
2. **风格统一**：是否与整体设计风格一致？
3. **清晰度**：放大后是否仍然清晰？
4. **可编辑性**：是否便于后续调整（如需添加文字）？
