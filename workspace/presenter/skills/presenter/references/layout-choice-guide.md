# 如何查找合适的 Layout

> 面对一页课件内容，快速找到最适合的呈现方式。
>
> 提供 4 种查找路径，总有一种适合你。

---

## 路径一：按内容类型查找（最常用）

> 我知道这页内容是什么类型 → 找到 Layout

| 内容类型 | 内容示例 | @structure | Layout 名称 | 索引 |
|----------|----------|------------|-------------|------|
| **封面** | 课程名、章节、教师信息 | `@cover` | 标题幻灯片 | 0 |
| **目录/重点问题** | 学习目标、问题清单 | `@list` | 标题和内容 | 1 |
| **章节分隔** | "PART 01"、"第一节" | `@section` | 节标题 | 2 |
| **概念定义** | "民族志是指..." | `@list` | 标题和内容 | 1 |
| **要点列举** | "五大特点"、"四个原则" | `@list` | 标题和内容 | 1 |
| **步骤流程** | "步骤1→步骤2→步骤3" | `@flowchart` | 标题和内容 | 1 |
| **时间发展** | "古希腊→19世纪→1960后" | `@timeline` | 标题和内容 | 1 |
| **对比分析** | "实验法 vs 质的研究" | `@compare` | 两栏内容 | 3 |
| **分类归纳** | "四大类型"、"特征分类" | `@cards` | 标题和内容 | 1 |
| **数据表格** | "风格对比表"、"统计数据" | `@table` | 标题和内容 | 1 |
| **案例分析** | "访谈片段编码练习" | `@list` | 标题和内容 | 1 |
| **讨论提问** | "思考题：如何自我反思？" | `@list` | 标题和内容 | 1 |
| **总结回顾** | "本章核心要点回顾" | `@list` | 标题和内容 | 1 |

**示例**：
```markdown
## 第1页：封面
@structure: cover        ← 内容类型是"封面"
```

## 路径三：按页面功能查找

> 这页在课件中承担什么功能 → 直接选 Layout

| 页面功能 | 视觉需求 | Layout 名称 | 索引 |
|----------|----------|-------------|------|
| **封面** | 大标题居中，教师信息在下 | 标题幻灯片 | 0 |
| **目录/导学** | 条目列表 | 标题和内容 | 1 |
| **章节分隔** | 大字+简洁装饰，视觉区分 | 节标题 | 2 |
| **正文讲解** | 标题+bullet列表（最常用） | 标题和内容 | 1 |
| **双栏对比** | 左右对等排列 | 两栏内容 | 3 |
| **多栏对比** | 多组对等排列 | 比较 | 4 |
| **思考题** | 只显示问题，留白引发思考 | 仅标题 | 5 |
| **带图片讲解** | 左侧文字+右侧图片 | 图片与标题 | 7 |
| **完全自定义** | 空白画布，手动排版 | 空白 | 6 |

**示例**：
```markdown
## 第19页：思考题
@layout: 5    ← 页面功能是"思考题"，直接选 Layout 5
```

## 路径四：决策树（最直观）

```
这页内容是什么？
│
├─ 课程名+章节+教师？ ──→ @cover    → Layout 0 (标题幻灯片)
│
├─ PART/第一节/章节分隔？ ──→ @section → Layout 2 (节标题)
│
├─ vs/对比/比较/异同？ ──→ @compare  → Layout 3 (两栏内容)
│
├─ 世纪/年代/起源/演变？ ──→ @timeline → Layout 1 (标题和内容)
│
├─ 步骤/流程/程序/①→②？ ──→ @flowchart → Layout 1
│
├─ 表格/数据/统计/百分比？ ──→ @table   → Layout 1
│
├─ 分类/类型/特点/五大？ ──→ @cards    → Layout 1
│
├─ 思考题/讨论/互动？ ──→ @list       → Layout 5 (仅标题)
│
└─ 其他（要点、条目、讲解）──→ @list     → Layout 1 (标题和内容)
```

## 五种特殊结构的详细说明

### @cover → 封面 (Layout 0)

**内容特征**：课程名称、章节标题、教师信息、机构信息。通常是第1页。

**脚本示例**：
```markdown
## 第1页：封面

@structure: cover

**核心内容**：
- 教育科学研究方法
- 第十章 质的研究法
- 授课教师：王雅欣
- 武汉文理学院 教育学院应用心理系
```

**设计原则**：
- 信息层级：课程名 > 章节名 > 教师信息
- 视觉焦点：大标题居中

---

### @section → 章节分隔 (Layout 2)

**内容特征**：章节过渡、PART 标识、新主题引入。

**脚本示例**：
```markdown
## 第4页：第一节标题

@structure: section

**核心内容**：
- 第一节
- 质的研究法概述
- 起源 · 发展 · 特点
```

**设计原则**：
- 视觉区分：与正文页有明显差异
- 信息简洁：只放章节名和核心关键词

---

### @compare → 双栏对比 (Layout 3)

**内容特征**：A vs B 对比、异同分析。必须包含"左侧"和"右侧"内容。

**脚本示例**：
```markdown
## 第3页：导入

@structure: compare
@layout: 3

**核心内容**：
- 左侧：实验法（ch09）
  - 控制变量 → 量化数据 → 验证假设
- 右侧：质的研究（ch10）
  - 自然情境 → 描述手法 → 归纳建构
```

**设计原则**：
- 对等结构：左右两侧条目数尽量一致
- 对应排列：相同维度在同一行对比

---

### @timeline → 时间轴 (Layout 1)

**内容特征**：历史演变、发展阶段。按时间顺序排列的事件。

**脚本示例**：
```markdown
## 第5页：起源与发展

@structure: timeline

**核心内容**：
- 一、质的研究的起源与发展
- [古希腊] 民族志起源，ethnos = 民族/文化
- [19世纪] 博厄斯：实地调查第一人
- [1930-1960] 殖民主义反思，研究者身份觉醒
- [1960后] 现象学+阐释学，互动建构
```

**设计原则**：
- 时间节点：4-6个为宜
- 标注格式：`[时间] 事件描述`
- 编译器自动在 slide 底部添加水平时间轴占位区域

---

### @flowchart → 流程图 (Layout 1)

**内容特征**：操作步骤、实施程序。线性流程、先后顺序。

**脚本示例**：
```markdown
## 第8页：设计研究课题

@structure: flowchart

**核心内容**：
- 一、设计研究课题
- 步骤1：确定研究问题
- 步骤2：了解背景与现状
- 步骤3：确立个案与方法
- 步骤4：思考研究价值
- 步骤5：确立预期方案与步骤
```

**设计原则**：
- 步骤数：5步以内最佳
- 标注格式：`步骤N：描述` 或 `N. 描述`
- 编译器自动在 slide 底部添加流程步骤占位区域

## 查看可用 Layout

```bash
python3 scripts/main.py list --template template
```

当前模板提供 10 个标准 Layout（索引 0-9）。如需专用 Layout（时间轴、流程图、卡片网格等），可通过 `extend` 命令添加：

```bash
python3 scripts/main.py extend --template template --add timeline flowchart cards
```
