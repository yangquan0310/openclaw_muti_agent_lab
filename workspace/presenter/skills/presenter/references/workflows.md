## Q&A

### Q1：如何选择正确的可视化类型？

1. 内容是"课程"吗？→ 是 → PPT制作
2. 内容是"流程/步骤"吗？→ 是 → 流程图
3. 内容是"概念关系"吗？→ 是 → 思维导图
4. 其他 → 信息图/图片

### Q2：PPT制作的标准流程？

1. 脚本编写：按script-writing-guide.md编写结构化Markdown
2. Layout选择：根据内容类型选择合适Layout
3. 编译生成：使用Python脚本编译成PPTX
4. 质量检查：按quality-standards.md检查

### Q3：图片生成的关键步骤？

1. 明确需求：确定图片用途、风格、尺寸
2. 提示词编写：描述画面内容、构图、风格
3. AI生成：使用image-generation-guide.md的方法
4. 人工调整：根据结果优化

## 错误排查

| 现象 | 可能原因 | 解决方法 |
|------|----------|----------|
| PPT编译失败 | 脚本格式错误 | 检查Markdown语法 |
| Layout选择不当 | 内容类型判断错误 | 对照决策树重新选择 |
| 图片模糊 | 分辨率设置过低 | 提高分辨率参数 |
| 图表不清晰 | 类型选择错误 | 换用更合适的图表类型 |
