# 视觉层级方法论

> 如何设计信息的优先级和呈现顺序

---

## 核心问题

**用户第一眼应该看到什么？第二眼呢？**

视觉层级回答这个问题：通过大小、颜色、位置、对比度引导用户注意力。

---

## 层级设计四要素

| 要素 | 作用 | 实现方式 |
|------|------|----------|
| **大小** | 越大越重要 | 字号、图形尺寸 |
| **颜色** | 越突出越重要 | 强调色、对比度 |
| **位置** | 越靠前越重要 | 左上→右下扫描 |
| **对比** | 越明显越重要 | 明暗、饱和度 |

---

## 层级决策框架

### 第一层：核心信息

**用户必须知道的信息**。

| 特点 | 设计方式 |
|------|----------|
| 字号 | 最大（36-44pt） |
| 颜色 | 强调色或高对比 |
| 位置 | 视觉焦点区（左上或中心） |

### 第二层：重要信息

**支持核心信息的详细内容**。

| 特点 | 设计方式 |
|------|----------|
| 字号 | 中等（20-24pt） |
| 颜色 | 主色调 |
| 位置 | 核心信息周围 |

### 第三层：辅助信息

**补充说明、来源、备注**。

| 特点 | 设计方式 |
|------|----------|
| 字号 | 较小（10-12pt） |
| 颜色 | 灰色或淡化 |
| 位置 | 边缘或底部 |

---

## 扫描模式

### F 模式（西方阅读习惯）

用户习惯从左到右、从上到下扫描：

```
┌─────────────┐
│ 重要  重要  │  ← 关注区域
├─────────────┤
│ 重要        │
├─────────────┤
│ 次要   次要  │  ← 关注减少
└─────────────┘
```

**应用**：重要信息放左上，次要信息放右下。

### Z 模式

适合标题 → 图像 → 行动的流程：

```
┌─────────────┐
│ 标题        │  ← 起点
│      图像    │  ← 视觉过渡
│ 行动号召    │  ← 终点
└─────────────┘
```

## 内容类型与层级

| 内容类型 | 第一层级 | 第二层级 | 第三层级 |
|----------|----------|----------|----------|
| **封面** | 课程名称 | 副标题 | 机构/教师 |
| **章节页** | 章节编号 | 章节标题 | 装饰元素 |
| **内容页** | 核心观点 | 支撑论据 | 案例/备注 |
| **对比页** | 对比项A | 对比项B | 共同点/差异 |
| **数据页** | 关键数字 | 数据来源 | 详细说明 |

## 常见错误

| 错误 | 问题 | 正确做法 |
|------|------|----------|
| 所有内容字号相同 | 无层级 | 区分主要/次要 |
| 强调色滥用 | 失去重点 | 只强调最关键 |
| 信息等权重 | 决策困难 | 强制排序优先级 |
| 视觉密度过高 | 认知过载 | 减少信息量 |

---

## 判断标准

**如何判断层级设计是否合格？**

1. **3秒测试**：用户 3 秒内能说出页面核心信息吗？
2. **一指原则**：视线从第一层级自然流向第二层级？
3. **去色测试**：去掉颜色后，层级仍然清晰吗？

## 一图胜千言

**能用图形表达的，不用文字**。

| 文字 | 图形 | 优势 |
|------|------|------|
| "增长50%" | 📈 图表 | 直观 |
| "步骤1→2→3" | 流程图 | 清晰 |
| "A vs B" | 对比卡片 | 易记 |
| "包含4个要素" | 四象限 | 结构化 |
