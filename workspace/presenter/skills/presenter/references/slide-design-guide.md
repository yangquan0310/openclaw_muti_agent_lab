# Slide 设计指南

> **Layout 只是画布，Slide 设计才是核心。**
>
> 本指南指导编译器如何根据内容自主设计 slide 的呈现方式，而非被 layout 的占位符结构限制。

---

## 〇、核心定位：Layout vs Slide 设计

### Layout 的作用（有限）

| Layout 提供 | 具体内容 | 使用方式 |
|-------------|---------|---------|
| **背景** | 母版背景色/背景图 | 直接使用 |
| **配色** | 主题色、强调色 | 提取后统一使用 |
| **字体** | 标题字体、正文字体 | 提取后统一使用 |
| **页眉页脚** | 机构名称、页码、日期 | 直接使用 |
| **占位符** | 标题框、内容框 | **参考位置，不强制填充** |

### Slide 设计的作用（核心）

编译器根据 `@structure` 和 `**图表设计**`，**自主决定** slide 上每一个元素的位置、大小、颜色、样式。

```
❌ 旧模式：用 Layout 1 的内容占位符 → 填 bullet 列表 → 结束
   结果：19页长得一样，只是文字不同

✅ 新模式：用 Layout 1 的背景+字体+页脚 → 自主设计排版
   结果：timeline 画时间轴、flowchart 画步骤框、cards 画卡片网格
```

### 什么时候用 Layout 占位符？

| 场景 | 处理方式 |
|------|---------|
| 封面标题 | **不用** title placeholder，自己画文本框（封面 layout 往往没有标题占位符） |
| 普通内容 | **不用** content placeholder 的 bullet 列表，自己排版 |
| 双栏对比 | 用 Layout 3 获取两栏占位符位置参考，但内容自主填充 |
| 章节分隔 | 用 Layout 2 的背景，但文字自己画（控制字号和位置） |

## 一、核心设计原则

### 1.1 四大基本原则（CRAP）

| 原则 | 含义 | 在课件中的应用 |
|------|------|---------------|
| **对比** Contrast | 元素之间要有明显差异 | 标题 vs 正文字号差 ≥ 8pt；重点内容用强调色 |
| **重复** Repetition | 统一视觉元素贯穿全文 | 同一层级的标题字号一致；配色方案固定 |
| **对齐** Alignment | 每个元素都与某条参考线对齐 | 所有文本框左对齐；图形中心对称 |
| **亲密性** Proximity | 相关元素靠近，无关元素远离 | 一个主题的内容在一个视觉区域内 |

### 1.2 一页一焦点

**错误**：一页塞满 10 个要点 + 3 张图 + 表格
**正确**：一页只说一件事，3-6 个要点为最佳

```
❌ 第6页：质的研究特点+实施程序+注意事项+思考题
✅ 第6页：质的研究的五大特点（5个要点）
✅ 第7页：实施程序（5个步骤）
```

## 二、颜色使用规范

### 2.1 配色方案（推荐）

```
主色    ████  #0096C7  蓝    → 标题、重点、节点
辅色    ████  #48CAE4  浅蓝  → 次级内容、交替行
强调色  ████  #90E0EF  更浅  → 背景、高亮
点缀色  ████  #F4A261  橙    → 警示、对比项
点缀色  ████  #9B59B6  紫    → 特殊标记
背景    ████  #F8F9FA  近白  → slide 底色
文字    ████  #212529  深灰  → 正文（不用纯黑）
```

### 2.2 颜色心理学

| 颜色 | 心理暗示 | 适用场景 |
|------|---------|---------|
| 蓝色 | 理性、专业、信任 | 学术课件主色 |
| 绿色 | 自然、成长、安全 | 环保、心理类 |
| 橙色 | 活力、温暖、提醒 | 重点标记、互动环节 |
| 红色 | 危险、禁止、紧急 | 极少使用，仅警示 |
| 紫色 | 神秘、创意、前沿 | 学术前沿、创新点 |

### 2.3 对比度要求

- **标题 vs 背景**：对比度 ≥ 4.5:1
- **正文 vs 背景**：对比度 ≥ 7:1
- **避免**：浅色字 + 浅色底；彩色字 + 彩色底

### 2.4 配色禁忌

| ❌ 不要做 | 原因 |
|-----------|------|
| 一页超过 4 种颜色 | 视觉混乱，学生注意力分散 |
| 用红色作为大面积背景 | 刺眼、压迫感 |
| 渐变色背景 + 彩色文字 | 对比度无法保证 |
| 纯黑文字 + 纯白背景 | 过于刺眼，用深灰 + 近白 |

## 三、逻辑表达方法

### 3.1 流程表达（线性逻辑）

**适用**：步骤、程序、时间顺序

```
步骤1 → 步骤2 → 步骤3 → 步骤4 → 步骤5
  ↑        ↑        ↑        ↑        ↑
圆角框   圆角框   圆角框   圆角框   圆角框
```

**设计要点**：
- 箭头方向统一（左→右 或 上→下）
- 步骤框等宽等高，间距一致
- 当前步骤用主色，其他用灰色
- 步骤编号放在框内左上角

### 3.2 对比表达（并列逻辑）

**适用**：A vs B、优缺点、异同分析

```
┌─────────────┐    ┌─────────────┐
│   实验法    │ ↔  │  质的研究   │
├─────────────┤    ├─────────────┤
│ 控制变量    │    │ 自然情境    │
│ 量化数据    │    │ 描述手法    │
│ 验证假设    │    │ 归纳建构    │
└─────────────┘    └─────────────┘
```

**设计要点**：
- 左右/上下严格对称
- 对应维度在同一行
- 两侧用对比色（冷色 vs 暖色）
- 中间用「vs」「→」等符号连接

### 3.3 分类表达（层级逻辑）

**适用**：特征归纳、类型划分、要素列举

```
        ┌─────────────┐
        │ 质的研究特点 │
        └──────┬──────┘
    ┌─────┬─────┬─────┬─────┬─────┐
    │  1  │  2  │  3  │  4  │  5  │
    │自然 │描述 │整体 │归纳 │研究者│
    │情境 │手法 │观点 │思维 │即工具│
    └─────┴─────┴─────┴─────┴─────┘
```

**设计要点**：
- 卡片等宽，间距相等
- 每卡顶部有色条或色块标识
- 编号清晰，与内容对齐
- 2-3 行排列，不超过 3 行

### 3.4 时间轴表达（演变逻辑）

**适用**：历史发展、阶段演变、时间序列

```
●━━━━━━━━━━━━━━━━━━━━━━━━━━●━━━━━━━━━━━━━━━━━━━━━━━━━━●
   ↑                          ↑                          ↑
 [古希腊]                   [19世纪]                   [1960后]
 民族志起源                 博厄斯实地调查             现象学+阐释学
```

**设计要点**：
- 水平线贯穿页面
- 节点等距分布
- 时间节点在上方，描述在下方
- 不同时间段用不同颜色区分

## 四、重点突出技巧

### 4.1 视觉权重金字塔

```
        大小            ← 最重要
         ↑
      颜色/位置        ← 次重要
         ↑
      粗细/形状        ← 辅助
         ↑
      间距/留白        ← 基础
```

### 4.2 六种突出方法

| 方法 | 操作 | 效果 | 注意 |
|------|------|------|------|
| **放大** | 字号从 24pt → 36pt | 最直观 | 不要放大太多 |
| **变色** | 普通文字→主色 | 吸引注意 | 一页最多 2 处 |
| **加粗** | font-weight: bold | 强调关键词 | 不要整段加粗 |
| **背景框** | 浅色底框包裹 | 隔离重点 | 框不要太粗 |
| **位置** | 放在视觉中心 | 自然聚焦 | 不要放角落 |
| **动画** | 逐条出现 | 引导节奏 | 课件中慎用 |

### 4.3 重点密度控制

```
❌ 一页 8 个重点 → 没有重点
✅ 一页 1-2 个重点 → 学生记得住
```

**原则**：如果所有都是重点，就没有重点。

## 五、信息层级设计

### 5.1 字号层级（16:9 比例）

| 层级 | 字号 | 字重 | 用途 | 每页出现次数 |
|------|------|------|------|-------------|
| H1 | 36-44pt | Bold | 页面大标题 | 1 次 |
| H2 | 28-32pt | Bold | 节标题/卡片标题 | 3-5 次 |
| Body | 20-24pt | Regular | 正文内容 | 不限 |
| Caption | 14-16pt | Regular | 注释/来源 | 0-2 次 |

### 5.2 间距层级

```
页面边距：≥ 0.5 inch（1.27cm）
标题到内容：≥ 0.3 inch（0.76cm）
内容行间距：≥ 1.2 倍行高
卡片间距：≥ 0.2 inch（0.5cm）
```

### 5.3 视觉动线

**F 型动线**（西方阅读习惯）：
```
1. 先看左上角（标题）
2. 横向扫到右上角
3. 纵向向下扫视
4. 偶尔横向扫视
```

**Z 型动线**（对比/双栏）：
```
1. 左上角 → 2. 右上角
         ↘
3. 左下角 → 4. 右下角
```

**设计建议**：把最重要的信息放在动线的起点和终点。

## 六、教学课件特殊要求

### 6.1 可读性优先

| 场景 | 要求 |
|------|------|
| 教室后排 | 字号 ≥ 24pt，行距 ≥ 1.5 |
| 投影仪 | 对比度 ≥ 7:1，避免细线 |
| 速记笔记 | 关键词前置，bullet 简短 |
| 拍照复习 | 信息密度适中，留白 ≥ 20% |

### 6.2 节奏控制

```
导入页：简洁，1-2 个信息点
内容页：3-5 个要点，有视觉锚点
对比页：左右对称，一目了然
互动页：问题醒目，留白充足
总结页：结构回顾，重点复述
```

### 6.3 避免认知过载

| ❌ 过载信号 | ✅ 优化方案 |
|-----------|-----------|
| 一页 8+ 个 bullet | 拆分为 2 页 |
| 文字铺满全页 | 删减 50%，只留关键词 |
| 多种字体混用 | 统一为 1 种中文 + 1 种英文 |
| 装饰元素过多 | 删除无意义的图形 |
| 颜色超过 4 种 | 回归主色+辅色+强调色 |

## 七、图形绘制规范

### 7.1 形状使用指南

| 形状 | 含义 | 适用场景 |
|------|------|---------|
| 矩形 | 容器、边界 | 卡片、文本框 |
| 圆角矩形 | 柔和、友好 | 步骤框、按钮 |
| 圆形 | 节点、重点 | 时间轴节点、编号 |
| 箭头 | 方向、流程 | 步骤连接、趋势 |
| 菱形 | 判断、决策 | 流程图判断节点 |

### 7.2 线条规范

```
主线条：2-3pt，主色
次线条：1pt，灰色
虚线：表示辅助/可选
细线分隔：0.5pt，浅灰
```

### 7.3 圆角与阴影

```
卡片圆角：4-8pt（太小=锐利，太大=幼稚）
阴影：轻微（透明度 10-20%，偏移 2-4pt）
避免：大圆角 + 重阴影 = 廉价感
```

## 八、检查清单

完成一页设计后，逐条检查：

- [ ] 一页只说一件事
- [ ] 信息密度适中（3-6 个要点）
- [ ] 字号层级清晰（标题 ≥ 36pt，正文 ≥ 20pt）
- [ ] 颜色不超过 4 种
- [ ] 对比度足够（深色字+浅色底）
- [ ] 所有元素对齐
- [ ] 留白 ≥ 20%
- [ ] 重点突出（1-2 处）
- [ ] 视觉动线自然
- [ ] 后排学生能看清

## 九、从 Slide 升级 Layout 的流程

当编译器画出的 slide 效果满意时，按以下步骤固化为模板 layout：

```
Step 1: 在 PowerPoint 中打开生成的 PPT
Step 2: 复制满意的 slide（Ctrl+C）
Step 3: 视图 → 幻灯片母版
Step 4: 在母版列表中粘贴（Ctrl+V）→ 自动创建新 layout
Step 5: 删除 layout 中的内容文本，保留图形和占位符框架
Step 6: 调整占位符位置，匹配图形区域
Step 7: 关闭母版视图，保存模板
Step 8: 运行 list 命令确认新 layout 索引
Step 9: 后续编译时检测到该 layout，直接使用而不再自己画
```

**核心原则**：先由编译器自由设计 slide → 用户认可后 → 固化为 layout → 下次复用。

Layout 是**沉淀下来的最佳实践**，不是**限制创造力的枷锁**。
