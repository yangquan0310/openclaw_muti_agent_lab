# 品牌视觉指南

> 统一视觉规范与品牌调性执行

---

## 核心原则

| 优先级 | 原则 | 说明 |
|--------|------|------|
| 1 | **一致性** | 所有触点保持统一视觉语言 |
| 2 | **差异化** | 视觉风格与竞品明显区分 |
| 3 | **可扩展** | 规范适用于不同场景和媒介 |
| 4 | **可传承** | 设计元素具有时间稳定性 |

---

## 品牌色

### 主色（Primary）
- 定义品牌的标志性颜色
- 使用场景：Logo、主要按钮、关键标题
- 建议：选择 1-2 种主色，避免过多

### 辅助色（Secondary）
- 辅助主色，丰富视觉层次
- 使用场景：背景、装饰、次要按钮
- 建议：2-4 种辅助色

### 中性色（Neutral）
- 文字、边框、背景
- 建议：5-9 级灰阶（从极深到极浅）

### 语义色（Semantic）
| 用途 | 色值 |
|------|------|
| 成功 | 绿系 |
| 警告 | 橙/黄系 |
| 错误 | 红系 |
| 信息 | 蓝系 |

---

## 字体规范

### 品牌字体
| 类型 | 字体 | 使用场景 |
|------|------|----------|
| 标题字体 | 选择具有品牌气质的字体 | H1-H3 |
| 正文字体 | 高可读性字体 | 正文、说明 |
| 数字字体 | 等宽或特殊数字字体 | 数据展示 |

### 字号系统
```
12 / 14 / 16 / 20 / 24 / 32 / 40 / 48 / 64
```
- 保持 1.2-1.5 的行高比例
- 标题字号通常是正文 1.25-1.5 倍

---

## Logo 使用规范

### 空间保护
- 最小安全空间 = Logo 高度的 1/4
- Logo 周围保持干净，避免干扰

### 尺寸规范
| 场景 | 最小尺寸 |
|------|----------|
| 数字端 | 高度 24px |
| 打印品 | 高度 10mm |
| 图标端 | 16px / 20px / 24px |

### 配色变体
- 深色背景：使用白色或浅色版本
- 浅色背景：使用深色版本
- 彩色背景：根据对比度选择最佳版本

---

## 图形元素

### 装饰图形
- 定义品牌特有的装饰元素
- 保持风格统一（线性/面性/几何/有机）
- 使用场景：背景纹理、分割线、角落装饰

### 图标风格
- 统一线宽：1.5px / 2px / 2.5px
- 统一圆角：0 / 2px / 4px / 8px
- 统一尺寸网格：4px 基准

---

## 图像风格

### 摄影风格
| 属性 | 规范 |
|------|------|
| 光线 | 自然光 / 特定氛围光 |
| 色调 | 与品牌色协调 |
| 构图 | 简洁，留白充足 |
| 人物 | 职业/亲切/多元 |

### 插画风格
- 定义插画的：描边/平涂/渐变/3D
- 统一颜色使用
- 定义角色/物品的基本形态

|------|----------|
| 课件/PPT | 使用品牌模板，遵守配色和字体 |
