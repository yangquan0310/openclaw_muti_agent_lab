### 2. 概念重构：三层架构清晰化
```
slide_master  = 画布（背景、主题色、字体、页脚）
slide_layout  = 画布 + 预置占位符（title/content/body 等）
slide         = 编译器在画布上自主绘制的具体画面
```
- **Layout 只是画布**，不是内容呈现的决定者
- **编译器自主设计 slide**：通过 add_textbox/add_shape 绘制所有内容
- **placeholder 只保留页脚相关**（date/footer/number），title/body/content 全部删除

### 3. 编译器重构（PptxCompiler.py）
- **移除**：`_prototypes`、`_clone_slide`、`_fill_by_textboxes`、`_clear_text`
- **新增**：8 种 `@structure` 的自主设计方法
  - `_design_cover`：大标题居中 + 装饰线
  - `_design_section`：PART 编号 + 竖线装饰
  - `_design_list`：编号圆点 + bullet 列表
  - `_design_compare`：左右卡片 + VS 标识
  - `_design_timeline`：水平时间轴 + 彩色节点
  - `_design_flowchart`：圆角步骤框 + 箭头
  - `_design_cards`：卡片网格 + 左侧色条
  - `_design_table`：真正表格（从 key:value 解析）
- **配色方案**（Theme 类）：PRIMARY/SECONDARY/ACCENT/ORANGE/PURPLE

### 4. 脚本解析器更新（ScriptParser.py）
