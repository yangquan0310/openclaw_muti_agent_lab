# 一致性检查清单

> 目标-内容-活动-评价四要素对齐性审核

---

## 四要素对齐模型

```
┌─────────────┐
│  教学目标   │ ← 课程标准/教学大纲要求
└──────┬──────┘
       ↓
┌──────┴──────┐
│  教学内容   │ ← 目标的具体化
└──────┬──────┘
       ↓
┌──────┴──────┐
│  教学活动   │ ← 内容的实施方式
└──────┬──────┘
       ↓
┌──────┴──────┐
│  评价方案   │ ← 目标的达成检验
└─────────────┘
```

---

## 检查清单

### 一、教学目标检查

- [ ] 目标是否来源于课程标准
- [ ] 目标是否具体、可观察、可测量
- [ ] 目标是否涵盖知识、能力、素养三个维度
- [ ] 目标数量是否合理（一般2-4条）

### 二、教学内容检查

- [ ] 内容是否完全覆盖目标要求
- [ ] 内容是否存在超纲或遗漏
- [ ] 内容顺序是否符合逻辑
- [ ] 重难点是否明确标注
- [ ] 概念定义是否准确

### 三、教学活动检查

- [ ] 活动是否服务于目标达成
- [ ] 活动时间分配是否合理
- [ ] 活动类型是否多样
- [ ] 师生互动是否充分
- [ ] 活动与内容是否匹配

### 四、评价方案检查

- [ ] 评价方式是否与目标对应
- [ ] 评价标准是否明确
- [ ] 评价是否覆盖所有目标
- [ ] 形成性评价与总结性评价是否结合

### 五、跨要素一致性检查

- [ ] 目标→内容：每个目标都有对应内容支撑
- [ ] 内容→活动：每个内容都有对应活动实施
- [ ] 活动→评价：每个活动都有对应评价检验
- [ ] 评价→目标：每个评价都能追溯到目标

---

## 一致性判定标准

| 等级 | 说明 |
|------|------|
| 完全一致 | 四要素完全对齐，无明显脱节 |
| 基本一致 | 存在个别不一致，但不影响整体 |
| 不一致 | 存在明显脱节，需要修改 |

---

## 常见不一致问题

| 问题类型 | 描述 | 示例 |
|----------|------|------|
| 目标-内容脱节 | 内容不能有效支撑目标 | 目标要求"分析"，内容只有"介绍" |
| 内容-活动脱节 | 活动不能有效实施内容 | 内容是"小组讨论"，活动只有"听讲" |
| 活动-评价脱节 | 评价不能检验活动效果 | 活动是"实践操作"，评价只考"笔试" |
| 目标-评价脱节 | 评价偏离目标重点 | 目标侧重"应用"，评价侧重"记忆" |
