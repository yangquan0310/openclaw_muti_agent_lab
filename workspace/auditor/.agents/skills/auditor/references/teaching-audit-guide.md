# 教学审核指南

> 学科内容准确性审核的方法与标准

---

## 审核范围

| 维度 | 说明 |
|------|------|
| 概念准确性 | 学科核心概念定义是否正确 |
| 方法陈述 | 研究方法的步骤、特点是否准确 |
| 引用规范 | 文献引用格式是否符合标准 |
| 案例真实 | 案例是否为真实或合理虚构 |
| 前沿同步 | 内容是否反映学科最新发展 |

---

## 概念审核要点

### 1. 定义检查
- 核心术语是否有明确定义
- 定义是否与权威来源一致
- 定义是否适用于当前教学语境

### 2. 陈述核实
- 事实性陈述是否可验证
- 数据、统计是否准确
- 引用文献是否真实存在

### 3. 方法论审核
- 研究方法描述是否准确
- 步骤逻辑是否通顺
- 适用条件是否说明

---

## 常见问题类型

| 类型 | 描述 | 示例 |
|------|------|------|
| 概念错误 | 核心概念定义有误 | 将"民族志"定义为"定量研究方法" |
| 方法错误 | 研究方法描述不准确 | 将"行动研究"描述为"纯理论探索" |
| 超纲内容 | 超出课程标准要求 | 加入教材未涉及的前沿理论 |
| 引用错误 | 文献引用格式或内容有误 | 作者姓名、发表年份、期刊名错误 |
| 逻辑错误 | 论证过程存在逻辑漏洞 | 因果关系颠倒、归纳不当 |

---

## 审核方法

### 1. 对照教材法
以教材为准，核对内容是否与教材一致。教材是教学的基本依据，任何偏离都需要充分理由。

### 2. 文献溯源法
对重要陈述进行文献溯源，确保有可靠出处。

### 3. 专家咨询法
对不确定的内容，通过搜索或咨询确认。

### 4. 交叉验证法
用多个独立来源相互印证。

```bash
exa_search --query "<文献标题> 作者 年份"
```
