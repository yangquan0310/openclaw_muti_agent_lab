# 问题描述格式模板

> 审核问题详细记录格式

---

## 格式说明

| 字段 | 说明 |
|------|------|
| 序号 | 问题编号 |
| 位置 | 问题所在页码/章节/具体位置 |
| 类型 | P0/P1/P2/P3 |
| 问题描述 | 具体描述问题所在 |
| 修改建议 | 具体的修改方案 |

---

## 示例

```markdown
| 序号 | 位置 | 类型 | 问题描述 | 修改建议 |
|------|------|------|----------|----------|
| 1 | P3 民族志定义 | P0 | 定义与教材P5不符，将民族志描述为定性研究方法的分支，但教材明确指出民族志是质性研究的核心方法 | 改为："民族志是质性研究中以长期参与观察..." |
```

---

## 位置标注规范

| 格式 | 说明 |
|------|------|
| P{页码} | 精确页码 |
| 第{章}章 | 章节位置 |
| {标题} | 幻灯片/段落标题 |
| {图/表}{编号} | 图表位置 |

---

## 问题类型代码

| 代码 | 类型 | 说明 |
|------|------|------|
| C | 一致性问题 | 四要素不一致 |
| A | 准确性错误 | 概念/事实错误 |
| F | 格式问题 | 排版/引用不规范 |
| L | 逻辑问题 | 论证/推理漏洞 |
| O | 优化建议 | 可选改进 |
