# 学术论文审稿清单

> 基于《心理学报》审稿指南 + 国际同行评审标准构建
> 版本：v1.1.0（搜索增强版）

---

## 使用说明

- [ ] 逐项检查，在 `[ ]` 中标记 ✅/❌
- 问题记录到「发现问题」栏
- 根据论文类型选择对应专项检查

---

## 一、选题的重要性

### 1.1 理论重要性
- [ ] 有重要的理论意义
- [ ] 为该领域指出新研究方向，或可能改变未来研究方向

### 1.2 实践意义
- [ ] 有重要的实践意义
- [ ] 用重要方式联系理论和实践

### 1.3 适切性
- [ ] 适合目标期刊及其读者
- [ ] 是待研究的新选题
- [ ] 与当前研究潮流一致

## 二、文献综述质量

### 2.1 文献覆盖
- [ ] 参考了重要相关文献
- [ ] 参考了新近出版的文献
- [ ] 覆盖了相关重要领域

### 2.2 研究框架形成
- [ ] 文献综述与研究问题密切相关
- [ ] 能反映该领域研究发展状况
- [ ] 能说明研究方向正确

### 2.3 文献处理
- [ ] 表明作者理解了文献
- [ ] 对各类文献进行分析整合，非简单堆砌
- [ ] 推论适当，无过度表述、误解、误用
- [ ] 用批判眼光综述，指出以往研究局限、矛盾和模糊之处
- [ ] 表述公正，松弛有度

### 2.4 文献完备准确
- [ ] 主要参考第一手研究文献
- [ ] 文献范围广泛
- [ ] 不引用与研究关系不大的文献，不过度引用作者自己文献
- [ ] 能帮助其他专业读者熟悉该研究领域

## 三、问题提出

### 3.1 研究问题恰当性
- [ ] 研究分析单元正确（刺激、行为、个人、小组、组织）
- [ ] 集中于关键变量，解释选择理由
- [ ] 清楚说明变量关系（交互作用、中介/调节作用、因果关系）
- [ ] 假设可证伪
- [ ] 考虑各种相关和相反理论观点

### 3.2 逻辑正确
- [ ] 研究变量界定清楚，指明与类似变量区别
- [ ] 基于的理论能够自洽
- [ ] 从文献综述到假设提出逻辑严密
- [ ] 研究目的、假设、问题和预期贡献表述清楚
- [ ] 推论符合逻辑
- [ ] 基于理论或事实提出假设，表述清楚
- [ ] 解释恰当，能让领域外读者看懂

## 四、研究方法

### 4.1 被试
- [ ] 取样适合研究问题，有代表性
- [ ] 交代被试特征、样本总体特点、大小及人口学特征
- [ ] 不写对结果无影响的被试变量
- [ ] 给出选取办法或取样计划
- [ ] 如用学生被试，说明是否适合研究问题

### 4.2 设备和材料
- [ ] 适合研究问题
- [ ] 特殊设备需描述特征
- [ ] 材料需给出来源或挑选方式
- [ ] 问卷或量表要有信度、效度指标
- [ ] 尽量使用标准化测验，不用需解释原因
- [ ] 新测验应放在附录中，从别处得到的应有参考文献

### 4.3 研究设计和过程
- [ ] 设计能回答研究问题
- [ ] 明确设计类型：实验、准实验、相关研究；组间/组内；多种测量需考虑平衡
- [ ] 被试在不同条件组中的分配方式
- [ ] 自变量控制方式
- [ ] 因变量测量方式
- [ ] 变量给出操作定义
- [ ] 研究程序按步骤说明
- [ ] 描述细节充分适当，可让别人重复

### 4.4 数据收集和管理
- [ ] 正确处理极端数据和无效数据
- [ ] 问卷回收率和无效问卷比例在可接受范围
- [ ] 努力提高回收率，分析不接受调查和被试丢失的影响
- [ ] 控制数据质量（采集和录入）
- [ ] 给出统计软件及版本

### 4.5 研究严谨性与可重复性（增强）
- [ ] 样本量计算/功效分析是否报告（如适用）
- [ ] 随机化方法是否明确（随机序列生成、分配隐藏）
- [ ] 是否实施盲法（受试者盲法、实施者盲法、评估者盲法）
- [ ] 是否报告脱落/退出情况及原因
- [ ] 是否有预注册声明（如有，说明是否按计划执行）
- [ ] 是否遵循相应报告指南（CONSORT/PRISMA/STROBE 等）

## 五、数据分析和结果

### 5.1 统计分析
- [ ] 统计方法使用正确
- [ ] 被试量满足统计要求
- [ ] 如需要，使用多因素统计方法
- [ ] 考虑是否有更简单或更高级的统计方法
- [ ] 数据转换方法正确

### 5.2 结果表达
- [ ] 分析顺序符合研究逻辑
- [ ] 先文字后数字，不以统计数据开始行文
- [ ] 先呈现描述统计，后推论统计
- [ ] 先行为数据，后生理数据
- [ ] 给出基本统计数据（平均数、标准差、样本数）
- [ ] 正确使用图表，不重复正文内容
- [ ] 每个统计分析报告自由度
- [ ] 显著性不写 p=0.000

### 5.3 公正客观
- [ ] 不只报告有利数据
- [ ] 不报告远离研究主题的数据分析

### 5.4 统计指标完整性（增强）
- [ ] 报告效应量（effect size）及置信区间
- [ ] 必要时报告统计功效
- [ ] 多重比较是否校正（如 Bonferroni）
- [ ] 非正态数据是否使用非参数方法或数据转换
- [ ] 是否报告实际 P 值（如 P=.034，而非仅 P<.05）
- [ ] 效应量的解释是否与领域惯例一致

### 5.5 可重复性（增强）
- [ ] 是否说明数据/代码可获取（如适用）
- [ ] 分析代码是否完整记录
- [ ] 原始数据处理是否有透明文档
- [ ] 异常值处理是否报告并说明理由

## 六、讨论和结论

### 6.1 结果解释
- [ ] 在研究设计和数据分析基础上正确推论
- [ ] 联系研究假设和目的
- [ ] 解释适度，不过度也不不足
- [ ] 不简单重复结果，解释含义
- [ ] 区分客观结果和主观解释
- [ ] 少讨论偏离主题的问题
- [ ] 探讨能否对结果进行相反解释
- [ ] 联系其他同类研究
- [ ] 在广阔背景下讨论
- [ ] 考虑最简单解释
- [ ] 不忽视或弱化与假设相反的结果
- [ ] 解释意外结果
- [ ] 结论简明

### 6.2 研究意义
- [ ] 从结果到理论提升恰当
- [ ] 理论和实践意义具体
- [ ] 指出未来研究逻辑方向和创新方向

### 6.3 研究局限
- [ ] 对局限和缺点实事求是自我批评
- [ ] 内容和方法的局限都考虑
- [ ] 说明推论限制条件

## 七、文稿呈现

### 7.1 写作质量
- [ ] 行文流畅，可读性强
- [ ] 表达清楚，少用专业术语
- [ ] 结构平衡
- [ ] 客观、无偏、专业
- [ ] 开头让读者明白研究问题重要性
- [ ] 各部分之间有清晰逻辑联系
- [ ] 整个研究"故事完整"（Good writing is good teaching）
- [ ] 用提高读者兴趣的方式写作
- [ ] 写作认真，准备充分，无低级细节错误

### 7.2 符合投稿要求
- [ ] 题目和摘要充分反映主要内容
- [ ] 文献列表正确给出所有参考文献
- [ ] 符合期刊风格和格式要求

### 7.3 图表质量（增强）
- [ ] 图表标题清晰，自明性强
- [ ] 坐标轴标签、单位完整
- [ ] 图例完整准确
- [ ] 表格结构规整
- [ ] 图表分辨率符合期刊要求
- [ ] 图表与正文不重复

## 八、研究贡献

### 8.1 总体贡献
- [ ] 理论贡献：提升、挑战而不仅是应用现有理论
- [ ] 实践贡献：研究结果不是常识
- [ ] 方法贡献：工具、策略、分析技术等
- [ ] 建设性重复研究：在重要方面扩展已有研究

### 8.2 文献价值
- [ ] 弥补知识空白
- [ ] 超越以往文献
- [ ] 以不同寻常方式做出贡献
- [ ] 激发未来研究
- [ ] 报告其他地方未报道的大量数据和观点
- [ ] 反映重要研究计划的主要方面

## 九、学术诚信与伦理（增强）

### 9.1 剽窃检测
- [ ] 无自我剽窃（重复发表）
- [ ] 无文本剽窃（未适当引用）
- [ ] 无观点剽窃（未注明他人观点）
- [ ] 无图像/数据剽窃

### 9.2 知情同意与伦理审批
- [ ] 人类被试有伦理审批声明（IRB/IEC 批准）
- [ ] 报告知情同意过程
- [ ] 保密和隐私保护措施说明
- [ ] 弱势群体研究有额外保护措施

### 9.3 利益冲突
- [ ] 作者声明利益冲突（如适用）
- [ ] 基金来源披露
- [ ] 作者贡献声明

### 9.4 数据伦理
- [ ] 数据来源合法
- [ ] 无数据造假/篡改
- [ ] 数据共享符合伦理要求（脱敏）
- [ ] 预注册与发表结果一致性

## 十二、文献真实性核查

> ⚠️ **警示**：AI 幻觉文献错误率高达 **40%**。随着论文工厂（Paper Mills）和虚假期刊泛滥，验证论文和引用的真实性成为审稿的必要环节。
> 
> **详细工作流**：参见 [citation-hallucination-guide.md](../references/citation-hallucination-guide.md)

### 12.1 期刊合法性验证
- [ ] 目标期刊在正规数据库索引（Web of Science、Scopus、PubMed）
- [ ] 期刊不在「论文工厂」黑名单（如撤稿观察数据库）
- [ ] 期刊有真实的同行评审流程（非快速/掠夺性出版）
- [ ] 期刊出版社信息可验证（非假冒出版社）

### 12.2 引用准确性验证
- [ ] 引用文献的 DOI 可正常解析
- [ ] 作者、年份、期刊、卷期页码与实际文献匹配
- [ ] 无「chimera」引用（正确 DOI + 错误元数据）
- [ ] 引用内容与原文相符（非断章取义）

### 12.3 论文工厂特征识别
- [ ] 论文结构过于模板化/模式化
- [ ] 作者单位与研究内容不匹配
- [ ] 图表来源不明或质量异常
- [ ] 数据模式异常（如过于完美的结果）
- [ ] 作者邮箱为个人邮箱（非机构邮箱）
- [ ] 同一作者短期内大量发表

### 12.4 预印本/预注册核查
- [ ] 如有预注册号，验证是否在对应平台存在
- [ ] 预注册内容与发表内容一致性
- [ ] 预印本版本号标注正确

### 12.5 图像/数据真实性
- [ ] 图像无拼接、复制、篡改痕迹
- [ ] 流式细胞图等有原始数据支撑
- [ ] 统计结果与图表数据一致
- [ ] 原始数据可追溯（如提供Supplement）
