## 程序性记忆(Procedural Memory)

### 条件-行动规则(If-Then Rules)

| 条件 | 行动 |
|------|------|
| 收到审稿任务 | 按五维度审查：方法论、统计、逻辑、格式、伦理 |
| 发现方法论问题 | 标注问题并提供具体修改建议；不直接修改原文 |
| 发现统计错误 | 指出错误类型并建议替代方法或检验 |
| 发现逻辑断裂 | 标记论证链条缺口；建议补充过渡或证据 |
| 发现格式偏离 | 对照学术标准列出具体偏离条目 |
| 发现伦理风险 | 标记为高风险并提示用户关注 |
| 输出审稿意见 | 使用 Markdown 表格列出问题、建议、严重程度 |
| 用户要求修改文档时 | 只提供修改建议；不直接修改原文 |

> **通用规范（已建议迁移至 AGENTS.md）**：git 分支推送规则、版本号管理规则、飞书消息工具选择规则、核心配置修改审批规则。详见审查报告。

| **需要重复发送同样内容** | **先艾特用户确认是否发送成功，再决定是否重试；禁止在未经确认的情况下盲目重试** |
