# 课程设计指南

> 指导课程整体规划、教学目标设定、内容架构设计、学时分配。

---

## 一、教学目标设定

### 1.1 目标层次（布鲁姆分类法）

| 层次 | 认知水平 | 动词示例 |
|------|----------|----------|
| 记忆 | 识别/回忆 | 列举、定义、描述 |
| 理解 | 解释意义 | 解释、总结、举例 |
| 应用 | 解决问题 | 运用、计算、演示 |
| 分析 | 拆解结构 | 分析、比较、区分 |
| 评价 | 判断价值 | 评价、批判、论证 |
| 创造 | 生成新物 | 设计、构建、创造 |

### 1.2 目标书写规范

**格式**：
```
学生能够（行为动词）+（具体内容）+（条件/标准）
```

**示例**：
- ❌ "理解教育研究方法"
- ✅ "学生能够运用问卷调查法设计研究工具，达到信度≥0.8的标准"

### 1.3 三维目标整合

| 维度 | 关注点 | 示例 |
|------|--------|------|
| 知识与技能 | 学科知识、操作能力 | 掌握行动研究的基本步骤 |
| 过程与方法 | 思维模式、学习策略 | 能够运用反思性实践改进教学 |
| 情感态度与价值观 | 态度、责任感、价值观 | 养成严谨的学术研究态度 |

## 二、内容架构设计

### 2.1 内容选择原则

| 原则 | 说明 |
|------|------|
| 目标导向 | 所有内容服务于教学目标 |
| 适度够用 | 避免过多/过少 |
| 循序渐进 | 符合学生认知规律 |
| 前沿关联 | 适当引入学科前沿 |

### 2.2 内容组织方式

**直线式**：知识线性排列，后不返前
- 适用：程序性知识、技能训练

**螺旋式**：核心概念反复深化
- 适用：核心概念理解、态度培养

**模块式**：相对独立单元组合
- 适用：综合性课程、选修课

## 三、学时分配

### 3.1 分配原则

| 原则 | 说明 |
|------|------|
| 重点多配 | 核心内容、重点难点多分配时间 |
| 节奏均衡 | 避免前松后紧或前紧后松 |
| 留有弹性 | 预留提问、讨论、答疑时间 |

### 3.2 常见分配参考

| 教学环节 | 时间比例 |
|----------|----------|
| 导入 | 5-10% |
| 知识讲解 | 40-50% |
| 案例/实践 | 20-25% |
| 总结/讨论 | 10-15% |
| 机动 | 5-10% |
