# 教案写作指南

> 指导单次课（课时）的教学设计，包括教学环节、时间分配、活动设计。

---

## 一、教案基本结构

| 模块 | 内容 | 必填 |
|------|------|------|
| 基本信息 | 课程名、教师、班级、日期 | ✅ |
| 教学目标 | 本课时要达成的具体目标 | ✅ |
| 教学内容 | 本课时的核心知识点 | ✅ |
| 教学重难点 | 重点（必须掌握）、难点（难以理解） | ✅ |
| 教学过程 | 导入→展开→总结的完整流程 | ✅ |
| 教学素材 | 案例、数据、讨论问题 | 建议 |
| 板书/PPT | 关键内容呈现 | 建议 |
| 作业/反思 | 课后巩固、课后反思 | 建议 |

---

## 二、教学过程设计

### 2.1 导入环节（5-10分钟）

| 方式 | 适用场景 |
|------|----------|
| 情境导入 | 引起兴趣、建立关联 |
| 问题导入 | 激发思考、明确目标 |
| 复习导入 | 温故知新、衔接旧知 |
| 案例导入 | 具体到抽象、激发兴趣 |

### 2.2 展开环节（核心）

**知识讲解**：定义→特点→应用→案例

**互动设计**：
- 提问（封闭式/开放式）
- 小组讨论（3-5人，5-10分钟）
- 角色扮演/情景模拟
- 随堂练习/即时反馈

### 2.3 总结环节（5-10分钟）

| 方式 | 说明 |
|------|------|
| 要点回顾 | 梳理本课核心知识 |
| 问题解答 | 回应学生疑问 |
| 布置作业 | 明确课后任务 |
| 预告下节 | 建立持续学习动机 |

---

## 三、重难点处理

### 3.1 重点处理策略

| 策略 | 方法 |
|------|------|
| 时间倾斜 | 多分配讲解/练习时间 |
| 多角度呈现 | 文字+图表+案例 |
| 强调标记 | 重复关键内容 |
| 练习强化 | 当堂练习巩固 |

### 3.2 难点突破策略

| 策略 | 方法 |
|------|------|
| 分解难点 | 拆分为多个小问题 |
| 铺垫过渡 | 从已知到未知的桥梁 |
| 直观化 | 图表、模型、动画 |
| 类比化 | 用熟悉事物解释陌生事物 |
| 反复强化 | 讲练结合 |

## 四、教案模板（标准格式）

> **适用场景**：用户上传PPT后，按PPT流程生成紧凑型教案。
> **格式特点**：约500字教学内容，含复习思考（承上启下），课后小结引出下节。

## 五、检查清单

- [ ] 目标具体、可观察、可评价
- [ ] 重难点明确
- [ ] 每个环节有明确的时间分配
- [ ] 教师活动与学生活动平衡
- [ ] 素材与内容匹配
- [ ] 有适当的互动/讨论设计
- [ ] 总结清晰，有作业布置
- [ ] 复习思考能衔接上一章、引入下一节
- [ ] 教学内容约500字，按PPT流程走
- [ ] 课后小结能自然引出下节课内容
