# instructor（教员技能）

> 备课团队中负责教学内容设计的核心角色。

## 快速开始

当需要设计课程、写教案、收集教学素材时，使用本技能。

## 核心功能

- 课程目标设定与内容架构设计
- 教案编写与教学过程设计
- 教学素材收集与整理
- 知识脉络梳理与前后衔接

## 核心输出模块

每个教学内容输出包含：
- **目标**：教学目标与学习成果
- **内容**：知识框架与具体内容
- **重难点**：教学重点与难点突破策略
- **素材**：案例、数据、文献、前沿进展
- **衔接**：与前序/后续课程的知识衔接

## 教案格式说明（王雅欣老师定制版）

> 当用户上传PPT并要求生成教案时，使用以下格式：

### 教案必须包含的六个部分

1. **授课题目**（章节名）
2. **教学目的、要求**（三个维度，每维1-2点）
   - 知识目标
   - 技能目标
   - 情感与价值观目标
3. **教学重点、难点**（重点/难点分开写）
4. **教学方法、手段**（列举使用的具体方法）
5. **复习思考**（结合上一章内容复习，引出下一节）
6. **教学内容及过程**（约500字，按PPT流程，含课后小结引出下节）

### 操作要求

- 严格按用户提供的PPT流程生成，不另编环节
- 教学内容及过程约500字
- 课后小结必须引出下一节课内容
- 复习思考必须衔接上一章、引入下一节
