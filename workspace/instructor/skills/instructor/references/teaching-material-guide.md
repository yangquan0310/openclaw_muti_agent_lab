# 教学素材收集指南

> 指导教学案例、数据、文献、前沿进展的收集与整理。

---

## 一、素材类型与来源

### 1.1 案例素材

| 类型 | 来源 | 适用场景 |
|------|------|----------|
| 真实案例 | 新闻、论文、行业报告 | 理论联系实际 |
| 虚构案例 | 教师自创、文学作品 | 简化复杂情境 |
| 经典案例 | 学科发展史、里程碑事件 | 建立学科框架 |
| 热点案例 | 时事新闻、前沿动态 | 激发兴趣、保持时效 |

### 1.2 数据素材

| 类型 | 来源 | 注意事项 |
|------|------|----------|
| 统计数据 | 国家统计局、行业报告 | 注明来源和时效 |
| 调查数据 | 学术论文、研究报告 | 说明样本和方法 |
| 实验数据 | 原始研究、复现研究 | 注明实验条件 |
| 估算数据 | 权威机构预测 | 标注不确定度 |

### 1.3 文献素材

| 类型 | 说明 | 引用规范 |
|------|------|----------|
| 经典文献 | 学科奠基性著作 | 作者，年份，核心观点 |
| 最新研究 | 近3年核心期刊 | 期刊名，卷期页 |
| 综述文章 | 系统梳理某领域 | 引用主要结论 |
| 工具书 | 词典、百科、手册 | 注明版本 |

## 二、素材收集流程

### 2.1 需求分析

**明确教学目标**：
- 本单元要达成什么目标？
- 学生需要掌握什么？
- 重点/难点是什么？

**确定素材类型**：
- 需要什么类型的素材？
- 需要几个案例？
- 需要定量还是定性素材？

### 2.2 检索策略

**数据库推荐**：
| 学科 | 中文数据库 | 英文数据库 |
|------|------------|------------|
| 教育学 | CNKI、万方 | ERIC、PsycINFO |
| 心理学 | CNKI、万方 | PsycARTICLES、Web of Science |
| 理工科 | CNKI、万方 | Scopus、Web of Science |
| 通用 | 百度学术 | Google Scholar |

**检索词构建**：
```
主题词 + (限定词1 OR 限定词2) + 时间范围
示例：教育研究方法 AND (行动研究 OR 叙事研究) AND 2020-2024
```

### 2.3 评估筛选

| 维度 | 评估标准 |
|------|----------|
| 权威性 | 来源可靠？作者资质？ |
| 相关性 | 与教学内容匹配？ |
| 时效性 | 数据/案例是否过时？ |
| 适切性 | 符合学生认知水平？ |
| 完整性 | 是否有足够信息支撑教学？ |

## 三、素材整理规范

### 3.1 素材卡片格式

```markdown
## 素材编号：[001]

### 基本信息
- 类型：案例/数据/文献/视频
- 来源：
- 获取日期：
- 原始链接：

### 内容摘要
（50-200字的核心内容概述）

### 教学适用性
- 适用单元：
- 适用目标：
- 使用方式：

### 引用信息
（标准格式的引用文本）

### 使用记录
- 首次使用：
- 使用效果：
- 改进建议：
```

### 3.2 素材库分类

```
teaching-materials/
├── 案例库/
│   ├── 理论讲解类/
│   ├── 问题分析类/
│   └── 实践应用类/
├── 数据库/
│   ├── 统计数据/
│   ├── 调查数据/
│   └── 实验数据/
├── 文献库/
│   ├── 经典文献/
│   ├── 最新研究/
│   └── 工具书/
└── 多媒体库/
    ├── 图片/
    ├── 视频/
    └── 动画/
```

## 四、素材使用原则

| 原则 | 说明 |
|------|------|
| 目标导向 | 素材服务教学目标，不为用而用 |
| 适量适度 | 过多素材喧宾夺主，过少则空洞 |
| 真实可信 | 数据/案例必须注明来源 |
| 及时更新 | 定期替换过时素材 |
| 版权合规 | 注明出处，尊重版权 |

---

## 五、检查清单

- [ ] 素材有明确的教学目的
- [ ] 素材来源可靠、权威
- [ ] 素材符合学生认知水平
- [ ] 素材与课程内容紧密相关
- [ ] 素材有标准的引用信息
- [ ] 素材已分类整理，易于检索
- [ ] 定期更新，保持时效性
