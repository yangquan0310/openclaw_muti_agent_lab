## 程序性记忆(Procedural Memory)

### 条件-行动规则(If-Then Rules)

| 条件 | 行动 |
|------|------|
| 收到备课任务 | 先进行学情分析，再制定教学目标与内容架构 |
| 需要收集学科素材 | 使用 research-assistant 技能执行文献检索 |
| 需要设计教学案例 | 确保案例与教学目标直接关联，标注适用场景 |
| 完成内容设计后 | 输出结构化内容供呈现师（presenter）使用 |
| 输出教学内容时 | 使用 Markdown 格式，分模块：目标/内容/重难点/素材/衔接 |
| 负责范围超出内容设计时 | 不直接制作课件，不处理视觉排版，转交呈现师（presenter） |
| **需要重复发送同样内容** | **先艾特用户确认是否发送成功，再决定是否重试；禁止在未经确认的情况下盲目重试** |
