### 场 B：人文社科研究方法的人机协同新图景

| 项目 | 内容 |
|------|------|
| 板块 | 课程+学科（板块 3） |
| 4 维度 | **方法 + 思维** |
| 学时 | **3 学时** |
| 主讲人类型 | 第二类（高级职称/博导） |
| 讲课费 | 1000 × 3 = **3000 元** |
| 主办/协办 | **3 系·承办** |
| 出资方 | **3 系 1 万预算** |

#### 2.B.1 教学目标

1. **方法目标**：建立"AI 增强型"研究方法工具箱（量化/质性/混合 3 类）
2. **思维目标**：辨析人机协同中"哪些环节由 AI 做""哪些必须由人做"的方法论边界
3. **实践目标**：能够为本人研究项目设计 1 份"人机协同研究方案"

#### 2.B.2 4 维度脚手架应用（3 模块 × 3 学时）

| 模块 | 维度 | 时长 | 关键产出 |
|------|------|------|----------|
| **M1 方法论反思** | 方法+思维 | 1h | AI 时代研究方法 5 大挑战清单 |
| **M2 智能协作工具** | 方法 | 1h | 3 类工具对比矩阵（文献/数据/写作）|
| **M3 人机边界 + 工作坊** | 方法+思维+价值 | 1h | 1 份"我的研究人机协同方案"（每位学员）|

#### 2.B.3 内容大纲（3 模块）

**M1 量化/质性方法论反思（方法+思维维度，1h）**
- AI 时代传统研究方法的 5 大挑战：
  1. **量化**：大模型生成仿真被试 → 调查数据真实性
  2. **质性**：AI 自动编码 → 研究者主体性
  3. **混合**：方法论整合的边界 → 黑箱解释力
  4. **文献**：AI 综述 → 学术原创性
  5. **伦理**：AI 参与研究的 IRB/伦理审查标准缺失
- 方法论反思框架：3 类研究问题 × 3 类研究方法 × 3 类 AI 工具

**M2 智能协作工具矩阵（方法维度，1h）**
- **文献阶段**：
  - 文献检索：Connected Papers / Litmaps / Research Rabbit
  - 文献综述：Scite / Consensus / 学术猫
  - 文献管理：Zotero GPT 插件 / Notion AI
- **数据阶段**：
  - 量化分析：R/Python + GitHub Copilot / Cursor
  - 质性编码：MAXQDA + AI Assist / NVivo + GPT 辅助
  - 文本挖掘：BERTopic / 主题建模
- **写作阶段**：
  - 初稿辅助：Grammarly / 秘塔写作猫 / 豆包学术
  - 学术规范：Scribbr / 易改
  - **核心原则**：AI 起草 + 人审稿 = 学术诚信底线
- **对比矩阵**：10+ 工具 × 5 维度（功能/价格/中文化/数据安全/学术认可度）

**M3 人机边界 + 工作坊（方法+思维+价值维度，1h）**
- **人机协同 4 原则**：
  1. **AI 不可独立署名**（学术规范）
  2. **AI 输出必经人类核查**（事实+价值）
  3. **研究伦理优先于效率**（隐私/知情同意）
  4. **方法论透明**（AI 工具使用需在方法章披露）
- **3 类研究问题的 AI 适配度**：
  - 高适配（AI 可大幅协助）：描述性研究 / 大样本分析 / 文献综述
  - 中适配（AI 部分协助）：解释性研究 / 混合方法 / 政策评估
  - 低适配（AI 谨慎使用）：批判理论研究 / 民族志 / 哲学反思
- **工作坊**：每位学员现场设计 1 份"本人研究项目人机协同方案"（30 分钟）+ 跨组互评（30 分钟）

#### 2.B.4 评价与产出

- **过程评价**：出勤 20% + 课堂参与 30% + 工作坊方案 50%
- **核心产出**：1 份"我的研究人机协同方案"（学员带入本人课题组）
- **后续行动**：优秀方案进入 3 系"AI 时代研究方法示范库"（3 系资助）
