# 学生练习作业（3 套）

> 配合 6 节微型课使用。6 次作业累加起来 = 一篇完整的开题报告。

---

## 📝 作业 1（第 1 节后）—— 选题练习

**任务**：从你最近看的一个短视频/生活中一个现象出发，写出 3 个可能的"研究问题"。

**格式**：

```
1. 痛点/现象：________________________________
   研究问题：________________________________
   问题类型：□ 描述性  □ 解释性  □ 对策性

2. 痛点/现象：________________________________
   研究问题：________________________________
   问题类型：□ 描述性  □ 解释性  □ 对策性

3. 痛点/现象：________________________________
   研究问题：________________________________
   问题类型：□ 描述性  □ 解释性  □ 对策性
```

**示例**：

```
1. 痛点：刷短视频停不下来
   研究问题：大学生短视频使用时长与学习动机的关系是什么？
   问题类型：解释性

2. 痛点：上课打瞌睡
   研究问题：高校课堂中"前 15 分钟"教学设计的吸引力如何？
   问题类型：描述性

3. 痛点：教师讲课学生不听
   研究问题：如何通过案例教学提升中学课堂参与度？
   问题类型：对策性
```

---

## 📝 作业 2（第 2 节后）—— 问题聚焦

**任务**：从作业 1 的 3 个问题中选 1 个深入，写出研究问题的"升级版"。

**格式**：

```
原问题（作业1）：________________________________

升级版问题：________________________________

为什么升级：________________________________

拟研究对象：________________________________

拟研究方法：________________________________
```

**示例**：

```
原问题：科普视频为什么好看？

升级版：科普类短视频中类比策略的使用频次与受众理解度的关系研究

为什么升级：原问题太模糊，升级版明确了"研究对象（类比策略）+ 研究问题（频次与理解度）+ 关系"

拟研究对象：B 站 100 个科普视频 + 200 名大学生

拟研究方法：内容分析法 + 问卷调查法
```

---

## 📝 作业 3（第 3 节后）—— 5 维度分析表

**任务**：选 1 个 5 分钟以上的科普视频（或你感兴趣的内容），完成 5 维度分析表。

**分析表模板**：

| 维度 | 编码内容 | 频次/原文 |
|------|----------|-----------|
| **选题** | 痛点：____<br>反差：____<br>纵深：____ | ____ |
| **结构** | 现象：____% 数据：____% 机理：____% 方案：____% 升华：____% | ____ |
| **策略** | 类比 ____ 次 / 量化 ____ 处 / 互动 ____ 处 / 悬念 ____ 处 / 自嘲 ____ 次 | ____ |
| **语言** | 口语化 □ 节奏感 □ 中二感 □ | ____ |
| **价值** | 知识 □ 兴趣 □ 敬畏 □ | ____ |

**要求**：
- 每个维度至少 1 句原文作为证据
- 策略维度要数清楚频次
- 价值维度要写出最有"敬畏感"的一句

---

## 📝 作业 4（第 4 节后）—— 文献综述提纲

**任务**：基于你聚焦的研究问题，写文献综述提纲。

**格式**：

```
一、国外研究现状
   1.1 ____________
   1.2 ____________
   1.3 ____________

二、国内研究现状
   2.1 ____________
   2.2 ____________
   2.3 ____________

三、研究缺口
   3.1 ____________
```

**要求**：
- 国外 + 国内各列 3 个主题
- 每个主题附 1-2 篇代表性文献
- 缺口部分要写出"我的研究与现有研究的差异"

---

## 📝 作业 5（第 5 节后）—— 对策框架

**任务**：基于你 5 维度分析中发现的"问题"，写出对策框架。

**格式**：

```
问题 1：____________
对策 1：____________
具体做法：____________

问题 2：____________
对策 2：____________
具体做法：____________

问题 3：____________
对策 3：____________
具体做法：____________
```

## 📝 作业 6（第 6 节后）—— 开题报告框架

**任务**：将前 5 次作业整合为开题报告（1500-2000 字）。

**模板**：

```
题目：《__________________研究——以____为例》

一、研究背景（200 字）
[来自作业 1-2 的整理]

二、研究目的与意义（150 字）
[目的 1-2 条，意义分理论+实践]

三、国内外研究现状（300 字）
[来自作业 4]

四、研究内容（100 字）
[4 个核心问题]

五、研究方法（200 字）
[文本分析/案例研究/访谈...]

六、5 维度分析框架（300 字）
[来自作业 3]

七、预期创新点（100 字）
[视角新/框架新/应用新]
```

**要求**：
- 严格按模板章节
- 字数符合要求
- 第 6 节课堂上做开题汇报（5 分钟/人）
