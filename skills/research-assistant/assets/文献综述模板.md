### 1.2 研究范围
- 文献的时间范围（如：近 5-10 年）
- 文献的学科领域
- 文献的类型（期刊论文/会议论文/学位论文/书籍等）

### 1.3 综述结构

## 写作要点

| 要点 | 说明 |
|------|------|
| 批判性分析 | 不仅描述，要分析、比较、评价 |
| 逻辑连贯 | 各部分之间逻辑清晰 |
| 引用规范 | 严格遵循 APA 格式 |
| 时效性 | 优先引用最新、最权威文献 |
| 研究空白 | 明确指出 gap，为自己的研究铺垫 |
