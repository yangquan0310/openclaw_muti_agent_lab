# 研究助手 - 项目数据结构说明

> 只保留知识库相关字段，删除项目级文件管理字段

## 元数据结构

```json
{
  "project_id": "项目名称",
  "title": "项目标题",
  "created_date": "创建日期",
  "status": "active",
  "version": "v1",
  "description": "项目描述",
  "directories": {
    "uploads": "uploads/",
    "manuscripts": "manuscripts/",
    "knowledge": "knowledge/",
    "note": "knowledge/note/",
    "review": "knowledge/review/",
    "search_query": "knowledge/search_query/",
    "retrieval_report": "knowledge/retrieval_report/",
    "topic": "knowledge/topic/",
    "temp": "temp/",
    "draft": "temp/draft/",
    "skills": "skills/"
  },
  "tags": [],
  "notes": {},
  "knowledge_base": {},
  "updated_at": "2026-05-09T10:00:00"
}
```

## directories 结构

```json
{
  "directories": {
    "uploads": "uploads/",
    "manuscripts": "manuscripts/",
    "knowledge": "knowledge/",
    "note": "knowledge/note/",
    "review": "knowledge/review/",
    "search_query": "knowledge/search_query/",
    "retrieval_report": "knowledge/retrieval_report/",
    "topic": "knowledge/topic/",
    "temp": "temp/",
    "draft": "temp/draft/",
    "skills": "skills/"
  }
}
```

| 字段 | 值类型 | 说明 |
|------|--------|------|
| uploads | str | 用户上传文档目录 |
| manuscripts | str | 论文草稿目录 |
| knowledge | str | 知识库根目录 |
| note | str | 笔记文件目录 |
| review | str | 综述文件目录 |
| search_query | str | 检索条件存放目录 |
| retrieval_report | str | 检索报告存放目录 |
| topic | str | topic 子集存放目录 |
| temp | str | 临时数据目录 |
| draft | str | 旧版本归档目录 |
| skills | str | 项目级技能存放目录 |

## tags 结构

```json
["AI降重", "提示工程", "学术写作"]
```

## notes 结构

记录笔记文件（Markdown 格式），不上传云端。

```json
{
  "笔记_自传体记忆.md": {
    "local_path": "knowledge/note/笔记_自传体记忆.md",
    "created_at": "2026-04-16",
    "description": "笔记描述"
  }
}
```

| 字段 | 值类型 | 说明 |
|------|--------|------|
| local_path | str | 本地笔记文件路径 |
| created_at | str | 创建日期 |
| description | str | 笔记描述 |

## knowledge_base 结构

记录知识库索引信息。

```json
{
  "index_file": "knowledge/index.json",
  "description": "项目知识库索引",
  "created_at": "2026-04-01",
  "updated_at": "2026-04-16"
}
```

| 字段 | 值类型 | 说明 |
|------|--------|------|
| index_file | str | 知识库索引文件路径 |
| description | str | 知识库描述 |
| created_at | str | 创建日期 |
| updated_at | str | 更新日期 |

## 自动更新规则

| 操作 | 更新字段 |
|------|----------|
| search 检索后 | knowledge_base.updated_at |
| summarize 总结后 | knowledge_base.updated_at |
| manage 导出笔记后 | notes（新增条目）+ knowledge_base.updated_at |
| synthesize 生成综述后 | knowledge_base.updated_at |
| version save 保存版本后 | updated_at（全局） |
