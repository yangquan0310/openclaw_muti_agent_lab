## 写作要点

| 要点 | 说明 |
|------|------|
| 聚焦"现在" | 重点是当前状态，非历史梳理 |
| 客观描述 | 不带价值判断，描述为主 |
| 结构清晰 | 按逻辑分类，非罗列文献 |
| 时效性 | 确保引用最新文献 |
| 判断依据 | 观点要有文献支撑 |
