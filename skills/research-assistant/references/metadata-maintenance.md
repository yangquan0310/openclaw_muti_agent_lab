# 元数据维护

> 使用 Maintainer 更新和管理文献元数据。

---

## 元数据类型

| 类型 | 说明 | 更新频率 |
|------|------|----------|
| 论文元数据 | 作者、年份、期刊等 | 仅初始化 |
| 引用关系 | 论文间引用关系 | 按需 |
| 标签 | topic/方法/观点标签 | 按需 |
| 时间戳 | 创建/修改时间 | 每次操作 |

---

## Maintainer 操作

### update_metadata

更新已有论文的元数据（标签、备注等）。

### add_citation

添加论文间的引用关系。

### generate_report

生成知识库的统计报告。

---

## 版本控制

使用 Git 管理元数据文件。每次更新后 commit。

---

## 数据一致性原则

### 单一来源

index.json 是唯一数据源，其他文件由工具生成。

### 不手动编辑

元数据由 Maintainer 自动维护，不手动编辑 index.json。

### 定期备份

定期 commit，防止数据丢失。

---

## 常见错误

| 错误 | 后果 |
|------|------|
| 手动编辑 | 被工具覆盖 |
| 不 commit | 更新丢失 |
| 不备份 | 数据丢失 |
| 标签混乱 | 筛选困难 |
