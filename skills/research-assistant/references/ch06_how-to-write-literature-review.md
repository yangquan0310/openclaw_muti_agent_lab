# 如何撰写文献综述

> 系统性综述某一专题领域的文献，形成学术文本。

---

## 问题

### 什么是文献综述？

文献综述（Literature Review）是对某个专题领域进行**系统性的文献检索、阅读、归纳整理**，综合分析后形成的学术文本。

**核心本质**：
- 英文是 **Literature Review**，重点在 **Review**
- 既有"回顾"之意，也有"评论"之意
- 不仅仅是"综合"和"述评"，更是对已有文献的**回顾并加以评论**

### 什么时候需要写文献综述？

| 场景 | 是否需要 |
|------|----------|
| 学位论文第二章 | ✅ |
| 研究论文引言 | ✅ |
| 项目申请书 | ✅ |
| 独立发表综述论文 | ✅ |

### 文献综述的 5 种类型

| 类型 | 核心特征 | 适用场景 |
|------|----------|----------|
| **描述性综述** | 客观描述与总结已有文献 | 快速了解某领域 |
| **批判性综述** | 在描述基础上展开批判性分析 | 研究论文引言部分 |
| **综合性综述** | 描述+批判，全面系统 | 学位论文第二章 |
| **系统性综述** | 严格预注册方案，明确纳入排除标准 | 循证研究 |
| **范围综述** | 快速描绘研究证据的性质和范围 | 新兴领域 |

## 方法论

### 合格标准

一篇合格的文献综述必须符合**两个标准**：

| 标准 | 要求 |
|------|------|
| **知识概述** | 提供当前有关该主题的知识、理论和方法的简明概述，并指出现有研究中存在的潜在差距 |
| **批判评价** | 提出作者自己的批判性评价和讨论，而非简单罗列他人研究 |

### 核心误区

**❌ 错误写法**：
> "论文A发现了X，论文B发现了Y，论文C发现了Z..."

**✅ 正确写法**：
> "多项研究发现了X（Author A, 2020；Author B, 2021），但也有研究者对此提出质疑（Author C, 2022），认为该现象可能受Z变量调节。"

## 工作流

### 阶段 1：理解

**目标**：知道什么是文献综述，判断是否该写

**操作**：
1. 明确研究主题
2. 确定综述类型
3. 列出检索关键词

### 阶段 2：准备

**目标**：确定主题、检索文献、筛选文献

**操作**：
1. 设计检索条件
2. 执行检索
3. 筛选高质量文献

详见：[ch02_how-to-search-academic-papers.md](ch02_how-to-search-academic-papers.md)

### 阶段 3：阅读

**目标**：高效阅读、记录要点、管理文献

**操作**：
1. 使用 Manager 筛选 topic
2. 使用 Summarizer 生成 notes
3. 导出结构化笔记

详见：
- [ch03_how-to-manage-knowledge-base.md](ch03_how-to-manage-knowledge-base.md)
- [ch04_how-to-summarize-papers.md](ch04_how-to-summarize-papers.md)

### 阶段 4：撰写

**目标**：组织结构、撰写引言/主体/结论

**操作**：
1. 阅读结构化笔记
2. 按主题/方法/理论组织文献
3. 撰写综述正文

### 阶段 5：检查

**目标**：排查常见问题、质量把关

**操作**：
1. 使用 Synthesizer 检查 APA 引用
2. 检查批判性评价是否充分
3. 更新元数据

详见：[ch05_how-to-synthesize-notes.md](ch05_how-to-synthesize-notes.md)

## 执行标准

### 撰写质量检查

| 检查项 | 标准 |
|--------|------|
| 结构完整 | 引言/主体/结论 |
| 引用格式 | APA 7th |
| 批判评价 | 有作者自己的观点 |
| 文献覆盖 | 核心文献不遗漏 |

### 常见问题

| 问题 | 解决方案 |
|------|----------|
| 文献堆砌 | 按主题组织，加批判性评价 |
| 引用错误 | 使用 check_references() 检查 |
| 结构混乱 | 按主题/方法/时间组织 |
