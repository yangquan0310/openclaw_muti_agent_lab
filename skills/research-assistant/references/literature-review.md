# 文献综述撰写

> 参照 `assets/文献综述模板.md` 撰写结构化文献综述。

---

## 核心结构

| 部分 | 内容 |
|------|------|
| 引言 | 研究背景、范围、结构 |
| 检索与筛选 | 检索策略、筛选标准、结果 |
| 主题分析 | 按主题分类分析 |
| 方法综述 | 研究方法梳理 |
| 综合讨论 | 比较、争议、gap |
| 未来方向 | 理论和实践方向 |
| 结论 | 核心贡献、局限 |

---

## 撰写原则

### 批判性分析

不仅描述，要分析、比较、评价。不要罗列文献，要按主题组织。

### 逻辑连贯

各部分之间逻辑清晰，过渡自然。

### 研究空白（Gap）

明确指出已有研究的不足，为自己的研究铺垫。

### 引用规范

严格遵循 APA 7th 格式。

---

## 时效性原则

- 优先引用最新文献（近 3-5 年）
- 但不忽视经典文献
- 高影响力文献优先

---

## 与研究现状的区别

| 维度 | 文献综述 | 研究现状 |
|------|----------|----------|
| 目的 | 支撑自己的研究 | 描述领域当前状态 |
| 重点 | gap 识别 | 热点和趋势 |
| 视角 | 批判性分析 | 客观描述 |
| 结构 | 主题分类 | 议题分类 |

---

## 常见错误

| 错误 | 后果 |
|------|------|
| 罗列文献 | 缺乏分析深度 |
| 缺少 gap | 研究动机不明 |
| 引用格式错 | 学术规范问题 |
| 时效性差 | 综述价值降低 |
| 结构混乱 | 难以阅读 |
