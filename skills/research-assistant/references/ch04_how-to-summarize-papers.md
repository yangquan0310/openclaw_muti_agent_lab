# 如何总结文献

> 使用 LLM 自动分析文献内容，添加 labels（分类标签）和 notes（结构化笔记）。

---

## 问题

### 为什么要 AI 总结？

手动阅读每篇论文太慢。AI 总结可以：
- 自动分类：实证/综述/理论
- 自动标记重要性：奠基/重要/一般
- 生成结构化笔记：研究问题/方法/结果/结论

### Summarizer 能做什么？

| 功能 | 说明 |
|------|------|
| labels | 自动添加分类标签和重要性标签 |
| notes | 自动生成结构化笔记 |
| 进度显示 | 每 10 篇打印一次进度 |

---

## 方法论

### labels 字段结构

```python
{
    "type": "📊实证",  # 或 "📖综述" / "💡理论" / "📋待分类"
    "importance": "🔴奠基文献",  # 或 "🟡重要文献" / "🔵一般文献"
    "JCR": ""
}
```

### notes 字段结构（按文献类型）

**实证文献**：
```python
{
    "研究问题": "...",
    "研究方法": "...",
    "研究结果": "...",
    "研究结论": "..."
}
```

**综述文献**：
```python
{
    "研究问题": "...",
    "研究结果": "...",
    "研究展望": "..."
}
```

**理论文献**：
```python
{
    "研究问题": "...",
    "理论观点": "..."
}
```

## 工作流

### 步骤 1：初始化

```python
from summarize.Summarizer import Summarizer

summarizer = Summarizer(kb_path="knowledge/index.json")
```

### 步骤 2：执行总结

```python
kb = summarizer.summarize()
```

**输出示例**：
```
正在总结文献...
完成! 知识库: my_kb.json
  论文总数: 30
  实证文献: 20
  综述文献: 8
  理论文献: 2
```

## 执行标准

### 总结质量检查

| 检查项 | 标准 |
|--------|------|
| labels.type | 每篇论文都有分类 |
| labels.importance | 每篇论文都有重要性标记 |
| notes | 实证/综述/理论各有对应结构 |

### 配置要求

| 配置项 | 要求 |
|--------|------|
| LLM base_url | 火山引擎方舟 / 腾讯云 tokenhub |
| API Key | 对应环境变量 |
