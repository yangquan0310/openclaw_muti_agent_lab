# Guide to Writing a Literature Review (文献综述撰写指南)

> 适用对象：心理学、教育学、医学等社会科学领域研究者
> 版本: v3.0 | 更新: 2026-05-15
> 来源: Taylor & Francis 官方写作指南 + EXA检索中文指南 + 学术写作规范

---

## 使用说明

本指南按**写作流程**组织，从准备到完稿共分5个阶段。建议按顺序阅读，每完成一个阶段再进入下一阶段。

| 阶段 | 内容 | 目标 |
|------|------|------|
| **阶段1** | 理解篇 | 知道什么是文献综述，判断是否该写 |
| **阶段2** | 准备篇 | 确定主题、检索文献、筛选文献 |
| **阶段3** | 阅读篇 | 高效阅读、记录要点、管理文献 |
| **阶段4** | 撰写篇 | 组织结构、撰写引言/主体/结论 |
| **阶段5** | 检查篇 | 排查常见问题、质量把关 |

---

## 阶段1：理解篇（What & Why）

### 1.1 什么是文献综述

文献综述是对某个专题领域进行系统性的文献检索、阅读、归纳整理、综合分析后形成的学术文本。

**核心本质**：英文是 **Literature Review**，重点在 **Review** —— 既有"回顾"之意，也有"评论"之意。因此，文献综述不仅仅是"综合"和"述评"，更是对已有文献的**回顾并加以评论**。

### 1.2 文献综述的5种类型

| 类型 | 核心特征 | 适用场景 |
|------|----------|----------|
| **描述性综述** | 客观描述与总结已有文献 | 快速了解某领域 |
| **批判性综述** | 在描述基础上展开批判性分析 | 研究论文引言部分 |
| **综合性综述** | 描述+批判，全面系统 | 学位论文第二章 |
| **系统性综述** | 严格预注册方案，明确纳入排除标准 | 循证研究 |
| **范围综述** | 快速描绘研究证据的性质和范围 | 新兴领域 |

> 💡 **学生论文提示**：学生毕业论文中的文献综述主要涉及**专题性综述**（聚焦于某一具体论题，进行微观层面的深入剖析），而非综合性综述（以整个学科为对象）。

### 1.3 合格标准

一篇合格的文献综述必须符合**两个标准**：

| 标准 | 要求 |
|------|------|
| **知识概述** | 提供当前有关该主题的知识、理论和方法的简明概述，并指出现有研究中存在的潜在差距 |
| **批判评价** | 提出作者自己的批判性评价和讨论，而非简单罗列他人研究 |

### 1.4 核心误区：文献综述 ≠ 文献堆砌

**错误写法**："论文A发现了X，论文B发现了Y，论文C发现了Z..."

**正确写法**："多项研究发现了X（Author A, 2020；Author B, 2021），但也有研究者对此提出质疑（Author C, 2022），认为该现象可能受Z变量调节。"

## 阶段2：准备篇（Preparation）

### 2.1 确定主题

主题必须**明确且可管理**。如果主题过于宽泛，建议聚焦**最近进展**或**特定子领域**。

确定途径：
- 咨询导师或专家
- 查阅相关文献了解热点和前沿

> ⚠️ **重要提示**：如果在CSSCI/SSCI/SCI等权威检索中找不到任何与主题相关或相近的文献，建议**放弃这个题目，重新选题**。

### 2.2 系统检索

#### 检索步骤

| 步骤 | 操作 |
|------|------|
| **Step 1** | 制作核心概念关键词列表（中英文对照） |
| **Step 2** | 使用多种渠道检索（学术数据库、Google Scholar、参考文献回溯） |
| **Step 3** | 阅读摘要判断相关性，下载全文 |
| **Step 4** | 检查文末参考文献列表，"滚雪球"式扩展 |

#### "三位一体"检索原则

1. **引证网络追踪**：通过高被引文献延伸检索
2. **文献时效性筛选**：近五年核心文献占比不低于60%
3. **权威数据库优先**：CNKI、Web of Science、PubMed、PsycINFO等

### 2.3 筛选文献

#### 评估标准（四问法）

- [ ] 是否已阅读该领域所有主要研究和核心理论？
- [ ] 文献是否可信？（引用量、期刊影响因子、作者权威性）
- [ ] 文献与领域其他文章的关系？（支持/反对/补充？）
- [ ] 综述范围是否明确且可管理？

#### 高水平文献三标准

1. **作者权威**：学术领域"大牛"
2. **期刊权威**：CSSCI/SSCI检索期刊
3. **引用率高**：相关文献中引用率上千甚至上万的必须看

## 阶段3：阅读篇（Reading）

### 3.1 三级过滤法

| 级别 | 方法 | 目标 |
|------|------|------|
| **① 标题摘要速览** | 快速浏览 | 初步判断价值 |
| **② 方法论章节精读** | 深入阅读方法部分 | 了解研究设计 |
| **③ 核心结论拆解** | 提取主要发现和观点 | 掌握研究贡献 |

### 3.2 批判性阅读记录表

每篇文献必须记录以下信息：

| 记录项 | 内容 |
|--------|------|
| 基本信息 | 题目、作者、出版信息、年份 |
| 理论基础 | 基于什么理论 |
| 研究问题 | 研究了什么 |
| 研究假设 | 假设是什么 |
| 样本 | 谁参与了研究 |
| 工具 | 问卷/量表/仪器 |
| 模型 | 理论模型/统计模型 |
| 统计方法 | 用了什么分析方法 |
| 主要结论 | 核心发现是什么 |
| 贡献与不足 | 优点和局限 |

### 3.3 文献管理

- **工具推荐**：EndNote、Zotero、Mendeley
- **分类方法**：按主题、研究方法、时间顺序、研究结论
- **可视化**：建立文献关系图谱，实现知识点关联

> 💡 **效率提示**：初期阅读较慢（需理解术语和方法），但随着积累会指数提升。"好记性不如烂笔头"——重要文献打印后用荧光笔标注，关键知识点摘录到便签纸订在原文献上。

## 阶段4：撰写篇（Writing）

### 4.1 选择组织策略

| 策略 | 适用场景 | 示例 |
|------|----------|------|
| **时间顺序** | 展示理论演进 | 从弗洛伊德到认知行为理论 |
| **主题分类** | 按子主题组织 | "治疗偏好""治疗期待""治疗匹配" |
| **方法论** | 比较研究方法 | 实验 vs 横断面 vs 纵向研究 |
| **理论框架** | 按理论流派 | 精神分析 vs 认知 vs 人本主义 |

### 4.2 标准结构

```markdown
# 标题

## 引言
- 研究背景（让非专业人士也能理解）
- 综述范围和边界（涵盖什么、不涵盖什么）
- 综述目的和意义
- 研究问题

## 主体
- 按逻辑顺序对文献进行综述（按主题，不是按论文！）

## 结论
- 总结主要发现
- 指出研究空白
- 引出自身研究（如果是论文的一部分）

## 参考文献
- APA 7th 格式
```

### 4.3 引言写法

**功能**：说清楚"为什么做这个综述"和"这个综述要回答什么问题"。

**示例**：
> "心理治疗的有效性已得到广泛证实，但'哪种疗法对哪类患者最有效'仍是该领域最具挑战性的议题。近年来，患者偏好、治疗期待、改变准备度等个体因素逐渐被识别为影响治疗结果的关键变量。本综述旨在系统梳理这些因素的现有研究，明确核心发现、理论框架与研究空白。"

### 4.4 主体写法（核心！）

**黄金法则**：按**主题**组织，不是按**论文**组织。

**每个段落的核心要求**：
- 围绕一个**核心论点**展开
- 使用**过渡句**连接不同文献
- 指出**研究空白**
- 对比**矛盾发现**并分析原因

**过渡句模板**：
- "与A的发现一致，B进一步指出..."
- "然而，C的研究对此提出了质疑..."
- "基于上述发现，D提出了...模型..."

### 4.5 结论写法

**必须包含**：
1. 总结主要发现
2. 强调重要性
3. 指出研究空白
4. **引出自身研究**（关键！）

**示例**：
> "综上所述，现有研究已证实治疗偏好匹配能显著提升治疗参与度，但对偏好动态变化、数字干预环境中的偏好机制、以及跨文化差异的研究仍显不足。本研究旨在通过大样本临床数据（n=2631），在中国文化背景下探讨CFPPS量表与治疗偏好/期待的关系..."

## 阶段5：检查篇（Checklist）

### 5.1 8个常见问题

| 问题 | 表现 | 解决方法 |
|------|------|----------|
| **跑马灯式综述** | 逐篇罗列"A说了什么，B说了什么" | 按主题/论点组织 |
| **缺乏批判性** | 只描述不评价 | 对比矛盾发现，指出空白 |
| **引用堆砌** | 一段话引用5-6篇文献 | 选1-2篇代表性文献深入讨论 |
| **范围过宽** | 试图涵盖所有相关文献 | 明确纳入/排除标准 |
| **过时文献** | 大量引用10年前文献 | 优先近5年，经典除外 |
| **忽略方法学** | 不讨论研究方法差异 | 比较方法论优劣 |
| **选择偏差** | 只引用支持自己观点的文献 | 全面收集正反证据 |
| **有述无评** | 只罗列观点，缺乏综合比较 | 建立"概念桥梁"，构建对话关系 |

### 5.2 质量检查清单（提交前逐项核对）

- [ ] 引言是否明确了范围、目的和研究问题？
- [ ] 主体是否按逻辑结构组织？
- [ ] 每个段落是否有核心论点，而非简单罗列？
- [ ] 是否体现了批判性评价？
- [ ] 是否明确指出了研究空白？
- [ ] 结论是否总结了主要发现并引出了自身研究？
- [ ] 引用是否使用APA格式？
- [ ] 语言是否通俗易懂？
- [ ] 是否避免了"逐篇总结论文"的错误写法？
- [ ] 是否建立了文献之间的对话关系？

### 5.3 进阶：研究空白识别

重点寻找以下空白：
1. 现有研究提出但未回答的问题
2. 尚未研究的人群或情境
3. 跨研究普遍存在的方法学局限
4. 尚未解决的相互矛盾的发现
5. 在新发展背景下已显过时的研究

## 附录

### 附录A：文献综述 vs 系统综述

| 维度 | 文献综述 | 系统综述 |
|------|----------|----------|
| 目的 | 梳理并综合研究 | 穷尽性与可复现性 |
| 方法 | 灵活性较高 | 严格遵循预注册方案 |
| 检索 | 较宽松 | 明确的检索策略与纳入/排除标准 |
| 分析 | 综合性分析 | 有时包括 Meta-analysis |

### 附录B：可视化工具

- **观点矩阵法**：建立表格比较不同研究的核心观点、方法、局限
- **时间轴梳理法**：展示研究发展脉络
- **概念地图**：展示知识结构

### 附录C：文献追踪技巧

- **顺藤摸瓜**：追踪重要文献的参考文献
- **反向追踪**：查看谁引用了该文献
