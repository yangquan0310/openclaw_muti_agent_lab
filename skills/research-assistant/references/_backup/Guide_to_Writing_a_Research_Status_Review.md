## 第1章：区别篇（Research Status vs Literature Review）

### 1.1 什么是研究现状

"研究现状"是学术写作中一种**特殊的文献综述形式**，常见于：
- 学位论文第2章（文献综述/研究现状）
- 科研项目申请书的"国内外研究现状"
- 期刊论文引言末尾的"研究背景"

### 1.2 核心区别

| 维度 | 一般文献综述 | 研究现状 |
|------|-------------|----------|
| **核心目标** | 全面评价某一领域的研究 | 展示特定研究问题的**提出与演进过程** |
| **组织结构** | 按主题/方法/理论分类 | 按**问题的时间演进脉络**（树状结构） |
| **重点** | 批判性综合现有研究 | 追踪"谁提出了什么问题→谁修正了→进展成什么" |
| **篇幅** | 可独立成文（数千至数万字） | 通常是论文的一个章节（2000-5000字） |
| **结论** | 总结研究空白，提出未来方向 | **自然引出本研究的必要性和创新点** |

### 1.3 核心判断：何时用研究现状？

**用研究现状，当：**
- 需要展示一个研究问题的**历史演进**
- 需要让读者理解"这个问题是如何发展到今天的"
- 需要自然过渡到"因此我的研究是必要的"

**用一般文献综述，当：**
- 需要全面评价某一领域的**当前状态**
- 需要按主题/方法/理论**分类整理**文献
- 需要作为**独立文本**存在（如发表综述论文）

## 第2章：核心结构——问题演进树（Problem-Evolution Tree）

### 2.1 树状结构模板

对于每个核心研究问题，必须按照以下**四层递进**结构展开：

```
## 问题X：XXXXXXXXXX

### 最早提出
[作者A, 年份] 最先提出了什么问题？
→ 做了什么研究？
→ 发现了什么现象？
→ 这一现象/概念被命名为什么？

### 质疑与修正
[作者B, 年份] 认为[作者A]的研究存在什么问题？
→ 做了什么修正/改进？
→ 发现了什么新的现象/矛盾？
→ 问题进展成了什么状态？

### 补充与发展
[作者C, 年份] 在[作者B]的基础上做了什么补充？
→ 提出了什么新理论/模型/方法？
→ 将研究拓展到了什么新领域/人群/情境？

### 最新进展与当前争议
[作者D, 年份] 目前的研究已经进展到了什么状态？
→ 还有什么未解决的争议？
→ 研究空白是什么？
```

### 2.2 关键写作原则

| 原则 | 说明 | 示例 |
|------|------|------|
| **"谁"优先** | 每句开头先提作者和年份 | "Kwan等（2010）首次发现..." |
| **动词精准** | 用具体动词描述研究动作 | "提出""修正""补充""拓展""质疑""验证" |
| **因果链清晰** | 明确展示问题如何演进 | "A的发现激发了B的质疑，B通过...方法发现..." |
| **空白明确** | 每个问题结尾必须指出空白 | "目前尚不清楚...""这一问题在...情境下仍未得到验证" |

### 2.3 完整示例（以"治疗偏好"为例）

**最早提出**：
> "Kwan等（2010）在抑郁症治疗研究中首次系统考察了治疗偏好对疗效的影响。他们将被试随机分配至偏好治疗组或非偏好治疗组，发现当患者被分配到与其偏好一致的治疗时，治疗参与度显著提高，临床改善也更明显。这一发现挑战了'疗法均等'假设，提示患者偏好可能是疗效差异的重要来源。"

**质疑与修正**：
> "然而，Williams等（2016）基于14,587名患者的全国横断面调查对此提出了质疑。他们发现，虽然大多数患者有明确治疗偏好，但偏好满足与自我报告结果之间的关联并不稳定，可能受治疗设置、疾病严重程度等调节变量影响。这一发现促使研究者从'偏好是否重要'转向'偏好何时重要'。"

**补充与发展**：
> "为将偏好研究从粗粒度走向精细化，Cooper和Norcross（2015）开发了Cooper-Norcross治疗偏好量表（C-NIP），将偏好从单一维度扩展为四个维度。随后，Cooper等（2019）比较了普通公众与心理健康专业人员的治疗师特征偏好，发现两组在指导性维度上存在显著差异。"

**最新进展**：
> "目前，该领域正从'是否匹配'转向'如何匹配'以及'匹配的边界条件'研究。Marziliano等（2021）在晚期癌症患者中发现，偏好匹配效应具有情境依赖性。未来需探索动态匹配策略和跨文化差异。"

## 第3章：整体结构模板（Overall Structure）

### 3.1 完整框架

```markdown
# 标题：XXXX的研究现状

## 摘要
- 研究背景的一句话概述
- 本文梳理的核心问题数量
- 核心发现的一句话概括
- 指出的研究空白

## 引言
### 研究背景
（1-2段，从宏观到微观，说明该领域为什么重要）

### 综述目的
（明确本文要回答什么问题，涵盖什么范围，不涵盖什么）

## 研究问题
（列出3-7个核心问题，每个问题一句话）
  - 问题1：XXXXXXXXX如何影响YYYYYYYYY？
  - 问题2：XXXXXXXXX如何作用于YYYYYYYYY？
  - 问题3：如何根据XXXXXXXXX实现YYYYYYYYY？

## 国内外研究现状
### 问题1：XXXX的提出与演进
（按"最早提出→质疑修正→补充发展→最新进展"四层展开）

### 问题2：XXXX的提出与演进
（同上）

## 展望
（基于上述空白，提出未来研究方向，**最后一段自然引出自身研究**）

## 参考文献
（APA 7th格式，按字母顺序排列）
```

### 3.2 分章撰写要点

#### 摘要（200-300字）

**四句话结构**：
1. **背景句**：XXX领域近年来受到广泛关注...
2. **目的句**：本文系统梳理了该领域N个核心问题的研究现状...
3. **发现句**：现有研究已证实...，但仍存在...争议/空白...
4. **结论句**：未来研究应聚焦于...（自然引出本研究）

#### 研究问题

列出**3-7个核心问题**，每个问题格式：
> "问题N：XXXXXXXXX如何影响/预测/调节YYYYYYYYY？"

**示例**：
- 问题1：患者治疗偏好如何影响治疗参与度和疗效？
- 问题2：治疗期待（结果预期）如何作用于治疗过程与结果？
- 问题3：如何根据患者特征实现个性化治疗匹配？

#### 国内外研究现状（核心章节，占全文70%篇幅）

每个问题按**四层递进**展开（见第2章）。

#### 展望（必须自然引出自身研究）

**写法**：
1. 总结当前研究空白（2-3点）
2. 提出未来研究方向（3-5点）
3. **关键：最后一段必须自然引出您的研究**

**示例**：
> "综上所述，现有研究已证实治疗偏好匹配能显著提升治疗参与度，但对偏好动态变化、数字干预环境中的偏好机制、以及中国文化背景下患者治疗偏好的研究仍显不足。本研究旨在通过大样本临床数据（n=2631），首次在中国患者中探讨CFPPS量表与治疗偏好/期待的关系，以期为个性化心理治疗匹配提供本土化实证依据。"

## 第4章：整合应用篇（Integration）

### 4.1 两种写法如何结合

| 场景 | 推荐结构 |
|------|----------|
| **学位论文** | 第2章标题为"文献综述"，内部按研究现状的"问题演进树"组织 |
| **期刊论文** | 引言中嵌入小型研究现状（2-3个问题的演进），主体是实证研究 |
| **项目申请书** | "国内外研究现状"章节严格按研究现状的树状结构撰写 |

### 4.2 常见问题（研究现状特有）

| 问题 | 表现 | 解决方法 |
|------|------|----------|
| **只有"提出"没有"演进"** | "A研究了X，B研究了Y，C研究了Z" | 用"然而""在此基础上""随后"等连接词展示演进 |
| **缺少"质疑"环节** | 文献之间没有对话关系 | 明确展示谁反对谁、谁修正了谁 |
| **问题边界模糊** | 一个问题写了5页，涵盖无数子话题 | 每个问题聚焦单一核心变量或关系 |
| **引用缺失** | 描述研究发现但不说谁做的 | 每句核心发现必须标注（作者, 年份） |
| **罗列无分析** | "A发现X，B发现Y" | 合并同类发现，提炼共同趋势，指出矛盾 |
| **结尾突兀** | 综述结束，但没有引出自身研究 | 最后一段必须过渡到"本研究将..." |

### 4.3 动词快速参考

| 阶段 | 推荐动词 |
|------|----------|
| **最早提出** | 首次发现、率先提出、开创了、奠定了基础 |
| **质疑修正** | 对此提出质疑、挑战了、修正了、完善了、补充了 |
| **补充发展** | 在此基础上、进一步发现、拓展到、深化了、细化了 |
| **最新进展** | 目前、近年来、最近、当前争议聚焦于、尚未明确 |

### 4.4 质量检查清单（研究现状专用）

- [ ] 是否识别了3-7个核心研究问题？
- [ ] 每个问题是否按"最早提出→质疑修正→补充发展→最新进展"四层展开？
- [ ] 是否展示了文献之间的对话关系（谁反对谁、谁修正了谁）？
- [ ] 每个问题的结尾是否明确指出了研究空白？
- [ ] 展望部分是否自然引出了自身研究？
- [ ] 所有引用是否使用APA格式（作者, 年份）？
- [ ] 是否存在"跑马灯式"简单罗列？
