# 排版标准

> 本文件定义研究现状和文献综述的排版格式规范。
> 最后更新：2026-05-30

---

## 1 文档格式

### 1.1 Pandoc YAML 头

所有 `.md` 文档必须包含 Pandoc YAML 头：

```markdown
---
title: "文档标题"

author: "作者名"

date: "YYYY-MM-DD"

keywords: [关键词1, 关键词2, 关键词3]

abstract: |
  摘要正文（150-300字）。
  包含研究背景、主要发现、结论。
---
```

**注意事项：**
- YAML 头之后必须用 `---` 闭合
- 文档正文从第一个一级标题开始
- **不要**在正文中重复 YAML 头已有的 title 和 author

### 1.2 摘要要求

| 项目 | 要求 |
|------|------|
| 长度 | 150-300 字 |
| 内容 | 研究背景（1句）→ 主要发现（2-3句）→ 结论（1句） |
| 格式 | 单独成段，不分段；不使用缩进 |
| 位置 | YAML 头之后，文档正文之前 |

### 1.3 关键词要求

- 数量：3-5 个
- 分隔：用中文逗号（"，"），不加空格
- 避免：重复 title 中的已有词汇

## 2 标题格式

### 2.1 禁止使用编号

**绝对禁止**在标题中使用数字编号：

| 错误 ❌ | 正确 ✅ |
|---------|---------|
| `# 1 引言` | `# 引言` |
| `## 2 认知卸载` | `## 认知卸载的理论框架与决策机制` |
| `### 2.1 概念界定` | `### 认知卸载的概念界定` |
| `## 3 Google效应` | `## Google效应：理论争议与边界条件` |

### 2.2 标题层级

| 层级 | Markdown 语法 | 用途 | 示例 |
|------|-------------|------|------|
| 一级 | `# ` | 引言、结论 | `# 引言`、`# 结论` |
| 二级 | `## ` | 主章节/核心议题 | `## 认知卸载的理论框架` |
| 三级 | `### ` | 具体论点/小节 | `### 认知卸载的概念界定` |

### 2.3 标题命名原则

- 用文字描述内容，不用编号
- 二级标题：概括性描述议题名称，可加冒号副标题
- 三级标题：精确描述具体论点

## 3 正文章节结构

### 3.1 研究现状（8部分）

```
1. 引言
2. 核心议题（N个）
3. 主要流派与观点
4. 研究热点与趋势
5. 代表性成果
6. 问题与挑战
7. 机遇与展望
8. 结论
```

### 3.2 文献综述（推荐结构）

```
1. 引言
2. 主题A的文献
3. 主题B的文献
4. 主题C的文献
5. 总结与未来方向
```

## 4 正文段落规范

### 4.1 段落结构

每个段落应包含：

- **论点**（段首句）：本段核心观点
- **论据**（段中）：文献支撑、数据、案例
- **小结**（段尾，可选）：承上启下或强调

### 4.2 段落衔接

相邻段落之间应有过渡：
- 使用过渡句连接相关内容
- 在进入新主题前使用承上启下句

### 4.3 引用格式

使用 APA 第7版格式：

| 类型 | 格式 | 示例 |
|------|------|------|
| 文内引用（作者-年份） | `姓（年份）` | `Gilbert (2024)` |
| 文内引用（作者，年份） | `姓，年份` | `Sparrow 等人（2011）` |
| 多篇并列 | `姓1，年份；姓2，年份` | `Gilbert, 2024; Vzorin et al., 2024` |
| 直接引用 | `姓（年份, p. X)` | `Clark 和 Chalmers (1998, p. 10)` |

### 4.4 禁止事项

- ❌ 禁止在正文标题中重复 YAML 已有的 title 和 author
- ❌ 禁止使用编号（章节、图表、公式均不编号）
- ❌ 禁止罗列式写法（"X说...Y说...Z说..."）
- ❌ 禁止空泛表述（无文献支撑的判断）
- ❌ 禁止大段落（超过200字应考虑拆分）

## 5 参考文献格式

### 5.1 位置

参考文献单独成节，位于正文之后，格式示例：

```markdown
## 参考文献

Anderson, M. C., & Hanslmayr, S. (2014). Neural mechanisms of motivated forgetting.
*Trends in Cognitive Sciences*, 18(6), 279–292. https://doi.org/10.1016/j.tics.2014.03.002
```

### 5.2 APA 第7版要点

- 作者姓氏只写首字母大写
- 年份置于作者之后
- 期刊名用斜体
- 卷号用斜体，期号不加斜体
- DOI 链接统一置于末尾
- 第二行缩进 0.5 英寸（悬挂缩进）

## 6 检查清单

撰写完成后，对照以下清单逐一检查：

- [ ] YAML 头完整（title, author, date, keywords, abstract）？
- [ ] 正文标题无编号？
- [ ] 正文无重复 YAML 中的 title 和 author？
- [ ] 摘要 150-300 字？
- [ ] 关键词 3-5 个？
- [ ] 每段落有论点+论据？
- [ ] 段落之间有过渡句？
- [ ] 引用格式符合 APA 第7版？
- [ ] 无大段落（>200字）？
- [ ] 无罗列式写法？
