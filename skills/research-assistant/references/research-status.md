# 研究现状撰写

> 参照 `assets/研究现状模板.md` 撰写领域研究现状报告。

---

## 核心结构

| 部分 | 内容 |
|------|------|
| 概述 | 主题定义、报告范围 |
| 核心议题 | 主要讨论的问题 |
| 主要流派 | 不同观点和阵营 |
| 研究热点 | 当前关注点 |
| 代表成果 | 高影响力论文/项目 |
| 问题与挑战 | 理论和实践障碍 |
| 机遇与展望 | 未来方向 |
| 结论 | 现状总结 |

---

## 撰写原则

### 聚焦"现在"

重点是当前状态，非历史梳理。历史背景仅作为引子。

### 客观描述

不带价值判断，描述为主。分析留给他人。

### 时效性

确保引用最新文献，反映当前状态。

---

## 与文献综述的区别

| 维度 | 研究现状 | 文献综述 |
|------|----------|----------|
| 目的 | 描述领域当前状态 | 支撑自己的研究 |
| 重点 | 热点和趋势 | gap 识别 |
| 视角 | 客观描述 | 批判性分析 |
| 结构 | 议题分类 | 主题分类 |

---

## 常见错误

| 错误 | 后果 |
|------|------|
| 写成历史 | 偏离"现状" |
| 堆砌文献 | 缺乏分析 |
| 过时引用 | 信息陈旧 |
| 观点堆砌 | 缺乏分类逻辑 |
