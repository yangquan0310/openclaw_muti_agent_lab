# 研究现状撰写

> 参照 `assets/研究现状模板.md` 撰写领域研究现状报告。

---

## 核心原则

1. **聚焦"现在"**：重点描述领域当前状态，历史背景仅作为引子（不超过一段）
2. **客观描述**：以"这个领域现在是什么样子"为主线，不写"我认为"
3. **结构分类**：按议题/流派分类，不按单篇文献罗列
4. **判断有据**：每个观点必须有文献支撑，禁止空泛表述

---

## 文档格式要求

排版格式规范详见：[formatting-standards.md](./formatting-standards.md)

---

## 核心结构（8部分）

| 部分 | 内容 | 重点 |
|------|------|------|
| 一、概述 | 主题定义、报告范围 | 边界清晰，范围明确 |
| 二、核心议题 | 主要讨论的问题，每个议题4个维度 | 按议题分类，逻辑递进 |
| 三、主要流派 | 不同阵营的核心主张 | 做对比表 |
| 四、研究热点 | 当前关注点 + 趋势 + 前沿问题 | 表格呈现热点 |
| 五、代表性成果 | 高影响力论文/专著 | 按影响力和时间排列 |
| 六、问题与挑战 | 理论/方法/实践/基础设施障碍 | 分类说明 |
| 七、机遇与展望 | 未来方向 + 建议 | 具体可行 |
| 八、结论 | 现状总结 + 核心判断 | 一段话概括 |

---

## 核心议题的写法（重点）

每个议题必须包含以下4个维度，缺一不可：

### 2.x.1 主流观点
- 当前学术界的主要看法（2-4句话）
- 代表性学者的观点（用"X等(2020)认为..."，"Y(2019)指出..."的句式）

### 2.x.2 最新进展
- 近3年（2023-2026）的重要研究发现（至少3条）
- 突破性成果（用"首次"、"首次系统"等表述）
- 每条结论必须注明来源

### 2.x.3 关键技术/方法
- 该议题的主流研究方法（1-3种）
- 新兴技术/工具
- 每种方法注明适用场景

### 2.x.4 实践应用
- 理论在实际中的应用（1-3个案例）
- 典型案例（含具体数据）

## 与文献综述的关键区别

| | 研究现状 | 文献综述 |
|--|---------|---------|
| **目的** | 描述领域当前状态 | 支撑自己的研究 |
| **写法** | "这个领域的主流观点是..." | "X(2020)研究了...发现..." |
| **重点** | 热点和趋势 | Gap 识别 |
| **视角** | 客观描述 | 批判性分析 |
| **结构** | 议题分类（按观点） | 主题分类（按文献） |

---

## 常见错误

| 错误 | 后果 |
|------|------|
| ❌ 写成历史（"从X年到Y年..."） | 偏离"现状" |
| ❌ 堆砌文献（"X说...Y说...Z说..."） | 缺乏分析框架 |
| ❌ 过时引用（超过10年无新文献） | 信息陈旧 |
| ❌ 空泛表述（无文献支撑的判断） | 缺乏可信度 |
| ❌ 写成文献综述（按单篇论文描述） | 结构错误 |

## 写作检查清单

- [ ] 开篇是否在3句话内定义研究主题？
- [ ] 核心议题是否覆盖了该领域的主要讨论问题？
- [ ] 每个议题是否有4个维度（主流观点/最新进展/技术方法/实践应用）？
- [ ] 研究热点是否用表格呈现？
- [ ] 代表性成果是否按影响力排列？
- [ ] 问题与挑战是否分类（理论/方法/实践/基础设施）？
- [ ] 结论是否是一段话而非列表？
- [ ] 所有观点是否都有文献支撑？
- [ ] 是否没有写成历史（超过1段历史梳理即为错误）？
