# 更新指南

> 如何更新已有技能

---

## 何时更新

以下情况需要更新技能：
- 发现技能有 bug 或缺陷
- 需求变更，需要扩展功能
- 用户提出新场景需要支持
- 优化代码结构或性能

---

## 更新流程

### 1. 评估变更范围

**小改动**（只改一个文件）：
- 修复错误
- 更新文档
- 调整参数

**中改动**（改 2-3 个文件）：
- 新增方法
- 修改目录结构
- 新增指南

**大改动**（涉及多个模块）：
- 重构核心逻辑
- 变更触发条件
- 版本升级

---

### 2. 执行更新

**更新 SKILL.md**：
```bash
# 更新版本历史
| 版本 | 日期 | 更新 |
|------|------|------|
| x.x.x | 2026-05-20 | 更新内容描述 |
```

**更新 _meta.json**：
```json
{
    "version": "x.x.x"
}
```

**更新代码**：
- 在 scripts/ 中添加或修改方法
- 在 mcp/server.py 中更新 EXPOSED_TOOLS

**更新指南**：
- 在 references/ 中新增或修改指南
- 更新 index.md 导航

---

### 3. 自检

```bash
python3 scripts/selfcheck.py /path/to/skill
```

---

### 4. Git 提交

```bash
git add .
git commit -m "更新 {技能名}：{更新内容}"
```

---

## 版本号规范

| 类型 | 规则 | 示例 |
|------|------|------|
| **大版本** | 不兼容的重大变更 | 1.0.0 → 2.0.0 |
| **小版本** | 向下兼容的功能新增 | 1.0.0 → 1.1.0 |
| **补丁** | bug 修复 | 1.0.0 → 1.0.1 |
