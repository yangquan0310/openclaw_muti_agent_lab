# 技能扩展

> 什么时候应该扩展现有技能，什么时候应该新建。

---

## 判断框架

### 应该扩展现有技能

| 条件 | 说明 |
|------|------|
| **目的相同** | 和现有技能解决同一类问题 |
| **触发条件重叠** | 新场景可以被现有触发条件覆盖 |
| **共享工具/脚本** | 底层工具可以共用 |
| **用户认知一致** | 用户认为这是同一类事 |

### 应该新建而非扩展

| 条件 | 说明 |
|------|------|
| **目的根本不同** | 虽然看起来像，但解决的问题不一样 |
| **触发条件互斥** | 新场景和现有场景逻辑相反 |
| **使用者不同** | 现有技能面向 A，新技能面向 B |
| **扩展会导致混乱** | 扩展后触发条件变得模糊 |

---

## 扩展方向

| 扩展类型 | 适用情况 |
|------|------|
| **增加触发词** | 新场景但同目的 |
| **增加分支判断** | 同目的但不同步骤 |
| **增加工具方法** | 同目的但需要新的底层能力 |

---

## 常见错误

- **强行扩展**：明明是两个目的，硬塞在一起导致触发条件模糊
- **拒绝扩展**：明明是同一个目的，复制代码而不是扩展
- **扩展过深**：技能变得越来越臃肿，应该新建而不是无限扩展
